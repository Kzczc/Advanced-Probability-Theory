# 讲义写作规范（所有页面必须遵守）

本站是一份「逐页精讲」：网页左边固定显示课件原页，右边是我们写的中文讲义。
**讲义本身必须能教会人**——左边课件只是对照，不是讲解。

---

## 0. 读者是谁（决定一切写法）

- 研究生，**几乎没有数学分析 / 测度论基础**；集合运算、上确界、极限、级数都可能不熟。
- **英语阅读吃力**：课件英文要翻译，更要用中文把意思讲透。
- 上课**完全没听懂**：不能默认读者记得课堂上讲过什么。
- 目标：**只看讲义就能自学看懂每一页**，看完能复述定义、会判断简单例子、知道每个条件为什么需要、看得懂老师的每一行板书。

因此，最常见的失败写法是：**把 PPT 翻译一遍就结束**。这是明确禁止的。
每个概念都要走完：**是什么 → 为什么需要 → 怎么用 → 具体例子 → 反例 / 易错点**。

## 1. 文件与页眉

- 路径：`content/topic1/pNN.md`，`NN` 是 **PDF 页码**（两位数，01–47）。
- 大纲（每页的幻灯片编号、类型、标题）见 `content/topic1/_outline.yaml`，**页眉以大纲为准**，标题可以改得更好懂。

```yaml
---
topic: topic1
page: 9                     # PDF 页码，必须等于文件名里的数字
slide: "8/42"               # 课件右下角的编号；手写续页写 "—"
kind: definition            # 见下表
title: σ-代数：对可数次「或、且、非」封闭的事件族      # 中文标题（意译，要让人一眼看懂这页讲什么）
title_en: "A sigma-algebra is closed under countable event logic"  # 课件蓝条标题原文，一字不差
---
```

`kind` 可选：`cover` 封面 · `goals` 目标 · `contents` 目录 · `roadmap` 路线图 · `definition` 定义 · `remark` 讨论 · `theorem` 定理 · `proof` 证明 · `example` 例子 · `figure` 图解 · `notes` 手写续页 · `summary` 总结。

`title` 里不要写 `$公式$`，直接用 Unicode：σ、Ω、μ、∪、∩、≤、ℝ、2^Ω。

## 2. 页面结构（按这个顺序写，用 `##` 二级标题）

二级标题会自动变成页面顶部的「本页小标题」导航，**名字请照抄下面的**，方便读者形成习惯。不适用的节可以省略（例如没有图就不写「图解」）。

```
## 这一页在讲什么
## 先补基础
## 课件原文逐句精读
## 老师板书在说什么
## 图解
## 例子
## 推导：一步一步来
## 常见疑问与易错点
## 小结与自测
```

### 2.1 这一页在讲什么（必写）

- 3–6 句人话：这页要解决什么问题？和上一页、下一页是什么关系？它在本讲五个部分里属于哪一部分？
- 可以开头放一个 `::: idea 一句话版` 卡片。

### 2.2 先补基础（本页用到读者可能不会的东西时必写）

- 放在 `::: basics 标题` 卡片里。
- 本页第一次出现的**每个符号、术语**都要讲：怎么读、什么意思、一个最小的例子。
  例：「$A \subseteq B$ 读作『A 包含于 B』，意思是 A 的每个元素都在 B 里；比如 $\{1\}\subseteq\{1,2\}$。」
- 前面页已经讲过的，一句话回顾 + 链接，例如「（详见 [[p:9|σ-代数那一页]]）」。
- 需要的背景知识（集合运算、函数、极限、上确界 sup / 下确界 inf、级数求和、可数与不可数、区间记号……）**就地讲清楚**，不要假设读者会。

### 2.3 课件原文逐句精读（必写，手写续页除外）

- 课件上**每一段印刷文字都必须出现**，不能漏。做法：
  1. `::: original 标题` 卡片放英文原文（公式用 LaTeX 重新打，保留「Definition 3」「Theorem 8」等编号）；
  2. 紧跟 `::: zh` 卡片放中文翻译；
  3. 然后用普通段落、列表**逐句、逐个符号讲解**：这句话在说什么？每个条件管什么？为什么要这个条件？去掉会怎样？
- 课件里的**小标题 / 彩色框标题**（例如 `Sometimes it works`、`Why it may be too large`、`Construct a Vitali selector`、`Why the translates work`）必须保留，用 `###` 写成「英文原文｜中文」：
  `### Why the translates work｜为什么这些平移互不相交`
- 正式的定义、定理用中文写进 `::: def 定义 3（σ-代数）`、`::: thm 定理 8（从下连续）` 卡片，方便复习时一眼找到。
- 讲解不能只是翻译的换一种说法。每个定义至少回答：**它在防止什么问题 / 它让我们能做什么**。

### 2.4 老师板书在说什么（这一页有手写笔记时必写）

Topic1 的课件上有老师用 iPad 写的蓝色（偶尔红色、粉色）手写笔记，课上讲的内容大多在这里。

1. 先用 `::: board 板书转写` 卡片**按从上到下的顺序逐条转写**：公式用 LaTeX，英文原样保留，箭头、下划线、圈出来的词都要说明（例：「老师把 realized 用红线划了出来」）。
2. 看不清的字写「（字迹不清，推测为 …）」，**不要编**。
3. 再逐条讲解：老师为什么写这个？它补充了印刷内容的哪一点？它背后的推理是什么？
4. 老师的笔误要指出并改正：「老师这里写成了 …，应为 …，因为 …」。
5. 手写续页（`kind: notes`）整页都是板书：完整转写，并把它组织成一个讲得通的推导或例子。

**识别手写和公式时，不许只依赖 PDF 文字层。** Topic1 的文字层有编码错乱（Ω 被提取成 `⌦`，ω 成 `!`，∈ 成 `2`，⊆ 成 `✓`，≤ 成乱码，手写更是一堆 `right left sum_` 碎片）。
必须**看图**：先看 `.work/pages/topic1/pNN.png`，手写区域再用放大工具看清楚：

```bash
python3 tools/zoom.py topic1 36 top      # 上半页（也可用 bottom、q1 左上、q2 右上、q3 左下、q4 右下）
python3 tools/zoom.py topic1 36 0.1,0.4,0.7,0.8   # 自定义区域 x0,y0,x1,y1（占整页比例）
```

命令会打印放大图的路径，再用看图工具打开。文字层 `.work/text/topic1/pNN.txt` 只用来核对英文单词拼写。

### 2.5 图解（课件有图、彩色框、示意图时必写）

- 用 `::: fig 图解：标题 | crop=x0,y0,x1,y1` 卡片。`crop` 是这张图在整页里的位置（左上角 x0,y0，右下角 x1,y1，都是 0–1 的比例），网页会把这一块裁出来放大显示在卡片里。先看图估计好位置。
- 逐块说明：每种颜色、形状、箭头、坐标轴分别代表什么；按什么顺序读；这张图想说明什么结论。
- 如果讲解时需要一张课件里没有的图，用文字清楚描述（例如画出数轴、写出每个区间）。

### 2.6 例子（内容页必写）

- 至少 1 个**课件之外的新例子**，定义页最好 2 个：一个「满足定义」的，一个「不满足」的（反例）。
- 用具体数字，优先用：抛硬币、掷骰子、区间 $[0,1]$、有限集合 $\{1,2,3\}$、简单的分段函数。
- 用 `::: ex 例 1：……` 卡片；计算要一步一步写出来，不跳步。

### 2.7 推导：一步一步来（有证明、推导、计算时必写）

- 先用 `::: proof 证明思路` 卡片给出 2–3 句大意（「先证 ≤，再证 ≥」「构造一个集合，然后用可数可加性」……）。
- 然后每一步单独一行或一个列表项，**后面写清理由**：用了哪个定义、哪条性质、前面哪一页的结论。
- 长推导用 `$$\begin{aligned} ... \end{aligned}$$` 对齐，并在旁边用 `\quad\text{（理由）}` 或正文列表说明。
- **禁止**「显然」「易知」「同理可得」「不难验证」。
- 课件和板书里被省略的中间步骤要补上。

### 2.8 常见疑问与易错点（内容页必写）

- `::: warn` 卡片，问答形式：「**问**：……」「**答**：……」。至少 2 条。
- 优先回答：为什么要这个条件？去掉会怎样（给反例）？和中学概率的直觉哪里不一样？和前后哪个概念容易混？

### 2.9 小结与自测（内容页必写）

- `::: sum 本页小结` 卡片：3–5 条要点。
- `::: quiz 自测` 卡片：2–3 道小题（判断、填空、举例、简答）。每道题后面放一个可折叠的答案卡片，答案要带解释。
- **嵌套写法**：外层用四个冒号，内层三个冒号：

```
::::quiz 自测
**1.** 判断：$\{\varnothing,\Omega\}$ 是 σ-代数吗？

:::answer
是。……（给出理由）
:::

**2.** ……

:::answer
……
:::
::::
```

## 3. 公式规范（网站用 KaTeX 在构建时排版）

- 行内公式 `$...$`；独立公式 `$$...$$` **单独成行**。`$` 内侧不要有空格：写 `$x$`，不要写 `$ x $`。
- 多行推导：

```
$$
\begin{aligned}
\mu(E) &= \mu\Big(\bigcup_{n} D_n\Big) \\
       &= \sum_{n} \mu(D_n)
\end{aligned}
$$
```

- 公式里的中文必须写成 `\text{中文}`。
- 可用的宏：`\R`（ℝ）`\N` `\Q` `\Z` `\P`（概率 ℙ）`\E`（期望 𝔼）`\F`（σ-代数 𝓕）`\ind`（示性函数的粗体 1）`\eps`（ε）`\dd`（积分里的 d，自带前置小空格：`\int f \dd\mu`）`\Leb`。
- 常用写法：集合 `\{ \}`，条件 `\{x \in \R : f(x) > a\}`，空集 `\varnothing`，补集 `A^c`，差集 `A \setminus B`，幂集 `2^{\Omega}`，递增收敛 `\uparrow`，递减 `\downarrow`，大号并集 `\bigcup_{n\ge 1}`。
- **禁止**：`\(` `\)` `\[` `\]`、`\label`、`\ref`、`\eqref`、`\newcommand`、`\def`。
- **表格里的公式不能出现竖线 `|`**（它是表格的分隔符）：绝对值写 `\lvert f_n\rvert`，条件竖线写 `\mid`。校验会报错提示。
- 公式**必须对着图片核对**，也要用数学知识核对（下标、上下限、不等号方向、条件是否写全）。

## 4. 卡片容器一览

| 写法 | 用途 |
| --- | --- |
| `::: original 标题` | 课件英文原文（印刷部分） |
| `::: zh` | 原文的中文翻译 |
| `::: board 板书转写` | 老师手写内容的逐条转写 |
| `::: def 定义 N（名称）` | 正式定义 |
| `::: thm 定理 N（名称）` / `::: prop` 命题 / `::: lemma` 引理 / `::: cor` 推论 | 正式结论 |
| `::: idea 标题` | 人话版、直觉、类比 |
| `::: basics 标题` | 零基础补课 |
| `::: ex 例 1：……` | 例子（含计算） |
| `::: proof 证明思路` | 推导、证明 |
| `::: fig 图解：…… \| crop=x0,y0,x1,y1` | 图的讲解，自动裁出课件局部 |
| `::: warn 标题` | 易错点、常见疑问 |
| `::: note 标题` | 补充说明、拓展 |
| `::: sum 本页小结` | 小结 |
| `::: quiz 自测` | 自测题 |
| `::: answer` | 可折叠答案（放在 quiz 里面） |
| `::: more 标题` | 可折叠的「更多细节」（例如更严格的证明） |

- 卡片里可以放任何 Markdown：段落、列表、公式、表格。
- 卡片套卡片时，外层冒号必须比内层多（`::::` 套 `:::`）。
- 引用本讲其他页：`[[p:12]]` 或 `[[p:12|从上连续那一页]]`。不要写外部网址。
- 链接**自己会显示**「第 12 页」（练习页里显示「第 5 题」「作业 2 第 3 题」），旁边不要再写一遍：写「由 [[p:8]] 的命题 B」，不要写「由第 [[p:8]] 页命题 B」（会显示成「第 第 8 页 页」）；写「[[hw1:p:3]]」，不要写「作业 1 第 3 题 [[hw1:p:3]]」。多个页码共用一个「第…页」时用数字标签：「第 [[p:38|38]]–[[p:40|40]] 页」。校验会把重复的文字报成错误。

## 5. 语言风格

- 中文为主。术语第一次出现写「中文（English）」，例如「σ-代数（sigma-algebra）」。译名以第 6 节为准。
- 段落短（不超过 4 行），多用编号列表；关键结论用 **粗体**；不用 emoji。
- 语气像耐心的助教一对一讲：「你可以把它想成……」「注意这里的关键词是……」。
- 每页只讲本页的内容；需要后面的知识时，说「后面第 N 页会讲」并链接，不展开。
- 讲解篇幅：内容页一般 2500–6000 字（中文字符），导航页（封面、目录、路线图）可以短，但也要讲清楚这一部分要解决什么问题。

## 8. 第 2、3 讲（课堂空白版）的特殊要求

第 2、3 讲的 PDF 是**课堂空白版**：每页只印了标题、「Definition 4」「Theorem 9」「Proof」等标签和少量设定文字，定义、定理、证明的正文都留白，老师上课现场手写。我们没有手写版，所以**要由我们自己把留白处完整补写出来**（相当于替读者写好批注）。

1. 把 `## 老师板书在说什么` 换成 **`## 补全课件留白`**，放在「课件原文逐句精读」之后：
   - 对课件上的**每一个**标签（Definition N、Theorem N、Proposition N、Corollary N、Example N、Proof、以及小标题如 `Proof: simple functions`、`Normalization`），都写出它下面应当出现的完整内容：
     正式陈述放进 `::: def` / `::: thm` / `::: prop` / `::: cor` / `::: lemma` 卡片（编号与课件一致），证明放进 `::: proof`，例题的完整计算放进 `::: ex`。
   - 每页在这一节开头放一句 `::: note 说明`：「课件此处留白（课堂板书），以下内容由本站根据标准教材补写，记号与本课件保持一致；如与老师课堂写法不同，以老师为准。」
2. **数学必须严格正确**：假设写全（非负？可积？独立？有限测度？），结论写准；有多种标准版本时，选与课件印刷设定一致的版本，并可在 `::: more` 里提一句其他版本。参考标准教材（Durrett《Probability: Theory and Examples》、Billingsley、Williams《Probability with Martingales》）的写法。
3. 课件上**印刷出来的设定文字**（例如「Let $(\Omega,\F,\P)$ be a probability space and $(S,\mathcal M)$ a measurable space」、具体例题里的函数和数值）必须原样出现在 `::: original` 里，补写内容必须与之吻合。
4. 大量使用第 1 讲的结论（MCT、Fatou、DCT、简单函数逼近、从上/下连续……），用跨讲链接标出出处：`[[t1:p:36|单调收敛定理]]`。第 1 讲重要页：σ-代数 p9、生成的 σ-代数 p11、测度空间 p12、从下连续 p13、从上连续 p14、勒贝格测度 p23、可测函数 p29、简单函数 p30、非负函数的积分 p33、二进逼近 p34、MCT p36、liminf/limsup p40（集合版本见 p7）、Fatou p41、a.e. 与 $L^1$ p43、DCT p44、BCT p46。第 3 讲引用第 2 讲用 `[[t2:p:N]]`。
5. 第 1 讲没有讲过、但证明要用的工具（例如 Fubini–Tonelli 定理、π-λ 定理、均值不等式、泰勒展开），要么换一种只用已学知识的证明，要么在 `::: basics` 里把工具的陈述和含义讲清楚，并明确说「这里把它当作已知结论使用」。
6. 页眉 `topic` 写 `topic2` / `topic3` / `topic4`；校验命令加 `--topic`：`node site-src/build.mjs --check --topic topic2 --pages 4`。
7. 页图：`.work/pages/topic2/pNN.png`；文字层：`.work/text/topic2/pNN.txt`（这两讲的文字层是干净的，可以直接用来核对英文）；放大：`python3 tools/zoom.py topic2 NN top`。

## 10. 练习页（作业与小测）的写法

作业、小测在 `content/hw1`、`hw2`、`quiz1`、`quiz2` 下，**一道题一页**：`p03.md` 是第 3 题。网站左栏自动显示这道题在解答 PDF 中的那几段（由页眉或大纲里的 `source` 决定），右栏是讲义。

### 10.1 页眉

```yaml
---
topic: hw1                 # 合集 id：hw1 / hw2 / quiz1 / quiz2
page: 3                    # 第几题，与文件名 p03.md 一致
slide: "第 1–2 页"         # 本题在解答 PDF 的哪几页（显示在徽标上），与大纲一致
kind: proof-exercise       # proof-exercise 证明题 / computation 计算题 / judgement 判断题 / statement 叙述题
title: 均值无穷时 |Xₙ| ≥ n 无穷多次，Sₙ/n 没有有限极限   # 中文标题：直接说出结论
title_en: "E|X| = ∞: |Xₙ| ≥ n i.o., and Sₙ/n has no finite limit"
---
```

`source`（左栏显示哪几段）已经写在 `_outline.yaml` 里，页眉可以不写；确实需要调整时，在页眉写 `source: [{ page: 1, from: 0.62, to: 0.87 }, { page: 2, from: 0.10, to: 0.33 }]`（page 是 PDF 页码，from/to 是占页高的比例）。

### 10.2 页面结构（按顺序，用 `##`）

1. `## 这道题在问什么`：`::: idea 一句话版` 用白话说出结论和它为什么重要；再列出考点、要用的讲义结论（加链接）、和本合集其他题的关系。
2. `## 先补基础`：题目和证明用到的每一个工具，读者可能不会的都要讲（定义 + 小例子）。**讲义里没有讲过的内容**（条件期望、鞅、停时、依分布收敛、中心极限定理、大数定律、一致可积……）要讲得尤其清楚，并注明「这里作为已知结论使用」及出处（Durrett《Probability: Theory and Examples》等）。
3. `## 题目与原解答`：`::: original 题目` 原样给出英文题目（公式以图片为准，修正排版错误），`::: zh` 给出中文翻译；然后用 2–4 条概括**原解答的思路**（左栏就是原解答）。
4. `## 思路：怎么想到的`：拿到题怎么入手、关键的一步是什么、为什么会想到它。
5. `## 完整解答`：本站自己写的严格解答。分步编号（**第 1 步**……），每一步写出理由，假设写全；多小问用 `### (i) …` 分开；结论放 `::: thm` / `::: prop` 卡片，证明放 `::: proof` 或正文，结尾 $\blacksquare$。
6. `## 原解答逐行对照`：逐行解释原解答在做什么、为什么成立；原解答的**笔误、跳步、错误**一律指出并改正，放进 `::: warn 原解答的问题：……` 卡片。语气客观：「原解答此处漏了……」「应为……」。**绝不能照抄原解答的错误。**
7. `## 例子与数值验证`：`::: ex` 具体例子、特殊情形、数值计算或模拟（用 python3 核对数字），以及说明「去掉某个条件就不成立」的反例。
8. `## 拓展延伸`：`::: more` 卡片：推广、相关的经典定理（写出名字和陈述）、更强的版本、与讲义和后续内容（大数定律、中心极限定理、鞅）的联系、「条件改成……会怎样」。
9. `## 常见疑问与易错点`：`::: warn` 问答。
10. `## 小结与自测`：`::: sum` + `::::quiz`（2–3 题，附答案）。

篇幅一般 3000–6000 字；多小问的题可以更长。深度和讲义页一样：只看这一页就能自学会这道题。

### 10.3 链接与文件

- 本合集其他题：`[[p:5]]`（显示「第 5 题」）；其他合集：`[[hw2:p:3]]`、`[[quiz1:p:2]]`（显示「作业 2 第 3 题」「小测 1 第 2 题」）；讲义：`[[t3:p:7]]`（只显示「第 7 页」，所以写成「第 3 讲 [[t3:p:7]]」）。题目链接前面**不要**再写「第 5 题」「作业 2 第 3 题」，否则会重复显示。链接不能写进公式。
- 原页图：`.work/pages/<合集>/pNN.png`，这里的 NN 是 **PDF 页码**，不是题号；文字层 `.work/text/<合集>/pNN.txt` 的公式下标、上标大多丢失，**公式一律以图片为准**；放大：`python3 tools/zoom.py hw1 3 top`（3 是 PDF 页码）。
