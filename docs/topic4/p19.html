这一页在讲什么

人话版一句话版

一元正态 N(μ,σ2) 由均值和方差决定。多元正态描述一个随机向量 (X1​,…,Xn​)，由均值向量 μ 和协方差矩阵 Σ 决定，密度是 (2π)n/2(detΣ)1/21​e−21​(x−μ)TΣ−1(x−μ)。二元时它是一座「山」，等高线是椭圆。这一页给出定义，并提出本讲最后两页要证明的结论：对多元正态，协方差为 0 ⇔ 独立。

  • 位置：第 3 部分的最后一个主题，也是本讲目标 ④（第 3 页）。
  • 为什么放在「独立性」里：一般来说协方差为 0（不相关）推不出独立；多元正态是最重要的例外，而证明要用到 第 17 页 的「联合分布 = 乘积测度 ⇔ 独立」。
  • 后面：第 20 页 证明二元情形，第 21 页 证明多元情形。

先补基础

基础补课向量、转置与矩阵乘法
  • 列向量：x=​x1​⋮xn​​​，课件说「把 Rn 的元素看成列向量」就是这个意思。
  • 转置 xT=(x1​,…,xn​)：把列变成行。
  • 矩阵乘向量：n×n 矩阵 A=(aij​) 乘 x，得到第 i 个分量为 ∑j​aij​xj​ 的列向量。
  • 二次型 xTAx=∑i,j​aij​xi​xj​，结果是一个数。例：A=(21​13​)，xTAx=2x12​+2x1​x2​+3x22​。
基础补课对称、行列式、逆矩阵（2×2 情形）

设 A=(ac​bd​)。

  • 对称：AT=A，即 b=c。
  • 行列式：detA=ad−bc。
  • 逆矩阵：detA=0 时，A−1=ad−bc1​(d−c​−ba​)，满足 AA−1=I（单位矩阵）。
  • 对角矩阵（只有对角线非零）：det= 对角元之积，逆矩阵 = 对角元取倒数。
基础补课正定矩阵

对称矩阵 Σ 正定（positive definite），指对每个非零向量 x，xTΣx>0。

  • 2×2 情形的判别：Σ=(ab​bd​) 正定 ⇔ a>0 且 ad−b2>0。
  • 例：(21​12​) 正定（2>0，4−1=3>0）；(12​21​) 不正定（1−4<0），取 x=(1,−1)T 得 xTΣx=1−4+1=−2<0。
  • 正定保证 detΣ>0、Σ−1 存在并且也正定，于是指数 −21​(x−μ)TΣ−1(x−μ)≤0，密度在 x=μ 处最大，往外衰减。
基础补课协方差与相关系数（回顾）

Cov(X,Y)=E[(X−EX)(Y−EY)]；Cov(X,X)=VarX。相关系数 ρ=VarXVarY​Cov(X,Y)​∈[−1,1]，衡量线性相关的强弱。「协方差为 0」也说成「不相关」（uncorrelated）。

课件原文逐句精读

课件原文Example: multivariate normal distribution
  • A random vector (X1​,…,Xn​) taking values in Rn is said to be a gaussian random vector if there exists μ=(μ1​,…,μn​)∈Rn and an n×n positive definite real symmetric matrix Σ:=(σij​)1≤i,j≤n​, denoting detΣ to be determinant of Σ, it follows
P((X1​,…,Xn​)∈S)=(2π)n/2(detΣ)1/21​∫S​e−21​(x−μ)TΣ−1(x−μ)dx,x∈S,

for all Borel sets S⊂Rn (where we identify elements of Rn with column vectors). The distribution of (X1​,…,Xn​) is called a multivariate normal distribution.

  • If (X1​,…,Xn​) is a gaussian random vector and 1≤i,j≤n:
  • Bivariate case: show that Xi​ and Xj​ are pairwise independent if and only if the covariance Cov(Xi​,Xj​) vanishes.
  • Multivariate case: Furthermore, show that (X1​,…,Xn​) are jointly independent if and only if all the covariances Cov(Xi​,Xj​) for 1≤i=j≤n vanish.
中文翻译

蓝条标题：例：多元正态分布。

  • 取值于 Rn 的随机向量 (X1​,…,Xn​) 称为高斯随机向量，如果存在 μ=(μ1​,…,μn​)∈Rn 和一个 n×n 的正定实对称矩阵 Σ=(σij​)（detΣ 记它的行列式），使得对 Rn 的所有博雷尔集 S（把 Rn 的元素看成列向量），上式成立。(X1​,…,Xn​) 的分布叫多元正态分布。
  • 设 (X1​,…,Xn​) 是高斯随机向量，1≤i,j≤n：
  • 二元情形：证明 Xi​ 与 Xj​ 独立，当且仅当协方差 Cov(Xi​,Xj​)=0。
  • 多元情形：进一步证明 X1​,…,Xn​ 相互独立，当且仅当所有 i=j 的协方差 Cov(Xi​,Xj​) 都为 0。

逐句说明：

  • gaussian 应大写为 Gaussian（高斯，人名），gaussian random vector 就是「服从多元正态的随机向量」。
  • 公式的意思：(X1​,…,Xn​) 有联合密度
f(x)=(2π)n/2(detΣ)1/21​exp(−21​(x−μ)TΣ−1(x−μ)),x∈Rn,

落在 S 里的概率就是 f 在 S 上的积分。公式末尾的「x∈S」写在积分外面是排版问题，意思是积分变量 x 跑遍 S。

  • 前面的常数 (2π)n/2(detΣ)1/21​：让总概率等于 1 的归一化常数，和一元时的 2π​σ1​ 同一个作用。
  • 两道题：pairwise independent 对两个变量来说就是「独立」；jointly independent 就是 第 18 页 的「相互独立」；vanishes 是「等于 0」。

补充说明

这一页的定义完整印出；以下对定义的展开、事实陈述与例子由本站依据标准教材补写，记号与课件一致，以老师课堂为准。

n = 1：回到熟悉的正态分布

Σ=(σ2) 是 1×1 矩阵，detΣ=σ2，Σ−1=σ21​，(x−μ)TΣ−1(x−μ)=σ2(x−μ)2​。密度变成

f(x)=2π​σ1​e−2σ2(x−μ)2​,

正是 N(μ,σ2)。「正定」在这里就是 σ2>0。

n = 2：二元正态的显式公式

把协方差矩阵写成

Σ=(σ12​ρσ1​σ2​​ρσ1​σ2​σ22​​),σ1​,σ2​>0, −1<ρ<1.
  • 正定：σ12​>0，detΣ=σ12​σ22​(1−ρ2)>0（这正是要求 ∣ρ∣<1 的原因）。
  • 逆矩阵：Σ−1=σ12​σ22​(1−ρ2)1​(σ22​−ρσ1​σ2​​−ρσ1​σ2​σ12​​)。
  • 记 u=x1​−μ1​，v=x2​−μ2​，二次型为
(x−μ)TΣ−1(x−μ)=1−ρ21​(σ12​u2​−σ1​σ2​2ρuv​+σ22​v2​).
  • 密度：
f(x1​,x2​)=2πσ1​σ2​1−ρ2​1​exp[−2(1−ρ2)1​(σ12​u2​−σ1​σ2​2ρuv​+σ22​v2​)].

参数的含义（事实，这里不证明）

若 (X1​,…,Xn​) 服从上面的多元正态分布，则

  1. EXi​=μi​，Cov(Xi​,Xj​)=σij​：μ 是均值向量，Σ 是协方差矩阵。二元时 VarX1​=σ12​，VarX2​=σ22​，相关系数就是 ρ。
  2. 每个分量都是一元正态：Xi​∼N(μi​,σii​)；任意几个分量组成的子向量也是多元正态，协方差矩阵取 Σ 的相应行列。
  3. 线性组合 aTX=∑ai​Xi​ 服从 N(aTμ, aTΣa)。

对角的情形可以马上验证第 1、2 条：Σ=diag(σ12​,…,σn2​) 时，密度分解成 n 个一元正态密度的乘积（第 21 页 会详细算），每个分量是 N(μi​,σi2​)，两两协方差为 0。

图解：二元正态的「山」和椭圆等高线

把 f(x1​,x2​) 画成曲面：

  • 山顶在 (μ1​,μ2​)，高度 2πσ1​σ2​1−ρ2​1​。
  • 等高线是二次型等于常数的曲线 σ12​u2​−σ1​σ2​2ρuv​+σ22​v2​=c，是一族同心椭圆。
  • ρ=0：椭圆的轴平行于坐标轴；再有 σ1​=σ2​ 时是圆。
  • ρ>0：椭圆沿 45° 方向（y=x 方向）拉长，X1​ 大时 X2​ 也倾向于大；ρ<0 时沿 y=−x 方向拉长。
  • ρ→±1：椭圆被压扁成一条直线，分布集中到直线上，密度不再存在，和 第 4 页 的 (U,U) 一样。

例子

例 1：标准二元正态，ρ 变化时山顶有多高

μ=0，σ1​=σ2​=1。原点处的密度 f(0,0)=2π1−ρ2​1​：

ρ 0 0.5 0.9
f(0,0) 0.159 0.184 0.365

ρ 越接近 ±1，概率越集中在一条直线附近，山越尖。ρ=0 时 f(x1​,x2​)=2π1​e−(x12​+x22​)/2=ϕ(x1​)ϕ(x2​)，是两个标准正态密度的乘积。

例 2：一个具体的协方差矩阵

μ=0，Σ=(21​12​)。

  • detΣ=3，Σ−1=31​(2−1​−12​)。
  • 二次型 xTΣ−1x=31​(2x12​−2x1​x2​+2x22​)。
  • 密度 f(x)=2π3​1​exp(−31​(x12​−x1​x2​+x22​))，原点处约 0.0919。
  • VarX1​=VarX2​=2，Cov=1，相关系数 ρ=2⋅2​1​=21​。
  • 由事实 3，X1​+X2​∼N(0, 2+2+2⋅1)=N(0,6)，X1​−X2​∼N(0, 2+2−2)=N(0,2)。
例 3：用两个独立的标准正态造出二元正态

设 Z1​,Z2​ 独立、都是 N(0,1)（第 17 页 保证它们存在）。令

X1​=Z1​,X2​=ρZ1​+1−ρ2​Z2​.
  • VarX2​=ρ2+(1−ρ2)=1；Cov(X1​,X2​)=ρVarZ1​=ρ（Z1​,Z2​ 独立，交叉项为 0）。
  • 可以证明 (X1​,X2​) 恰好服从相关系数为 ρ 的标准二元正态。电脑模拟（ρ=0.6，20 万组）得到样本协方差约 0.600，样本方差约 0.998。
  • ρ=0 时 X2​=Z2​，X1​,X2​ 就是两个独立的标准正态，和下一页的结论一致。
例 4：相关如何改变「同时为正」的概率

标准二元正态有一个漂亮的公式（Sheppard 公式，这里不证明）：P(X1​>0, X2​>0)=41​+2πarcsinρ​。

ρ −0.5 0 0.5 0.9
P(X1​>0,X2​>0) 61​ 41​ 31​ 0.428

只有 ρ=0 时它等于 P(X1​>0)P(X2​>0)=41​。电脑模拟（每个 ρ 40 万组）结果与公式相差不到 0.001。

常见疑问与易错点

易错点问：为什么 Σ 必须正定？

答：密度公式里要用 Σ−1 和 (detΣ)1/2，必须 detΣ>0。从概率上看，aTΣa=Var(aTX)≥0 对任何 a 都成立；若某个 a=0 使它等于 0，则 aTX 是常数，分布集中在一个低维平面上，没有密度（例如 X2​=X1​）。正定排除了这种「退化」情形；更一般的定义允许 Σ 半正定，但那时就不能用这个密度公式了。

易错点问：每个分量都是正态，向量就一定是多元正态吗？

答：不一定。第 20 页 会给出反例：X∼N(0,1)，Y=SX（S 是独立的随机正负号），X、Y 都是标准正态，(X,Y) 却不是二元正态，并且不相关但不独立。多元正态要求的是联合分布有这个密度，比「各分量正态」强得多。

易错点问：「协方差为 0」和「独立」到底什么关系？

答：一般情况下：独立 ⇒ 协方差为 0（第 10 页 推论：E[XY]=EXEY），反之不成立。多元正态是重要的例外：协方差为 0 ⇒ 独立。下两页证明这件事，而且会看到证明的核心正是 第 17 页：密度分解成乘积 ⇒ 联合分布是乘积测度 ⇒ 独立。

小结与自测

小结本页小结
  • 多元正态：密度 (2π)n/2(detΣ)1/21​e−21​(x−μ)TΣ−1(x−μ)，μ 是均值向量，Σ（正定对称）是协方差矩阵。
  • n=1 回到 N(μ,σ2)；n=2 时由 σ1​,σ2​,ρ 决定，等高线是椭圆，ρ 控制倾斜和扁平程度。
  • 分量、子向量、线性组合仍是正态；但各分量正态不保证联合正态。
  • 待证：联合正态时，不相关 ⇔ 独立（二元 第 20 页，多元 第 21 页）。
自测

1. 写出 μ=0、Σ=(10​04​) 的二元正态密度，并把它写成两个一元密度的乘积。

点开看答案

detΣ=4，Σ−1=diag(1,41​)，f(x1​,x2​)=2π⋅21​e−21​(x12​+x22​/4)=(2π​1​e−x12​/2)(2π​⋅21​e−x22​/8)，即 N(0,1) 与 N(0,4) 的密度之积。

2. (42​21​) 能作为多元正态的 Σ 吗？

点开看答案

不能。det=4−4=0，不正定。取 a=(1,−2)T，aTΣa=4−8+4=0，对应 X1​−2X2​ 方差为 0，即 X1​=2X2​（减去均值后），分布落在一条直线上，没有密度。

3. 在例 3 中取 ρ=−0.8，Cov(X1​,X2​) 和 Var(X1​+X2​) 各是多少？

点开看答案

Cov=−0.8；Var(X1​+X2​)=1+1+2(−0.8)=0.4。
