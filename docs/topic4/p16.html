人话版一句话版

「独立」有三个层次：两个事件独立、两个随机变量独立、两个 σ-代数独立。三者说的都是同一条乘法规则：同时发生的概率 = 各自概率的乘积。要同时谈很多个（甚至无穷多个）对象的独立，需要把很多个空间乘在一起；在这个大空间里，只限制有限个坐标的集合叫柱集（cylinder set），它是下一页定义「无穷乘积测度」的砖块。

  • 位置：第 3 部分「独立性」（第 16 页–第 21 页）的第一页。
  • 和前面的关系：
    • 第 3 讲 第 6 页 已经定义了一列事件的相互独立，并用于第二 Borel–Cantelli 引理；
    • 本讲第 1 部分说明：两个随机变量各自的分布（边缘分布）相同，联合分布可以完全不同（第 4 页 的 (U,U) 与 (U,1−U)）。独立就是一种特殊的联合分布：联合分布等于边缘分布的乘积测度。这一点 第 17 页 会证明。
  • 本页的任务：
    1. 把独立的定义从事件推广到随机变量和 σ-代数；
    2. 提出问题「n 个对象怎么办」；
    3. 为回答这个问题，引入无穷乘积空间里的柱集。

先补基础

基础补课概率空间三件套（回顾）

(Ω,F,P)：

  • Ω 是样本空间，里面每个点 ω 是一次试验的一个可能结局；
  • F 是 σ-代数（第 9 页），是「可以谈概率的事件」组成的集合；
  • P:F→[0,1] 是概率测度（第 12 页），给每个事件一个 0 到 1 之间的数，满足 P(Ω)=1 和可数可加性。

注意 P 的定义域是 F，不是 Ω 的全部子集。所以凡是要写 P(⋯) 的集合，都必须先确认它在 F 里。

基础补课随机变量决定的事件 {X ∈ C}
  • 随机变量 X:Ω→R 是可测函数（第 4 页）：对每个博雷尔集 C⊆R，{X∈C}={ω:X(ω)∈C}=X−1(C) 都在 F 里。
  • 博雷尔集（Borel set）：由所有区间经过可数次并、交、补得到的集合，例如 [0,1]、(2,∞)、{3}、Q。它们组成博雷尔 σ-代数 B(R)。
  • 为什么要求 C 是博雷尔集：X 只保证博雷尔集的原像是事件。对一个非博雷尔的怪集合 C，{X∈C} 可能不在 F 里，P(X∈C) 就没有定义。
  • 记号 P(X∈C,Y∈D) 中的逗号表示「且」：P({X∈C}∩{Y∈D})。
基础补课由随机变量生成的 σ-代数 σ(X)
σ(X)={X−1(C):C∈B(R)}={{X∈C}:C 是博雷尔集}.
  • 它是 σ-代数：原像保持集合运算，X−1(Cc)=(X−1(C))c，X−1(⋃n​Cn​)=⋃n​X−1(Cn​)，并且 X−1(R)=Ω。
  • 含义：σ(X) 是「只看 X 的值就能判断发生没有」的所有事件，可以理解成「X 携带的信息」。
  • 例：掷骰子，X 是点数，Z=1{X 为偶数}​。σ(Z)={∅,{2,4,6},{1,3,5},Ω}：知道 Z，只能判断「偶数」「奇数」这两类事件；「掷出 6」不在 σ(Z) 里，因为只知道 Z=1 时分不清是 2、4 还是 6。
基础补课子 σ-代数

若 G 是 σ-代数，并且 G⊆F，就说 G 是 F 的子 σ-代数（sub-σ-algebra）。σ(X) 就是一个子 σ-代数。σ-field 和 σ-algebra 是同一个意思（field 是「域」的旧称）。

基础补课很多个空间的乘积 ∏ 与坐标映射
  • 下标集 Γ（读作「大伽马」）：任意一个用来编号的集合，可以是 {1,2}、N，甚至 [0,1]。
  • 乘积集合 ∏γ∈Γ​Ωγ​：每个元素 ω=(ωγ​)γ∈Γ​ 是「给每个下标 γ 挑一个 ωγ​∈Ωγ​」。Γ={1,2} 时就是 第 6 页 的 Ω1​×Ω2​；Γ=N 时就是无穷序列 (ω1​,ω2​,ω3​,…)。
  • 坐标映射（coordinate map，也叫投影）πγ​(ω)=ωγ​：从整个序列里读出第 γ 个坐标。
  • 例：无穷次抛硬币，Ωn​={H,T}，∏n∈N​Ωn​={H,T}N 是所有正反序列；π3​(HTTHH⋯)=T。

课件原文逐句精读

课件原文Independence of two events
  • Probability space is (Ω,F,P) where Ω is sample space, F is set of events (the σ-algebra) and P:F→[0,1] is the probability function.
  • Two events A and B are independent if P(A∩B)=P(A)P(B). Random variables X and Y are independent if for all sets C,D, we have P(X∈C,Y∈D)=P(X∈C)P(Y∈D), i.e., the events {X∈C} and {Y∈D} are independent. Two σ-fields F and G are independent if A and B are independent whenever A∈F and B∈G.
  • How to describe the independence over multiple n events?
  • Let (Ωi​,Fi​),i∈N, be a sequence of measurable spaces. Let (∏γ∈Γ​Ωγ​,⊗γ∈Γ​Fγ​) be its product, a measurable set B∈Fγ1​​⊗Fγ2​​⊗⋯⊗Fγn​​, let the set B be chosen of the form B=B1​×⋯×Bn​, for some B1​∈F1​,…,Bn​∈Fn​, the set C is called a (product) cylinder set
中文翻译

蓝条标题：两个事件的独立。

  • 概率空间是 (Ω,F,P)，其中 Ω 是样本空间，F 是事件全体（σ-代数），P:F→[0,1] 是概率函数。
  • 两个事件 A、B 称为独立，如果 P(A∩B)=P(A)P(B)。随机变量 X 和 Y 称为独立，如果对所有集合 C,D，都有 P(X∈C,Y∈D)=P(X∈C)P(Y∈D)，也就是说事件 {X∈C} 与 {Y∈D} 独立。两个 σ-代数 F 与 G 称为独立，如果只要 A∈F、B∈G，A 与 B 就独立。
  • 多个（n 个）事件的独立该怎样描述？
  • 设 (Ωi​,Fi​)，i∈N，是一列可测空间，(∏γ∈Γ​Ωγ​,⊗γ∈Γ​Fγ​) 是它们的乘积。取一个可测集 B∈Fγ1​​⊗⋯⊗Fγn​​，并让 B 取 B=B1​×⋯×Bn​ 的形式（B1​∈F1​,…,Bn​∈Fn​），这样的集合 C 称为（乘积）柱集。

Probability space｜概率空间

  • 第一句只是回顾记号。probability function（概率函数）就是概率测度 P。
  • 写 P:F→[0,1] 而不是 P:Ω→[0,1]：P 是给事件（集合）打分，不是给单个样本点打分。

Two events A and B are independent｜两个事件、两个随机变量、两个 σ-代数的独立

  • 事件：P(A∩B)=P(A)P(B)。直觉是「知道 B 发生，不改变 A 的概率」：P(B)>0 时它等价于 P(A∣B)=P(A)（第 6 页 的「先补基础」）。
  • 随机变量：X 能决定的每个事件 {X∈C}，都和 Y 能决定的每个事件 {Y∈D} 独立。这是「无穷多条」乘法规则，C、D 跑遍所有博雷尔集。
  • σ-代数：F 里的每个事件都和 G 里的每个事件独立。σ-代数代表「信息」，两个 σ-代数独立就是「两份信息互不相干」。
  • 三者是层层推广的关系：随机变量的独立，就是 σ(X) 与 σ(Y) 的独立（下一节命题 1）；事件的独立，就是 σ(1A​) 与 σ(1B​) 的独立（命题 2）。
  • 两处措辞需要改正：
    1. 「for all sets C,D」应为「for all Borel sets C,D⊆R」。理由见「先补基础」：只有博雷尔集的原像才保证是事件。
    2. 「Two σ-fields F and G」里的 F 和第一句概率空间里的 F 撞了名字。这里应当是 F 的两个子 σ-代数，例如写成 G 与 H（G,H⊆F）。否则「F 与 G 独立」会把整个 F 拿来和别的比，而 F 里包含 G 的每个事件 B，于是要求 P(B)=P(B∩B)=P(B)2，只有 G 里的事件全是概率 0 或 1 才可能成立。

How to describe the independence over multiple n events?｜n 个事件的独立怎么描述

课件把它作为一个问题抛出来，答案在下一节和 第 17 页、第 18 页。简要地说：n 个事件要求任意有限个的交都满足乘法规则（第 6 页），而不只是两两满足。为了把「n 个独立的试验」放进同一个概率空间里，要用 n 个（甚至无穷多个）空间的乘积，这就引出了最后一句话里的柱集。

Cylinder set｜柱集

这一句话很长，拆开读：

  1. 先有一列可测空间 (Ωi​,Fi​)，每个代表一次「小试验」。
  2. 把它们全部乘在一起，得到乘积可测空间 (∏γ​Ωγ​,⊗γ​Fγ​)。
  3. 挑有限个下标 γ1​,…,γn​，在这 n 个坐标组成的有限乘积 Ωγ1​​×⋯×Ωγn​​ 里取一个可测集 B，特别地取成矩形 B=B1​×⋯×Bn​。
  4. 「只要求这 n 个坐标落在 B 里，其余坐标随便」，这样得到的大空间里的集合叫柱集。

课件这句话里有几处记号不一致，按标准写法改正如下：

  • B 与 C 混用：课件先选了集合 B，结尾却说「the set C is called a cylinder set」，C 从没定义过（并且 C 刚在第二条里被用作博雷尔集）。正确的关系是：B 是有限个坐标空间里的「底」，柱集是大空间里的
C={ω:(ωγ1​​,…,ωγn​​)∈B}.

B 和 C 不在同一个空间里，不能混为一谈。

  • 下标 i∈N 与 γ∈Γ 混用：课件开头说下标是 i∈N，接着又用一般的下标集 Γ。两种都可以，但要统一。用 Γ 时，应写 Bk​∈Fγk​​，而不是 Bk​∈Fk​。
  • 下一页（第 17 页）的课件取 Γ=N、γk​=k，这时柱集就是 B1​×⋯×Bn​×Ωn+1​×Ωn+2​×⋯。

三个层次的独立：正式定义

定义（两个事件、两个随机变量、两个 σ-代数的独立）

设 (Ω,F,P) 是概率空间。

  1. 事件 A,B∈F 独立，如果 P(A∩B)=P(A)P(B)。
  2. 随机变量 X,Y:Ω→R 独立，如果对所有博雷尔集 C,D⊆R，
P(X∈C, Y∈D)=P(X∈C)P(Y∈D).
  1. 子 σ-代数 G,H⊆F 独立，如果对所有 A∈G、B∈H，P(A∩B)=P(A)P(B)。
命题 1（随机变量的独立 = 生成的 σ-代数的独立）

X 与 Y 独立，当且仅当 σ(X) 与 σ(Y) 独立。

推导证明

由「先补基础」，σ(X) 的元素恰好是形如 {X∈C}（C 博雷尔）的事件，σ(Y) 的元素恰好是 {Y∈D}。

  • 「σ(X),σ(Y) 独立」说的是：对所有 A∈σ(X)、B∈σ(Y)，P(A∩B)=P(A)P(B)。
  • 把 A={X∈C}、B={Y∈D} 代入，这句话逐字变成定义第 2 条。

两句话说的是同一件事。■

命题 2（事件的独立 = 示性函数的独立）

对事件 A,B，下面三条等价：(a) A,B 独立；(b) σ(1A​)={∅,A,Ac,Ω} 与 σ(1B​)={∅,B,Bc,Ω} 独立；(c) 随机变量 1A​ 与 1B​ 独立。

推导证明
  • σ(1A​) 是什么：1A​ 只取 0、1 两个值，所以 {1A​∈C} 只有四种可能：C 两个值都不含时是 ∅；只含 1 时是 A；只含 0 时是 Ac；两个都含时是 Ω。
  • (b)⇔(c)：命题 1。
  • (b)⇒(a)：取 A∈σ(1A​)、B∈σ(1B​) 即可。
  • (a)⇒(b)：要验证 4×4=16 对事件。含 ∅ 的对两边都是 0；含 Ω 的对两边相等（例如 P(Ω∩B)=P(B)=1⋅P(B)）；剩下 A 与 B、Ac 与 B、A 与 Bc、Ac 与 Bc。第一对就是 (a)。第二对：
P(Ac∩B)=P(B)−P(A∩B)=P(B)−P(A)P(B)=P(Ac)P(B),

第一个等号是因为 B 被分成不相交的 A∩B 与 Ac∩B。第三、四对用同样的减法（第 6 页 的命题 A）。■

命题 3（独立随机变量的函数仍然独立）

若 X,Y 独立，f,g:R→R 是博雷尔可测函数，则 f(X) 与 g(Y) 独立。

推导证明

对博雷尔集 C,D，{f(X)∈C}={X∈f−1(C)}，其中 f−1(C) 是博雷尔集（f 可测）。于是

P(f(X)∈C, g(Y)∈D)=P(X∈f−1(C), Y∈g−1(D))=P(X∈f−1(C))P(Y∈g−1(D)),

最后一步用 X,Y 独立；右边就是 P(f(X)∈C)P(g(Y)∈D)。■

例：X,Y 独立，则 X2 与 eY 独立，1{X>0}​ 与 ∣Y∣ 独立。

How to describe the independence over multiple n events?｜对问题的回答

定义（n 个事件、n 个 σ-代数的独立）
  1. 事件 A1​,…,An​ 相互独立，如果对每个至少含两个元素的子集 J⊆{1,…,n}，
P(j∈J⋂​Aj​)=j∈J∏​P(Aj​).
  1. 子 σ-代数 G1​,…,Gn​ 相互独立，如果对所有 A1​∈G1​,…,An​∈Gn​，
P(A1​∩⋯∩An​)=P(A1​)⋯P(An​).
  • 第 1 条与 第 6 页 的定义 3 一致：n 个事件要查 2n−n−1 个等式；只查两两不够（第 18 页 的例子）。
  • 第 2 条为什么只写一个等式就够了？因为每个 Gi​ 都含有 Ω。想检查某个子集 J 上的乘法规则，只要对 i∈/J 取 Ai​=Ω：交集里多出来的 Ω 不改变交集，乘积里多出来的 P(Ω)=1 不改变乘积。所以子集上的等式被「全部 n 个」的等式自动包含。
  • 随机变量 X1​,…,Xn​ 相互独立，就定义为 σ(X1​),…,σ(Xn​) 相互独立。第 18 页 会写成课件的形式，并推广到任意多个。

为什么要引入乘积空间：要讨论「n 次独立的试验」，必须先有一个概率空间，让 n 个结果同时住在里面。自然的选择是乘积 Ω1​×⋯×Ωn​：一个样本点就是「n 次试验的结果清单」。若要讨论无穷多次试验（例如第 3 讲的无穷次抛硬币、样本均值的极限），就要无穷乘积 ∏i∈N​Ωi​。在无穷乘积里，最容易计算概率的集合就是只涉及有限个坐标的柱集。

Cylinder set｜柱集：改正后的定义

定义（柱集与乘积 σ-代数）

设 (Ωγ​,Fγ​)，γ∈Γ，是一族可测空间，Ω=∏γ∈Γ​Ωγ​。

  1. 取有限个互不相同的下标 γ1​,…,γn​∈Γ 和一个可测集 B∈Fγ1​​⊗⋯⊗Fγn​​。集合
C={ω∈Ω: (ωγ1​​,…,ωγn​​)∈B}

称为以 B 为底（base）的柱集。2. 若底是矩形 B=B1​×⋯×Bn​（Bk​∈Fγk​​），即

C={ω: ωγ1​​∈B1​, …, ωγn​​∈Bn​},

则称 C 为乘积柱集（product cylinder set）。3. 乘积 σ-代数 ⨂γ∈Γ​Fγ​ 定义为由所有乘积柱集生成的 σ-代数。它也是使所有坐标映射 πγ​ 都可测的最小 σ-代数。

逐条理解：

  • 「有限个」是关键：柱集只对有限个坐标提要求，其余无穷多个坐标完全自由。
  • Γ=N、γk​=k 的情形：乘积柱集就是
B1​×B2​×⋯×Bn​×Ωn+1​×Ωn+2​×⋯.
  • 为什么叫「柱」：在三维空间 R3=R2×R 里，取底 B 为平面上的单位圆盘，柱集 {(x1​,x2​,x3​):(x1​,x2​)∈B} 就是一根沿 x3​ 方向无限延伸的圆柱：底决定截面形状，第三个坐标随便取。无穷乘积里的柱集是同样的样子，只是「随便取」的方向有无穷多个。
  • 和 第 6 页 的关系：两个空间时（Γ={1,2}），乘积柱集就是可测矩形 A1​×A2​，乘积 σ-代数就是 F1​⊗F2​。所以这是 第 6 页 的直接推广。
  • 最后一句「也是使所有坐标映射可测的最小 σ-代数」：乘积柱集 {ωγ1​​∈B1​,…,ωγn​​∈Bn​}=⋂k=1n​πγk​−1​(Bk​) 是有限个「坐标原像」的交；反过来每个坐标原像 πγ−1​(B) 本身就是只限制一个坐标的乘积柱集。两族集合生成同一个 σ-代数，这和 第 6 页 的「F1​⊗F2​=σ(π1​,π2​)」是同一个论证。
命题 4（乘积柱集对有限交封闭）

两个乘积柱集的交仍是乘积柱集。用 第 8 页 的术语：乘积柱集全体是一个 π 系。

推导证明

设 C={ωγ​∈Bγ​, γ∈S}，C′={ωγ​∈Bγ′​, γ∈S′}，S,S′ 是有限下标集。把两者都看成限制 S∪S′ 上的坐标：对 γ∈S′∖S 令 Bγ​=Ωγ​，对 γ∈S∖S′ 令 Bγ′​=Ωγ​（「不限制」就是「落在全空间里」）。于是

C∩C′={ωγ​∈Bγ​∩Bγ′​, γ∈S∪S′},

S∪S′ 仍是有限集，每个 Bγ​∩Bγ′​∈Fγ​，所以 C∩C′ 是乘积柱集。■

这条性质 第 17 页 马上要用：两个概率测度只要在乘积柱集上相等，就在整个乘积 σ-代数上相等（π 系唯一性定理，第 8 页）。

例子

例 1：掷两颗骰子，「第一颗是偶数」与「点数和为 7」独立

Ω={1,…,6}2，36 个结局等可能。令 A={第一颗为偶数}，B={点数和=7}。

  • P(A)=3618​=21​（第一颗 3 种 × 第二颗 6 种）。
  • B={(1,6),(2,5),(3,4),(4,3),(5,2),(6,1)}，P(B)=366​=61​。
  • A∩B={(2,5),(4,3),(6,1)}，P(A∩B)=363​=121​=21​⋅61​。独立。

直觉：不管第一颗掷出几，第二颗都恰好有一个点数能凑成 7，所以知道第一颗的奇偶不改变「和为 7」的概率。

对照（不独立）：把 B 换成 B′={点数和=8}={(2,6),(3,5),(4,4),(5,3),(6,2)}，P(B′)=365​。A∩B′={(2,6),(4,4),(6,2)}，P(A∩B′)=363​，而 P(A)P(B′)=725​=362.5​，不相等。原因：第一颗掷出 1 时无论如何凑不出 8，知道第一颗的点数会改变「和为 8」的概率。

例 2：两颗骰子的点数是独立的随机变量；第一颗点数与点数和不独立

令 X(i,j)=i，Y(i,j)=j，S=X+Y。

  • X,Y 独立：对任意 C,D⊆{1,…,6}，{X∈C,Y∈D}=C×D 有 ∣C∣⋅∣D∣ 个结局（∣C∣ 表示 C 的元素个数），所以
P(X∈C, Y∈D)=36∣C∣∣D∣​=6∣C∣​⋅6∣D∣​=P(X∈C)P(Y∈D).

对一般的博雷尔集 C，只有 C∩{1,…,6} 起作用，结论相同。

  • X,S 不独立：取 C={1}、D={12}。P(X=1,S=12)=0（第一颗是 1 时和最多是 7），而 P(X=1)P(S=12)=61​⋅361​>0。只要找到一对不满足乘法规则的 C,D，就足以说明不独立。
  • σ-代数的语言：σ(X)={A×{1,…,6}:A⊆{1,…,6}}（只看第一颗能判断的事件，共 26=64 个，都是「竖条」）；σ(Y) 由「横条」{1,…,6}×D 组成。竖条与横条的交是矩形 A×D，概率 36∣A∣∣D∣​，正是乘积。这就是「乘积测度 ⇒ 坐标独立」的最小例子。
例 3：回到 (U, U)——边缘分布一样，独立与否却不同

U,V 都在 (0,1) 上均匀分布（第 4 页）。

  • (U,U)：取 C=[0,21​]，D=(21​,1]。P(U∈C, U∈D)=P(∅)=0，而 P(U∈C)P(U∈D)=41​。不独立：知道第一个坐标，第二个坐标就完全确定了。
  • (U,1−U)：同样取 C=[0,21​]、D=[0,21​)。{U≤21​}∩{1−U<21​}={U≤21​}∩{U>21​}=∅，概率 0，而乘积是 41​。不独立。
  • U,V 独立：联合分布是单位正方形上的面积 λ×λ（第 7 页），P(U∈C,V∈D)=λ(C∩[0,1])⋅λ(D∩[0,1])，乘法规则对所有博雷尔集成立。

三个随机点的每个坐标都服从均匀分布，区别全在联合分布。独立是联合分布的一种特殊形式。

例 4：无穷次抛硬币中的柱集与非柱集

Ω={H,T}N，每次公平且相互独立（这样的 P 存在，见 第 17 页）。

  • 乘积柱集：「第 1 次正面且第 3 次反面」={H}×Ω2​×{T}×Ω4​×Ω5​×⋯。下标 γ1​=1,γ2​=3，底是 {H}×{T}⊆Ω1​×Ω3​。概率 21​⋅21​=41​。
  • 柱集但底不是矩形：「前两次结果相同」={ω:(ω1​,ω2​)∈{HH,TT}}，底 {HH,TT} 不是矩形，但它是两个矩形的不交并，概率 41​+41​=21​。
  • 不是柱集：「每一次都是正面」=⋂n≥1​{ω1​=⋯=ωn​=H} 限制了无穷多个坐标，不是柱集。但它是可数个柱集的交，所以在乘积 σ-代数里。它包含于每个 {ω1​=⋯=ωn​=H}，所以概率 ≤2−n 对所有 n 成立，只能是 0。

常见疑问与易错点

易错点问：检查两个随机变量独立，真的要验证所有博雷尔集 C、D 吗？

答：不必。离散情形（取值可数）只要验证 P(X=x,Y=y)=P(X=x)P(Y=y) 对所有取值 x,y 成立，因为

P(X∈C,Y∈D)=x∈C∑​y∈D∑​P(X=x,Y=y)=x∈C∑​P(X=x)y∈D∑​P(Y=y).

一般情形只要验证 P(X≤x,Y≤y)=P(X≤x)P(Y≤y) 对所有实数 x,y 成立，即联合 CDF 等于 CDF 之积。这一步要用 π 系唯一性定理（第 8 页），第 17 页 会解释。

易错点问：「独立」和「互斥」一样吗？

答：不一样，几乎相反。概率都为正的两个互斥事件一定不独立，因为 P(A∩B)=0=P(A)P(B)（第 6 页 的易错点）。例 3 的 (U,U) 不独立，用的正是两个互斥的事件 {U≤21​}、{U>21​}。

易错点问：独立是集合本身的性质吗？

答：不是，它取决于概率测度 P。同一对坐标映射 π1​,π2​，在乘积测度 λ×λ 下独立（例 3 的 U,V）；在「集中在对角线上」的测度下（(U,U) 的分布）就不独立。乘积测度正是让坐标独立的那个测度，这是 第 17 页 的主题。

易错点问：柱集为什么只允许限制有限个坐标？

答：因为有限个坐标的概率我们会算：用有限个空间的乘积测度，P1​(B1​)⋯Pn​(Bn​)。限制无穷多个坐标的事件（例如例 4 的「每次都是正面」）不能直接写出概率，要先表示成柱集的可数交、并，再用测度的连续性（第 13 页、第 14 页）去算。先在简单集合上定义、再扩张到生成的 σ-代数，这和第 1 讲构造勒贝格测度的思路一样。

小结与自测

小结本页小结
  • 事件独立：P(A∩B)=P(A)P(B)；随机变量独立：对所有博雷尔集 C,D，{X∈C} 与 {Y∈D} 独立；σ-代数独立：其中任意两个事件独立。
  • 三者一脉相承：X,Y 独立 ⇔ σ(X),σ(Y) 独立；A,B 独立 ⇔ 1A​,1B​ 独立。独立随机变量的函数仍独立。
  • n 个事件要求任意子族满足乘法规则；n 个 σ-代数只需写一个等式，因为可以取 Ai​=Ω。
  • 柱集：在无穷乘积 ∏Ωγ​ 里只限制有限个坐标的集合 {(ωγ1​​,…,ωγn​​)∈B}；乘积柱集生成乘积 σ-代数，并且对交封闭。
  • 课件笔误：柱集的底 B 与柱集 C 混用；「all sets C,D」应为博雷尔集；与 G 比较的应是子 σ-代数，不是整个 F。
自测

1. 掷两颗骰子，A={第一颗是 1 或 2}，B={点数和为 7}。A,B 独立吗？

点开看答案

独立。P(A)=3612​=31​，P(B)=61​；A∩B={(1,6),(2,5)}，P(A∩B)=362​=181​=31​⋅61​。

2. 写出 σ(1A​)。若 P(A)=0.3，A 与自己独立吗？

点开看答案

σ(1A​)={∅,A,Ac,Ω}。A 与自己独立要求 P(A)=P(A∩A)=P(A)2，即 0.3=0.09，不成立，所以不独立。只有 P(A)∈{0,1} 时事件才与自己独立。

3. 在 {H,T}N 中，把「第 2 次和第 5 次都是正面」写成乘积柱集的形式，指出它的底，并求公平独立抛掷下的概率。

点开看答案

Ω1​×{H}×Ω3​×Ω4​×{H}×Ω6​×⋯，即 {ω:ω2​=H, ω5​=H}。下标 γ1​=2,γ2​=5，底是 {H}×{H}⊆Ω2​×Ω5​。概率 21​⋅21​=41​。
