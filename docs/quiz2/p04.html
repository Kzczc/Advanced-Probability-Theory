The limit of an independent sequence is a constant

这道题在问什么

人话版一句话版

如果 X1​,X2​,… 相互独立，并且依概率收敛到 X，那么 X 几乎必然是一个常数。直观理解：X 由序列「很远的尾巴」决定；而独立性让尾巴和任何有限个 Xn​ 都无关，甚至和它自己也无关。一个随机变量和自己独立，只能是常数。几乎必然收敛是依概率收敛的特例，所以那种情形的答案也是「是」。

  • 考点：独立性（第 4 讲 第 16 页、第 18 页；第 3 讲 第 6 页）、依概率收敛（第 3 讲 第 14 页）、有界依概率收敛下期望的收敛（第 3 讲 第 20 页），以及 Kolmogorov 0-1 律。
  • 答题结构：题目有两问：依概率收敛的情形（要证明），几乎必然收敛的情形（问能否得到同样结论）。
  • 和讲义的关系：第 4 讲 第 17 页 证明过「非退化的 i.i.d. 序列几乎必然不收敛」，本题是它的推广：不要求同分布，结论是极限必须退化。

先补基础

基础补课方差为 0 的随机变量是常数

若 EY2<∞ 且 VarY=E(Y−EY)2=0，则 (Y−EY)2 是一个积分为 0 的非负函数，几乎必然为 0，所以 Y=EY 几乎必然。

基础补课独立随机变量的函数仍然独立，乘积的期望可以拆开

若 Xn​、Xm​ 独立（n=m），h 是有界的博雷尔函数，则 h(Xn​)、h(Xm​) 也独立（第 4 讲 第 16 页 命题 3），并且

E[h(Xn​)h(Xm​)]=Eh(Xn​)⋅Eh(Xm​)

（第 4 讲 第 10 页 的推论）。

基础补课有界序列：依概率收敛 ⇒ 期望收敛

若 ∣Wn​∣≤C，Wn​→W 依概率（于是 ∣W∣≤C a.s.），则 EWn​→EW。

理由：对任意 ε>0，把 E∣Wn​−W∣ 按 {∣Wn​−W∣≤ε} 拆开：

​EWn​−EW​≤E∣Wn​−W∣≤ε+2CP(∣Wn​−W∣>ε) n→∞​ ε.

ε 任意，所以极限为 0。这是第 3 讲 第 20 页 依概率控制收敛定理的特例（控制函数是常数 C）。

基础补课Kolmogorov 0-1 律（这里作为已知结论使用）

设 X1​,X2​,… 独立。尾 σ-代数 T=⋂n≥1​σ(Xn​,Xn+1​,…) 由「改动任意有限个 Xn​ 都不影响是否发生」的事件组成。Kolmogorov 0-1 律：T 中每个事件的概率只能是 0 或 1。推论：关于 T 可测的随机变量几乎必然是常数。（Durrett《Probability: Theory and Examples》定理 2.5.3。）

尾事件的例子：「Xn​ 收敛」「∑Xn​ 收敛」「limsupXn​≤x」。第 4 讲 第 17 页 已经在 i.i.d. 情形下见过「收敛」这个尾事件。

题目与原解答

课件原文题目
  1. If Xn​→X in probability, and {Xn​}n=1∞​ are independent, show that X must be a constant random variable. How about the case Xn​→X a.s., can we get the limit is a constant random variable?

*** You may try to the proof by contradiction.

中文翻译
  1. 若 Xn​→X 依概率收敛，并且 {Xn​} 相互独立，证明 X 必为常数随机变量。如果 Xn​→X 几乎必然收敛，能否得到极限是常数？

*** 提示：可以试试反证法。

  • 「常数随机变量」应理解为几乎必然等于某个常数：在零概率事件上改动 X 不影响依概率收敛，所以只能证到「几乎必然是常数」。
  • try to the proof 应为 try the proof。

原解答的思路（左栏方框）：

  • 依概率收敛：反证。若 X 不是常数，取 a<b 使 P(X<a)、P(X>b) 都 ≥ε；n,m 很大时，独立性使「Xn​<a 且 Xm​>b」有正概率；可依概率收敛又使 Xn​、Xm​ 都离 X 很近，两者矛盾。另一种写法：取几乎必然收敛的子列。
  • 几乎必然收敛：用 Kolmogorov 0-1 律，F(x)=P(X≤x) 满足 F(x)=F(x)2，只能取 0 或 1，所以 X 是常数。

思路正确，但几处写得不严谨（见「原解答逐行对照」）。下面先给一个不用 0-1 律的初等证明，再把原解答的反证法写严格。

思路：怎么想到的

  • 关键现象：如果 X 是「随机」的，那么相隔很远的 Xn​ 和 Xm​ 都接近同一个随机的 X，它们应该高度相关；可它们是独立的，毫不相关。两者冲突，除非 X 根本不随机。
  • 怎么量化「相关」：用乘积的期望。独立给出 E[h(Xn​)h(Xm​)]=Eh(Xn​)Eh(Xm​)；取极限，左边趋于 E[h(X)2]，右边趋于 (Eh(X))2。两者相等就是 Varh(X)=0。
  • 为什么要套一个 h：X 不一定有期望。取有界的 h 可以避开可积性问题；取严格单调的 h，「h(X) 是常数」就推出「X 是常数」。

完整解答

(1) 依概率收敛的情形

取 h(x)=arctanx。它有界（∣h∣<2π​）、连续、严格递增，并且 ∣h(a)−h(b)∣≤∣a−b∣（中值定理，h′(x)=1+x21​≤1）。

第 1 步（h(Xn​)→h(X) 依概率）：P(∣h(Xn​)−h(X)∣>ε)≤P(∣Xn​−X∣>ε)→0。

第 2 步（乘积也依概率收敛）：令 Wn​=h(Xn​)h(Xn+1​)。由 ∣h∣≤2π​，

​Wn​−h(X)2​≤∣h(Xn​)∣∣h(Xn+1​)−h(X)∣+∣h(X)∣∣h(Xn​)−h(X)∣≤2π​(∣h(Xn+1​)−h(X)∣+∣h(Xn​)−h(X)∣),

右边两项都依概率趋于 0，所以 Wn​→h(X)2 依概率。

第 3 步（取期望）：Wn​、h(Xn​) 都有界，由「有界序列：依概率收敛 ⇒ 期望收敛」，

EWn​→E[h(X)2],Eh(Xn​)→Eh(X),Eh(Xn+1​)→Eh(X).

第 4 步（用独立性）：Xn​ 与 Xn+1​ 独立，所以 EWn​=Eh(Xn​)⋅Eh(Xn+1​)。令 n→∞，两边分别趋于 E[h(X)2] 和 (Eh(X))2，于是

Varh(X)=E[h(X)2]−(Eh(X))2=0.

第 5 步（结论）：由「方差为 0 的随机变量是常数」，h(X)=c 几乎必然，其中 c∈(−2π​,2π​)（h 的取值都在这个开区间里）。h 严格递增，有反函数 tan，所以 X=tanc 几乎必然。■

注意这个证明只用到了相邻两项 Xn​、Xn+1​ 独立。

(2) 几乎必然收敛的情形

能。 几乎必然收敛推出依概率收敛（第 3 讲 第 14 页），所以 (1) 直接给出结论：X 几乎必然是常数。不需要另外证明。

另一种证法：原解答的反证法（写严格）

设 X 不是几乎必然的常数。

第 1 步（找两个分开的区域）：X 的分布函数 F 不只取 0 和 1（否则 X 是常数，见「拓展延伸」），所以存在 x0​ 使 0<F(x0​)<1。令 α=P(X≤x0​)>0；又 P(X>x0​)>0，由从下连续性，存在 k 使 β:=P(X≥x0​+k1​)>0。记 a=x0​，b=x0​+k1​，δ=3b−a​。

第 2 步（Xn​ 也常常落在两边）：{X≤a}⊆{Xn​<a+δ}∪{∣Xn​−X∣≥δ}，所以

P(Xn​<a+δ)≥α−P(∣Xn​−X∣≥δ)≥2α​(n 充分大),

同理 P(Xm​>b−δ)≥2β​（m 充分大）。

第 3 步（独立性给出正概率）：取充分大的 n=m，由独立性，

P(Xn​<a+δ, Xm​>b−δ)=P(Xn​<a+δ)P(Xm​>b−δ)≥4αβ​>0.

第 4 步（依概率收敛给出矛盾）：在上面的事件上，Xm​−Xn​>(b−δ)−(a+δ)=δ。所以

4αβ​≤P(∣Xm​−Xn​∣>δ)≤P(∣Xm​−X∣>2δ​)+P(∣Xn​−X∣>2δ​) n,m→∞​ 0,

矛盾。所以 X 几乎必然是常数。■

原解答逐行对照

  1. 「there are some a<b and ε such that P(X<a)≥ε and P(X>b)≥ε」：对非常数的 X，这样的 a<b 确实存在，但需要论证（上面第 1 步）。
  2. 「Convergence in probability implies convergence in distribution, so ... P(Xn​<a)≥ε/2」：依分布收敛只保证分布函数在连续点收敛，a 不一定是连续点；而且绕到依分布收敛完全没必要。直接用第 2 步的包含关系即可。
  3. 「Therefore with probability (ε/2)2>0 ... {Xn​<a} and {Xm​>b} happen at the same time」：这里用了独立性（n=m），正确。
  4. 「the probability of events ∣Xn​−X∣≤δ and ∣Xm​−X∣≤δ is also 1」：应为「趋于 1」，有限的 n,m 上这个概率一般不是 1。
  5. 「so it is impossible」：需要写出矛盾的不等式（上面第 4 步）。
  6. 「a subsequence that converges almost surely, but infinitely often we have Xn​<a and also infinitely often Xn​>b」：这个想法可以写成严格证明：由第二 Borel–Cantelli 引理（独立 + 概率之和无穷），Xn​<a+δ 和 Xn​>b−δ 都几乎必然发生无穷多次，于是任何子列……要小心：子列是事先固定的，需要对子列本身再用一次 Borel–Cantelli。
  7. 几乎必然情形：「F(X)=P(X≤x)」应为 F(x)；「{X≤x}={X≤x}∩{X≤x} we get F(x)=F(x)F(x)」的真正理由是：{X≤x}（修改一个零概率事件后）是尾事件，而 0-1 律的证明表明尾事件与自己独立，所以 P(A)=P(A∩A)=P(A)2。
易错点原解答的问题：几乎必然的情形其实不用单独证明

几乎必然收敛 ⇒ 依概率收敛，所以第二问的答案直接由第一问得出。原解答又用 0-1 律重新证了一遍，结论对，但没有指出这一点；而且没有说明 {X≤x} 为什么属于尾 σ-代数（理由：X=limsupn​Xn​ 几乎必然，而 limsupn​Xn​ 不受任何有限个 Xn​ 影响）。

易错点原解答的问题：依分布收敛只在连续点成立

「依概率收敛 ⇒ 依分布收敛 ⇒ P(Xn​<a)→P(X<a)」这条推理在 a 是 X 分布函数的跳跃点时可能失败。应该像第 2 步那样直接估计，或者选 a 为连续点（连续点稠密，总能选到）。

例子与数值验证

例 1：收敛到常数的独立序列

Xn​=c+nZn​​，Zn​ i.i.d. N(0,1)。Xn​ 独立，P(∣Xn​−c∣>ε)=P(∣Z1​∣>nε)→0，依概率收敛到常数 c（实际上几乎必然收敛），和结论一致。

例 2：去掉独立性，结论就错了

Xn​=X 对所有 n 成立，X∼N(0,1)。Xn​→X 显然成立，极限不是常数。这里 Xn​ 之间完全相关，远不是独立的。

例 3：换成依分布收敛，结论也不成立

Xn​ i.i.d. N(0,1)。每个 Xn​ 的分布都是 N(0,1)，所以 Xn​ 依分布收敛到 N(0,1)，极限分布不是常数。依分布收敛只看各自的分布，不要求 Xn​ 与某个固定的 X 在同一个 ω 上靠近。这说明题目里「依概率」不能换成「依分布」。由本题，这个序列不可能依概率收敛（和第 4 讲 第 17 页 的结论一致）。

拓展延伸

分布函数只取 0、1 ⇒ 常数

若 F(x)=P(X≤x)∈{0,1} 对所有 x 成立，令 c=sup{x:F(x)=0}（F 单调，非常数部分只有一个跳跃点）。则 x<c 时 F(x)=0，x≥c 时 F(x)=1（右连续），所以 P(X=c)=F(c)−F(c−)=1。这是原解答最后一段的推理，也是上面反证法第 1 步的依据。

Kolmogorov 0-1 律为什么成立（思路）

设 A∈T。对每个 n，A∈σ(Xn+1​,Xn+2​,…)，它与 σ(X1​,…,Xn​) 独立。于是 A 与 ⋃n​σ(X1​,…,Xn​) 中的每个事件独立；用 π-λ 定理（第 4 讲 第 7 页）推广到它生成的 σ-代数 σ(X1​,X2​,…)，而 A 自己就在里面。所以 A 与自己独立：P(A)=P(A)2，P(A)∈{0,1}。

进一步的应用
  • 随机级数：Xn​ 独立时，∑Xn​ 收敛的概率只能是 0 或 1（收敛是尾事件）。Kolmogorov 三级数定理给出它是 1 的充要条件。
  • 大数定律的极限是常数：nSn​​ 若几乎必然收敛，极限是尾 σ-代数可测的，因而是常数。强大数定律说这个常数就是 EX1​。
  • Hewitt–Savage 0-1 律：对 i.i.d. 序列，「交换任意有限个下标都不变」的事件，概率也只能是 0 或 1。

常见疑问与易错点

易错点问：为什么不直接证明「X 与自己独立」？

答：要说 X 与自己独立，得先知道 X 关于尾 σ-代数可测；依概率收敛时 X 不一定是「尾巴的函数」（只能说它几乎必然等于一个子列的极限）。用 0-1 律可以做到，但需要子列论证。上面的初等证明绕开了这一点，只用了「乘积的期望可以拆开」。

易错点问：证明里为什么只用了 Xₙ 和 Xₙ₊₁？

答：只需要每对相邻项独立就够了（甚至只要每对 Xn​,Xm​、m=n 中有无穷多对独立）。题目给的「相互独立」比证明需要的条件强。

易错点问：h 一定要选 arctan 吗？

答：不一定。任何有界、连续、严格单调的函数都行，例如 h(x)=1+∣x∣x​。有界保证期望存在且能取极限，严格单调保证能从 h(X) 是常数推回 X 是常数。

小结与自测

小结本题小结
  • 独立序列依概率收敛到 X ⇒ X 几乎必然是常数；几乎必然收敛是特例，结论同样成立。
  • 初等证明：取 h=arctan，由独立性 E[h(Xn​)h(Xn+1​)]=Eh(Xn​)Eh(Xn+1​)，取极限得 Varh(X)=0。
  • 反证法：X 若不是常数，独立性使「Xn​ 在左、Xm​ 在右」有正概率，与 ∣Xn​−Xm​∣→0（依概率）矛盾。
  • 0-1 律视角：极限是尾巴的函数，尾事件概率只能是 0 或 1。
  • 原解答：依分布收敛的使用不严谨（连续点），「概率为 1」应为「趋于 1」，几乎必然情形可直接由第一问得出。
自测

1. 设 Xn​ 独立，Xn​→X 依概率，且 EXn​=5、∣Xn​∣≤10。X 等于多少？

点开看答案

由本题 X 几乎必然是常数 c；Xn​ 有界，由有界序列的期望收敛，EXn​→EX=c，所以 c=5。

2. 举一个独立序列的例子，它依分布收敛但不依概率收敛。

点开看答案

i.i.d. 的 N(0,1) 序列：依分布收敛到 N(0,1)；若依概率收敛，极限必为常数，可每个 Xn​ 都是 N(0,1)，与「趋于常数」矛盾（P(∣Xn​−c∣>1) 是不随 n 变化的正数）。

3. 判断：「∑n​Xn​ 收敛」是关于独立序列 Xn​ 的尾事件。

点开看答案

正确。改动有限个 Xn​ 只改变级数的有限个项，不影响是否收敛。由 0-1 律，它的概率是 0 或 1。

累积分布函数cumulative distribution function (CDF)F(x) = P(X ≤ x)，单调不减、右连续，完全决定分布。
从下连续continuity from below集合一层层变大（Eₙ ↑ E）时，测度也跟着收敛：μ(Eₙ) → μ(E)。
依分布收敛convergence in distribution在极限分布函数 F 的每个连续点 x 上，P(Xₙ ≤ x) → F(x)。它只比较分布，不要求 Xₙ 本身靠近 X。
Borel–Cantelli 引理Borel–Cantelli lemma概率之和有限 ⇒ 只发生有限次；独立且概率之和无穷 ⇒ 发生无穷多次。
无穷多次infinitely often (i.o.)「Aₙ 发生无穷多次」就是集合 lim sup Aₙ。
稠密dense任何一小段区间里都能找到它的点，例如有理数在实数轴上稠密。
π-λ 定理Dynkin's π-λ theoremπ-系（对有限交封闭）包含于 λ-系时，它生成的 σ-代数也包含于该 λ-系。常用来证明「两个测度在生成元上相等就处处相等」。
生成的 σ-代数generated sigma-algebra包含给定集合族的最小 σ-代数 σ(𝒞)：只加入「被逼着加入」的集合。
级数series无穷多项相加 a₁ + a₂ + …，它的值是前 n 项和在 n → ∞ 时的极限。
强大数定律strong law of large numbers独立同分布且 E|X₁| < ∞ 时，样本均值 Sₙ/n 几乎必然收敛到 E X₁。
