这道题在问什么

人话版一句话版

Xn​ 只取 0 和 1，取 1 的概率是 pn​。「依概率收敛到 0」只看每一项单独取 1 的概率，所以它等价于 pn​→0；「几乎必然收敛到 0」要求每条路径上只出现有限个 1，这由两个 Borel–Cantelli 引理精确判定：∑pn​<∞ 时只有有限个 1（第一引理），∑pn​=∞ 且独立时有无穷多个 1（第二引理）。pn​=n1​ 夹在两者之间：依概率收敛，却几乎必然不收敛。

  • 考点：依概率收敛的定义（第 3 讲 第 14 页 定义 10）；几乎必然收敛与误差事件（第 3 讲 第 9 页 命题 B）；两个 Borel–Cantelli 引理（第 3 讲 第 4 页、第 7 页）。
  • 这道题的意义：它给出「依概率收敛但不几乎必然收敛」的最简单的例子，也是小测 2 第 1 题 里的第二个反例。而且它说明：两种收敛的差距，恰好是「pn​→0」与「∑pn​<∞」的差距。
  • 和其他题的关系：第 2 题、第 5 题 同样是「第一引理管有限次、第二引理（加独立）管无穷多次」。本题的独立性只在 (ii) 的一个方向上用到，例 4 说明去掉它会怎样。

先补基础

基础补课伯努利随机变量就是示性函数
  • 伯努利随机变量（Bernoulli random variable）：只取 1 和 0 的随机变量，P(X=1)=p，P(X=0)=1−p。可以想成一枚「正面概率为 p」的硬币，正面记 1。
  • 记 A={X=1}，则 X=1A​：ω∈A 时为 1，否则为 0。所以关于 X 的问题都可以换成关于事件 A 的问题。
  • 本题第 n 枚硬币的正面概率是 pn​，可以随 n 变化。例如 pn​=n1​：第 1 枚必出正面，第 2 枚一半一半，第 100 枚只有 1% 的机会出正面。
基础补课依概率收敛（第 3 讲 p14）

Xn​→X 依概率（in probability），是说对每个 ε>0，

P(∣Xn​−X∣>ε)→0(n→∞).

人话：对任何容忍度 ε，「误差超过 ε」的概率越来越小。它只看每个 n 单独的概率，不关心同一个 ω 在不同 n 上的表现。例：Xn​ 在 [0,1] 上均匀分布再除以 n，P(Xn​>ε)=max(1−nε,0)→0，所以 Xn​→0 依概率。

基础补课几乎必然收敛，以及 0-1 数列什么时候收敛到 0
  • Xn​→0 几乎必然：P({ω:Xn​(ω)→0})=1（第 3 讲 第 9 页 定义 6）。等价说法（同页命题 B）：对每个 ε>0，P(∣Xn​∣>ε i.o.)=0。
  • 只取 0、1 的数列 a1​,a2​,… 收敛到 0，当且仅当其中只有有限个 1。理由：若有无穷多个 1，则 ∣an​−0∣=1 无穷多次，不收敛；若只有有限个 1，最后一个 1 之后全是 0，当然收敛到 0。
  • 例：1,0,1,0,1,0,… 不收敛；1,1,0,1,0,0,0,…（第 4 项以后全是 0）收敛到 0。
基础补课两个 Borel–Cantelli 引理（回顾）
  • 第一引理（第 3 讲 第 4 页 定理 2）：∑n​P(An​)<∞⇒P(An​ i.o.)=0。对任何事件列成立，不需要独立。
  • 第二引理（第 3 讲 第 7 页 定理 4）：An​ 相互独立且 ∑n​P(An​)=∞⇒P(An​ i.o.)=1。
  • Xn​ 相互独立时，事件 An​={Xn​=1}={Xn​∈{1}} 相互独立（第 3 讲 第 6 页 补充定义，{1} 是博雷尔集）。
基础补课级数：各项趋于 0 不等于和有限
  • 若 ∑n​pn​<∞，则 pn​→0：部分和 sn​=p1​+⋯+pn​ 收敛，pn​=sn​−sn−1​→0。
  • 反过来不对：调和级数 ∑n​n1​=∞，虽然 n1​→0。部分和大约是 lnn+0.577：Python 算得 ∑n≤106​n1​≈14.39，增长极慢但没有上限。
  • p-级数：∑n​ns1​<∞⟺s>1。所以 ∑n21​=6π2​ 有限，∑n​1​=∞。
  • 更细的分界：∑n≥2​nlnn1​=∞，∑n≥2​n(lnn)21​<∞（用积分 ∫xlnxdx​=lnlnx、∫x(lnx)2dx​=−lnx1​ 比较）。

题目与原解答

课件原文题目
  1. Let X1​,X2​,… be independent with P(Xn​=1)=pn​ and P(Xn​=0)=1−pn​. Show that

(i) Xn​→0 in probability if and only if pn​→0, and

(ii) Xn​→0 a.s. if and only if ∑pn​<∞.

中文翻译
  1. 设 X1​,X2​,… 相互独立，P(Xn​=1)=pn​，P(Xn​=0)=1−pn​。证明：

(i) Xn​→0 依概率成立，当且仅当 pn​→0；

(ii) Xn​→0 几乎必然成立，当且仅当 ∑pn​<∞。

  • 题设的「independent」只在 (ii) 的「⇒」方向用到；(i) 和 (ii) 的「⇐」对任何相关结构都成立。
  • 结论 (ii) 里的「⇒」是说：几乎必然收敛 ⇒ 级数有限。通常证它的逆否命题：级数无穷 ⇒ 不几乎必然收敛。

原解答的思路（左栏）：

  1. (i)：0<ε<1 时 P(∣Xn​∣>ε)=pn​，所以依概率收敛 ⟺pn​→0；
  2. (ii)：令 An​={∣Xn​∣>ε}，则 P(An​ i.o.)=0⟺∑P(An​)=∑pn​<∞，并注明「⇒」用了独立性。

结论都对，但写得太省：没有交代 ε≥1 的情形，没有说明「几乎必然收敛」和「P(An​ i.o.)=0」为什么等价，也没有点明两个方向分别用哪个引理。见「原解答逐行对照」。

思路：怎么想到的

  1. 0-1 变量的误差事件只有一个。Xn​ 只取 0、1，所以对 0<ε<1，「∣Xn​∣>ε」就是「Xn​=1」，和 ε 无关；对 ε≥1，它是空集。于是所有问题都归结为事件 An​={Xn​=1}。
  2. (i) 只看单个概率：依概率收敛就是 P(An​)=pn​→0。
  3. (ii) 看「发生几次」：路径收敛到 0 ⟺ 只有有限个 1 ⟺ ω∈/{An​ i.o.}。于是几乎必然收敛 ⟺ P(An​ i.o.)=0，而这个概率正是 Borel–Cantelli 引理计算的对象：和有限时为 0，和无穷且独立时为 1。

完整解答

定理命题（独立伯努利序列的两种收敛）

设 X1​,X2​,… 相互独立，P(Xn​=1)=pn​=1−P(Xn​=0)。则

  1. Xn​→0 依概率 ⟺pn​→0（不需要独立）；
  2. Xn​→0 几乎必然 ⟺∑n​pn​<∞（「⇐」不需要独立）。

而且 P(Xn​→0) 只能是 0 或 1：∑pn​<∞ 时为 1，∑pn​=∞ 时为 0。

推导证明思路

先把误差事件 {∣Xn​∣>ε} 算出来：0<ε<1 时就是 An​={Xn​=1}，ε≥1 时是空集。(i) 直接由定义得到。(ii) 先证 {Xn​→0}={An​ i.o.}c，再用第一引理（⇐）和第二引理的逆否（⇒）。

预备：误差事件。 令 An​={Xn​=1}。因为 Xn​ 只取 0、1：

  • 若 0<ε<1：∣Xn​∣>ε⟺Xn​=1，所以 {∣Xn​∣>ε}=An​，P(∣Xn​∣>ε)=pn​；
  • 若 ε≥1：∣Xn​∣≤1≤ε 总成立，所以 {∣Xn​∣>ε}=∅，概率为 0。

(i) 依概率收敛 ⇔ pₙ → 0

  • （⇐） 设 pn​→0。任给 ε>0：若 ε<1，P(∣Xn​∣>ε)=pn​→0；若 ε≥1，P(∣Xn​∣>ε)=0。所以对每个 ε 都趋于 0，即 Xn​→0 依概率。
  • （⇒） 设 Xn​→0 依概率。在定义中取 ε=21​：pn​=P(∣Xn​∣>21​)→0。

整个过程只用了每个 Xn​ 自己的分布，没有用独立性。

(ii) 几乎必然收敛 ⇔ ∑ pₙ < ∞

第 1 步：收敛集就是「只有有限个 1」。 固定 ω。数列 X1​(ω),X2​(ω),… 只取 0、1，由「先补基础」，它收敛到 0 当且仅当只有有限个 n 使 Xn​(ω)=1，即 ω∈/{An​ i.o.}。所以

{Xn​→0}={An​ i.o.}c,P(Xn​→0)=1−P(An​ i.o.).

第 2 步（⇐，不需要独立）。 设 ∑n​pn​<∞，即 ∑n​P(An​)<∞。由第一 Borel–Cantelli 引理，P(An​ i.o.)=0，所以 P(Xn​→0)=1。

第 3 步（⇒，用独立性）。 证逆否命题：设 ∑n​pn​=∞。Xn​ 相互独立，所以事件 An​={Xn​∈{1}} 相互独立；又 ∑n​P(An​)=∞。由第二 Borel–Cantelli 引理，P(An​ i.o.)=1，所以 P(Xn​→0)=0=1，Xn​ 不几乎必然收敛到 0。

第 4 步：结论。 第 2、3 步合起来就是 (ii)；顺便得到 P(Xn​→0) 只能是 1（级数有限）或 0（级数无穷）。■

第 1 步的另一种写法（用命题 B）：由第 3 讲 第 9 页 命题 B，Xn​→0 a.s. ⟺ 对每个 ε>0，P(∣Xn​∣>ε i.o.)=0。由预备，ε≥1 时事件是空集，自动成立；0<ε<1 时事件都是同一个 {An​ i.o.}。所以条件化为一句话：P(An​ i.o.)=0。

原解答逐行对照

(i) For 0<ε<1, P(∣Xn​∣>ε)=pn​→0⟺pn​→0.

想说的是：0<ε<1 时误差概率就是 pn​，所以「误差概率趋于 0」等价于「pn​→0」。

易错点原解答的问题：(i) 漏了 ε ≥ 1，而且写法像循环论证
  • 依概率收敛要求每个 ε>0。原解答只讨论了 0<ε<1，应补一句：ε≥1 时 {∣Xn​∣>ε}=∅，概率恒为 0，自动趋于 0。
  • 「=pn​→0⟺pn​→0」把要证的结论写在了等价号两边，读起来像「A⟺A」。应写成：Xn​→0 依概率 ⟺ 对每个 ε∈(0,1)，P(∣Xn​∣>ε)→0 ⟺pn​→0（第一个等价用了 ε≥1 的情形自动成立，第二个等价用了 P(∣Xn​∣>ε)=pn​）。

(ii) Let An​={∣Xn​∣>ε}. Then, P(An​ i.o.)=0⟺∑n=1∞​P(An​)=∑n=1∞​pn​<∞.

想说的是：用两个引理判定 P(An​ i.o.)。

易错点原解答的问题：ε 没有限定，也没说明 a.s. 收敛为什么等价于 P(Aₙ i.o.) = 0
  • 这里的 ε 必须取在 (0,1) 里。若 ε≥1，An​=∅，∑P(An​)=0，等价式的右边永远成立，和 pn​ 无关。
  • 原解答直接写「P(An​ i.o.)=0⟺⋯」，却没说明左边为什么等价于「Xn​→0 a.s.」。需要补：0-1 数列收敛到 0 ⟺ 只有有限个 1（完整解答第 1 步），或者用命题 B 并指出 An​ 对所有 ε∈(0,1) 是同一个事件。
  • 等价号的两个方向用的是不同的引理：「⇐」是第一引理（不需要独立），「⇒」是第二引理的逆否命题（需要独立）。应当分开写。

Note Note that (⇒) holds since Xn​'s are independent.

方向标注是对的：在「P(An​ i.o.)=0⇒∑pn​<∞」这个方向上，要用第二引理的逆否命题，所以需要独立。最好写全：「若 ∑pn​=∞，由独立性和第二 Borel–Cantelli 引理，P(An​ i.o.)=1=0」。

例 2：pₙ = 1/n，一条路径上的 1 越来越稀，但永不消失

Python 模拟一条路径，前 106 项中 Xn​=1 的位置是

1, 4, 7, 25, 33, 38, 115, 1208, 8256, 8546, 27637, 44397,

共 12 个（理论平均 ∑n≤106​n1​≈14.39 个）。相邻两个 1 之间的间隔越来越长，可按第二引理，几乎每条路径上的 1 都有无穷多个。另一方面，任意固定的 n，P(Xn​=1)=n1​ 都很小，这就是依概率收敛。

一个精确的计算：从第 m 项到第 M 项全是 0 的概率是 ∏n=mM​(1−n1​)=∏n=mM​nn−1​=Mm−1​（相邻项约掉），M→∞ 时趋于 0：再长的「全 0」都会被打断。

例 3：pₙ = 1/n²，最后一个 1 出现在哪里

从第 m 项（m≥2）起全是 0 的概率：

n≥m∏​(1−n21​)=n≥m∏​n⋅n(n−1)(n+1)​=mm−1​.

所以「最后一个 1 的位置 ≤m−1」的概率是 mm−1​。注意 p1​=1，第 1 项必为 1。Python 模拟 2 万条路径（每条看前 2000 项）：最后一个 1 就是第 1 项的比例为 0.504（理论 21​），最后一个 1 在前 9 项的比例为 0.902（理论 109​）。

注意「最后一个 1」可以很晚：由上式，P(最后一个 1 的位置≥k)=k1​，只是以 k1​ 的速度变小。所以 2 万条路径里，平均约有 20000×20011​≈10 条路径的最后一个 1 落在第 2000 项之后，前 2000 项的模拟看不到它们（模拟中「看得见的」最晚一个 1 在第 1893 项，就是被这个观察窗口截住的）。尽管如此，每条路径都只有有限个 1，几乎必然收敛。

例 4（反例）：去掉独立，(ii) 的「⇒」失败

设 U 在 (0,1) 上均匀，令 Xn​=1{U<1/n}​。

  • 边缘分布和例 2 完全一样：P(Xn​=1)=P(U<n1​)=n1​，∑pn​=∞。
  • 但几乎必然收敛到 0：Xn​(ω)=1⟺n<1/U(ω)。对固定的 ω，满足这个条件的 n 只有有限个（最后一个是 ⌊1/U(ω)⌋，当 1/U(ω) 不是整数时）。例如 U(ω)=0.247 时，1/U≈4.04，只有 X1​,…,X4​ 是 1。所以每个 ω 上 Xn​(ω)→0。
  • 证明坏在第 3 步：事件 {U<n1​} 一个套一个，不独立，第二引理用不上。
  • 对照小测 2 第 1 题 的打字机序列：它也是 pn​→0、∑pn​=∞（第 m 层的 2m 项各为 2−m），却是每个 ω 都碰到无穷多个 1。同样的边缘分布，可以「全收敛」也可以「全不收敛」：只知道每个 pn​，判断不了几乎必然收敛；独立性把联合结构定死了，才有本题的判别法。

拓展延伸

推广：独立序列几乎必然收敛到 0 的判别法

同样的论证对一般的独立随机变量成立：

Xn​ 独立:Xn​→0 a.s.⟺对每个 ε>0, n∑​P(∣Xn​∣>ε)<∞.

「⇐」是第 3 讲 第 10 页 推论 7（偏差概率可求和），不需要独立；「⇒」：若某个 ε 使级数发散，独立 + 第二引理给出 ∣Xn​∣>ε 无穷多次（概率 1），不可能收敛到 0。本题的 0-1 变量是最简单的特例，因为它的误差事件不依赖 ε。

Lᵖ 收敛和子列
  • E∣Xn​∣p=P(Xn​=1)=pn​，所以对任何 p>0，Xn​→0 在 Lp 中 ⟺pn​→0⟺ 依概率收敛。
  • 依概率收敛的序列一定有几乎必然收敛的子列（第 3 讲 第 16 页）。在 pn​=n1​ 时可以直接看出来：取子列 nk​=k2，∑k​pk2​=∑k​k21​<∞，由第一引理，Xk2​→0 a.s.。整个序列不收敛，但抽稀之后就收敛了。
0-1 律

本题的副产品「P(Xn​→0)∈{0,1}」是 Kolmogorov 0-1 律的特例（这里作为已知结论介绍，见 Durrett《Probability: Theory and Examples》第 2.5 节）：独立序列的尾事件（改动有限项不影响其是否发生的事件）概率只能是 0 或 1。{Xn​→0} 就是尾事件。0-1 律只告诉我们「是 0 或 1」，Borel–Cantelli 引理则告诉我们「到底是哪一个」。

常见疑问与易错点

易错点问：(i) 用到独立性了吗？

答：没有。依概率收敛只涉及每个 n 单独的概率 P(∣Xn​∣>ε)，与 Xn​ 之间的关系无关。例 4 中的 Xn​=1{U<1/n}​ 不独立，(i) 照样成立。

易错点问：∑pₙ = ∞ 时，Xₙ 只是「不几乎必然收敛到 0」，还是「几乎必然不收敛」？

答：后者，而且更强：几乎每条路径上都有无穷多个 1。若再有 pn​→0，则 ∑(1−pn​)=∞，同样由第二引理，几乎每条路径上也有无穷多个 0，所以路径在 0、1 之间无穷次跳动，根本不收敛（到任何数）。

易错点问：为什么说两种收敛的差距就是「pₙ → 0」和「∑pₙ < ∞」的差距？

答：由本题，依概率收敛 ⟺ pn​→0，几乎必然收敛 ⟺ ∑pn​<∞。级数有限 ⇒ 各项趋于 0，所以几乎必然收敛 ⇒ 依概率收敛（与第 3 讲 第 14 页 命题 11 一致）；反过来，pn​=n1​ 各项趋于 0 而级数发散，正好是依概率收敛而不几乎必然收敛。

易错点问：如果 pₙ 不单调（比如忽大忽小），结论还对吗？

答：对。证明里从没用到单调性。例如 pn​=n1​（n 是完全平方数）、pn​=n21​（其他 n）：∑n​pn​≤∑k​k21​+∑n​n21​<∞，所以几乎必然收敛。

小结与自测

小结本题小结
  • 0-1 变量的误差事件：0<ε<1 时是 {Xn​=1}，ε≥1 时是空集。
  • (i) 依概率收敛 ⟺ pn​→0，不需要独立。
  • (ii) 收敛集 ={Xn​=1 i.o.}c；∑pn​<∞ ⇒ 第一引理 ⇒ a.s. 收敛（不需要独立）；∑pn​=∞ + 独立 ⇒ 第二引理 ⇒ P(Xn​→0)=0。
  • 去掉独立，(ii) 的「⇒」失败（Xn​=1{U<1/n}​）。
  • 原解答要补的地方：ε≥1 的情形；ε 要限定在 (0,1)；「a.s. 收敛 ⟺ P(An​ i.o.)=0」的理由；两个方向分别用哪个引理。
自测

1. Xn​ 独立，pn​=n​1​。Xn​ 依概率收敛到 0 吗？几乎必然呢？

点开看答案

2. Xn​ 独立，pn​=n1.011​。Xn​ 几乎必然收敛到 0 吗？记 Em​ 为「从第 m 项起全是 0」，P(Em​) 在 m→∞ 时趋于多少？

3. 设 U 在 (0,1) 上均匀，Xn​=1{U<pn​}​，pn​→0。证明 Xn​→0 a.s.，不管 ∑pn​ 是否有限。这和本题矛盾吗？
