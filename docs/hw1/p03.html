这道题在问什么

人话版一句话版

独立同分布的 X1​,X2​,…，若 E∣X1​∣=∞，会发生两件事：(1) 观测值会无穷多次大到超过自己的下标，即 ∣Xn​∣≥n 无穷多次（概率 1）；(2) 因此样本均值 Sn​/n 几乎必然没有有限的极限。第一件事用「尾级数比较 + 第二 Borel–Cantelli 引理」；第二件事用一个恒等式：Sn​/n 若收敛，相邻两个平均值之差必须趋于 0，可每当 ∣Xn+1​∣≥n+1，这个差都要跳一大步。

  • 考点：期望与尾级数的比较（第 3 讲 第 12 页）；第二 Borel–Cantelli 引理（第 3 讲 第 7 页）；收敛数列「相邻两项之差趋于 0」。第一部分其实就是第 3 讲 第 13 页 定理 9 取斜率 C=1 的情形。
  • 这道题的意义：强大数定律说 E∣X1​∣<∞ 时 Sn​/n→EX1​ 几乎必然。本题说明这个条件不能去掉：对独立同分布序列，「Sn​/n 收敛到有限数」与「E∣X1​∣<∞」是等价的。
  • 和其他题的关系：第 2 题、第 4 题、第 5 题 也用第二引理把「概率之和发散」变成「发生无穷多次」。作业 2 第 5 题 把本题推广到一般的除数 an​。

先补基础

基础补课独立同分布、部分和与样本均值
  • 独立同分布（i.i.d.，independent and identically distributed）：X1​,X2​,… 相互独立，而且每个 Xn​ 的分布都和 X1​ 一样（第 3 讲 第 6 页 补充定义）。所以对任何博雷尔集 B，P(Xn​∈B)=P(X1​∈B)。
  • 部分和：Sn​=X1​+X2​+⋯+Xn​。样本均值：Sn​/n，前 n 次观测的平均。
  • 小例子：抛一枚均匀硬币，正面记 1、反面记 0。Sn​ 是前 n 次的正面个数，Sn​/n 是正面的比例，直觉上它应当趋于 21​。本题要说的是：如果单次观测的平均大小是无穷，这种「平均值稳定下来」的现象就不会发生。
  • 相邻部分和之差就是单项：Sn+1​−Sn​=Xn+1​。本题第二部分的全部技巧都来自这一行。
基础补课E|X₁| = ∞ 的意思，以及「期望 ≤ 上阶梯」
  • 对非负随机变量 Y，尾积分公式：EY=∫0∞​P(Y>x)dx（第 2 讲 第 12 页、第 21 页 推论 21 取 p=1）。人话：期望是尾函数 x↦P(Y>x) 曲线下方的面积。
  • 尾函数是递减的：x 越大，「Y>x」越难发生。所以在 [n,n+1) 上，P(Y>x)≤P(Y>n)：曲线不高于左端点的值。把每一段的面积换成「宽 1、高 P(Y>n)」的矩形，矩形盖住曲线，得到
EY≤n=0∑∞​P(Y>n).

这就是第 3 讲 第 12 页 的「上阶梯」不等式。

  • E∣X1​∣=∞ 不是说 X1​ 会取到 ∞：每个 X1​(ω) 都是有限实数，只是大值出现得不够罕见，平均起来没有上限。例：U 在 (0,1) 上均匀，X=1/U，P(X>t)=t1​（t≥1），EX=∫01​1dt+∫1∞​tdt​=∞；柯西分布（密度 π(1+x2)1​）也是 E∣X∣=∞。
基础补课第二 Borel–Cantelli 引理（回顾）

若事件 A1​,A2​,… 相互独立，且 ∑n​P(An​)=∞，则 P(An​ i.o.)=1（第 3 讲 第 7 页 定理 4）。「i.o.」是 infinitely often（无穷多次）的缩写：{An​ i.o.}=⋂m≥1​⋃n≥m​An​（第 3 讲 第 3 页）。

独立随机变量 ⇒ 独立事件：若 Xn​ 相互独立，Bn​ 是博雷尔集，则事件 {Xn​∈Bn​}（n=1,2,…）相互独立（第 3 讲 第 6 页）。本题用 Bn​=(−∞,−n]∪[n,∞)，{Xn​∈Bn​}={∣Xn​∣≥n}。

基础补课数列极限的两条小性质

设 an​→c，c 是有限实数。

  1. 相邻两项之差趋于 0：an​−an+1​→c−c=0。逆否说法：若 ∣an​−an+1​∣>32​ 对无穷多个 n 成立，an​ 就不可能收敛到有限数。
  2. 有界乘以趋于 0 还是趋于 0：若 bn​→0，则 an​bn​→c⋅0=0。

注意性质 1 只能单向使用：an​=lnn 的相邻差 lnnn+1​→0，可它趋于 ∞。另外，「liman​∈(−∞,∞)」是说「极限存在并且是有限数」；an​=(−1)n（极限不存在）和 an​=n（极限是 +∞）都不满足。

基础补课强大数定律（讲义尚未讲，这里作为已知结论使用）

强大数定律（strong law of large numbers，SLLN）：若 X1​,X2​,… 独立同分布，且 E∣X1​∣<∞，则

nSn​​→EX1​几乎必然.

出处：Durrett《Probability: Theory and Examples》第 2.4 节。小例子：Xn​∼Exp(1)，EX1​=1，于是 Sn​/n→1 a.s.（「例子」一节有模拟）。原解答最后一句说的「necessary for SLLN」，就是指本题证明了这个定理里的条件 E∣X1​∣<∞ 去不掉。

题目与原解答

课件原文题目
  1. If X1​,X2​,… are i.i.d. with E∣Xi​∣=∞, then P(∣Xn​∣≥n i.o.)=1. So if Sn​=X1​+⋯+Xn​ then
P(n→∞lim​Sn​/n∈(−∞,∞))=0.
中文翻译
  1. 若 X1​,X2​,… 独立同分布，且 E∣Xi​∣=∞，则 P(∣Xn​∣≥n 无穷多次)=1。因此，若记 Sn​=X1​+⋯+Xn​，则
P(n→∞lim​Sn​/n 存在且属于 (−∞,∞))=0.
  • 题目有两个结论，用「So」（因此）连接：第二个结论要用第一个结论来证。
  • limSn​/n∈(−∞,∞) 的意思是「极限存在且有限」。题目没有排除 Sn​/n→+∞ 这种情形（例 2 就是这样）。
  • E∣Xi​∣ 写成 Xi​ 还是 X1​ 都一样：同分布，所有 E∣Xi​∣ 相等。

原解答的思路（左栏）：

  1. 由 E∣X1​∣=∫0∞​P(∣X1​∣>x)dx≤∑n=0∞​P(∣X1​∣>n) 得级数发散，再由独立同分布和第二 Borel–Cantelli 引理得 P(∣Xn​∣≥n i.o.)=1；
  2. 恒等式 nSn​​−n+1Sn+1​​=n(n+1)Sn​​−n+1Xn+1​​，在 C={limSn​/n 存在且有限} 上 n(n+1)Sn​​→0；
  3. 在 C∩{∣Xn​∣≥n i.o.} 上，相邻平均值之差 >32​ 无穷多次，与收敛矛盾，所以交集是空集，P(C)=0。

这正是 Durrett 教材里的证明，思路完全正确，但有几处跳步（求和从 n=0 开始、> 与 ≥、32​ 从哪里来）和一处笔误，见「原解答逐行对照」。

思路：怎么想到的

  1. 第一部分是「无穷多次」，找第二引理。要证某个事件以概率 1 发生无穷多次，标准工具是第二 Borel–Cantelli 引理。它要两样东西：事件独立（题目给了独立）、概率之和发散（要从 E∣X1​∣=∞ 得到）。
  2. 同分布把概率之和变成尾级数。P(∣Xn​∣≥n) 和 P(∣X1​∣≥n) 一样，于是 ∑n​P(∣Xn​∣≥n) 只和 X1​ 的尾巴有关。「期望无穷 ⇒ 尾级数无穷」正是第 3 讲 第 12 页 的上阶梯不等式。
  3. 第二部分：怎样把「平均值」和「单项」联系起来？ 单项可以从部分和里「减」出来：Xn+1​=Sn+1​−Sn​。如果 Sn​/n 稳定在某个有限数附近，相邻两个平均值几乎一样，那么单项 Xn+1​ 相对 n+1 必须很小。
  4. 可第一部分说单项无穷多次「很大」：∣Xn+1​∣/(n+1)≥1 无穷多次。两者矛盾，所以「平均值收敛」只能发生在概率 0 的事件上。恒等式只是把这个想法写成精确的算式。

完整解答

定理命题（一阶矩无穷时样本均值不收敛）

设 X1​,X2​,… 是独立同分布的实值随机变量，E∣X1​∣=∞，Sn​=X1​+⋯+Xn​。则

  1. P(∣Xn​∣≥n i.o.)=1；
  2. 记 C={ω:limn→∞​Sn​(ω)/n 存在且是有限实数}，则 P(C)=0。
推导证明思路

第一部分：上阶梯不等式 ⇒ 尾级数发散（去掉 n=0 那一项）⇒ 同分布把它变成 ∑n​P(∣Xn​∣≥n)=∞ ⇒ 独立 + 第二引理。第二部分：在 C 上，恒等式左边和右边第一项都趋于 0；第一部分给出右边第二项无穷多次绝对值 ≥1；矛盾，所以 C 与「∣Xn​∣≥n 无穷多次」不相交。

第一部分：|Xₙ| ≥ n 无穷多次

第 1 步：尾级数发散。 令 Y=∣X1​∣≥0。由「先补基础」的上阶梯不等式，

∞=EY≤n=0∑∞​P(Y>n)=≤1P(Y>0)​​+n=1∑∞​P(Y>n).

左边是 ∞，右边第一项不超过 1，所以第二项必须是 ∞：

n=1∑∞​P(∣X1​∣>n)=∞.

为什么要去掉 n=0 这一项：下一步要把第 n 项换成 Xn​ 的事件，而序列里没有 X0​；去掉一个不超过 1 的有限项，不改变级数是否发散。

第 2 步：换成 Xn​ 的事件。 令 An​={∣Xn​∣≥n}，n=1,2,…。因为 {∣Xn​∣>n}⊆{∣Xn​∣≥n}，又因为 Xn​ 与 X1​ 同分布，

P(An​)≥P(∣Xn​∣>n)=P(∣X1​∣>n),所以n=1∑∞​P(An​)≥n=1∑∞​P(∣X1​∣>n)=∞.

第 3 步：独立 + 第二引理。 An​={Xn​∈Bn​}，Bn​=(−∞,−n]∪[n,∞) 是闭集，因而是博雷尔集。Xn​ 相互独立，所以 A1​,A2​,… 相互独立。由第二 Borel–Cantelli 引理，P(An​ i.o.)=1，即 P(∣Xn​∣≥n i.o.)=1。

第二部分：Sₙ/n 没有有限极限

第 4 步：恒等式。 由 Sn+1​=Sn​+Xn+1​，

nSn​​−n+1Sn+1​​=nSn​​−n+1Sn​​−n+1Xn+1​​=Sn​(n1​−n+11​)−n+1Xn+1​​=n(n+1)Sn​​−n+1Xn+1​​.

（n1​−n+11​=n(n+1)(n+1)−n​=n(n+1)1​。）

第 5 步：在 C 上，两项都趋于 0。 取 ω∈C，记 c=limn​Sn​(ω)/n，它是有限实数。

  • 左边：由「先补基础」性质 1，nSn​​−n+1Sn+1​​→c−c=0。
  • 右边第一项：n(n+1)Sn​​=nSn​​⋅n+11​，由性质 2，趋于 c⋅0=0。

所以存在 N=N(ω)，使 n≥N 时 ​n(n+1)Sn​​​<31​。

第 6 步：再在「∣Xn​∣≥n 无穷多次」上，推出矛盾。 假设 ω 同时属于 {An​ i.o.}。满足 ∣Xm​(ω)∣≥m 的 m 有无穷多个，其中有无穷多个 m>N；对每个这样的 m，令 n=m−1≥N，则 ∣Xn+1​∣≥n+1。对这些 n，由第 4 步和三角不等式 ∣a−b∣≥∣b∣−∣a∣：

​nSn​​−n+1Sn+1​​​ ≥ n+1∣Xn+1​∣​−​n(n+1)Sn​​​ > 1−31​=32​.

这样的 n 有无穷多个，所以左边不趋于 0，与第 5 步矛盾。因此

C∩{An​ i.o.}=∅.

第 7 步：结论。 由第 6 步，C⊆{An​ i.o.}c；由第 3 步，后者的概率是 1−1=0。所以 P(C)=0。■

第 5–6 步的另一种说法（第 3 讲 第 13 页 的写法）：在 C 上，由第 4 步，n+1Xn+1​​=n(n+1)Sn​​−(nSn​​−n+1Sn+1​​)→0−0=0，即 Xm​/m→0；而在 {An​ i.o.} 上 ∣Xm​∣/m≥1 无穷多次。两者不能同时成立。原解答的「>32​」只是把这个矛盾写成了具体的数。

原解答逐行对照

等号是尾积分公式，不等号是上阶梯（每段 [n,n+1) 上，尾函数不超过左端点的值）。两步都对。

这一句把三件事压在了一起：期望无穷 ⇒ 级数发散；同分布 ⇒ 级数就是 ∑n​P(∣Xn​∣>n)；独立 ⇒ 事件 {∣Xn​∣≥n} 独立，可以用第二引理。

第二引理要求的是事件相互独立、事件的概率之和发散。「i.i.d.」里的「同分布」负责后者（把概率换成 X1​ 的尾概率），「独立」负责前者（{∣Xn​∣≥n}={Xn​∈Bn​}）。只写「i.i.d.」，读者看不出两个字分别用在哪里。

例子与数值验证

例 1：独立同分布的柯西变量——平均值永远在跳

Xn​ 服从标准柯西分布，P(∣X1​∣≥t)=1−π2​arctant≈πt2​（t 大时）。

越线次数：前 N 项中满足 ∣Xn​∣≥n 的平均个数是 ∑n=1N​(1−π2​arctann)。Python 算得：N=103 时约 4.59，N=106 时约 8.99，大致像 π2​lnN 那样增长——极慢，但趋于无穷，和第二引理一致。

很多条路径：一个已知事实（用特征函数可以证明，这里作为已知结论使用）是 Sn​/n 本身仍服从标准柯西分布，所以 P(∣Sn​/n∣>1)=21​ 对每个 n 都成立。模拟 2 万条路径，n=1000 时 ∣Sn​/n∣>1 的比例是 0.49985。平均 1000 个数并没有让结果更集中。

例 2：非负的 1/U——极限存在，但等于 +∞

Xn​=1/Un​，Un​ 独立、在 (0,1) 上均匀，EX1​=∞。由本题，Sn​/n 没有有限极限。但由于 Xn​≥1>0，实际发生的是 Sn​/n→+∞ 几乎必然（Durrett 第 2.4 节；思路：把 Xn​ 截断成 min(Xn​,M)，对截断后的变量用强大数定律，再让 M→∞）。

一条模拟路径（Python，numpy.random.default_rng(1)）上 Sn​/n 的值（括号里是 lnn）：n=10 时 5.83（2.30），n=102 时 6.94（4.61），n=103 时 6.27（6.91），n=104 时 10.76（9.21），n=105 时 28.34（11.51），n=106 时 14.13（13.82）。第 98886 项出现了一个约 1.3×106 的巨大观测值，一下子把平均值从 15.5 抬到 28.6，此后慢慢回落，但整体趋势随 lnn 一起往上走。

这说明题目写 (−∞,∞) 是有意的：结论只排除有限极限，不排除 ±∞。

例 3（反例）：去掉独立，两个结论都会失败

令 X 服从标准柯西分布，每个 Xn​=X。同分布，E∣X1​∣=∞，但不独立。

  • 第一个结论失败：X(ω) 是有限数，∣X(ω)∣≥n 只对有限个 n 成立，所以 P(∣Xn​∣≥n i.o.)=0。证明坏在第 3 步：事件 {∣X∣≥n} 一个套一个，不独立，第二引理用不上，尽管概率之和照样发散。
  • 第二个结论失败：Sn​/n=nX/n=X，对每个 ω 都收敛到有限数 X(ω)，所以 P(C)=1。
例 4（对照）：一阶矩有限时一切正常

Xn​∼Exp(1) 独立同分布，EX1​=1<∞。

  • ∑n​P(Xn​≥n)=∑n​e−n<∞，由第一引理，Xn​≥n 只发生有限次（第 3 讲 第 11 页 推论 8 说得更多：Xn​/n→0 a.s.）。
  • 强大数定律：Sn​/n→1。一条模拟路径在 n=10,102,…,106 的值是 0.885, 0.955, 0.970, 0.986, 0.997, 1.001，稳稳地靠近 1。

拓展延伸

强大数定律及其逆：独立同分布时的完整图景

把本题和强大数定律合起来，对独立同分布序列：

nSn​​ 几乎必然收敛到有限数⟺E∣X1​∣<∞,此时极限=EX1​.

而且本题说明「收敛到有限数」的概率只能是 0 或 1，没有中间情况。这和第 3 讲 第 11 页、第 13 页 的二分法（Xn​/n→0 a.s. ⟺E∣X1​∣<∞）是平行的：单项的次线性增长和平均值的收敛，由同一个条件决定。

更强的结论：lim sup |Sₙ|/n = ∞

第 3 讲 第 13 页 定理 9 说 limsupn​∣Xn​∣/n=∞ a.s.。由 Xn​=Sn​−Sn−1​，

n∣Xn​∣​≤n∣Sn​∣​+n∣Sn−1​∣​≤n∣Sn​∣​+n−1∣Sn−1​∣​.

若某个 ω 上 limsupn​∣Sn​∣/n=L<∞，则 n 足够大时右边两项都 ≤L+1，于是 ∣Xn​∣/n≤2(L+1)，与 limsup∣Xn​∣/n=∞ 矛盾（除了一个概率 0 的事件）。所以 limsupn​∣Sn​∣/n=∞ a.s.：平均值不仅不收敛，而且无界。作业 2 第 5 题 进一步把除数 n 换成一般的 an​。

C 是一个事件吗？

要谈 P(C)，C 必须属于 F。数列收敛到有限数等价于它是柯西列（任给 k1​，从某项起任意两项之差 ≤k1​），所以

C=k≥1⋂​ N≥1⋃​ m,n≥N⋂​{​mSm​​−nSn​​​≤k1​}.

里面每个集合都是事件（Sm​/m−Sn​/n 是随机变量），外面只用了可数次交、并，所以 C∈F。

常见疑问与易错点

易错点问：P(C) = 0 是不是说 Sₙ/n → +∞ 或 −∞？

答：不是。ω∈/C 包含两种情况：极限是 ±∞（例 2，非负的 1/U），或者极限根本不存在（例 1，柯西变量的平均值来回跳）。本题只说「有限极限」几乎不可能。

易错点问：第二部分用到独立性了吗？

答：没有直接用到。第 4–7 步只用了恒等式和极限运算，对任何序列都成立；独立性只通过第一部分的结论「P(∣Xn​∣≥n i.o.)=1」进入。例 3 说明，一旦第一部分失败，第二部分也会失败。

易错点问：为什么是 2/3？换成 1/2 行不行？

答：行。只要先取 N 使 n≥N 时 ​n(n+1)Sn​​​<η（0<η<1），就得到差值 >1−η 无穷多次。原解答取 η=31​，所以是 32​。重要的是这个下界是一个固定的正数，而收敛要求差值趋于 0。

易错点问：第一部分为什么不能直接说「E|X₁| = ∞，所以 P(|X_n| ≥ n) 不趋于 0」？

答：因为这不对。柯西分布的 P(∣Xn​∣≥n)≈πn2​→0，但和 ∑πn2​ 发散。第二引理要的正是「和发散」，不是「各项不趋于 0」。「各项趋于 0 但和发散」恰好是期望无穷时的典型样子。
