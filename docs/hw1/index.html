原解答问题速览12 道题 · 36 处

解答原页不是标准答案：下面是各题精讲里指出的笔误、跳步和错误（「题目」表示题面本身的问题）。点题目标题直接跳到那道题的「原解答逐行对照」，那里有正确写法。考前复习时，这些地方最容易丢分。

  1. 01任何随机变量序列都能被某个 cₙ → ∞ 压到 0
    • 问题要选的是 cₙ，而且没说明它为什么存在
    • 问题2² 应为 2ⁿ
    • 问题没有保证 cₙ → ∞
    • 问题「ε < 1/N」方向写反，最后一个等号也缺理由
  2. 02独立序列：sup Xₙ 有限 ⇔ 某个 A 使 ∑ P(Xₙ > A) 有限
    • 问题反证的假设必须写成「对每个 A」
    • 问题引理名拼写、引理编号、事件独立性
    • 问题从「每个 A 概率为 1」到「sup = ∞ a.s.」要用可数交
    • 问题「similarly」不恰当，最后一步有跳步
  3. 03均值无穷时 |Xₙ| ≥ n 无穷多次，Sₙ/n 没有有限极限
    • 问题求和从 n = 0 开始，还要从「>」过渡到「≥」
    • 问题第二引理的两个条件各从哪里来，应当写明
    • 问题「> 2/3」的来历没有交代
    • 问题笔误 E[|X|₁]，以及「必要」的确切含义
  4. 04独立伯努利序列：依概率收敛 ⇔ pₙ → 0，几乎必然收敛 ⇔ ∑ pₙ < ∞
    • 问题(i) 漏了 ε ≥ 1，而且写法像循环论证
    • 问题ε 没有限定，也没说明 a.s. 收敛为什么等价于 P(Aₙ i.o.) = 0
  5. 05独立 Exp(1) 序列：lim sup Xₙ / ln n = 1 几乎必然
    • 问题n = 1 和 α 的范围
    • 问题m 要取正整数，「and so」中间缺两步
    • 问题P(L ≥ 1 + 1/n) = 0 不能直接从第 4 行得到，需要留余量
  6. 06依测度收敛：和总能保持，积需要有限测度
    • 问题(i) 中的 ε 应为 ε/2，原不等式不成立
    • 问题M 应为 M₁，「>」应为「≥」
    • 问题(ii) 第 3–5 行的笔误
    • 问题极限的顺序、有限测度用在哪里、记号
    • 问题缺少 μ(Ω) = ∞ 时的反例
  7. 07Hölder 不等式（指数 3/2 与 3）的应用：常数 4/25 与等号条件
    • 问题只证明了「充分」，c 的符号也不对
    • 问题用的是 Hölder，不是 Cauchy–Schwarz
  8. 08积分的绝对连续性：小集合上的积分一定小（ε–δ 刻画）
    • 问题f 应为 |X|，还要求 0 ≤ φ ≤ |X|
    • 问题δ 可能除以 0，界也取得太粗
    • 问题第一个「<」没有根据
    • 问题证法二的小毛病
  9. 09用控制收敛定理求 lim ∫ k ln(1 + f²/k²) dμ（答案是 0）
    • 问题换元造成记号混乱，且没有必要
    • 问题最关键的不等式没有证明
    • 问题逐点极限没有说明，连续参数也要交代
  10. 10推广的控制收敛定理：控制函数也可以随 n 变
    • 问题g 应为 gₙ，而且「f_n + g ≥ 0」一般不成立
    • 问题漏掉了 ∫gₙ → ∫g 这一步
    • 问题Fatou 给的是「≤」，不是「=」；还有笔误
  11. 11逐点收敛的非负函数：三种附加条件下，积分是否跟着收敛
    • 问题原解答的小问题
  12. 12|f| ≤ 1 时 ∫√(1−f²) ≤ √(1−(∫f)²)：单位圆上的点，平均起来落在圆盘里
    • 问题等号条件找错了地方
