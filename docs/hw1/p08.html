这道题在问什么

人话版一句话版

可积函数不能把大量的「积分质量」堆在测度很小的集合上：任给 ε>0，总有 δ>0，只要 μ(F)<δ，就有 ∫F​∣X∣dμ<ε。理由一句话：∣X∣ 只可能在小集合上很大，而它的总积分有限，所以「很大的部分」本身积分就小；剩下「不太大的部分」在小集合上的积分不超过「上限 × 测度」。两种证法分别用简单函数和截断来实现这个拆分。

  • 考点：用简单函数从下逼近积分（第 1 讲 第 30 页、第 33 页、第 34 页）；控制收敛定理 / 单调收敛定理（第 1 讲 第 44 页、第 36 页）；按 {∣X∣≤n}、{∣X∣>n} 截断。
  • 和其他题的关系：小测 2 第 3 题 把本题推广到一族随机变量（一致绝对连续），小测 2 第 2 题 的「单个可积变量一致可积」用的是本题证法二同样的截断。第 6 题 的乘积证明也用了截断技巧。

先补基础

基础补课集合上的积分 ∫_F |X| dμ
  • 定义：∫F​∣X∣dμ:=∫∣X∣1F​dμ，即把 F 外面的值改成 0 再积分。
  • 单调：F⊆G 时 ∣X∣1F​≤∣X∣1G​，所以 ∫F​∣X∣≤∫G​∣X∣。
  • 可加：F 拆成两个不相交的部分 F1​∪F2​ 时，∫F​∣X∣=∫F1​​∣X∣+∫F2​​∣X∣（因为 1F​=1F1​​+1F2​​）。
  • 例：[0,1] 上 X(x)=x，∫[0,1/2]​xdx=81​，∫(1/2,1]​xdx=83​，加起来 21​。
基础补课简单函数，以及「从下逼近」积分（第 1 讲 p30、p33）
  • 简单函数（simple function）：只取有限个值的可测函数，写成 φ=∑k=1m​ak​1Ak​​。Ak​ 两两不交、ak​≥0 时，∫F​φ=∑k​ak​μ(Ak​∩F)。
  • 简单函数有界：它的最大值 K=maxk​ak​ 是有限数，所以 ∫F​φ≤Kμ(F)（每一项 ak​μ(Ak​∩F)≤Kμ(Ak​∩F)，再用 Ak​∩F 两两不交）。
  • 非负可测函数的积分定义为 ∫∣X∣=sup{∫φ: φ 简单, 0≤φ≤∣X∣}（第 1 讲 第 33 页 定义 27）。所以当 ∫∣X∣<∞ 时，对任意 η>0，存在简单函数 0≤φ≤∣X∣，使 ∫(∣X∣−φ)<η（上确界的定义：比上确界小一点点的数不再是上界）。
  • 例：X(x)=x 在 [0,1] 上，φ=21​1[1/2,1]​ 满足 0≤φ≤X，∫(X−φ)=21​−41​=41​；分得更细，误差可以任意小（二进逼近，第 1 讲 第 34 页）。
基础补课可积函数几乎处处有限

若 ∫∣X∣<∞，则 μ(∣X∣=∞)=0。理由：对每个 n，∣X∣≥n1{∣X∣=∞}​，积分得 nμ(∣X∣=∞)≤∫∣X∣；若 μ(∣X∣=∞)>0，令 n→∞ 左边趋于 ∞，矛盾。所以 ∣X∣1{∣X∣>n}​→0 几乎处处：对每个使 ∣X(ω)∣<∞ 的 ω，n 超过 ∣X(ω)∣ 之后这一项就是 0。

基础补课控制收敛定理（回顾，第 1 讲 p44）

若 hn​→h a.e.，且存在可积的 G 使 ∣hn​∣≤G a.e. 对所有 n 成立，则 ∫hn​→∫h。证法二取 hn​=∣X∣1{∣X∣>n}​，h=0，G=∣X∣。

基础补课ε–δ 的读法

「任给 ε>0，存在 δ>0，使得只要 μ(F)<δ 就有 ∫F​∣X∣<ε」：先有人给你一个容忍度 ε，你要给出一个门槛 δ；δ 可以依赖 ε（和 X），但不能依赖 F——同一个 δ 要对所有测度小于 δ 的集合同时管用。这和函数连续性的 ε–δ 定义是同一种句式。

题目与原解答

课件原文题目
  1. Let X be an integrable function on (Ω,F,μ). Then for any ε>0, there exists δ>0 such that
F∈F, μ(F)<δ⟹∫F​∣X∣dμ<ε.
中文翻译
  1. 设 X 是 (Ω,F,μ) 上的可积函数。证明：对任意 ε>0，存在 δ>0，使得只要 F∈F 且 μ(F)<δ，就有 ∫F​∣X∣dμ<ε。
  • 「Then …」按意思是「证明 …」。
  • 「可积」（integrable）：∫∣X∣dμ<∞。题目没有假设 μ(Ω)<∞，结论对无穷测度空间也成立。

原解答的思路（左栏）：

  1. 证法一：取简单函数 φ 使「∫f−φdμ<2ε​」；∫A​φ≤μ(A)∑ak​，取 δ=2∑ak​ε​；
  2. 证法二（「or」之后）：令 Xn​=∣X∣1{∣X∣>n}​，由 DCT 取 n 使 ∫{∣X∣>n}​∣X∣<2ε​；拆分 ∫A​∣X∣≤nμ(A)+2ε​，取 δ=2nε​。

两种思路都对。证法一的记号混乱（f、x、X 混用）、逼近的对象没说清，导致最后一个不等式不成立，δ 还可能除以 0；证法二基本正确，只有字母 F、A 混用和 DCT 条件没写。见「原解答逐行对照」。

思路：怎么想到的

  1. 什么样的 F 会让 ∫F​∣X∣ 大？ 只能是 ∣X∣ 很大的地方。如果 ∣X∣ 有上界 K，那么 ∫F​∣X∣≤Kμ(F)，取 δ=ε/K 就完事了。
  2. 困难：∣X∣ 可以无界（例如 x−1/2 在 0 附近）。办法是把 ∣X∣ 拆成「有界的部分」+「余下的部分」：有界部分用第 1 条处理；余下部分在整个空间上的积分就很小，在 F 上当然更小。
  3. 两种拆法：证法一用简单函数 φ≤∣X∣ 当「有界部分」，余下的 ∣X∣−φ 积分很小来自积分的定义；证法二用截断 ∣X∣1{∣X∣≤n}​ 当「有界部分」，余下的 ∣X∣1{∣X∣>n}​ 积分很小来自 DCT。

完整解答

定理命题（积分的绝对连续性）

设 ∫∣X∣dμ<∞。则对任意 ε>0，存在 δ>0，使对所有满足 μ(F)<δ 的 F∈F，都有 ∫F​∣X∣dμ<ε。

推导证明思路

把 ∣X∣ 写成「有界部分 + 积分很小的部分」：有界部分在 F 上的积分 ≤ 上界 ×μ(F)，用 δ 控制；积分很小的部分直接 <2ε​。

证法一：简单函数逼近

第 1 步：选 φ。 由「先补基础」，存在简单函数 φ，满足 0≤φ≤∣X∣ 且

∫(∣X∣−φ)dμ<2ε​.

第 2 步：φ 有界。 记 K=maxφ（φ 只取有限个值，K 是有限的非负数）。对任何 F，∫F​φ≤Kμ(F)。

第 3 步：定 δ。 令 δ=2(K+1)ε​（分母加 1 是为了 K=0 时也有意义）。若 μ(F)<δ，则

∫F​∣X∣=∫F​(∣X∣−φ)+∫F​φ≤∫(∣X∣−φ)+Kμ(F)<2ε​+2(K+1)Kε​<2ε​+2ε​=ε.

第一个等号：∣X∣=(∣X∣−φ)+φ，两部分都非负；第一个不等号：∣X∣−φ≥0，F 换成整个空间积分只会变大，以及第 2 步。■

证法二：截断 + 控制收敛定理

第 1 步：大值部分的积分趋于 0。 令 hn​=∣X∣1{∣X∣>n}​。由「先补基础」，hn​→0 a.e.；又 0≤hn​≤∣X∣，∣X∣ 可积。由 DCT，

∫{∣X∣>n}​∣X∣dμ=∫hn​dμ→0.

所以可以取正整数 N 使 ∫{∣X∣>N}​∣X∣<2ε​。

第 2 步：定 δ 并拆分。 令 δ=2Nε​。若 μ(F)<δ，把 F 拆成 F∩{∣X∣≤N} 和 F∩{∣X∣>N}：

∫F​∣X∣=∫F∩{∣X∣≤N}​∣X∣+∫F∩{∣X∣>N}​∣X∣≤Nμ(F)+∫{∣X∣>N}​∣X∣<N⋅2Nε​+2ε​=ε.

第一块里 ∣X∣≤N；第二块把 F 去掉，集合变大，积分不减。■

用 MCT 代替 DCT 也可以：∣X∣1{∣X∣≤n}​↑∣X∣ a.e.，由 MCT，∫{∣X∣≤n}​∣X∣↑∫∣X∣<∞，两者之差 ∫{∣X∣>n}​∣X∣→0。

等价的序列说法

推论：若 μ(Fn​)→0，则 ∫Fn​​∣X∣→0。证明：任给 ε，取命题中的 δ；n 足够大时 μ(Fn​)<δ，于是 ∫Fn​​∣X∣<ε。

原解答逐行对照

证法一 第 1 句 Due to X is an integrable function, there is a simple function ϕ s.t. ∫f−ϕdμ<2ε​.

想说的是完整解答证法一第 1 步。

易错点原解答的问题：f 应为 |X|，还要求 0 ≤ φ ≤ |X|
  • f 在题目中没有出现，应为 ∣X∣；式子应写成 ∫(∣X∣−φ)dμ<2ε​。
  • 必须说明 φ 满足 0≤φ≤∣X∣：这样 ∣X∣−φ≥0，而且这样的 φ 的存在性正是积分定义（上确界）给的。不加这个条件，「∫(∣X∣−φ) 很小」并不能推出 ∣X∣−φ 在 F 上的积分也很小（正负可以抵消）。
  • 英文：Due to X is 应为 Since X is。

证法一 第 2 句 We can rewrite ϕ=Σak​IAk​​⇒∫A​ϕdμ=∑ak​μ(Ak​∩A)≤μ(A)∑k=1n​ak​

把简单函数写成示性函数的组合，算出它在 A 上的积分。不等号用的是 μ(Ak​∩A)≤μ(A) 和 ak​≥0。

证法一 第 3 句 we can set δ=2Σak​ε​.

易错点原解答的问题：δ 可能除以 0，界也取得太粗
  • 若 φ≡0（例如 ∫∣X∣<2ε​ 时可以取 φ=0），∑ak​=0，δ 没有定义。应写成 δ=2(1+∑ak​)ε​，或者像完整解答那样用最大值 K：δ=2(K+1)ε​。
  • ∑ak​ 依赖于 φ 的写法（同一个函数可以有不同的写法），用 K=maxak​（Ak​ 两两不交）更自然：∫A​φ≤Kμ(A)，界也更紧。

证法一 第 4 句 Then ∫F​∣x∣dμ≤∫F​∣x−ϕ∣dμ+∫F​∣ϕ∣dμ<2ε​+μ(F)∑ak​<2ε​+2ε​=ε.

易错点原解答的问题：第一个「<」没有根据
  • 小写 x 应为 X。
  • 不等式 ∣X∣≤∣X−φ∣+∣φ∣ 本身对，但接下来需要 ∫F​∣X−φ∣<2ε​，而第 1 句给的是 ∫(∣X∣−φ)<2ε​。两者不同：在 X<0 的地方，∣X−φ∣=∣X∣+φ，比 ∣X∣−φ 大。例：X=−1、φ=1 处，∣X∣−φ=0，∣X−φ∣=2。
  • 改正：直接写 ∫F​∣X∣=∫F​(∣X∣−φ)+∫F​φ≤∫(∣X∣−φ)+Kμ(F)（完整解答第 3 步）。另一种改法是让 φ 在 L1 意义下逼近 X 本身（∫∣X−φ∣<2ε​，φ 可正可负），那时第一行的写法就对了，但要把 ∑ak​ 换成 ∑∣ak​∣。

证法二 Let Xn​≜∣X∣1{∣X∣>n}​. By DCT, ∫Ω​Xn​dμ=∫{∣X∣>n}​∣X∣dμ→0 … For any measurable set A, ∫A​∣X∣=∫F∩{∣X∣≤n}​∣X∣+∫A∩{∣X∣>n}​∣X∣≤nμ(A)+∫{∣X∣>n}​∣X∣<nμ(A)+2ε​<ε, δ=2nε​.

这正是完整解答证法二，思路正确。

易错点原解答的问题：证法二的小毛病
  • DCT 的两个条件没写：Xn​→0 a.e.（因为可积函数几乎处处有限），∣Xn​∣≤∣X∣ 且 ∣X∣ 可积。
  • 第一个积分下标里的 F 应为 A（同一个集合，字母前后不一致）。
  • 「<ε」要在 μ(A)<δ 时才成立，而 δ=2nε​ 写在了最后。逻辑顺序应是：先取 n，再令 δ=2nε​，然后对任意 μ(A)<δ 的 A 推出 ∫A​∣X∣<ε。

例子与数值验证

例 1：X(x) = x^{−1/2}，把三种 δ 都算出来

在 (0,1] 上（勒贝格测度），X(x)=x−1/2 无界，但可积：∫01​x−1/2dx=2。取 ε=0.1。

最好的 δ：X 递减，在测度为 t 的集合中，(0,t] 上的积分最大（把 F 中位于 t 右边的部分换成 (0,t] 中同样测度、不在 F 里的部分，被积函数只会变大）。∫0t​x−1/2dx=2t​，要 2t​≤ε，即 t≤4ε2​=0.0025。所以最好的 δ 是 0.0025。

证法二的 δ：{X>N}=(0,N21​)，∫01/N2​x−1/2=N2​。要 N2​<0.05，取 N=41（412​≈0.0488），δ=820.1​≈0.00122。

证法一的 δ：取二进逼近 φN​=min(2−N⌊2NX⌋,N)≤X。误差 ∫(X−φN​)≤N1​+2−N（{X≥N} 上贡献 N2​−N1​=N1​，其余地方误差不超过 2−N）。N=21 时 ≤0.04762+0.0000005<0.05；K=21，δ=2⋅220.1​≈0.00227。

两种证法给出的 δ 都比最好的小，这没关系：题目只要求存在一个能用的 δ。

例 2（反例）：去掉可积性，结论失败

(0,1] 上 X(x)=x1​，∫01​xdx​=∞。对任何 δ>0，取 F=(0,2δ​)，μ(F)<δ，但 ∫F​xdx​=∞。不存在能用的 δ。证明坏在哪里：证法二里 ∫{∣X∣>n}​∣X∣=∫01/n​xdx​=∞，不趋于 0。

例 3：反过来不成立——绝对连续不推出可积

R 上 X≡1，不可积（∫R​1=∞）。但 ∫F​1=μ(F)，取 δ=ε 就有「μ(F)<δ⇒∫F​∣X∣<ε」。所以在无穷测度空间上，本题的结论比可积性弱。（在概率空间上加上「总量有界」，两者才接近，见小测 2 第 3 题。）

例 4：每个都绝对连续，但不「一致」

尖峰 Xn​=n1(0,1/n)​ 在 [0,1] 上，每个都可积，由本题各有自己的 δn​。取 ε=21​：F=(0,n1​) 时 ∫F​Xn​=1，所以 δn​ 必须 ≤n1​。n→∞ 时 δn​→0，没有一个公共的 δ 对所有 Xn​ 管用。这正是小测 2 第 3 题 里「一致绝对连续」要排除的情况。

拓展延伸

测度的绝对连续与 Radon–Nikodym 定理

令 ν(F)=∫F​∣X∣dμ，它是一个测度（可数可加性来自 MCT）。本题说：μ(F) 小 ⇒ ν(F) 小；特别地 μ(F)=0⇒ν(F)=0，记作 ν≪μ（ν 关于 μ 绝对连续）。测度论的 Radon–Nikodym 定理（这里作为已知结论介绍）说反过来也对：若 μ 是 σ-有限测度、ν 是有限测度且 ν≪μ，则存在可积的 h≥0 使 ν(F)=∫F​hdμ。概率论里的「密度」就是这样来的：随机变量有密度 ⟺ 它的分布关于勒贝格测度绝对连续。

从一个函数到一族函数：一致可积
  • 有限个可积函数：各取 δi​，再取 δ=mini​δi​，一个 δ 对所有成员管用。
  • 无穷多个就不一定（例 4）。「存在公共的 δ」叫一致绝对连续，在概率空间上它加上 supE∣Xt​∣<∞ 等价于一致可积（小测 2 第 2 题、小测 2 第 3 题）。一致可积是「依概率收敛 + 一致可积 ⟺ L1 收敛」（Vitali 收敛定理）里的关键条件。
与微积分的联系：变上限积分是绝对连续函数

令 G(x)=∫0x​f(t)dt（f 在 [0,1] 上可积）。对互不相交的小区间 (ai​,bi​)，取 F=⋃i​(ai​,bi​)，本题给出：∑i​(bi​−ai​)<δ⇒∑i​∣G(bi​)−G(ai​)∣≤∫F​∣f∣<ε。这正是实分析中「绝对连续函数」的定义；勒贝格积分版本的微积分基本定理说，绝对连续函数恰好就是变上限积分。

常见疑问与易错点

易错点问：δ 能不能随 F 变？

答：不能。若允许 δ 依赖 F，对 μ(F)>0 的 F 只要取 δ=μ(F)，条件「μ(F)<δ」就不成立，命题自动为真；对 μ(F)=0 的 F，∫F​∣X∣=0 本来就成立。这样命题对任何可测函数都成立，成了一句空话（例 2 的 x1​ 也「满足」）。本题的力量在于：一个 δ 同时管住所有测度小于 δ 的集合，不管它们长什么样、在什么位置。

易错点问：证法一为什么一定要 φ ≤ |X|？

答：两个用处：(1) 让 ∣X∣−φ≥0，于是「它在整个空间上的积分小」能推出「它在 F 上的积分也小」；(2) 这样的 φ 的存在性正是非负函数积分的定义（取简单函数下方逼近的上确界）。没有 φ≤∣X∣，原解答最后一行就出了问题。

易错点问：无穷测度空间上也成立吗？

答：成立。两种证法都没有用到 μ(Ω)<∞，只用到 ∫∣X∣<∞。例 3 甚至说明，无穷测度时这个性质可能对不可积函数也成立。

易错点问：为什么证法二要用 DCT，直接说「n 大时 {|X| > n} 的测度小」不行吗？

答：不够。测度小不等于积分小——这正是本题要证的东西，不能拿来用。证法二需要的是大值部分的积分 ∫{∣X∣>n}​∣X∣ 趋于 0，这要靠 DCT（或 MCT）和可积性。

小结与自测

小结本题小结
  • 结论：X 可积 ⇒ 任给 ε 有 δ，μ(F)<δ⇒∫F​∣X∣<ε；等价地，μ(Fn​)→0⇒∫Fn​​∣X∣→0。
  • 证法一：简单函数 0≤φ≤∣X∣，∫(∣X∣−φ)<2ε​，δ=2(K+1)ε​，K=maxφ。
  • 证法二：DCT 给出 ∫{∣X∣>N}​∣X∣<2ε​，δ=2Nε​。
  • 可积性不能去掉（x1​）；单个函数可以，一族函数不一定有公共的 δ（尖峰）。
  • 原解答要改的地方：f 应为 ∣X∣ 且要 0≤φ≤∣X∣；∫F​∣X−φ∣ 应为 ∫F​(∣X∣−φ)；δ 的分母可能为 0；证法二的 F/A 混用与 DCT 条件。
自测

1. (0,1] 上 X(x)=x−1/3，ε=0.3。求最大的 δ，使 μ(F)<δ⇒∫F​X<0.3。

点开看答案

X 递减，最坏的集合是 (0,t]：∫0t​x−1/3dx=23​t2/3。要 23​t2/3≤0.3，即 t2/3≤0.2，t≤0.23/2≈0.0894。所以 δ=0.0894（μ(F)<δ 时 ∫F​X<23​δ2/3=0.3）。

2. 用本题证明：若 X 可积，则 ∫[0,1/n]​∣X∣dx→0（μ 为 [0,1] 上的勒贝格测度）。

点开看答案

Fn​=[0,n1​]，μ(Fn​)=n1​→0。由推论，∫Fn​​∣X∣→0。也可以直接用 DCT：∣X∣1Fn​​→0 a.e.（除了 x=0），被 ∣X∣ 控制。

3. 判断：「在 [0,1]（勒贝格测度）上，若可测函数 X 满足本题的结论，则 X 可积。」对照例 3 说明为什么 [0,1] 和 R 不一样。

点开看答案

正确。取 ε=1，得到 δ。把 [0,1] 等分成 N 个长度小于 δ 的小区间 I1​,…,IN​（N>δ1​ 即可），每个上 ∫Ij​​∣X∣<1，所以 ∫01​∣X∣≤∑j=1N​∫Ij​​∣X∣<N<∞。R 不一样，是因为它要无穷多个小区间才能盖住，每块积分小于 1 加起来仍可能是 ∞（例 3 的 X≡1）。
