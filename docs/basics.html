易错点读「∀ ∃」句子的诀窍

2. 集合

基础补课元素与子集
  • a∈A：a 属于 A；a∈/A：不属于。
  • A⊆B：A 的每个元素都在 B 里。要证明 A⊆B，就任取 a∈A，证明 a∈B。
  • A=B 的意思是 A⊆B 且 B⊆A。这是证明两个集合相等的标准办法（「双向包含」）。
  • 空集 ∅：没有元素。它是任何集合的子集。
基础补课集合的写法
  • 列举法：{1,2,3}。元素没有顺序、不重复：{1,2}={2,1}={1,1,2}。
  • 描述法：{x∈R:x2<4}=(−2,2)。冒号读作「使得」。
  • 区间：[a,b]={x:a≤x≤b}（含端点），(a,b) 不含端点，[a,b) 含左不含右。(0,∞) 是全体正实数。
基础补课并、交、补、差

设 A,B⊆Ω：

A∪BAc​={ω:ω∈A 或 ω∈B},={ω∈Ω:ω∈/A},​A∩BA∖B​={ω:ω∈A 且 ω∈B},=A∩Bc.​

无穷多个集合也一样：

n=1⋃∞​An​={ω: 至少有一个 n 使 ω∈An​},n=1⋂∞​An​={ω: 对所有 n 都有 ω∈An​}.
例：无穷并与无穷交

令 An​=[0,1−n1​]。A1​={0}，A2​=[0,21​]，A3​=[0,32​]，…… 越来越大。

  • ⋃n​An​=[0,1)：任何 x<1 迟早落进某个 An​（取 n>1/(1−x)），但 x=1 永远进不去。
  • 令 Bn​=(0,n1​)，越来越小。⋂n​Bn​=∅：任何 x>0，只要 n>1/x 就有 x∈/Bn​。
基础补课德摩根律
(n⋃​An​)c=n⋂​Anc​,(n⋂​An​)c=n⋃​Anc​.

人话：「不是（至少一个发生）」＝「一个都不发生」；「不是（全都发生）」＝「至少一个不发生」。它让我们可以在「并」和「交」之间来回转换，σ-代数的定义里只要求对并封闭，就是靠它推出对交也封闭。

基础补课集合族与幂集
  • 集合族：元素是集合的集合，例如 {∅,{1},{1,2}}。
  • 幂集 2Ω：Ω 的全部子集。Ω={1,2} 时，2Ω={∅,{1},{2},{1,2}}，共 22=4 个。
  • 三层要分清：ω∈A（点属于集合），A∈F（集合属于集合族），A⊆Ω（集合包含于集合）。

3. 函数与原像

基础补课函数

f:A→B：给 A 中每个元素指定 B 中唯一一个元素 f(a)。A 叫定义域，B 叫陪域。

  • 像：f(E)={f(a):a∈E}，把 E 里的点都送过去得到的集合。
  • 原像：f−1(D)={a∈A:f(a)∈D}，「所有被送进 D 的输入」。注意：原像不需要 f 有反函数，f−1(D) 只是一个集合的名字。
例：原像

f(x)=x2，A=R。

  • f−1([0,4])={x:x2≤4}=[−2,2]；
  • f−1({9})={−3,3}；
  • f−1((−∞,0))=∅（没有实数的平方是负数）。

概率里最常见的写法 {X≤x} 就是原像：{X≤x}=X−1((−∞,x])={ω:X(ω)≤x}。

基础补课原像保持所有集合运算（测度论最常用的性质）
f−1(n⋃​Dn​)=n⋃​f−1(Dn​),f−1(n⋂​Dn​)=n⋂​f−1(Dn​),f−1(Dc)=(f−1(D))c.

理由（以并为例）：a∈f−1(⋃Dn​)⟺f(a)∈⋃Dn​⟺ 存在 n 使 f(a)∈Dn​⟺ 存在 n 使 a∈f−1(Dn​)。正因为这个性质，「可测函数」和「分布」的定义才顺理成章。

基础补课示性函数
1A​(x)={1,0,​x∈A,x∈/A.​

它把「集合」变成「函数」：1A∩B​=1A​1B​，1Ac​=1−1A​；A,B 不相交时 1A∪B​=1A​+1B​。在概率里，E[1A​]=P(A)。

4. 数列与极限

基础补课极限的定义（慢慢读）

an​→a（读作「an​ 收敛到 a」）的意思是：

∀ε>0, ∃N, 使得 n≥N 时 ∣an​−a∣<ε.

逐字翻译：不管你要求多近（任意 ε），总能找到一个位置 N，从这以后所有项都离 a 不超过 ε。

例：证明 1/n → 0

给定 ε>0。要让 ∣1/n−0∣<ε，只要 n>1/ε。所以取 N 为大于 1/ε 的整数，n≥N 时就有 1/n≤1/N<ε。比如 ε=0.01 时取 N=101。

基础补课单调数列与无穷
  • 递增（不减）：a1​≤a2​≤⋯，记作 an​↑；递减记作 an​↓。
  • 单调收敛原理：递增的数列要么有上界并收敛到它的上确界，要么趋于 +∞。所以递增数列总有极限（可能是 ∞）。测度的连续性、MCT 都建立在这一点上。
  • 扩展实数 [−∞,∞]：允许取值 ±∞。约定 a+∞=∞（a>−∞），c⋅∞=∞（c>0），以及测度论专用的 0⋅∞=0。但 ∞−∞ 没有定义。

5. 上确界与下确界

基础补课sup 和 inf
  • 集合 E⊆R 的上界：大于等于 E 中所有元素的数。上确界 supE：最小的上界。
  • 下确界 infE：最大的下界。
  • 和最大值 max 的区别：最大值必须属于集合，上确界不必。
例：sup 不一定取得到
  • E=(0,1)：没有最大值（任何 x<1 都还有更大的 2x+1​<1），但 supE=1；也没有最小值，infE=0。
  • E={1−n1​:n≥1}={0,21​,32​,…}：supE=1（不属于 E），minE=infE=0。
  • 约定：没有上界时 supE=+∞。
基础补课最常用的两个性质
  1. 若 s=supE 有限，则对任意 ε>0，存在 x∈E 使 x>s−ε（「上确界可以被无限逼近」）。
  2. 若 E⊆F，则 supE≤supF，infE≥infF（集合越大，上确界越大、下确界越小）。外测度、勒贝格积分的定义都用到这两点。

6. 求和与级数

基础补课求和号

∑k=1n​ak​=a1​+a2​+⋯+an​。无穷级数 ∑k=1∞​ak​ 定义为部分和 Sn​=∑k=1n​ak​ 的极限。

例：三个必须记住的级数
  • 几何级数：∑n=1∞​2n1​=21​+41​+81​+⋯=1。它给出测度论里常用的「ε/2n 技巧」：想让可数个量的总和不超过 ε，就让第 n 个不超过 ε/2n。
  • 调和级数：∑n=1∞​n1​=∞（发散），尽管每一项都趋于 0。
  • ∑n=1∞​n21​=6π2​<∞（收敛）。
基础补课非负项级数：可以随便重排

每一项都 ≥0 时，部分和递增，所以级数总有值（可能是 ∞），而且任意重新排列、分组都不改变这个值。可数可加性里的 ∑n​μ(An​) 都是非负项级数，所以不用担心求和顺序。

7. 可数与不可数

基础补课定义

集合是可数的，如果它的元素能排成一列 x1​,x2​,x3​,…（有限集合也算可数）。排不成一列的无穷集合叫不可数。

例：有理数可数，实数不可数
  • 整数可数：0,1,−1,2,−2,3,−3,…
  • 有理数可数：把分数 p/q 按 ∣p∣+q=2,3,4,… 分组，每组只有有限个，一组一组往下排，就把所有有理数排成了一列。
  • [0,1] 不可数（康托尔对角线法）：假设能排成一列 x1​,x2​,…，写出它们的小数展开，构造一个数，让它第 n 位小数和 xn​ 的第 n 位不同，那么它和列表里每一个数都不同，矛盾。
人话版为什么测度论这么在乎「可数」

测度只要求可数可加：可数个不相交集合，测度可以相加。对不可数多个集合不要求（也做不到：[0,1] 是不可数个单点的并，每个单点长度 0，总长却是 1）。所以「可数」是测度论里「能相加」和「不能相加」的分界线。

8. 上极限与下极限

基础补课数列的 lim sup 与 lim inf
n→∞limsup​an​=N≥1inf​ n≥Nsup​an​,n→∞liminf​an​=N≥1sup​ n≥Ninf​an​.

先看「从第 N 项往后的尾巴」的最大可能值 supn≥N​an​，它随 N 增大而减小；它的极限就是上极限。下极限同理。数列收敛当且仅当上下极限相等。

例：a_n = (−1)^n

尾巴里永远既有 1 也有 −1，所以每个 supn≥N​an​=1，每个 infn≥N​an​=−1。于是 limsupan​=1，liminfan​=−1，不相等，数列不收敛。

基础补课集合的 lim sup 与 lim inf
nlimsup​An​=N≥1⋂​n≥N⋃​An​={ω: ω 属于无穷多个 An​},
nliminf​An​=N≥1⋃​n≥N⋂​An​={ω: 从某个 N 起，ω 属于所有 An​}.

读法：⋂N​⋃n≥N​ 是「对每个 N，都存在 n≥N」——不管从多靠后开始数，后面总还会再发生，也就是发生无穷多次。⋃N​⋂n≥N​ 是「存在 N，对所有 n≥N」——从某一刻起一直发生。详见第 1 讲 第 7 页、第 40 页。

9. 积分回顾

基础补课定积分的直观

∫ab​f(x)dx：函数图像与 x 轴之间的（带符号）面积。黎曼的做法：把 [a,b] 切成小段，每段用「长度 × 函数值」近似，再让小段越来越细取极限。

基础补课本课常用的积分
∫01​xndx=n+11​,∫0∞​e−λxdx=λ1​ (λ>0),∫01​x−αdx=⎩⎨⎧​1−α1​,∞,​α<1,α≥1.​

最后一个说明：函数在 0 附近无界，积分也可能有限（α<1 时），这在第 3 讲的重要性抽样里会用到。

10. 怎样读定义和定理

人话版三个习惯
  1. 先分清假设和结论。「若 A，则 B」中，A 是假设，B 是结论。把假设逐条列出来。
  2. 问每个假设为什么在那里。试着去掉它，找一个反例看结论怎样失败。课件里的反例（尖峰、[n,∞)、狄利克雷函数……）就是在做这件事。
  3. 定理是充分条件，不是必要条件。假设不满足时，结论可能仍然成立，只是这个定理不能保证。
例：读「从上连续」

「若 En​↓E 且 μ(E1​)<∞，则 μ(En​)→μ(E)。」

  • 假设 1：集合一层层变小；假设 2：第一个集合的测度有限。
  • 去掉假设 2：En​=[n,∞)，每个测度都是 ∞，交集是空集，测度为 0，结论失败。
  • 所以假设 2 不是多余的——这正是第 1 讲 第 14 页 标题里「necessary hypothesis（必要的假设）」的意思。
