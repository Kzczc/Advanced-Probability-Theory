先补基础

基础补课要证的是什么（命题 21 回顾）

设 P、Q 是 (Ω,F) 上的概率测度，Q≪P，L=dPdQ​（取值在 [0,∞)，第 27 页）。命题 21（第 32 页）说：

  1. 对每个可测的 X:Ω→[0,∞]，EQ​X=EP​[XL]（两边可以同时为 +∞）；
  2. 对每个可测的 X:Ω→R，X∈L1(Q)⟺XL∈L1(P)，并且此时 EQ​X=EP​[XL]。

上一页已经证明：当 X 是非负简单函数时，第 1 条成立。 这一页就从这里出发。

基础补课二进逼近：任何非负可测函数都能被递增的台阶逼近

第 1 讲定理 29（第 34 页）：若 X:Ω→[0,∞] 可测，则存在非负简单函数 s1​≤s2​≤⋯，使得对每个 ω，sn​(ω)↑X(ω)。一个具体的选法是

sn​=2−n⌊2n(X∧n)⌋,

意思是「先把 X 截在高度 n（X∧n 表示 X 和 n 中较小的那个），再向下取整到 2−n 的整数倍」。⌊a⌋ 读作「a 的下取整」，是不超过 a 的最大整数，例如 ⌊2.7⌋=2。

  • 例：X(ω)=0.7 时，s1​(ω)=21​⌊1.4⌋=0.5，s2​(ω)=41​⌊2.8⌋=0.5，s3​(ω)=81​⌊5.6⌋=0.625，一步步往上贴近 0.7。
  • 在 X(ω)=+∞ 的点，sn​(ω)=n→+∞，同样是「递增地趋于 X(ω)」。
基础补课单调收敛定理（MCT）对任何测度都成立

第 1 讲定理 30（第 36 页）：在任意测度空间上，若非负可测函数 f1​≤f2​≤⋯ 逐点趋于 f，则 ∫fn​↑∫f。

「任意测度空间」这几个字这一页要用两次：一次用在 (Ω,F,Q) 上，一次用在 (Ω,F,P) 上。定理并不关心测度叫什么名字。

基础补课正部与负部

对实值函数 X，定义

X+=max(X,0),X−=max(−X,0).
  • X+ 保留 X 的正值、把负值改成 0；X− 把负值取反、把正值改成 0。两者都非负。
  • 例：X(ω)=−3 时 X+(ω)=0、X−(ω)=3；X(ω)=5 时 X+(ω)=5、X−(ω)=0。
  • 恒等式：X=X+−X−，∣X∣=X++X−。
  • 可积函数的积分定义为 ∫X=∫X+−∫X−（第 43 页）。可积保证两项都有限，所以减法有意义。
基础补课非负常数乘上递增数列

设 0≤a1​≤a2​≤⋯，an​→a（a 可以是 +∞），c≥0 是有限常数。那么 can​ 也递增，并且 can​→ca，这里按测度论约定 0⋅∞=0。

  • c=0：每一项都是 0，极限是 0，而 ca=0（包括 a=∞ 的情形，按约定）。
  • c>0、a<∞：常数乘收敛数列，极限是 ca。
  • c>0、a=∞：an​ 越过任何界，can​ 也越过任何界，所以 can​→∞=ca。

  • 这是标准四步里的第 3 步：对象从「只取有限个值的简单函数」扩大到「任意非负可测函数」。后者可以取无穷多个值，可以无界，甚至可以在某些点取 +∞。

Nonnegative measurable functions｜非负可测函数

要证：对每个可测的 X:Ω→[0,∞]，EQ​X=EP​[XL]。

推导证明思路

取简单函数 sn​↑X。对每个 n，上一页已经给出 EQ​sn​=EP​[sn​L]。左边在 Q 下用 MCT 趋于 EQ​X；右边因为 sn​L↑XL，在 P 下用 MCT 趋于 EP​[XL]。同一个数列只有一个极限，所以两者相等。

  1. 取逼近列。由二进逼近（第 34 页 定理 29），存在非负简单函数 s1​≤s2​≤⋯，对每个 ω 都有 sn​(ω)↑X(ω)。
  2. 乘上密度以后仍然单调逼近。sn​L 是两个可测函数的乘积，所以可测，而且非负。固定一个 ω，把 c=L(ω) 看成一个非负有限常数，由上面「非负常数乘上递增数列」，
    s1​(ω)L(ω)≤s2​(ω)L(ω)≤⋯,sn​(ω)L(ω)→X(ω)L(ω).
    也就是 sn​L↑XL 逐点成立（下面「推导」一节把四种情形逐一列出）。
  3. 在 Q 下用 MCT：sn​↑X，所以 EQ​sn​↑EQ​X。
  4. 在 P 下用 MCT：sn​L↑XL，所以 EP​[sn​L]↑EP​[XL]。
  5. 用上一页的结论把两列数连起来：每个 sn​ 都是非负简单函数，由 第 32 页 第 2 步，EQ​sn​=EP​[sn​L] 对每个 n 成立。所以第 3 步和第 4 步里的两列数是同一列数。
  6. 结论：同一列数的极限是唯一的（在 [0,∞] 里也是如此），所以 EQ​X=EP​[XL]。

把第 3–5 步写成一行：

EQ​X​=n→∞lim​EQ​sn​=n→∞lim​EP​[sn​L]=EP​[XL]​​（MCT，测度用 Q）（简单函数的情形，第 32 页）（MCT，测度用 P）​

两边可以同时是 +∞：这时两列数都无界。命题 21 第 1 条证毕。

可积的有符号函数：拆成正部与负部（课件未印小标题）

要证：对可测的 X:Ω→R，X∈L1(Q)⟺XL∈L1(P)，并且此时 EQ​X=EP​[XL]。

推导证明思路

∣X∣、X+、X− 都是非负可测函数，可以直接套用刚证完的第 3 步。先用 ∣X∣ 得到「可积 ⟺ 可积」，再用 X+、X− 各得一个等式，两式相减。

  1. 可积性的等价。∣X∣ 非负可测，由第 3 步 EQ​∣X∣=EP​[∣X∣L]。又因为 L≥0，∣X∣L=∣XL∣。所以
    EQ​∣X∣=EP​∣XL∣.
    左边有限当且仅当右边有限，也就是 X∈L1(Q)⟺XL∈L1(P)。
  2. 乘积的正部、负部。因为 L≥0，乘上 L 不改变符号，所以
    (XL)+=X+L,(XL)−=X−L.
    逐点核对：若 X(ω)≥0，则 X(ω)L(ω)≥0，左边分别是 X(ω)L(ω) 和 0，右边也是（此时 X−(ω)=0）；若 X(ω)<0，则 X(ω)L(ω)≤0，左边分别是 0 和 −X(ω)L(ω)，右边也是（此时 X+(ω)=0）。
  3. 相减。设 X∈L1(Q)。因为 X±≤∣X∣，EQ​X+ 和 EQ​X− 都有限。于是
    EQ​X​=EQ​X+−EQ​X−=EP​[X+L]−EP​[X−L]=EP​[(XL)+]−EP​[(XL)−]=EP​[XL]​​（可积函数积分的定义）（第 3 步分别用于 X+、X−）（本步第 2 条）（第 1 条保证 XL 可积，再用定义）​

命题 21 全部证毕。标准四步到此走完：

步骤 对象 关键工具 在哪一页
1 示性函数 1A​ 密度的定义 第 32 页
2 非负简单函数 两边都是线性的 第 32 页
3 非负可测函数 二进逼近 + 两次 MCT 本页

只有一边有限时也成立（选读）

如果 EQ​X+、EQ​X− 中恰有一个是 +∞（另一个有限），测度论里仍然把 EQ​X 定义为 EQ​X+−EQ​X−，结果是 +∞ 或 −∞。第 3 步已经给出 EQ​X±=EP​[(XL)±]，所以 EP​[XL] 按同样方式定义，且两边相等。只有两项都是 +∞ 时，两边都没有定义（见下面例 4）。

Ω=(0,1)，P=Q=λ（此时 L≡1）。令 X(x)=x1​（当 x<21​），X(x)=−1−x1​（当 x≥21​）。

推导：一步一步来

推导证明思路

把第 3 步第 2 条「sn​L↑XL」按 L(ω) 是否为 0、X(ω) 是否有限分成四种情形，逐一核对，特别看清约定 0⋅∞=0 在哪里起作用。

固定 ω，记 an​=sn​(ω)，a=X(ω)，c=L(ω)。已知 an​↑a，c∈[0,∞)。

情形 an​c 的变化 极限 X(ω)L(ω)
c=0，a<∞ 恒为 0 0 a⋅0=0
c=0，a=∞ 恒为 0 0 ∞⋅0=0（约定）
c>0，a<∞ 递增 ca ca
c>0，a=∞ 递增且无界 ∞ ∞⋅c=∞

四种情形里，极限都等于 X(ω)L(ω)，并且数列都不减（an​≤an+1​ 乘以 c≥0 不改变不等号方向）。所以 sn​L↑XL 在每一点成立，MCT 的条件完全满足。

第二行说明了约定 0⋅∞=0 的必要性：若 X 在 Q 看不见的地方（L=0）取 +∞，这些点对 EP​[XL] 毫无贡献；对 EQ​X 也毫无贡献，因为 Q(L=0)=EP​[L1{L=0}​]=0。约定让两边的「看不见」保持一致。

常见疑问与易错点

易错点问：为什么不能像上一页那样直接用线性性？

答：线性性只能处理有限和。简单函数是有限个 ak​1Ak​​ 之和，所以上一页可以一项一项地换算；一般的非负可测函数（例如例 1 的 x​1​）取无穷多个值，写不成有限和。它的积分是用「下方简单函数积分的上确界」定义的（第 33 页），要从简单函数走到它，必须经过一个极限，MCT 正是保证「极限和积分可以交换」的工具。

易错点问：证明里用了两次 MCT，它们有什么不同？

答：测度不同、函数列也不同。第一次在 (Ω,F,Q) 上，函数列是 sn​↑X；第二次在 (Ω,F,P) 上，函数列是 sn​L↑XL。MCT 对任何测度都成立，所以两次都合法。少了任何一次，等式的一边就停在「limEsn​」而到不了期望本身。

易错点问：第 4 步为什么要先算绝对值的期望？

答：第 4 步第 1 条先证 EQ​∣X∣=EP​∣XL∣，是因为有正有负的函数，期望只在可积时才有定义（否则可能是 ∞−∞，例 4）。这一行说明两边的可积性是同一回事：只要 X 在 Q 下可积，XL 在 P 下就自动可积，右边的期望一定有定义。反过来也一样。注意判断标准是 XL 是否 P-可积，不是 X 是否 P-可积（第 32 页 例 3）。

易错点问：X 在 L = 0 的地方取什么值会影响结果吗？

答：不会。Q(L=0)=EP​[L1{L=0}​]=0，所以 {L=0} 是 Q 的零概率事件，X 在那里的值不影响 EQ​X；在右边，这些点上 XL=0，也不影响 EP​[XL]。两边「看不见」的地方恰好一致。

小结与自测

小结本页小结
  • 第 3 步（非负可测函数）：取简单函数 sn​↑X，则 sn​L↑XL；在 Q 下和 P 下各用一次 MCT，中间用简单函数的结论 EQ​sn​=EP​[sn​L] 连起来。
  • 第 4 步（可积函数）：EQ​∣X∣=EP​∣XL∣ 给出可积性的等价；(XL)±=X±L，正部减负部即得 EQ​X=EP​[XL]。
  • 约定 0⋅∞=0 保证 Q 看不见的区域 {L=0} 在两边都没有贡献。
  • 「示性函数 → 简单函数 → 非负函数 → 可积函数」的标准四步到此走完，命题 21 对所有随机变量成立。
自测

1. Ω=(0,1)，P=λ，L(x)=2x。求 EQ​[−lnx]。（提示：∫01​xlnxdx=−41​。）

点开看答案

−lnx≥0 且可测，由第 3 步 EQ​[−lnx]=EP​[(−lnx)⋅2x]=−2∫01​xlnxdx=−2×(−41​)=21​。这个函数在 0 附近无界，不是简单函数，正是本页第 3 步处理的对象。

2. 同上，求 EQ​[x−21​]，并说明用的是第几步。

点开看答案

x−21​ 有正有负，而且有界，所以在 Q 下可积，用第 4 步：EQ​[x−21​]=EP​[(x−21​)⋅2x]=∫01​(2x2−x)dx=32​−21​=61​。

3. 判断：本页证明中，只要在 P 下用一次 MCT 就够了。

点开看答案

错误。只在 P 下用 MCT，只能得到 EP​[sn​L]→EP​[XL]；还需要在 Q 下用 MCT 得到 EQ​sn​→EQ​X，才能把两列数（上一页已证它们逐项相等）的极限分别认出来。两次缺一不可。
