人话版一句话版

第 3 部分一直在问「极限和期望能不能交换」。这里是一个只能得到不等号的经典例子：f 单调不减时，∫01​f′≤f(1)−f(0)。这一页先做准备：把导数 f′ 写成一列非负差商 gn​ 的极限。下一页（第 47 页）算出 ∫gn​，用 Fatou 引理收尾，并说明不等号确实可以严格。

  • 位置：第 3 讲最后的补充材料（两页）。同一道题在第 1 讲老师的板书里出现过（第 42 页），这里换成第 3 讲的视角重新讲一遍。
  • 概率的视角：[0,1] 上的长度（勒贝格测度）总量是 1，所以 ([0,1],B,Leb) 本身就是一个概率空间。差商 gn​ 和导数 f′ 都是这个空间上的随机变量，∫01​gn​dx 就是期望。问题于是变成第 3 部分的老问题：gn​→f′ 几乎必然，期望能不能跟着收敛？（第 19 页、第 20 页、第 22 页）
  • 标题的意思：When only an inequality is justified，「只有不等式有根据的时候」。控制收敛（第 20 页）需要一个可积的上界，Scheffé 引理（第 22 页）需要预先知道积分收敛，这里都没有，只剩 Fatou 引理可用，而 Fatou 只给不等号。

先补基础

基础补课单调不减、几乎处处可导
  • 单调不减（nondecreasing）：x≤y⇒f(x)≤f(y)。图像只往上走或走平，可以有跳跃。
  • 几乎处处可导：除去一个长度为 0 的集合，其余每一点都有导数。勒贝格证明过：单调函数一定几乎处处可导，所以这个假设其实是自动成立的，课件写出来是为了清楚。
  • 例：f=1[1/2,1]​（x<21​ 时为 0，x≥21​ 时为 1）只在 x=21​ 处不可导，其余点导数为 0。
基础补课差商就是割线的斜率

从点 (x,f(x)) 到点 (x+h,f(x+h)) 连一条线段（割线），斜率是

hf(x+h)−f(x)​.

h→0+ 时割线转成切线，斜率的极限就是（右）导数 f′(x)。f 单调不减时，割线永远不会向下倾斜，所以差商总是 ≥0。

基础补课把 [0,1] 当成概率空间

令 U 在 [0,1] 上均匀分布。对任意（可积或非负）可测函数 h，

Eh(U)=∫01​h(x)dx

（无意识统计学家定律，第 2 讲 第 7 页）。所以「对 x 积分」和「对随机点 U 求期望」是一回事，「对几乎每个 x 成立」就是「几乎必然成立」。

基础补课Fatou 引理（回顾）

若 Xn​≥0 可测，则 E[liminfn​Xn​]≤liminfn​EXn​（第 1 讲 第 41 页）。它只要求非负，不需要单调，也不需要上界；代价是只能得到 ≤，而且这个不等号可以严格（尖峰例子，第 19 页）。

例 24（只能证明不等式的情形） 设 f:[0,1]→R 单调不减，且几乎处处可导。在导数不存在的点上，令 f′=0。

逐句说明：

  • nondecreasing：单调不减，允许走平；differentiable a.e.：几乎处处可导。
  • Set f′=0 where the derivative does not exist：不可导点组成零测集，在零测集上改函数值不影响积分（第 1 讲 第 43 页）。这样规定以后，f′ 就是定义在整个 [0,1] 上的非负函数。
  • justified：有根据的、被证明了的。「只有不等式有根据」预告了结论只有 ≤。

例 24（完整陈述）

在上述条件下，f′ 在 [0,1] 上勒贝格可积，并且

∫01​f′(x)dx ≤ f(1)−f(0).

不等号可以是严格的（见 第 47 页）。

Nonnegative difference quotients｜非负差商

第 1 步（向右延拓）：差商要用到 f(x+n1​)，而 x 靠近 1 时 x+n1​ 超出了 [0,1]。为此规定

f(x)=f(1)(x>1).

延拓后的 f 在 [0,∞) 上仍然单调不减：在 1 的右边它保持水平，不会往下走。

第 2 步（定义差商）：对 n=1,2,… 和 x∈[0,1]，令

gn​(x)=1/nf(x+n1​)−f(x)​=n[f(x+n1​)−f(x)].

它是步长 h=n1​ 的割线斜率。

第 3 步（三条性质）：

  1. 非负：x+n1​>x 且 f 单调不减，所以 f(x+n1​)≥f(x)，gn​(x)≥0。
  2. 可测：单调函数可测，因为对每个 a，{f>a} 是一个区间。x↦f(x+n1​) 也单调，所以 gn​ 是可测函数之差的常数倍，仍可测。
  3. 几乎处处收敛到 f′：取 x∈(0,1) 且 f 在 x 处可导。n 足够大时 x+n1​<1，延拓不起作用，gn​(x) 就是 h=n1​→0+ 的右差商，所以 gn​(x)→f′(x)。可能失败的点只有不可导点和两个端点 0、1，它们合起来是零测集。

第 4 步（副产品）：f′ 几乎处处是可测函数 gn​ 的极限，因而可测（勒贝格测度完备，零测集上的改动不破坏可测性）；又由第 1 条，f′≥0 几乎处处。所以 ∫01​f′ 有意义，取值在 [0,∞] 中。下一页证明它其实 ≤f(1)−f(0)<∞。

图解：一族越来越短的割线

在 f 的图像上取一点 x，向右走 n1​ 连一条割线：

  • n=1 时割线很长，它的斜率 g1​(x) 是 f 在 [x,x+1] 上的平均增长速度；
  • n 越大，割线越短，越贴近 x 处的切线，gn​(x) 趋向 f′(x)；
  • 因为 f 单调不减，每条割线都是水平或向上的，gn​≥0 正是 Fatou 引理需要的条件。

在跳跃点附近情况不同：若 f 在 x0​ 处向上跳了 J，那么对 x 刚好在 x0​ 左边、距离不到 n1​ 的点，割线跨过了跳跃，斜率约为 nJ，非常大。这就是下面例 2 里出现的「尖峰」。

例子

例 1：光滑函数 f(x) = x²——差商老老实实收敛

x≤1−n1​ 时，

gn​(x)=n[(x+n1​)2−x2]=n[n2x​+n21​]=2x+n1​ ⟶ 2x=f′(x).

x>1−n1​ 时用到了延拓：gn​(x)=n[1−x2]，只占长度 n1​ 的一小段。这一段上 gn​≤n[1−(1−n1​)2]=2−n1​<2，所以所有 gn​ 都被常数 2 压住，控制收敛定理可以用，期望会收敛（下一页算出 ∫01​gn​=1−3n21​→1）。

例 2：一个跳跃 f = 𝟏[1/2,1]——差商变成尖峰

逐点算 gn​(x)=n[f(x+n1​)−f(x)]：

x 的位置 f(x) f(x+n1​) gn​(x)
x<21​−n1​ 0 0 0
21​−n1​≤x<21​ 0 1 n
x≥21​ 1 1 0
  • gn​ 是一个宽 n1​、高 n 的尖峰，紧贴在跳跃点 21​ 的左边，面积恒为 1。
  • 固定任意 x：若 x<21​，n 大到 n1​<21​−x 后 gn​(x)=0；若 x≥21​，gn​(x)=0 一直成立。所以 gn​(x)→0 对每个 x 都成立，而 f′=0 几乎处处，极限正确。
  • 这和 第 19 页 的尖峰一模一样，只是位置平移到了 21​ 左边：每一点都趋于 0，面积却一直是 1。没有可积的上界（尖峰高度 n→∞），控制收敛用不了。
例 3：康托尔函数——连续，差商却仍然「藏」着质量

康托尔函数 F（第 2 讲 第 19 页）连续、单调不减，在康托尔集之外导数为 0，而康托尔集长度为 0，所以 F′=0 几乎处处，gn​→0 几乎处处。

但 F 从 0 爬到了 1，差商 gn​ 的「质量」聚集在康托尔集附近越来越窄的许多小区间上。和例 2 不同，这里没有一个单独的尖峰，而是很多个越来越细的小尖峰。下一页会算出 ∫01​gn​→1，而 ∫01​F′=0。

常见疑问与易错点

易错点问：为什么要把 f 延拓到 1 的右边？老师板书里是怎么做的？

答：x>1−n1​ 时 f(x+n1​) 没有定义，必须处理。这里用常数 f(1) 延拓，好处是单调性和 gn​≥0 都保留，下一页的计算也最短。第 1 讲的板书（第 42 页）用的是另一种办法：在最后一段 [1−n1​,1] 上直接令 gn​=0。两种做法都对，最后得到同样的不等式。

易错点问：既然 g_n → f′，为什么不直接说 ∫ g_n → ∫ f′？

答：逐点收敛推不出积分收敛，这正是第 3 部分反复强调的（第 19 页）。例 2 就是反例：gn​→0 处处成立，但 ∫gn​=1 不趋于 0。要交换极限和积分，需要额外条件：控制收敛要一个可积上界，Scheffé 要已知积分收敛。这两个条件在一般的单调 f 下都没有。

易错点问：g_n 真的可以叫「随机变量」吗？

答：可以。在概率空间 ([0,1],B,Leb) 上，任何可测函数都是随机变量（第 2 讲 第 4 页）。记 U(x)=x，则 gn​=gn​(U)，「对几乎每个 x，gn​(x)→f′(x)」就是「gn​(U)→f′(U) 几乎必然」，而 ∫01​gn​dx=Egn​(U)。

小结与自测

小结本页小结
  • 例 24：f 单调不减、几乎处处可导，不可导点令 f′=0，目标是证明 ∫01​f′≤f(1)−f(0)。
  • 准备工作：把 f 在 1 的右边延拓成常数 f(1)，定义差商 gn​(x)=n[f(x+n1​)−f(x)]。
  • 三条性质：gn​≥0、可测、几乎处处 gn​→f′，正好是 Fatou 引理需要的条件。
  • 跳跃（例 2）和康托尔函数（例 3）会让 gn​ 变成尖峰，没有可积上界，所以只能用 Fatou。
自测

1. 对 f(x)=x​，算出 gn​(0)。gn​(0) 收敛吗？这会影响结论吗？

点开看答案

gn​(0)=n[1/n​−0]=n​→∞，不收敛到有限值（x​ 在 0 处的右导数是 +∞，不可导）。但 {0} 只是一个点，长度为 0，按约定令 f′(0)=0 即可，不影响积分，也不影响「几乎处处收敛」。

2. 对 f=1[1/2,1]​，∫01​gn​ 等于多少？∫01​limn​gn​ 等于多少？

点开看答案

∫01​gn​=n⋅n1​=1（尖峰的面积）；limn​gn​=0 处处成立，所以 ∫01​limn​gn​=0。两者不相等，极限和积分不能交换。

3. 若 f 单调不增，gn​ 的符号是什么？还能直接用 Fatou 吗？

点开看答案

gn​≤0，不满足 Fatou 的非负条件。办法是对 −f（单调不减）使用本例，得到 ∫01​(−f)′≤−f(1)+f(0)，即 ∫01​f′≥f(1)−f(0)。
