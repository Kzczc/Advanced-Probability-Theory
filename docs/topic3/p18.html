人话版一句话版

设 Xn​P​X。「超过门槛 c 的概率」P(Xn​>c) 会不会收敛到 P(X>c)？只要极限 X 恰好等于 c 的概率是 0，就会；如果 P(X=c)>0，就可能不会——反例是 Xn​=c+n1​、X=c。

这是第 2 部分「随机变量的收敛」的最后一页，是上一页连续映射定理的一个应用。

  • 上一页 第 17 页 的定理 13 说：只要函数 g 在极限 X 处（以概率 1）连续，依概率收敛就能「穿过」g，即 g(Xn​)P​g(X)。
  • 这一页取 g 为门槛函数 g(x)=1(c,∞)​(x)：超过 c 记 1，否则记 0。它在 x=c 处跳了一下，c 是它的间断点（discontinuity）。标题里的 discontinuities 指的就是这个跳跃。
  • 因为 P(Xn​>c)=E[g(Xn​)]，这一页其实已经在问「期望能不能跟着收敛」。这正是下一页 第 19 页 开始的第 3 部分「期望与密度的收敛」的主题，所以这一页也是两部分之间的桥。

先补基础

基础补课依概率收敛（第 14 页定义 10）

Xn​P​X 读作「Xn​ 依概率收敛到 X」，意思是：对每个 ε>0，

P(∣Xn​−X∣>ε)→0(n→∞).

也就是「第 n 步误差超过容忍度 ε」这个坏事件的概率越来越小（第 14 页）。

  • 例：Xn​=X+n1​。误差恒为 n1​；当 n>ε1​ 时坏事件是空集，概率为 0，所以 Xn​P​X。
  • 几乎必然收敛推出依概率收敛（第 14 页 命题 11），反过来不对（第 15 页 的打字机序列）。所以本页结论对几乎必然收敛也成立。
基础补课门槛函数与「在一点连续」
  • 固定实数 c（门槛）。门槛函数 g(x)=1(c,∞)​(x)：x>c 时取 1，x≤c 时取 0。于是 g(Xn​)=1{Xn​>c}​，并且 E[g(Xn​)]=P(Xn​>c)（示性函数的期望就是事件的概率）。
  • g 在点 x 连续的意思：只要数列 xk​→x，就有 g(xk​)→g(x)。
  • 若 x>c：当 xk​ 与 x 的距离小于 x−c 时 xk​>c，于是 g(xk​)=1=g(x)，所以 g 在 x 处连续。
  • 若 x<c：当 xk​ 与 x 的距离小于 c−x 时 xk​<c，于是 g(xk​)=0=g(x)，g 在 x 处也连续。
  • 若 x=c：取 xk​=c+k1​→c，却有 g(xk​)=1，而 g(c)=0。所以 c 是 g 唯一的间断点。
基础补课原子：随机变量在一点上的质量
  • 若 P(X=c)>0，就说 X 的分布在 c 点有一个原子（atom），也说「X 在 c 上有质量」。
  • 用分布函数 F(x)=P(X≤x)（第 8 页）来看：事件 {X≤c−k1​} 随 k 增大而变大，并起来是 {X<c}，由从下连续，F 在 c 处的左极限 F(c−)=P(X<c)。所以
P(X=c)=P(X≤c)−P(X<c)=F(c)−F(c−).

也就是说，P(X=c)=0 恰好等价于 F 在 c 处连续。

  • 例：X 服从 (0,1) 上的均匀分布时，每个 c 都有 P(X=c)=0（一个点的长度是 0）。X 是抛硬币的结果（各以 21​ 的概率取 0 或 1）时，P(X=1)=21​，在 1 处有原子。
基础补课实数列的上极限与下极限

第 40 页 讲过函数列的 liminf、limsup，这里只要实数列的版本：

  • limsupn​an​=limm→∞​supn≥m​an​，是数列最终的「最高水平」；liminfn​an​=limm→∞​infn≥m​an​，是最终的「最低水平」。
  • 例：an​=(−1)n 时 liminfn​an​=−1，limsupn​an​=1。
  • 本页要用三条性质：
    1. 总有 liminfn​an​≤limsupn​an​；
    2. 若 an​≤b+δn​（b 是常数，δn​≥0 且 δn​→0），则 limsupn​an​≤b；若 an​≥b−δn​，则 liminfn​an​≥b；
    3. 若 liminfn​an​=limsupn​an​=L，则 an​→L。
基础补课从下连续与从上连续（第 1 讲）
  • 从下连续（第 13 页）：事件递增 B1​⊆B2​⊆⋯，则 P(Bk​)→P(⋃k​Bk​)。
  • 从上连续（第 14 页）：事件递减 B1​⊇B2​⊇⋯，则 P(Bk​)→P(⋂k​Bk​)（概率测度总质量为 1，有限，所以可以用）。
  • 本页会用到：{X>c+k1​} 随 k 递增，并起来是 {X>c}；{X>c−k1​} 随 k 递减，交起来是 {X≥c}。所以
P(X>c+k1​)↑P(X>c),P(X>c−k1​)↓P(X≥c).

  • 标题 Threshold probabilities and discontinuities：threshold（阈值、门槛）指一个固定的数 c；threshold probability（阈值概率）指「超过门槛的概率」P(Xn​>c)。discontinuities（间断点）指门槛函数在 c 处的跳跃。标题把两件事放在一起，暗示了结论：阈值概率能否取极限，取决于极限 X 在间断点 c 上有没有质量。
  • Assume Xn​P​X：本页唯一的假设，依概率收敛（第 14 页 定义 10）。

为什么关心阈值概率？实际问题里常常要算「超过某条线」的概率：产品寿命超过 c 年的概率、投资损失超过 c 元的概率、检验统计量超过临界值的概率。如果 Xn​ 是 X 的近似（模拟、估计、数值逼近），我们希望近似出来的阈值概率也逼近真实的阈值概率。这一页说明：大多数门槛可以，落在极限原子上的门槛不一定可以。

命题（阈值概率的收敛）

设 Xn​P​X，c∈R 是固定的门槛。

  1. 若 P(X=c)=0，则
P(Xn​>c)→P(X>c),P(Xn​≤c)→P(X≤c)(n→∞).
  1. 若 P(X=c)>0，上述结论可能不成立。反例：Xn​=c+n1​，X=c。

逐句理解：

  • 条件 P(X=c)=0：极限 X 在门槛上没有原子。它不要求 Xn​ 满足什么，只看极限。
  • 结论：阈值概率跟着收敛。第二个式子是第一个的补集版本。
  • 第 2 条说明条件不是摆设：极限的质量一旦压在间断点上，结论就可能失败。

补写的证明：连续映射 + 有界

推导证明思路

把 P(Xn​>c) 写成 E[g(Xn​)]，g=1(c,∞)​。g 只在 c 处间断，而 X 以概率 1 不落在 c 上，所以连续映射定理给出 g(Xn​)P​g(X)；g 只取 0 和 1，是有界的，于是期望也收敛。

  1. 间断点：由先补基础，g 在 C=R∖{c} 的每一点连续，唯一的间断点是 c。
  2. 极限不落在间断点上：P(X∈C)=1−P(X=c)=1。
  3. 连续映射：由 第 17 页 定理 13（在随机极限处连续即可），g(Xn​)P​g(X)，也就是
1{Xn​>c}​P​1{X>c}​.
  1. 从依概率收敛到期望收敛：记 Dn​=1{Xn​>c}​−1{X>c}​。两个示性函数相减，只可能是 −1、0、1，所以 ∣Dn​∣ 只取 0 或 1，而且 ∣Dn​∣=1 恰好当 ∣Dn​∣>21​。于是
​P(Xn​>c)−P(X>c)​=​EDn​​≤E∣Dn​∣=P(∣Dn​∣>21​)→0.

第一个等号用了期望的线性，不等号是 ∣EZ∣≤E∣Z∣（第 43 页 命题 35），最后的「→0」就是第 3 步取 ε=21​。 5. 补集：P(Xn​≤c)=1−P(Xn​>c)→1−P(X>c)=P(X≤c)。

补充第 4 步就是「有界收敛」

第 4 步的本质是：∣g∣≤1 有界，依概率收敛就能推出期望收敛。第 1 讲的有界收敛定理 BCT（第 46 页 推论 37）要求的是几乎处处收敛，不能直接套在依概率收敛上；它的依概率版本是 第 20 页 定理 15 取 Y≡1 的特例。对示性函数，上面的直接计算最省事。

第 3 步用到的连续映射定理：为什么只要求「在 X 处连续」

设 Xn​P​X，g:R→R 博雷尔可测，g 在博雷尔集 C 的每一点连续，且 P(X∈C)=1。要证 g(Xn​)P​g(X)。

  1. 任取一个子列 (nk​)。它仍依概率收敛到 X，由子列判别法（第 16 页 定理 12）存在子子列 (nkj​​)，使 Xnkj​​​→X 几乎必然。
  2. 在事件 {Xnkj​​​→X}∩{X∈C} 上（两个概率为 1 的事件之交，概率仍为 1）：Xnkj​​​(ω)→X(ω)，而 g 在 X(ω) 处连续，所以 g(Xnkj​​​(ω))→g(X(ω))。
  3. 所以 g(Xn​) 的每个子列都有几乎必然收敛到 g(X) 的子子列。由定理 12 的另一个方向，g(Xn​)P​g(X)。

补写的反例：极限落在门槛上

例子反例：X_n = c + 1/n，X = c
  • 收敛：∣Xn​−X∣=n1​。对每个 ε>0，当 n>ε1​ 时 P(∣Xn​−X∣>ε)=0，所以 Xn​P​X（其实是每个 ω 上都收敛）。
  • 阈值概率：Xn​=c+n1​>c 对每个 ω 成立，所以 P(Xn​>c)=1；而 X=c 不大于 c，所以 P(X>c)=0。
  • 结论：P(Xn​>c)=1→0=P(X>c)。
  • 原因：P(X=c)=1>0，极限的全部质量都压在门槛这个间断点上。Xn​ 从右边逼近 c，每一步都「刚好过线」，到了极限却「刚好没过线」。用 g 的语言：g(Xn​)=1，g(X)=0，g(Xn​) 根本不收敛到 g(X)，连续映射定理的条件在这里失效。

例子

例 1：均匀分布的极限，任何门槛都可以

设 X 服从 (0,1) 上的均匀分布，Xn​=X+n1​，门槛 c=0.5。P(X=0.5)=0，命题说 P(Xn​>0.5)→P(X>0.5)=0.5。直接验证：

P(Xn​>0.5)=P(X>0.5−n1​)=1−(0.5−n1​)=0.5+n1​(n≥2),

这里用了均匀分布 P(X>t)=1−t（0≤t<1）。数值：n=2 时是 1，n=10 时是 0.6，n=100 时是 0.51，确实趋于 0.5。

例 2：抛硬币的极限，门槛在原子上就出问题

设 X 以各 21​ 的概率取 0 或 1，Xn​=X+n1​。

  • 门槛 c=0.5（不是原子）：当 n≥3 时，0+n1​≤31​<0.5，而 1+n1​>0.5，所以 Xn​>0.5 恰好当 X=1，P(Xn​>0.5)=21​=P(X>0.5)。结论成立。
  • 门槛 c=1（原子，P(X=1)=21​）：Xn​>1 恰好当 X=1，所以 P(Xn​>1)=21​ 对每个 n 成立；但 P(X>1)=0。极限是 21​=0，结论失败。
  • 门槛 c=0（原子，P(X=0)=21​）：Xn​>0 总成立，P(Xn​>0)=1；但 P(X>0)=21​。结论也失败。

两次失败的差距都恰好是原子的质量 21​，下面的推导会说明这不是巧合。

例 3：极限是常数时

设 Xn​P​a（a 是一个常数，比如「估计量依概率收敛到真值 a」）。常数 a 只在 a 这一点有原子（质量为 1）。

  • 若 c<a：P(a=c)=0，所以 P(Xn​>c)→P(a>c)=1。
  • 若 c>a：同样 P(Xn​>c)→P(a>c)=0。
  • 若 c=a：命题不给结论。例如 Xn​=a+n(−1)n​，n 为偶数时 Xn​>a，为奇数时 Xn​<a，所以 P(Xn​>a) 在 1 和 0 之间来回跳，连极限都不存在。

这说明：依概率收敛到 a，等于说「落在 a 两侧任何一条固定线之外的概率趋于 0」，但它不管 Xn​ 从哪一侧贴近 a。

推导：一步一步来

不用连续映射的直接夹逼证明

这个证明只用依概率收敛的定义和第 1 讲的从上、从下连续，还顺便说明了差距为什么恰好是 P(X=c)。

推导证明思路

「Xn​ 超过 c」和「X 超过 c」只在误差大于 ε、或 X 离 c 不到 ε 时才可能不一致。前者的概率趋于 0，后者在 ε→0 时缩成 {X=c}。

固定 ε>0，记 δn​=P(∣Xn​−X∣>ε)，由依概率收敛，δn​→0。

  1. 上方的包含：{Xn​>c}⊆{X>c−ε}∪{∣Xn​−X∣>ε}。理由：若 Xn​>c 且 ∣Xn​−X∣≤ε，则 X≥Xn​−ε>c−ε。
  2. 下方的包含：{X>c+ε}⊆{Xn​>c}∪{∣Xn​−X∣>ε}。理由：若 X>c+ε 且 ∣Xn​−X∣≤ε，则 Xn​≥X−ε>c。
  3. 取概率（单调性与次可加性 P(A∪B)≤P(A)+P(B)）：
P(X>c+ε)−δn​ ≤ P(Xn​>c) ≤ P(X>c−ε)+δn​.
  1. 令 n→∞：由上极限、下极限的性质 2（先补基础），
P(X>c+ε)≤nliminf​P(Xn​>c)≤nlimsup​P(Xn​>c)≤P(X>c−ε).
  1. 令 ε=k1​→0：第 4 步对每个 k 成立，中间两项不依赖 k。由从下连续，左端 ↑P(X>c)；由从上连续，右端 ↓P(X≥c)。所以
P(X>c)≤nliminf​P(Xn​>c)≤nlimsup​P(Xn​>c)≤P(X≥c).
  1. 差距就是原子：两端之差 P(X≥c)−P(X>c)=P(X=c)。若它为 0，上下极限都等于 P(X>c)，由性质 3，P(Xn​>c)→P(X>c)。

第 5 步的不等式不需要任何条件：阈值概率的极限行为总被夹在 P(X>c) 和 P(X≥c) 之间，最多「漂移」P(X=c) 那么多。例 2 中两次失败的差距都是 21​，正是原子的质量。

原子最多可数个：几乎所有门槛都没问题

  1. 固定正整数 k，考虑集合 {c: P(X=c)≥k1​}。它最多有 k 个点：若有 k+1 个不同的点 c1​,…,ck+1​，事件 {X=ci​} 两两不交，它们的并的概率是 ∑i​P(X=ci​)≥kk+1​>1，与概率不超过 1 矛盾。
  2. 所有原子组成的集合是 ⋃k≥1​{c:P(X=c)≥k1​}，可数个有限集合之并，至多可数。
  3. 所以除了至多可数个门槛以外，命题的条件 P(X=c)=0 都成立。例 2 的原子只有 0 和 1 两个。

常见疑问与易错点

易错点问：X_n 都收敛到 X 了，为什么 ℙ(X_n > c) 不一定收敛到 ℙ(X > c)？

答：因为 P(Xn​>c)=E[g(Xn​)] 中间隔着门槛函数 g，而 g 在 c 处是跳跃的。在 c 附近，Xn​ 哪怕只挪动一点点，g(Xn​) 也会在 0 和 1 之间翻转。如果极限 X 有正的概率正好停在 c 上，这种翻转就会以正的概率发生，阈值概率就收敛不到正确的值（反例 Xn​=c+n1​）。

易错点问：条件 ℙ(X = c) = 0 是必要的吗？

答：不是，它是充分条件。Xn​=c−n1​、X=c 时，P(X=c)=1，但 P(Xn​>c)=0=P(X>c)，结论碰巧成立。不过换成「≥」就失败了：P(Xn​≥c)=0，P(X≥c)=1。条件 P(X=c)=0 的好处是让 >、≥、<、≤ 四种写法同时成立，不用操心 Xn​ 从哪一侧逼近。

易错点问：把「>」换成「≥」，结论还成立吗？

答：只要 P(X=c)=0 就成立。把推导第 1 步换成 {Xn​≥c}⊆{X≥c−ε}∪{∣Xn​−X∣>ε}（若 Xn​≥c 且误差 ≤ε，则 X≥c−ε），第 2 步不变（Xn​>c 当然推出 Xn​≥c），再令 ε=k1​→0，得到同样的夹逼：P(X>c)≤liminfP(Xn​≥c)≤limsupP(Xn​≥c)≤P(X≥c)。

易错点问：这和以后会学的「依分布收敛」有什么关系？

答：命题的第二个结论说：在 FX​ 的每个连续点 c 上（即 P(X=c)=0），都有 P(Xn​≤c)→P(X≤c)。这正是「依分布收敛」的定义。所以这一页顺便证明了：依概率收敛推出依分布收敛。依分布收敛的定义之所以只要求在连续点上收敛，原因就是本页的反例。

易错点问：如果 X 有密度，是不是任何门槛都可以？

答：是。有密度 f 时，P(X=c)=∫{c}​f(x)dx=0（一个点的勒贝格测度为 0，第 17 页），所以对每个 c 都有 P(Xn​>c)→P(X>c)。只有带原子的极限（离散分布、混合分布）才需要小心那几个原子。

小结与自测

小结本页小结
  • 阈值概率 P(Xn​>c)=E[1(c,∞)​(Xn​)]；门槛函数只在 c 处间断。
  • 设 Xn​P​X。一般地 P(X>c)≤liminfn​P(Xn​>c)≤limsupn​P(Xn​>c)≤P(X≥c)，上下界之差恰为 P(X=c)。
  • 若 P(X=c)=0（c 是 FX​ 的连续点），则 P(Xn​>c)→P(X>c)，≤、≥、< 的版本也成立。证明可以走「连续映射 + 有界」，也可以直接夹逼。
  • 若 P(X=c)>0，可能失败：Xn​=c+n1​，X=c，P(Xn​>c)=1 而 P(X>c)=0。
  • 原子至多可数个，所以除可数个门槛外结论都成立。
自测

1. 设 Xn​P​X，X 服从 (0,1) 上的均匀分布。P(Xn​≤0.3) 收敛吗？收敛到多少？

点开看答案

收敛到 0.3。因为 P(X=0.3)=0，由命题 P(Xn​≤0.3)→P(X≤0.3)=0.3。

2. 设 X=2（常数），Xn​=2+n(−1)n​。Xn​ 依概率收敛到 X 吗？P(Xn​>2) 收敛吗？是命题的哪个条件不满足？

点开看答案

∣Xn​−X∣=n1​→0，所以依概率收敛（其实处处收敛）。n 为偶数时 Xn​=2+n1​>2，P(Xn​>2)=1；n 为奇数时 Xn​=2−n1​<2，P(Xn​>2)=0。数列 1,0,1,0,… 没有极限。不满足的条件是 P(X=2)=0：这里 P(X=2)=1。

3. 填空：在夹逼不等式 P(X>c)≤liminfn​P(Xn​>c)≤limsupn​P(Xn​>c)≤P(X≥c) 中，最右端与最左端之差等于 ______；它为 0 时阈值概率收敛。

点开看答案

P(X=c)。因为 {X≥c} 是 {X>c} 与 {X=c} 的不交并，所以 P(X≥c)−P(X>c)=P(X=c)。
