这一页在讲什么

人话版一句话版

上一页的 Q 让 X∼N(a,1)。现在再换一次测度，得到第三个概率 Q​，让 X∼N(b,1)。第二段权重必须以当前均值 a 为中心：dQdQ​​=e(b−a)(X−a)−(b−a)2/2。用链式法则把两段权重相乘，指数里的项逐一抵消，得到 dPdQ​​=ebX−b2/2——和「一步从 0 挪到 b」的公式完全一样。

  • 这一页是链式法则（命题 22，第 34 页）在连续情形的第一个具体检验：两条路线（两步走、一步走）必须给出同一个密度，否则链式法则或我们的计算就有错。
  • 它还教一条实用规则：从非标准的正态出发再平移时，先减去当前均值。课件小标题 centered at the current mean 说的就是这个。
  • 下一页 第 43 页 回到一步平移，取 a=b 去抽稀有事件。

先补基础

基础补课中心化：减去当前均值
  • 若在 Q 下 X∼N(a,1)，令 Y:=X−a，则在 Q 下 Y∼N(0,1)。理由：对任意 y，Q(Y≤y)=Q(X≤y+a)=Φ((y+a)−a)=Φ(y)，这里用了上一页的结论 Q(X≤x)=Φ(x−a)。
  • 「中心化」（centering）就是减去均值，把中心挪回 0。例：a=3，某次 X=4.5，则 Y=1.5，表示「比当前均值高 1.5」。
基础补课链式法则回顾（命题 22）
  • 第三个概率记作 Q​（读作「Q 波浪」），和 第 34 页 的记号一致。
  • 命题 22：若 Q​≪Q 且 Q≪P，则 Q​≪P，并且 dPdQ​​=dQdQ​​⋅dPdQ​ P-几乎必然。人话：放大倍数一段一段相乘。
  • 比值形式（第 34 页）：若 dPdQ​>0，则 dQdQ​​=dQ/dPdQ​/dP​。
基础补课本页要用的展开
  • (u−v)(s−t)=us−ut−vs+vt。例：(b−a)(X−a)=bX−ab−aX+a2。
  • (b−a)2=b2−2ab+a2。例：(3−1)2=9−6+1=4。
  • 指数合并：eu⋅ev=eu+v，所以两段权重相乘，就是把两个指数相加。

中文翻译

以当前均值为中心的第二次平移

逐词看：

  • a second shift（第二次平移）：上一页 第 41 页 是第一次平移，把 X 的均值从 0 挪到 a。这一页在此基础上再挪一次，从 a 挪到 b。
  • the current mean（当前均值）：做完第一次换测度后，X 在 Q 下的均值是 a（第 41 页「推导」第 2 条算过 EQ​X=a）。「当前」强调：现在的参照概率是 Q，不再是 P。
  • centered at（以……为中心）：第二段权重的公式里，X 要以 X−a 的形式出现，也就是先中心化再代公式。
  • 蓝条标题 Composition of Gaussian shifts：高斯平移的复合。「复合」指一个接一个地做，就像函数的复合 g(f(x))。

这一页要回答两个问题：（1）第二段权重应该长什么样？（2）两段合起来，是不是等于一步到位？课件只印了小标题，内容是板书，下面补全。

A second shift centered at the current mean｜以当前均值为中心的第二次平移

设定。 Q 是 第 41 页 造出的概率：dPdQ​=eaX−a2/2，在 Q 下 X∼N(a,1)。再固定一个 b∈R，目标是造 Q​，使 X 在 Q​ 下服从 N(b,1)。

第 1 步：在 Q 下找一个标准正态变量。 由基础补课，Y:=X−a 在 Q 下服从 N(0,1)。

第 2 步：把上一页的命题用在 (Q,Y) 上。 上一页的命题只用到一件事：「有一个概率，在它之下某个随机变量是标准正态」。把那里的 (P,X,a) 换成 (Q,Y,c)，其中平移量 c:=b−a，就得到

dQdQ​​:=ecY−c2/2=e(b−a)(X−a)−(b−a)2/2,Q​(A):=EQ​[e(b−a)(X−a)−(b−a)2/21A​](A∈F).

上一页的命题保证：这个权重处处为正、在 Q 下期望为 1，所以 Q​ 是概率，Q​≪Q，并且在 Q​ 下 Y∼N(c,1)。

第 3 步：翻译回 X。 X=Y+a，所以对任意 x，

Q​(X≤x)=Q​(Y≤x−a)=Φ((x−a)−c)=Φ(x−b).

最后一步用了 a+c=b。于是在 Q​ 下 X∼N(b,1)。

另一条路：用「密度之比」核对第二段权重。 在 Q 下 X 的密度是 ϕ(x−a)，目标密度是 ϕ(x−b)。按 第 41 页 的思路，权重应是两者之比：

ϕ(x−a)ϕ(x−b)​=e−2(x−b)2​+2(x−a)2​=e2−(x2−2bx+b2)+(x2−2ax+a2)​=e(b−a)x−2b2−a2​.

再把第 2 步的「中心化形式」展开：

(b−a)(x−a)−2(b−a)2​​=(b−a)x−ab+a2−2b2−2ab+a2​=(b−a)x−ab+a2−2b2​+ab−2a2​=(b−a)x−2b2−a2​.​

两者相同。所以 「以当前均值为中心」的公式，正是 N(b,1) 的密度除以 N(a,1) 的密度。

用链式法则把两次平移合起来

条件。 Q​ 由关于 Q 的密度定义，Q 由关于 P 的密度定义，由 第 26 页 的命题，Q​≪Q、Q≪P。命题 22 的条件满足。

相乘。 由命题 22，

dPdQ​​=dQdQ​​⋅dPdQ​=e(b−a)(X−a)−2(b−a)2​⋅eaX−2a2​=eE,

其中指数 E=(b−a)(X−a)−2(b−a)2​+aX−2a2​。

逐项展开。 三块分别是

  1. (b−a)(X−a)=bX−aX−ab+a2；
  2. −2(b−a)2​=−2b2−2ab+a2​=−2b2​+ab−2a2​；
  3. aX−2a2​（原样保留）。

按类型合并（表中「—」表示这一块没有这种项）：

项的类型 第 1 块 第 2 块 第 3 块 合计
含 X bX−aX — +aX bX
含 ab −ab +ab — 0
含 a2 +a2 −2a2​ −2a2​ 0
含 b2 — −2b2​ — −2b2​

所以 E=bX−2b2​，

dPdQ​​=ebX−b2/2.

与一步到位比较。 直接用 第 41 页，把平移量 a 换成 b，得到的概率 Qb​ 满足 dPdQb​​=ebX−b2/2。两者密度完全相同，所以对每个事件 A∈F，

Q​(A)=EP​[ebX−b2/21A​]=Qb​(A).

两步走和一步走得到的是同一个概率测度，不只是 X 的分布相同。

人话版像换外币：汇率相乘

把 P、Q、Q​ 想成三种货币，Radon–Nikodym 导数是「汇率」（第 32 页 的比喻）。人民币先换美元、再把美元换欧元，总汇率等于两段汇率相乘，并且等于人民币直接换欧元的汇率——前提是两段报价用的是同一个中间货币。「以当前均值为中心」就相当于第二段必须按「美元」报价（以 Q 为参照），而不是又按「人民币」报价（以 P 为参照）。

补充分步平移在实际中有什么用

实际的重要性抽样里，最好的平移量往往事先不知道，常见做法是先小挪一步、根据样本再调整、再挪一步。本页保证：无论中间走了多少步，最后的样本权重都可以统一写成相对于原概率 P 的一个密度（这里是 ebX−b2/2），而估计 P 下的量只需要这一个总权重。

命题（高斯平移的复合）

设在 P 下 X∼N(0,1)，a,b∈R，dPdQ​=eaX−a2/2。令 Q​(A):=EQ​[e(b−a)(X−a)−(b−a)2/21A​]。那么

  1. Q​ 是概率测度，Q​≪Q，dQdQ​​=e(b−a)(X−a)−(b−a)2/2，并且在 Q​ 下 X∼N(b,1)；
  2. Q​≪P，dPdQ​​=ebX−b2/2；
  3. 因此 Q​ 与「从 P 一步平移 b」得到的概率在所有事件上都相等。

为什么一定要「以当前均值为中心」

一个很自然的错误：直接照抄上一页的公式，把平移量写成 c=b−a，却忘了中心化，用 L2′​=ecX−c2/2 当第二段权重。检查它能不能归一化：

EQ​ecX​=EP​[ecX⋅eaX−a2/2]=e−a2/2EP​e(a+c)X=e−a2/2e(a+c)2/2=eac+c2/2.​​（命题 21：期望换算）（指数合并，常数提出）（上一页的公式 EP​etX=et2/2）（2(a+c)2−a2​=ac+2c2​）​

所以 EQ​L2′​=e−c2/2⋅eac+c2/2=eac。除非 a=0 或 c=0，它不等于 1，造出来的「概率」总质量是 eac，根本不是概率。

如果硬要把它归一化（除以它的期望 eac），得到

eacL2′​​=ecX−ac−c2/2=ec(X−a)−c2/2,

恰好就是中心化的公式。「以当前均值为中心」不是随意的写法，而是归一化逼出来的。 原因也很好理解：上一页公式 eaX−a2/2 里的 X，其实是「X 减去 P 下的均值 0」；参照概率换成 Q 之后，要减去的就是 Q 下的均值 a。

例子

例 1：a = 1，b = 3，代数字核对
  • 第一段：dPdQ​=eX−1/2。
  • 第二段：c=b−a=2，dQdQ​​=e2(X−1)−22/2=e2X−4。
  • 相乘：eX−1/2⋅e2X−4=e3X−9/2；直接公式 ebX−b2/2=e3X−9/2。一致。
  • 在 X=2 处：e1.5×e0≈4.482，直接 e6−4.5=e1.5；在 X=0 处：e−0.5×e−4=e−4.5≈0.0111，直接 e−4.5。
  • 三个概率下 X>3 的可能性：P(X>3)=1−Φ(3)≈0.00135，Q(X>3)=1−Φ(2)≈0.0228，Q​(X>3)=1−Φ(0)=0.5。每挪一步，事件 {X>3} 就变得更常见。
例 2：往回挪（b = 0）就是倒数密度
  • 取 b=0：dQdQ​​=e−a(X−a)−a2/2=e−aX+a2−a2/2=e−aX+a2/2。
  • 链式法则：dPdQ​​=e0⋅X−0=1，所以 Q​=P：挪过去再挪回来，回到原来的概率。
  • 于是 dQdP​=e−aX+a2/2=L1​，这正是 第 35 页 的倒数密度，也是上一页命题的第 3 条。验证：e−aX+a2/2⋅eaX−a2/2=e0=1。
例 3：分两小步挪，和一大步一样

把 0→b 拆成 0→2b​→b：

  • 第一步（从 0 挪 2b​）：e2b​X−8b2​；
  • 第二步（从 2b​ 再挪 2b​，以 2b​ 为中心）：e2b​(X−2b​)−8b2​=e2b​X−4b2​−8b2​；
  • 相乘：指数是 bX−(81​+41​+81​)b2=bX−2b2​。和一步挪 b 相同。
例 4（反例）：不中心化，总质量就不是 1

a=1、b=3（c=2）。若错误地取第二段权重 L2′​=e2X−2，则由上面的计算，EQ​L2′​=eac=e2≈7.39。按它定义的 Q​′(Ω)≈7.39，不是概率。对比正确的 e2(X−1)−2=e2X−4：两者只差常数因子 e2，这个因子恰好就是中心化时减掉的 ac。

推导：一步一步来

推导证明思路

把上面的计算写成一个对任意两个均值都成立的公式；再用 第 34 页 的「连换多次」推论，说明任意多步平移的复合都等于一步平移。

  1. 任意两个正态之间的密度之比。 对任意 μ,ν∈R，把上面「另一条路」中的 a,b 换成 μ,ν，同样的展开给出
    ϕ(x−μ)ϕ(x−ν)​=e(ν−μ)(x−μ)−(ν−μ)2/2.
    μ=0 就是 第 41 页，μ=a、ν=b 就是本页的第二段权重。
  2. 相乘就是分数约分。 这些比值都是正数，可以像普通分数一样约分：
    ϕ(x−a)ϕ(x−b)​⋅ϕ(x)ϕ(x−a)​=ϕ(x)ϕ(x−b)​=ebx−b2/2.
    这是验证本页结论最快的办法；上面按类型合并的表格，是把同一件事用指数写出来。
  3. 任意多步。 取任意一串点 0=a0​,a1​,…,ak​=b，第 j 步从 aj−1​ 挪到 aj​，权重是 ϕ(X−aj−1​)ϕ(X−aj​)​。由 第 34 页 的「连换多次」推论，总密度是连乘积，中间的分子分母两两约掉：
    j=1∏k​ϕ(X−aj−1​)ϕ(X−aj​)​=ϕ(X−a0​)ϕ(X−ak​)​=ϕ(X)ϕ(X−b)​=ebX−b2/2.
    这种「中间项全部抵消」的乘积叫望远镜乘积（像把一节节套筒收起来）。
  4. 结论。 不管怎么分段，只要每一段都以当前均值为中心，最终的概率都等于一步平移 b 的概率。例 3 是 k=2、每步 2b​ 的情形。

常见疑问与易错点

易错点问：d Q̃/dℚ 和 d Q̃/dℙ，哪个才是 Q̃ 的「密度」？

答：都是，只是参照的概率不同。同一个 Q​，相对 Q 的放大倍数是 e(b−a)(X−a)−(b−a)2/2，相对 P 的放大倍数是 ebX−b2/2，两者由链式法则联系。用哪一个，取决于你手里的样本是从哪个概率抽出来的。

易错点问：b 可以比 a 小吗？

答：可以，b−a 为负就是往左挪。例：a=3、b=1，第二段权重 e−2(X−3)−2，它随 X 增大而减小，把质量往左搬。例 2 的 b=0 是一个特例。

易错点问：两个概率都让 X ~ N(b,1)，它们是不是一定相等？

答：不一定。X 的分布只描述「和 X 有关的事件」。如果 Ω 里还有一枚和 X 无关的硬币，你可以在平移 X 的同时把硬币换成偏的：X 仍然服从 N(b,1)，但概率测度已经不同。本页能断言 Q​=Qb​，靠的是两者关于 P 的密度相同，而不仅仅是 X 的分布相同。

易错点问：链式法则的条件在这里一定满足吗？

答：满足，而且更强。三段密度 eaX−a2/2、e(b−a)(X−a)−(b−a)2/2、ebX−b2/2 都处处为正，所以 P、Q、Q​ 两两相互绝对连续（第 35 页），往哪个方向换都可以。

小结与自测

小结本页小结
  • 在 Q 下 X∼N(a,1) 时，先中心化 Y=X−a，再平移 b−a：dQdQ​​=e(b−a)(X−a)−(b−a)2/2，它就是密度之比 ϕ(X−a)ϕ(X−b)​。
  • 链式法则：两段相乘，指数中含 ab、a2 的项全部抵消，得 dPdQ​​=ebX−b2/2，与一步平移相同，所以是同一个概率测度。
  • 不中心化的权重 e(b−a)X−(b−a)2/2 在 Q 下期望是 ea(b−a)，不满足归一化。
  • b=0 给出倒数密度 dQdP​=e−aX+a2/2；分多少步平移结果都一样（望远镜乘积）。
自测
