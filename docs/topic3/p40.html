人话版一句话版

电脑只会直接生成均匀随机数 U。要从密度 q(x)=(1−α)x−α 抽样，用第 2 讲的逆变换法（第 14 页）：

  1. q 的分布函数是 G(x)=x1−α；
  2. 反解得 G−1(u)=u1/(1−α)，所以 X=U1/(1−α) 服从 q；
  3. 一个样本返回 1−αe−X​=1−αe−U1/(1−α)​。

整套重要性抽样只需要「均匀随机数 → 乘方 → 指数」三步。

这是第 5 部分「抽样中的应用」的第五页，也是 (0,1) 上这个例子的最后一页。

  • 第 38 页 选了抽样密度 q；
  • 第 39 页 证明每个样本的返回值 qh​=1−αe−X​ 有界、方差有限；
  • 本页回答最后一个问题：服从 q 的样本 X 从哪里来。课件的三个小标题正好是上面的三步。

先补基础

基础补课逆变换法（回顾第 2 讲）

若 G 是一个连续、在 (0,1) 上严格递增的分布函数，U 服从 (0,1) 上的均匀分布，则 X=G−1(U) 的分布函数就是 G（第 14 页）。理由只有一行：G−1 递增，所以

P(X≤x)=P(G−1(U)≤x)=P(U≤G(x))=G(x).

第 2 讲 第 15 页 用它从均匀分布造出了指数分布：G(x)=1−e−x，X=−log(1−U)。

基础补课幂的运算
  • ∫0x​t−αdt=1−αx1−α​（α<1，第 36 页 的基础补课）。
  • (xa)b=xab，所以 (x1−α)1/(1−α)=x1=x。这就是「反解」u=x1−α 的方法：两边同时取 1−α1​ 次方。
  • 在 (0,1) 上，指数大于 1 的幂会把数变小：例如 0.52=0.25、0.510/3≈0.099。
基础补课变量替换（换元）

若 x=ψ(u) 在 (0,1) 上可导且严格递增，则 ∫01​f(x)dx=∫01​f(ψ(u))ψ′(u)du。本页会看到：整个重要性抽样其实就是对积分 I 做了一次换元。

CDF and inverse transform｜分布函数与逆变换

分布函数：对 0<x<1，

G(x)=Q((0,x])=∫0x​(1−α)t−αdt=(1−α)⋅1−αx1−α​=x1−α;

x≤0 时 G(x)=0，x≥1 时 G(x)=1。

  • G 连续，在 (0,1) 上严格递增（1−α>0），从 G(0)=0 升到 G(1)=1。
  • 虽然密度 q 在 0 处趋于无穷，分布函数却是有限、连续的：密度无界不妨碍抽样，逆变换法只用分布函数。
  • 例：α=0.7 时 G(x)=x0.3，G(0.1)≈0.501：一半的概率集中在 (0,0.1] 这个长度只有十分之一的区间里。

逆变换：给定 u∈(0,1)，解 u=G(x)=x1−α。两边取 1−α1​ 次方：

G−1(u)=u1/(1−α).

验证：G(u1/(1−α))=(u1/(1−α))1−α=u。

A sample from q｜从 q 抽一个样本

命题（从 q 抽样）

设 U 服从 (0,1) 上的均匀分布，令

X=U1/(1−α).

则 X 的密度是 q(x)=(1−α)x−α，即 X 的分布是 Q。

证明：t↦t1/(1−α) 在 (0,1) 上严格递增，所以对 0<x<1，

P(X≤x)=P(U1/(1−α)≤x)=P(U≤x1−α)=x1−α=G(x).

（第二个等号：两边取 1−α 次方，递增函数保持大小关系；第三个等号：均匀分布 P(U≤c)=c。）分布函数决定分布（第 2 讲 第 8 页），所以 X∼Q。■

为什么样本会挤向 0：指数 1−α1​>1，而 (0,1) 里的数取大于 1 的次方会变小。α=0.7 时指数是 310​：

U 0.01 0.1 0.25 0.5 0.75 0.9 0.99
X=U10/3 2.2×10−7 4.6×10−4 0.0098 0.099 0.383 0.704 0.967

一半的 U（U<0.5）被送到了 (0,0.1) 里，正好落在 h 的「墙脚」下（第 36 页 的图解）。这就是 第 38 页 所说的「让撒点本身往墙脚下集中」。

The value returned by one sample｜一个样本返回的值

把 X=U1/(1−α) 代入 第 39 页 化简好的返回值：

R=q(X)h(X)​=1−αe−X​=1−α1​exp(−U1/(1−α)).
人话版完整的算法

要估计 I=∫01​x−αe−xdx：

  1. 生成 n 个独立的均匀随机数 U1​,…,Un​；
  2. 变换：Xi​=Ui1/(1−α)​；
  3. 计算返回值：Ri​=1−αe−Xi​​；
  4. 输出平均值 I^nIS​=n1​∑i=1n​Ri​。

由 第 38 页、第 39 页：它无偏，每个 Ri​ 都在 (1−αe−1​,1−α1​) 里，均方误差是 nVarR​。

换一个角度：这就是一次换元。直接验证 ER=I：ER=∫01​1−α1​e−u1/(1−α)du。令 u=x1−α，则 du=(1−α)x−αdx，u 从 0 到 1 时 x 也从 0 到 1：

ER=∫01​1−α1​e−x⋅(1−α)x−αdx=∫01​x−αe−xdx=I.

所以「用 q 做重要性抽样」等价于「先对 I 做换元 x=u1/(1−α)，把它变成一个没有奇点的积分 ∫01​1−αe−u1/(1−α)​du，再用均匀抽样」。被积函数有界，均匀抽样自然就好用了。

常见疑问与易错点

易错点问：密度 q 在 0 处是无穷大，真的能从它抽样吗？

答：能。密度无界不代表概率无穷：G(x)=x1−α 是一个普通的连续分布函数，每个小区间的概率都有限。逆变换法只用 G，不用 q 在某一点的值。X=U1/(1−α) 落在 0 附近的机会很大，但恰好等于 0 的概率是 0。

易错点问：为什么不直接写 X = G⁻¹(U)，还要验证分布函数？

答：逆变换法的结论需要 G−1 存在且递增。这里 G 在 (0,1) 上连续、严格递增，条件满足，一行验证 P(X≤x)=G(x) 就够了。遇到有跳跃或平台的分布函数，要用第 2 讲 第 14 页 的广义逆（分位数函数）。

易错点问：把整个方法看成「换元」，和「换测度」矛盾吗？

答：不矛盾，是同一件事的两种说法。换测度说：I=EP​h=EQ​[qh​]，X∼Q。换元说：X=G−1(U)，∫01​h(x)dx=∫01​q(G−1(u))h(G−1(u))​du。因为 G′=q，两边算的是同一个积分。前者是概率的语言，后者是微积分的语言。

小结与自测

小结本页小结
  • 分布函数：G(x)=x1−α；逆变换：G−1(u)=u1/(1−α)。
  • 抽样：X=U1/(1−α) 服从 q；指数大于 1，样本挤向奇点 0。
  • 一个样本返回 R=1−αe−X​=1−α1​e−U1/(1−α)，有界。
  • 整个重要性抽样 = 对 I 做换元 x=u1/(1−α) 消去奇点，再均匀抽样。
自测

1. 取 α=0.5。写出 G、G−1，并说明 U=0.3 时得到的样本 X 和返回值 R。

点开看答案

G(x)=x0.5=x​，G−1(u)=u2。U=0.3 时 X=0.09，R=2e−0.09≈1.828。

点开看答案

P(X<0.001)=P(U<0.0010.3)=0.0010.3≈0.126。均匀抽样落在那里的概率只有 0.001。
