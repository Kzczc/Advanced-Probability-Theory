Glossary

术语表

每个术语：中文 · 英文原词 · 一句白话解释 · 第一次出现的页面。讲义正文里带虚线的词，就是这里的术语。

  1. 集合set

    把一些对象放在一起当成一个整体，例如 {1,2,3}。

    第 1 讲 p05

  2. 元素element

    集合里的对象。ω ∈ Ω 读作「ω 属于 Ω」。

    第 1 讲 p05

  3. 子集subset

    A 的每个元素都在 B 里，就说 A 是 B 的子集，记作 A ⊆ B。

    第 1 讲 p06

  4. 空集empty set

    一个元素也没有的集合，记作 ∅。作为事件，它永远不会发生。

    第 1 讲 p06

  5. 并集union

    至少属于其中一个集合的元素全体，A ∪ B 对应「A 或 B」。

    第 1 讲 p06

  6. 交集intersection

    同时属于两个集合的元素全体，A ∩ B 对应「A 且 B」。

    第 1 讲 p06

  7. 补集complement

    样本空间里不属于 A 的元素全体，记作 Aᶜ，对应「A 不发生」。

    第 1 讲 p06

  8. 差集set difference

    在 A 里但不在 B 里的元素，记作 A \ B，等于 A ∩ Bᶜ。

    第 1 讲 p06

  9. 幂集power set

    一个集合的所有子集组成的集合族，记作 2^Ω；n 个元素的集合有 2ⁿ 个子集。

    第 1 讲 p06

  10. 集合族family of sets

    元素本身都是集合的集合，例如事件族 𝓕。

    第 1 讲 p06

  11. 德摩根律De Morgan's laws

    「并的补 = 补的交」「交的补 = 补的并」，把「非（A 或 B）」变成「非 A 且非 B」。

    第 1 讲 p06

  12. 两两不交pairwise disjoint

    一列集合中任意两个都没有公共元素，对应「任意两件事不会同时发生」。

    第 1 讲 p08

  13. 笛卡尔积Cartesian product

    A × B 是所有有序对 (a, b) 组成的集合；Aⁿ 是所有长度为 n 的数组。

    第 1 讲 p05

  14. 可数countable

    元素能排成第 1 个、第 2 个、第 3 个……的一列（有限也算），例如自然数、有理数。

    第 1 讲 p07

  15. 不可数uncountable

    无论怎么排都排不成一列，例如区间 [0,1] 里的全体实数。

    第 1 讲 p07

  16. 有理数rational number

    能写成分数 p/q 的数，全体有理数记作 ℚ；它们可数，却在数轴上处处稠密。

    第 1 讲 p17

  17. 稠密dense

    任何一小段区间里都能找到它的点，例如有理数在实数轴上稠密。

    第 1 讲 p17

  18. 区间interval

    数轴上的一段，[a,b] 包含端点，(a,b) 不包含端点。

    第 1 讲 p05

  19. 等价关系equivalence relation

    满足自反、对称、传递的「相似」关系，能把集合分成互不重叠的等价类。

    第 1 讲 p21

  20. 等价类equivalence class

    在等价关系下彼此「相似」的元素组成的一组。

    第 1 讲 p21

  21. 选择公理axiom of choice

    允许从无穷多个非空集合里各挑一个元素，组成一个新集合；维塔利集就是这样造的。

    第 1 讲 p21

  22. 函数function / map

    f: A → B 给 A 中每个元素指定 B 中唯一一个元素。

    第 1 讲 p05

  23. 原像preimage

    f⁻¹(B) 是「所有被 f 送进 B 的输入」组成的集合，可测性就是用原像定义的。

    第 1 讲 p29

  24. 示性函数indicator function

    𝟏_A(x) 在 x ∈ A 时取 1，否则取 0；它的积分就是 A 的测度。

    第 1 讲 p30

  25. 上确界supremum (sup)

    最小的上界。最大值不一定存在，但有上界的实数集一定有上确界。

    第 1 讲 p16

  26. 下确界infimum (inf)

    最大的下界。例如 (0,1] 没有最小值，但下确界是 0。

    第 1 讲 p16

  27. 上极限limit superior (lim sup)

    数列「尾部的最大可能值」的极限；对集合则表示「发生无穷多次」。

    第 1 讲 p07

  28. 下极限limit inferior (lim inf)

    数列「尾部的最小可能值」的极限；对集合则表示「从某一项起一直发生」。

    第 1 讲 p07

  29. 级数series

    无穷多项相加 a₁ + a₂ + …，它的值是前 n 项和在 n → ∞ 时的极限。

    第 1 讲 p08

  30. 单调递增nondecreasing

    后一项不小于前一项；单调有界的数列一定有极限。

    第 1 讲 p13

  31. 逐点收敛pointwise convergence

    对定义域里的每一个点 x，数列 fₙ(x) 都收敛到 f(x)。

    第 1 讲 p36

  32. 样本空间sample space

    一次试验所有可能的完整结局组成的集合，记作 Ω。

    第 1 讲 p05

  33. 样本点sample point

    一个完整的结局 ω；每次试验恰好实现一个样本点。

    第 1 讲 p05

  34. 事件event

    样本空间的（允许谈概率的）子集；实现的 ω 落在里面，就说事件发生。

    第 1 讲 p06

  35. 随机变量random variable

    从样本空间到实数的（可测）函数，把结局翻译成数字；随机性来自「实现了哪个 ω」。

    第 1 讲 p05

  36. 随机过程stochastic process

    一族随时间变化的随机变量 {Sₜ}；固定 ω 得到一条路径。

    第 1 讲 p05

  37. σ-代数sigma-algebra

    允许谈概率的「事件清单」：含 Ω，对补集和可数并封闭。

    第 1 讲 p09

  38. 生成的 σ-代数generated sigma-algebra

    包含给定集合族的最小 σ-代数 σ(𝒞)：只加入「被逼着加入」的集合。

    第 1 讲 p11

  39. 博雷尔 σ-代数Borel sigma-algebra

    由实数轴上所有开区间生成的 σ-代数 𝓑(ℝ)，包含所有常见的集合。

    第 1 讲 p11

  40. 可测空间measurable space

    一个集合加上它上面的一个 σ-代数，例如 (Ω, 𝓕)；还没有给出测度。

    第 1 讲 p12

  41. 测度measure

    给 σ-代数里的每个集合一个 [0, ∞] 中的「大小」，空集为 0，并且可数可加。

    第 1 讲 p12

  42. 测度空间measure space

    三元组 (S, 𝓜, μ)：空间、σ-代数、测度。

    第 1 讲 p12

  43. 概率测度probability measure

    总质量 P(Ω) = 1 的测度。

    第 1 讲 p03

  44. 概率空间probability space

    三元组 (Ω, 𝓕, P)：样本空间、事件的 σ-代数、概率测度。

    第 1 讲 p03

  45. 可数可加性countable additivity

    两两不交的可数个集合，并集的测度等于各自测度之和。

    第 1 讲 p08

  46. 次可加性subadditivity

    并集的测度不超过各部分测度之和：μ(A ∪ B) ≤ μ(A) + μ(B)。

    第 1 讲 p18

  47. 从下连续continuity from below

    集合一层层变大（Eₙ ↑ E）时，测度也跟着收敛：μ(Eₙ) → μ(E)。

    第 1 讲 p13

  48. 从上连续continuity from above

    集合一层层变小（Eₙ ↓ E）且 μ(E₁) < ∞ 时，μ(Eₙ) → μ(E)。

    第 1 讲 p14

  49. 点质量point mass (Dirac measure)

    把全部质量 1 放在一个点上：δ₀(E) = 1 当且仅当 0 ∈ E。

    第 1 讲 p10

  50. 初等集elementary set

    有限个有界区间的不交并；它的「长度」就是各区间长度之和。

    第 1 讲 p16

  51. 乔丹容量Jordan content

    用有限个区间从里、从外逼近一个集合；两边逼近值相等时才有定义。

    第 1 讲 p16

  52. 外测度outer measure

    用可数个区间覆盖集合，所有覆盖总长度的下确界 m*(E)；对每个子集都有定义。

    第 1 讲 p18

  53. 卡拉泰奥多里Carathéodory

    卡拉泰奥多里判别：用 E 去切任何集合 A，两块外测度之和都等于 m*(A)。

    第 1 讲 p20

  54. 维塔利集Vitali set

    用选择公理造出的「坏」集合，证明了不可能给 ℝ 的所有子集定义长度。

    第 1 讲 p21

  55. 平移不变性translation invariance

    把集合整体平移，测度不变：μ(E + t) = μ(E)。长度就有这个性质。

    第 1 讲 p21

  56. 勒贝格测度Lebesgue measure

    实数轴上「长度」的严格版本，定义在勒贝格可测集上，m([a,b]) = b − a。

    第 1 讲 p23

  57. 勒贝格可测Lebesgue measurable

    能被勒贝格测度称重量的集合（通过卡拉泰奥多里判别）。

    第 1 讲 p23

  58. 零测集null set

    测度为 0 的集合，例如单点、有理数全体、康托尔集。

    第 1 讲 p23

  59. 完备测度complete measure

    零测集的任何子集也都可测（并且测度为 0）。

    第 1 讲 p23

  60. 分割partition

    把区间 [a,b] 用分点 a = x₀ < x₁ < … < xₙ = b 切成小段。

    第 1 讲 p25

  61. 达布和Darboux sums

    每小段取函数的下确界（或上确界）乘以长度再求和；上下和夹住黎曼积分。

    第 1 讲 p25

  62. 振幅oscillation

    函数在一小段上的「最高值减最低值」M − m，衡量函数在那里抖动得多厉害。

    第 1 讲 p25

  63. 黎曼积分Riemann integral

    大一学的定积分：按 x 轴切竖条求和取极限。

    第 1 讲 p25

  64. 狄利克雷函数Dirichlet function

    在有理点取 1、无理点取 0 的函数；黎曼不可积，勒贝格积分为 0。

    第 1 讲 p28

  65. 可测函数measurable function

    对每个 a，集合 {f > a} 都可测；这样的函数才能积分。

    第 1 讲 p29

  66. 简单函数simple function

    只取有限个值的可测函数，是若干示性函数的线性组合，图像像台阶。

    第 1 讲 p30

  67. 标准表示canonical representation

    把简单函数写成 Σ aₖ 𝟏_{Aₖ}，其中 aₖ 各不相同、Aₖ = {s = aₖ}。

    第 1 讲 p30

  68. 勒贝格积分Lebesgue integral

    按函数值分块的积分：先定义简单函数的积分，再用下方的简单函数逼近取上确界。

    第 1 讲 p33

  69. 正部positive / negative part

    f⁺ = max(f, 0)，f⁻ = max(−f, 0)，f = f⁺ − f⁻，|f| = f⁺ + f⁻。

    第 1 讲 p33

  70. 几乎处处almost everywhere (a.e.)

    除了一个测度为 0 的集合之外都成立；零测集上的值不影响积分。

    第 1 讲 p43

  71. 可积integrable (L¹)

    ∫|f| dμ < ∞。全体可积函数记作 L¹(μ)。

    第 1 讲 p29

  72. 单调收敛定理monotone convergence theorem (MCT)

    非负可测函数单调递增地收敛时，积分也收敛：∫fₙ ↑ ∫f。

    第 1 讲 p36

  73. Fatou 引理Fatou's lemma

    非负可测函数列满足 ∫ liminf fₙ ≤ liminf ∫ fₙ（只保证这个方向）。

    第 1 讲 p41

  74. 控制收敛定理dominated convergence theorem (DCT)

    fₙ → f 几乎处处且 |fₙ| ≤ g、g 可积时，∫fₙ → ∫f。

    第 1 讲 p44

  75. 有界收敛定理bounded convergence theorem (BCT)

    有限测度上一致有界、几乎处处收敛的函数列，积分收敛；是 DCT 的特例。

    第 1 讲 p46

  76. 期望expectation

    随机变量对概率测度的积分 E[X] = ∫ X dP，也就是「加权平均」。

    第 2 讲 p05

  77. 分布law / distribution

    X 把概率「推」到取值空间上得到的测度：L(X)(B) = P(X ∈ B)。

    第 2 讲 p06

  78. 累积分布函数cumulative distribution function (CDF)

    F(x) = P(X ≤ x)，单调不减、右连续，完全决定分布。

    第 2 讲 p08

  79. 分位数quantile

    Q(u) = inf{x : F(x) ≥ u}，是 CDF 的「广义反函数」。

    第 2 讲 p14

  80. 逆变换法inverse transform method

    U 服从 (0,1) 上的均匀分布时，Q(U) 的分布函数恰好是 F，用来生成任意分布。

    第 2 讲 p14

  81. 概率密度density

    满足 P(X ∈ B) = ∫_B f(x) dx 的函数 f；有密度等价于 CDF 绝对连续。

    第 2 讲 p17

  82. 绝对连续absolute continuity

    函数版：小区间总长很小时增量总和也很小；测度版：Q ≪ P，P 为零的事件 Q 也为零。

    第 2 讲 p17

  83. 康托尔集Cantor set

    反复挖掉中间三分之一得到的集合：不可数，但长度为 0。

    第 2 讲 p18

  84. 阶矩moment

    E[|X|ᵖ] 叫 p 阶（绝对）矩；它有限与否反映尾部有多「重」。

    第 2 讲 p21

  85. 凸函数convex function

    图像上任意两点连线都在图像上方的函数，例如 x²、eˣ。

    第 2 讲 p23

  86. Jensen 不等式Jensen's inequality

    φ 凸时 φ(E X) ≤ E φ(X)，例如 (E X)² ≤ E X²。

    第 2 讲 p24

  87. Hölder 不等式Hölder's inequality

    E|XY| ≤ ‖X‖_p ‖Y‖_q（1/p + 1/q = 1）；p = q = 2 就是柯西–施瓦茨不等式。

    第 2 讲 p26

  88. Markov 不等式Markov's inequality

    X ≥ 0 时 P(X ≥ t) ≤ E X / t：期望小，取大值的概率就小。

    第 2 讲 p29

  89. Chebyshev 不等式Chebyshev's inequality

    P(|X − μ| ≥ t) ≤ σ² / t²：方差控制偏离均值的概率。

    第 2 讲 p29

  90. 方差variance

    Var X = E[(X − E X)²]，衡量随机变量围绕均值的波动大小。

    第 2 讲 p32

  91. 无穷多次infinitely often (i.o.)

    「Aₙ 发生无穷多次」就是集合 lim sup Aₙ。

    第 3 讲 p03

  92. Borel–Cantelli 引理Borel–Cantelli lemma

    概率之和有限 ⇒ 只发生有限次；独立且概率之和无穷 ⇒ 发生无穷多次。

    第 3 讲 p04

  93. 独立independence

    任意有限个事件同时发生的概率等于各自概率的乘积。

    第 3 讲 p06

  94. 几乎必然收敛almost sure convergence

    除了概率为 0 的结局以外，Xₙ(ω) 都收敛到 X(ω)。

    第 3 讲 p09

  95. 依概率收敛convergence in probability

    对每个 ε > 0，P(|Xₙ − X| > ε) → 0；比几乎必然收敛弱。

    第 3 讲 p14

  96. 子列subsequence

    从一个数列里按顺序挑出无穷多项组成的新数列。

    第 3 讲 p16

  97. Radon–Nikodym 导数Radon–Nikodym derivative

    Q ≪ P 时存在 L = dQ/dP ≥ 0，使 Q(A) = ∫_A L dP；它是「换测度的密度」。

    第 3 讲 p27

  98. 换测度change of measure

    用 E_Q[X] = E_P[X · dQ/dP] 在两个概率之间换算期望。

    第 3 讲 p32

  99. 重要性抽样importance sampling

    从另一个更合适的分布抽样，再乘以权重纠正，从而减小估计的方差。

    第 3 讲 p38
