## 怎么用这个网站复习

1. **每一页课件对应网站里的一页。** 左侧目录按课件的章节分组，编号就是 PDF 页码。
2. **键盘 ← → 翻页**，或点页面底部的"上一页 / 下一页"。
3. 每页的固定结构：**30 秒看懂 → 课件原文与翻译 → 手写批注整理 / 板书补全 → 逐句精讲 → 例子 → 易错点 → 小结 → 自测 → 英文词汇**。右侧"本页小标题"可以跳转。
4. 看讲解时想对照课件，点图片下方的 **"悬浮课件"**，课件会浮在右下角跟着你滚动。
5. 遇到看不懂的基础符号（$\in$、$\subseteq$、$\cup$、$\sup$、$\lim$……），去 **[零基础数学补课](/basics/)** 和 **[符号与术语速查](/glossary)**。
6. 顶部 **搜索** 支持中文和英文关键词，比如"σ-代数""Fatou""dominated"。
