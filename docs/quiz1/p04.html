An Lp bound survives Lp convergence

这道题在问什么

人话版一句话版

已知 fk​→f 在 Lp 意义下（∫∣f−fk​∣p→0），并且每个 fk​ 的「p 次方总量」都不超过同一个常数 M。要证极限 f 的总量也不超过 M：上界在取极限时不会丢。提示的路线是「Lp 收敛 ⇒ 依测度收敛 ⇒ 有几乎处处收敛的子列 ⇒ Fatou」。其实还有更直接的办法，并且能得到更强的结论：∫∣fk​∣p→∫∣f∣p。

  • 考点：题目开头复习的「两种基本收敛方式」：依测度收敛与几乎处处收敛；Markov 不等式；Riesz 子列定理；Fatou 引理。
  • 和讲义的关系：Markov 不等式（第 2 讲 第 29 页），依概率收敛有几乎必然收敛的子列（第 3 讲 第 16 页），Fatou（第 1 讲 第 41 页），Minkowski 不等式（第 2 讲 第 27 页）。
  • 和其他题的关系：小测 2 第 1 题 会说明 Lp 收敛不能推出几乎处处收敛，所以这里必须先取子列。

先补基础

基础补课Lᵖ 收敛与依测度收敛

设 p>0。

  • Lp 收敛：∫∣fk​−f∣pdμ→0。
  • 依测度收敛：对每个 ε>0，μ({∣fk​−f∣>ε})→0，即「误差超过 ε 的地方」越来越小。概率空间里叫依概率收敛（第 3 讲 第 14 页）。
  • 几乎处处收敛：使 fk​(x)→f(x) 的点组成零测集。
基础补课Markov 不等式（一般测度空间）

若 h≥0 可测，t>0，则 μ({h≥t})≤t1​∫hdμ。

理由：t1{h≥t}​≤h 逐点成立，两边积分。第 2 讲 第 29 页 在概率空间上讲过，证明对一般测度一字不改。

基础补课Riesz 子列定理

若 fk​→f 依测度，则存在子列 fkj​​→f 几乎处处。

做法：对每个 j，取 kj​（递增）使 μ(∣fkj​​−f∣>2−j)<2−j。由 ∑j​2−j<∞ 和 Borel–Cantelli 型的论证（只用到测度的可数次可加性，第 3 讲 第 4 页），几乎每一点 x 只在有限个 j 上有 ∣fkj​​(x)−f(x)∣>2−j，所以 fkj​​(x)→f(x)。概率空间里的版本见第 3 讲 第 16 页。

基础补课两个初等不等式
  1. 0<p≤1：∣a+b∣p≤∣a∣p+∣b∣p。理由：设 a,b≥0、a+b>0，令 s=a+ba​∈[0,1]；t∈[0,1] 时 tp≥t，所以 sp+(1−s)p≥s+(1−s)=1，两边乘 (a+b)p 即得。
  2. p≥1，Minkowski 不等式：∥u+v∥p​≤∥u∥p​+∥v∥p​，其中 ∥u∥p​=(∫∣u∣p)1/p（第 2 讲 第 27 页）。

题目与原解答

课件原文题目
  1. We defined convergence in probability (measure): limn→∞​P(∣Xn​−X∣>ε)=0, in general, we have convergence in measure accordingly: limn→∞​μ(∣Xn​−X∣>ε)=0.

We defined convergence almost surely (a.s.): P(limn→∞​Xn​=X)=1, in general, we have convergence almost everywhere (a.e.): μ(limn→∞​Xn​=X)=1.

If p>0 and

∫∣f−fk​∣pdμ→0

as k→∞, there is a constant M>0 such that

∫∣fk​∣p≤M,for all k,

show that

∫∣f∣p≤M.

Hint: Start from showing that fk​→f in measure.

中文翻译
  1. 我们定义过依概率收敛：P(∣Xn​−X∣>ε)→0；一般测度下相应地有依测度收敛：μ(∣Xn​−X∣>ε)→0。我们定义过几乎必然收敛：P(limXn​=X)=1；一般测度下相应地有几乎处处收敛。

设 p>0，k→∞ 时 ∫∣f−fk​∣pdμ→0，并且存在常数 M>0 使得对所有 k，∫∣fk​∣p≤M。证明 ∫∣f∣p≤M。

提示：先证明 fk​→f 依测度收敛。

易错点题目的一处笔误：一般测度下的 a.e. 收敛

题目把一般测度下的几乎处处收敛写成 μ(limXn​=X)=1。一般测度的总量不一定是 1（例如 R 的长度是 ∞），正确的写法是例外集测度为 0：μ({limXn​=X})=0（包括极限不存在的点）。概率空间里两种写法等价，一般测度下只有后一种对。

原解答的思路（左栏方框）：

  1. 用反证法说明 fk​→f 依测度（这一段写得比较乱，见下文）；
  2. 由依测度收敛取一个几乎处处收敛的子列 fkj​​；
  3. 对 ∣fkj​​∣p 用 Fatou：∫∣f∣p≤liminf∫∣fkj​​∣p≤M。

思路：怎么想到的

  • 为什么不能直接用 Fatou：Fatou 需要逐点（几乎处处）收敛，可我们只知道 Lp 收敛，而 Lp 收敛推不出几乎处处收敛（小测 2 第 1 题）。
  • 补救：Lp 收敛 ⇒ 依测度收敛（Markov 不等式）⇒ 存在几乎处处收敛的子列（Riesz）。对子列用 Fatou；子列的积分也都 ≤M，结论不受影响。
  • 另一条路：∫∣f∣p 和 ∫∣fk​∣p 只差一个「误差项」，而误差项 ∫∣f−fk​∣p→0。只要有一个把 ∣f∣p 拆成 ∣fk​∣p 加误差的不等式，就能直接得到结论，连子列都不用取。

完整解答

方法一（按提示）：依测度收敛 + 子列 + Fatou

第 1 步（Lp 收敛 ⇒ 依测度收敛）：固定 ε>0。{∣fk​−f∣>ε}={∣fk​−f∣p>εp}，由 Markov 不等式，

μ(∣fk​−f∣>ε) ≤ εp1​∫∣fk​−f∣pdμ k→∞​ 0.

所以 fk​→f 依测度。

第 2 步（取子列）：由 Riesz 子列定理，存在子列 fkj​​→f 几乎处处。于是 ∣fkj​​∣p→∣f∣p 几乎处处（t↦∣t∣p 连续）。

第 3 步（Fatou）：∣fkj​​∣p≥0，由 Fatou，

∫∣f∣pdμ=∫jliminf​∣fkj​​∣pdμ ≤ jliminf​∫∣fkj​​∣pdμ ≤ M.

最后一步用了每个 ∫∣fkj​​∣p≤M。■

方法二（更直接）：用不等式把 f 拆成 fₖ 加误差

情形 0<p≤1：由 ∣a+b∣p≤∣a∣p+∣b∣p（取 a=fk​，b=f−fk​），

∫∣f∣p≤∫∣fk​∣p+∫∣f−fk​∣p≤M+∫∣f−fk​∣p k→∞​ M.

情形 p≥1：由 Minkowski 不等式，

∥f∥p​≤∥fk​∥p​+∥f−fk​∥p​≤M1/p+∥f−fk​∥p​ k→∞​ M1/p,

两边取 p 次方得 ∫∣f∣p≤M。■

更强的结论：同样的不等式把 f 和 fk​ 的角色对调，可以得到

​∫∣fk​∣p−∫∣f∣p​≤∫∣fk​−f∣p (0<p≤1),​∥fk​∥p​−∥f∥p​​≤∥fk​−f∥p​ (p≥1),

所以 ∫∣fk​∣p→∫∣f∣p：Lp 收敛蕴含 p 次方总量收敛。题目的结论 ∫∣f∣p=lim∫∣fk​∣p≤M 只是它的推论。

原解答逐行对照

  1. 「Suppose that there is ε>0 such that ∣X∣≥ε for all k, where E={∣f−fk​∣>ε}」：意思应当是「假设不依测度收敛：存在 ε>0，使得对无穷多个 k，μ(Ek​)≥ε，其中 Ek​={∣f−fk​∣>ε}」。写成「∣X∣≥ε」是笔误。
  2. 「∫∣f−fk​∣p≥∫E​∣f−fk​∣p≥∫E​εp≥εp+1>0」：在 Ek​ 上 ∣f−fk​∣p>εp，所以 ∫∣f−fk​∣p≥εpμ(Ek​)≥εp⋅ε=εp+1。这对无穷多个 k 成立，与 ∫∣f−fk​∣p→0 矛盾。思路正确。
  3. 「for all ε. Hence, we have fk​→f in measure」：反证法的结论。
  4. 「we use the previous problem ... there exists a subsequence fkj​​→f a.e.」：这里用的是 Riesz 子列定理，并不是「上一题」（第 3 题讲的是 L1 收敛的等价条件）。
  5. Fatou 一行：正确。
易错点原解答的问题：反证法写得混乱，而且没有必要

原解答把两个不同的量（误差阈值和集合的测度）都叫 ε，「∣X∣≥ε」也是笔误，读起来很难懂。实际上用 Markov 不等式一行就能直接证明依测度收敛（方法一第 1 步），不需要反证。如果坚持用反证法，应写成：「若不然，存在 ε,δ>0 和无穷多个 k，使 μ(∣f−fk​∣>ε)≥δ，于是 ∫∣f−fk​∣p≥εpδ，与 Lp 收敛矛盾。」

易错点原解答的问题：子列结论的出处写错

「依测度收敛有几乎处处收敛的子列」是 Riesz 子列定理（概率版本见第 3 讲 第 16 页），不是第 3 题的结论。

例子与数值验证

例 1：总量的极限就是极限的总量

[0,1] 上 fk​(x)=1+kx​，f≡1，p=2。

  • ∫∣fk​−f∣2=∫01​k2x2​dx=3k21​→0，L2 收敛。
  • ∫∣fk​∣2=1+k1​+3k21​：k=1 时 ≈2.333，k=10 时 ≈1.103，k=100 时 ≈1.010，趋于 ∫∣f∣2=1。
  • 取 M=37​（所有 ∫∣fk​∣2 的最大值），结论 1≤37​ 成立；而且由「更强的结论」，1 正是 ∫∣fk​∣2 的极限。
例 2：只有几乎处处收敛时，上界也保持（但总量可以丢）

fk​=k1/p1(0,1/k)​ 在 [0,1] 上：∫∣fk​∣p=1=:M，fk​→0 处处，但不在 Lp 中收敛（∫∣fk​−0∣p=1）。由 Fatou，∫∣0∣p=0≤1，上界保持；但总量从 1 掉到 0，不再相等。对比例 1：Lp 收敛时总量不会丢。

例 3：为什么 p ≥ 1 时不能用粗糙的不等式

p≥1 时也有 ∣a+b∣p≤2p−1(∣a∣p+∣b∣p)（凸性）。用它只能得到 ∫∣f∣p≤2p−1(M+∫∣f−fk​∣p)→2p−1M，比 M 大，不够。比如 p=2 时只得到 ≤2M。要得到精确的 M，必须用 Minkowski（或方法一的 Fatou）。

拓展延伸

范数的下半连续性

方法一其实证明了一个更一般的事实：若 fk​→f 几乎处处（或依测度），则

∫∣f∣p≤kliminf​∫∣fk​∣p.

这叫「Lp 范数在几乎处处收敛下是下半连续的」：极限的范数不会比序列的范数「跳上去」，只可能「掉下来」（例 2）。Lp 收敛时不会掉，范数连续。

Lᵖ 空间的完备性（Riesz–Fischer 定理）

方法一的「先取快速收敛的子列，再用 Fatou」正是证明 Lp 完备（柯西列一定收敛）的标准方法：对 Lp 中的柯西列，取子列使 ∥fkj+1​​−fkj​​∥p​<2−j，证明它几乎处处收敛到某个 f，再用 Fatou 证明 f∈Lp 且 ∥fk​−f∥p​→0。

收敛方式的关系图
从 到 成立吗
Lp 收敛 依测度收敛 成立（Markov）
依测度收敛 几乎处处收敛 不成立，但有 a.e. 收敛的子列（Riesz）
Lp 收敛 几乎处处收敛 不成立（小测 2 第 1 题）
几乎处处收敛 Lp 收敛 不成立（例 2 的尖峰）；加上一致可积或范数收敛就成立
几乎处处收敛 依测度收敛 有限测度时成立（第 3 讲 第 14 页）

常见疑问与易错点

易错点问：对子列用 Fatou，得到的结论为什么对 f 成立？

答：子列 fkj​​ 几乎处处收敛到的就是 f（依测度收敛的极限在 a.e. 意义下唯一）。Fatou 给出的是关于极限函数 f 的不等式，与选了哪个子列无关。

易错点问：0 < p < 1 时 ∫|f|ᵖ 的 p 次方根还是范数吗？

答：不是：三角不等式 ∥u+v∥p​≤∥u∥p​+∥v∥p​ 在 p<1 时不成立。但 ∫∣u+v∣p≤∫∣u∣p+∫∣v∣p 成立，所以 d(u,v)=∫∣u−v∣p 仍是一个距离。方法二用的正是这个不等式。

易错点问：题目给的 M > 0 有用吗？

答：M 只需要是有限常数；M>0 没有实质作用（若所有 ∫∣fk​∣p=0，结论 ∫∣f∣p=0 也成立）。

小结与自测

小结本题小结
  • 方法一（提示）：Markov 不等式 ⇒ 依测度收敛 ⇒ Riesz 子列 a.e. 收敛 ⇒ Fatou ⇒ ∫∣f∣p≤M。
  • 方法二：0<p≤1 用 ∣a+b∣p≤∣a∣p+∣b∣p，p≥1 用 Minkowski，直接得到；并且 ∫∣fk​∣p→∫∣f∣p。
  • 原解答：反证法一段笔误较多（应写 μ(Ek​)≥δ），子列结论应归于 Riesz 定理。
  • 题目笔误：一般测度下 a.e. 收敛应写成 μ({limXn​=X})=0。
自测

μ(∣fk​−f∣>0.1)≤0.011​∫∣fk​−f∣2=100∫∣fk​−f∣2→0。

能，直接用 Fatou：∫∣f∣p=∫liminf∣fk​∣p≤liminf∫∣fk​∣p≤M。不需要取子列。

3. 举一个 fk​→f 几乎处处、∫∣fk​∣p≤M，但 ∫∣f∣p<liminf∫∣fk​∣p 的例子。

依测度收敛convergence in measure对每个 ε > 0，μ(|fₙ − f| > ε) → 0：偏差超过 ε 的区域，测度越来越小。在概率空间上就是依概率收敛。
几乎处处almost everywhere (a.e.)除了一个测度为 0 的集合之外都成立；零测集上的值不影响积分。
子列subsequence从一个数列里按顺序挑出无穷多项组成的新数列。
Markov 不等式Markov's inequalityX ≥ 0 时 P(X ≥ t) ≤ E X / t：期望小，取大值的概率就小。
Riesz 子列定理Riesz's subsequence theorem依测度（依概率）收敛的序列，一定有一个子列几乎处处收敛到同一个极限。
Fatou 引理Fatou's lemma非负可测函数列满足 ∫ liminf fₙ ≤ liminf ∫ fₙ（只保证这个方向）。
测度measure给 σ-代数里的每个集合一个 [0, ∞] 中的「大小」，空集为 0，并且可数可加。
几乎必然收敛almost sure convergence除了概率为 0 的结局以外，Xₙ(ω) 都收敛到 X(ω)。
依概率收敛convergence in probability对每个 ε > 0，P(|Xₙ − X| > ε) → 0；比几乎必然收敛弱。
概率空间probability space三元组 (Ω, 𝓕, P)：样本空间、事件的 σ-代数、概率测度。
零测集null set测度为 0 的集合，例如单点、有理数全体、康托尔集。
次可加性subadditivity并集的测度不超过各部分测度之和：μ(A ∪ B) ≤ μ(A) + μ(B)。
可数countable元素能排成第 1 个、第 2 个、第 3 个……的一列（有限也算），例如自然数、有理数。
集合set把一些对象放在一起当成一个整体，例如 {1,2,3}。
一致可积uniformly integrable一族随机变量的尾部期望一致地变小：supₜ E[|Xₜ|; |Xₜ| > λ] → 0（λ → ∞）。它是「依概率收敛 ⇒ 期望收敛」的关键条件。
