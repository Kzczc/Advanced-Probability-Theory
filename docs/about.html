这个网站是什么

这是「高等概率论」课程的复习网站，写给数学基础比较薄弱、英语读起来吃力的同学。目标是：只看这个网站，就能把课件和作业一页一页地读懂。

  • 四讲课件，共 147 页：第 1 讲「测度与积分」（47 页，带老师的手写批注）；第 2 讲「随机变量、期望与不等式」（32 页）；第 3 讲「Borel–Cantelli、收敛与 Radon–Nikodym」（47 页）；第 4 讲「乘积测度与独立性」（21 页）。第 2–4 讲是课堂空白版。
  • 作业与小测，共 32 道题：作业 1、作业 2 各 12 题，小测 1、小测 2 各 4 题。每道题单独一页，附解答原页对照。
  • 每一页都是左右对照：左边是课件原页（练习页是解答原页中这道题所在的那几段），右边是中文精讲。

内容是怎样写成的

  • 课件原文：从页图逐句转写，再翻译成中文。公式一律按图片辨认，不用 PDF 的文字层（文字层会丢失上下标）。
  • 老师板书：第 1 讲的手写批注逐条转写，并解释每一条在说什么。
  • 课件留白：第 2–4 讲的空白处（定义、定理、证明）由本站根据标准教材补写，页面上会用一张标题为「说明」的卡片注明。如与老师课堂上的写法不同，以老师为准。
  • 作业与小测：随作业、小测附带的解答原页不一定是标准答案。精讲会补全跳过的步骤，并在「原解答逐行对照」一节里指出笔误、跳步和错误，给出正确写法。每个练习的目录页末尾有「原解答问题速览」，把这些地方汇总在一起。
  • 数值：例子里的数值和模拟结果都用程序重新算过。模拟结果带有随机误差，换一组随机数会略有不同。
  • 讲义里没讲过的工具（条件期望、鞅、中心极限定理等）：在「先补基础」卡片里讲清定义和结论，注明「作为已知结论使用」，并给出 Durrett《Probability: Theory and Examples》中的出处。

每一页按同一个顺序讲

讲义页：这一页在讲什么 → 先补基础 → 课件原文逐句精读 → 老师板书在说什么（第 2–4 讲为「补全课件留白」）→ 图解 → 例子 → 推导 → 常见疑问与易错点 → 小结与自测。页面末尾有「本页术语」中英对照表；如果作业或小测里有题用到了这一页，还会列出「相关练习」。

练习页：这道题在问什么 → 先补基础 → 题目与原解答 → 思路：怎么想到的 → 完整解答 → 原解答逐行对照 → 例子与数值验证 → 拓展延伸 → 常见疑问与易错点 → 小结与自测。建议先看「这道题在问什么」和「思路」，自己动手写一遍，再对照「完整解答」。

卡片的颜色：每张卡片左上角的小标签说明它的作用。

怎样使用

  • 翻页：页面底部的「上一页 / 下一页」，或键盘 ← →。左上角「目录」打开本讲（本练习）的全部页面。
  • 放大原页：点击左边的课件原页或解答原页，可以全屏查看；再点一下放大到原尺寸，Esc 关闭。
  • 查术语：正文里带虚线的词，鼠标停留（手机上点一下）就会弹出白话解释；完整列表见术语表。
  • 搜索：右上角「搜索」或按 /，中文、英文关键词都可以。点开结果后，页面会自动滚动到第一处匹配的文字并高亮。
  • 记录进度：读懂一页就勾选页面底部的「这一页我看懂了」，目录和首页会显示进度；首页的「继续上次阅读」直接回到你上次看的那一页。
  • 专注阅读：右上角「专注阅读」把原页缩到讲义上方，讲义居中显示（宽屏时可用）。
  • 字号：右上角 A− / A+。
  • 夜间模式：右上角「夜间」，再点一次回到日间。没有手动选过时，跟随系统的深色 / 浅色设置。
  • 手机：原页显示在讲义上方；顶部导航收起时，点左上角的标题回到首页。
  • 打印：打印时自动隐藏导航和原页图，自测答案和「展开更多细节」会全部展开。

发现错误怎么办

讲义难免有错。如果你发现了笔误、算错的数、讲不通的地方，欢迎在 GitHub 上提交问题，写明是哪一讲第几页（或哪个练习第几题）、哪一句，以及你认为正确的写法。

隐私

本站是纯静态网页，不收集任何数据，没有统计或广告脚本。「看懂了」的勾选、上次读到哪一页、字号、夜间模式等设置，只保存在你自己浏览器的本地存储里；换一台设备或清除浏览器数据，这些记录就会重置。
