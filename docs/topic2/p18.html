这一页在讲什么

人话版一句话版

从 [0,1] 开始，一遍遍挖掉每段中间的三分之一，剩下的点组成康托尔集 C。它的总长度是 0，却有不可数多个点——因为每个点都对应一串 0/1 的无穷序列（这就是标题里的「二进编码」）。

  • 位置：第 2 部分，为下一页的反例做准备。第 17 页 说「有密度 ⟺ CDF 绝对连续」；第 19 页 要造一个 CDF 连续、却没有密度的分布，它需要一个「点多到不可数、长度却为 0」的集合来存放全部概率——康托尔集正好合适。
  • 要澄清的误解：直觉上「长度为 0 的集合，点很少（可数个）」。康托尔集说明这是错的：零测集可以不可数。
  • 第 1 讲的回顾：可数集一定是零测集（第 17 页、第 23 页）；本页给出反方向的反例。

先补基础

基础补课三进制小数

就像十进制小数 0.d1​d2​d3​… 表示 ∑k​dk​10−k，三进制小数 0.t1​t2​t3​…(3)​（每个 tk​∈{0,1,2}）表示

x=k≥1∑​3ktk​​=3t1​​+9t2​​+27t3​​+⋯.
  • 第一位 t1​ 告诉你 x 在 [0,1] 的哪个三分之一里：t1​=0 在 [0,31​]，t1​=1 在 [31​,32​]，t1​=2 在 [32​,1]。
  • 例：31​=0.1000…(3)​=0.0222…(3)​（和十进制的 0.1=0.0999… 一样，有些数有两种写法）；41​=0.020202…(3)​（因为 92​⋅1−1/91​=92​⋅89​=41​）。
基础补课二进制与 0/1 序列

二进制小数 0.b1​b2​b3​…(2)​=∑k​bk​2−k（bk​∈{0,1}）能表示 [0,1] 里的每个数。所有无穷 0/1 序列 (b1​,b2​,…) 组成的集合记作 {0,1}N。它是不可数的（第 7 页 的无穷次抛硬币就是它；对角线论证见 基础补课）。

基础补课闭集

「闭集」可以简单理解为「包含了自己所有边界点」的集合，例如闭区间 [a,b]。闭集的交仍是闭集，有限个闭区间的并也是闭集。闭集都是博雷尔集，所以可以谈测度。

课件原文逐句精读

课件原文The Cantor set and its binary encoding

Definition 18 (Middle-thirds Cantor set) Start with C0​=[0,1]. To obtain Cn+1​, delete the open middle third of every interval in Cn​, keeping all endpoints. Thus

C1​C2​​=[0,31​]∪[32​,1],=[0,91​]∪[92​,31​]∪[32​,97​]∪[98​,1].​

Define C:=⋂n≥0​Cn​. Each Cn​ contains 2n disjoint closed intervals of length 3−n. Hence C is closed, and

0≤Leb(C)≤Leb(Cn​)=(2/3)n→0.
中文翻译

定义 18（三分康托尔集） 从 C0​=[0,1] 开始。要得到 Cn+1​，就把 Cn​ 中每个区间的开的中间三分之一删掉，保留所有端点。于是 C1​=[0,31​]∪[32​,1]，C2​=[0,91​]∪[92​,31​]∪[32​,97​]∪[98​,1]。

定义 C:=⋂n≥0​Cn​。每个 Cn​ 由 2n 个互不相交、长度为 3−n 的闭区间组成。因此 C 是闭集，并且 0≤Leb(C)≤Leb(Cn​)=(2/3)n→0。

（后面的「二进编码」课件留白，见下一节。）

delete the open middle third, keeping all endpoints｜每一步做什么

  • open middle third（开的中间三分之一）：从 [0,1] 删掉 (31​,32​)，不含端点 31​,32​，所以端点留下。
  • 每一步，每个剩下的区间都一分为三、删掉中间那份、保留两边两份：区间个数翻倍，每段长度变成原来的 31​。
步数 n 区间个数 每段长度 总长度 Leb(Cn​) 这一步删掉的总长度
0 1 1 1 —
1 2 1/3 2/3 1/3
2 4 1/9 4/9 2/9
3 8 1/27 8/27 4/27
n 2n 3−n (2/3)n 2n−1/3n

Define C := ⋂ Cₙ｜康托尔集是什么

  • C 是所有步都没被删掉的点。C0​⊇C1​⊇C2​⊇⋯ 一层层缩小。
  • C 是闭集：每个 Cn​ 是有限个闭区间的并，是闭集；闭集的交还是闭集。
  • Leb(C)=0：C⊆Cn​，测度单调（第 12 页），所以 Leb(C)≤(2/3)n 对每个 n 成立，只能是 0。（也可以用从上连续 第 14 页：Leb(Cn​)↓Leb(C)。）
  • 被删掉的总长度：31​+92​+274​+⋯=31​⋅1−2/31​=1，全部长度都被删光了。

命题康托尔集的二进编码
  1. 三进制刻画：x∈C 当且仅当 x 有一个三进制展开 x=∑k≥1​tk​3−k，其中每一位 tk​∈{0,2}（不出现 1）。
  2. 与 0/1 序列一一对应：映射
    Φ:{0,1}N→C,(b1​,b2​,…)↦k≥1∑​3k2bk​​
    是双射（把三进制数字里的 2 换成 1，就得到二进制数字）。
  3. 因此 C 不可数，但 Leb(C)=0。
推导证明思路

第 k 步删掉的正是「第 k 位三进制数字只能是 1」的那些点，所以留下来的点每一位都可以选 0 或 2；而「每一位二选一」的方式和 0/1 序列一样多。

第 1 步（第一位）：x∈[0,1] 的第一位三进制数字 t1​ 决定它在哪个三分之一里。删掉的开区间 (31​,32​) 里的点，第一位只能是 1（没有别的写法）；留下的 [0,31​] 可以写成 t1​=0，[32​,1] 可以写成 t1​=2。端点 31​=0.0222…(3)​ 也能避开 1。所以 x∈C1​⟺ 有一个展开使 t1​∈{0,2}。

第 2 步（逐位归纳）：在 C1​ 的每个小区间里重复同样的论证，第二位 t2​ 决定在这个小区间的哪个三分之一里，删掉的中间三分之一恰好是 t2​ 只能为 1 的点。一般地，x∈Cn​⟺ 有展开使 t1​,…,tn​∈{0,2}。对所有 n 取交，就得到第 1 条。

第 3 步（双射）：

  • 映射 Φ 把 (bk​) 送到三进制数字为 tk​=2bk​∈{0,2} 的数，由第 1 条它落在 C 里。
  • 满射：C 里每个点都有只含 0、2 的展开，令 bk​=tk​/2 即可。
  • 单射：两个只含 0、2 的不同序列，在第一个不同的位置 k 上，一个是 0、一个是 2；后面所有位的差最多是 ∑j>k​2⋅3−j=3−k，而第 k 位造成的差是 2⋅3−k，所以两个数之差至少是 2⋅3−k−3−k=3−k>0，两数不同。

第 4 步（不可数）：{0,1}N 不可数，Φ 是双射，所以 C 不可数。■

  • C1​：[0,31​] 与 [32​,1] 两段，中间的 (31​,32​) 空了。

每往下一行，每段都「掰成两半、扔掉中间」。课件上没有画图，这张想象图就是定义 18 的全部内容。注意：留下来的点越来越「稀」，但永远不会被删光——每一步的端点永远留下。

例子

例 1：哪些点在康托尔集里？
  • 0、1、31​、32​、91​、92​……：所有步骤的端点都在 C 里（它们从不被删掉），这样的点有可数多个。
  • 41​=0.020202…(3)​：每一位都是 0 或 2，所以 41​∈C。但它不是任何一步的端点（端点都是 3nm​ 的形式）。所以康托尔集里不只有端点。
  • 21​=0.1111…(3)​：第一位就是 1，而且没有别的写法，所以 21​∈/C（它在第一步就被删掉了）。
例 2：用编码读出位置

序列 b=(1,0,1,0,…)（交替）对应 x=Φ(b)=32​+272​+2432​+⋯=32​⋅1−1/91​=43​。验证：43​=0.2020…(3)​，每一位都是 0 或 2，确实在 C 里。读法：第 1 位是 1（二进制）→「走右边的三分之一」，第 2 位是 0 →「在其中走左边的三分之一」……编码就是一份「每一步往左还是往右」的路线图。

例 3：长度与点数的对比
集合 点的个数 勒贝格测度
有理数 Q∩[0,1] 可数 0
康托尔集 C 不可数 0
[0,1] 不可数 1

所以「测度为 0」和「可数」不是一回事：可数 ⇒ 测度 0，但测度 0 ⇏ 可数。

常见疑问与易错点

易错点问：每一步都删掉了点，最后会不会什么都不剩？

答：不会。每一步删的是开区间，所有端点都永远保留，所以 C 至少包含可数多个端点；由二进编码，它甚至有不可数多个点。「长度被删光」和「点被删光」是两回事。

易错点问：既然 C 的长度为 0，为什么它能「装下」不可数多个点？

答：长度是对集合的「宽度」的度量，不是对点数的计数。单个点长度为 0；可数多个点用 ε/2n 的技巧也能盖住；康托尔集说明，即使不可数多个点，只要排列得足够「稀疏」，也能被总长度任意小的区间盖住（第 n 步的 2n 段，总长 (2/3)n）。

易错点问：为什么编码要用 0 和 2，而不是 0 和 1？

答：三进制数字 1 恰好对应「被删掉的中间三分之一」，所以康托尔集里的点不用数字 1；剩下的两种选择 0、2 与二进制的 0、1 一一对应。这就是标题 binary encoding（二进编码）的意思。

小结与自测

小结本页小结
  • 康托尔集 C=⋂n​Cn​：每步删掉每段的开的中间三分之一；Cn​ 有 2n 段、每段长 3−n。
  • C 是闭集，Leb(C)≤(2/3)n→0，所以测度为 0；删掉的总长度恰好是 1。
  • 二进编码：x∈C⟺ 三进制展开只用 0 和 2；把 2 换成 1 得到与 {0,1}N 的双射，所以 C 不可数。
  • 零测集可以不可数——这是下一页构造「连续但无密度」分布的关键。
自测

23=8 段，每段长 271​，总长度 278​。C2​ 总长 94​=2712​，所以第 3 步删掉了 274​。

2. 101​ 在康托尔集里吗？（提示：101​ 在 [0,91​] 吗？）

点开看答案

91​≈0.111>101​=0.1，所以 101​∈[0,91​]，前两步都留下了。再看第 3 步：[0,91​] 被分成 [0,271​]、(271​,272​)、[272​,91​]，而 271​≈0.037，272​≈0.074，0.1 落在 [272​,91​]，留下。继续下去需要算三进制：101​=0.00220022…(3)​（循环节 0022），每一位都是 0 或 2，所以 101​∈C。

3. 判断：测度为 0 的集合一定只有可数多个点。

点开看答案
