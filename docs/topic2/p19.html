这一页在讲什么

人话版一句话版

用无穷次抛硬币决定「在康托尔集里往左走还是往右走」，得到一个随机点 X。它的 CDF（著名的「魔鬼阶梯」）处处连续，却没有密度：全部概率都落在长度为 0 的康托尔集上，导数几乎处处是 0。

  • 位置：第 2 部分的关键反例。第 17 页 说「有密度 ⟺ CDF 绝对连续」，第 18 页 准备了「不可数、长度为 0」的康托尔集 C。这一页把两者结合：造一个分布，没有原子（所以 CDF 连续），又没有密度（所以 CDF 不绝对连续）。
  • 它打破的直觉：「CDF 连续就有密度」「CDF 几乎处处导数为 0 就是常数」——两条都错。
  • 后面怎么用：第 20 页 把它作为分布的「第三种成分」（奇异连续部分）的标准例子；第 1 讲 第 42 页 与第 3 讲 第 47 页 用它说明 ∫01​F′<F(1)−F(0) 可以严格。

先补基础

基础补课独立的公平硬币

ξ1​,ξ2​,… 是独立的公平硬币：每个 ξk​ 以概率 21​ 取 0、21​ 取 1，并且前 n 个取某一串指定值的概率是 2−n（例如 P(ξ1​=1,ξ2​=0,ξ3​=1)=81​）。独立性的正式定义在第 3 讲 第 6 页；这里只用「前 n 位取定的概率是 2−n」这一点。第 1 讲 第 23 页 的注释还说明了：这样的硬币序列可以严格地在 [0,1) 上用勒贝格测度造出来。

基础补课回顾：康托尔集的编码（第 18 页）

C 中的点恰好是三进制展开只用 0 和 2 的数，Φ(b1​,b2​,…)=∑k​2bk​3−k 是从 0/1 序列到 C 的双射。第 k 位决定「在当前小区间里走左边三分之一（bk​=0）还是右边三分之一（bk​=1）」。

例子反例 19（康托尔分布）

设 ξ1​,ξ2​,… 是独立的公平 0/1 硬币，令

X=k≥1∑​3k2ξk​​.

X 的分布叫康托尔分布，它的 CDF F 叫康托尔函数。则：

  1. X∈C（康托尔集）恒成立，所以 P(X∈C)=1；
  2. 对每个 x∈R，P(X=x)=0，所以 F 处处连续；
  3. X 没有勒贝格密度，所以 F 不是绝对连续的；
  4. F′(x)=0 对几乎所有 x 成立，但 F(0)=0、F(1)=1。
推导证明思路

第 1 条是编码的直接结果；第 2 条因为「命中一个具体的点」需要无穷多位都对上，概率是 2−n→0；第 3 条用反证：若有密度，在零测集 C 上积分只能是 0，与 P(X∈C)=1 矛盾；第 4 条因为 F 在每个被删掉的区间上是常数。

第 1 步（X 总在康托尔集里）：X 的三进制数字是 tk​=2ξk​∈{0,2}，由 第 18 页 的刻画，X∈C。所以 P(X∈C)=1。

第 2 步（没有原子）：任取 x。若 x∈/C，则 P(X=x)=0。若 x∈C，它对应唯一的序列 b=Φ−1(x)（双射），于是 X=x 意味着 ξk​=bk​ 对所有 k 成立，所以

P(X=x)≤P(ξ1​=b1​,…,ξn​=bn​)=2−n对每个 n,

只能是 0。由 第 8 页，P(X=x)=F(x)−F(x−)，所以 F 没有跳跃、处处连续。

第 3 步（没有密度）：反设 X 有密度 f。则

1=P(X∈C)=∫C​f(x)dx=0,

最后一步因为 Leb(C)=0，非负函数在零测集上积分为 0（第 43 页）。矛盾。由 第 17 页 的定理 17，F 不绝对连续。

第 4 步（导数几乎处处为 0）：被删掉的每个开区间（如 (31​,32​)、(91​,92​)……）都与 C 不相交，X 落在里面的概率是 0，所以 F 在这些区间上是常数，导数为 0。这些区间的总长度是 1−Leb(C)=1，所以 F′=0 几乎处处。而 F(0)=P(X≤0)=P(X=0)=0，F(1)=1。■

康托尔函数长什么样：「魔鬼阶梯」

  • X≤31​ 当且仅当 ξ1​=0（第一步走左边），所以 F(31​)=21​；同理 F(32​)=P(X≤32​)=P(ξ1​=0)=21​。所以在整个 [31​,32​] 上 F=21​——一级平台。
  • 第二层：F(91​)=F(92​)=41​，F(97​)=F(98​)=43​——又多了两级平台。
  • 一般地，若 x∈C 的三进制数字是 tk​∈{0,2}，则
    F(x)=k≥1∑​2ktk​/2​(把三进制的 2 换成 1，当成二进制读).
    例：x=41​=0.0202…(3)​，F(41​)=0.0101…(2)​=31​。

图像是一道有无穷多级平台的楼梯：平台占满了几乎全部长度，楼梯却从 0 连续地爬到 1——所有「爬升」都发生在长度为 0 的康托尔集上。所以叫魔鬼阶梯（devil's staircase）。

例子

例 1：计算几个概率
  • P(X≤31​)=21​，P(31​<X<32​)=0（被删掉的区间）。
  • P(X∈[92​,31​])=P(ξ1​=0,ξ2​=1)=41​。
  • P(X>98​)=P(ξ1​=1,ξ2​=1)=41​（x=98​ 本身概率为 0）。
例 2：均值与方差（期望是线性的，独立变量的方差可加）
  • EX=∑k​3k2Eξk​​=∑k​3k1​=1−1/31/3​=21​。也可以由对称性看出：1−X=∑k​3k2(1−ξk​)​ 与 X 同分布，所以均值是 21​。
  • VarX=∑k​9k4Varξk​​=∑k​9k4⋅41​​=1−1/91/9​=81​。

（交换期望与无穷求和用的是单调收敛定理 第 36 页；方差相加用到独立性，见第 3 讲。）对比：[0,1] 上均匀分布的方差是 121​≈0.083，康托尔分布 81​=0.125 更大——它的质量更多地挤向两端。

例 3：用 第 12 页 的公式算均值，不需要密度

EX=∫01​(1−F(x))dx。由对称性 F(1−x)=1−F(x)（除可数个点外），所以 ∫01​F=∫01​(1−F)，两者相加为 1，各为 21​。和例 2 一致。这再次说明：用 CDF 算期望的公式不依赖于密度是否存在。

常见疑问与易错点

易错点问：F′ = 0 几乎处处，为什么 F 不是常数？

答：微积分基本定理「F(1)−F(0)=∫01​F′」需要 F 绝对连续（第 17 页）。康托尔函数不绝对连续，所以 ∫01​F′=0=1=F(1)−F(0)。导数「看不见」发生在零测集上的增长。

易错点问：现实中会遇到这种分布吗？

答：很少直接遇到，但它的意义在于划清概念的边界：「没有原子」和「有密度」是两回事，中间还有一类「奇异连续」的分布。下一页的分解定理说：一般分布就是这三种成分的混合。

易错点问：X 是不可数多个值中的一个，每个值概率都是 0，概率加起来怎么会是 1？

答：可数可加只对可数个不交事件成立；康托尔集不可数，不能把单点概率相加。这和 [0,1] 上均匀分布的情形一样（第 23 页）。

小结与自测

小结本页小结
  • 康托尔分布：X=∑k​2ξk​/3k，ξk​ 独立公平 0/1，X∈C 恒成立。
  • 没有原子（P(X=x)≤2−n→0）⇒ CDF 连续；但 P(X∈C)=1、Leb(C)=0 ⇒ 没有密度 ⇒ CDF 不绝对连续。
  • 康托尔函数（魔鬼阶梯）：在每个被删区间上是常数，F′=0 a.e.，却从 0 连续地升到 1。
  • EX=21​，VarX=81​。
自测

1. 求 P(X≤91​) 和 F(21​)。

点开看答案

X≤91​ ⟺ ξ1​=ξ2​=0，概率 41​。21​ 落在被删掉的 (31​,32​) 里，F 在那里恒为 21​，所以 F(21​)=21​。

2. 若改成 Y=∑k​ξk​/2k（二进制而不是三进制），Y 的分布是什么？有密度吗？

点开看答案

Y 的二进制数字就是 ξk​，前 n 位取定对应一个长 2−n 的区间，概率恰好 2−n，所以 Y∼Unif(0,1)，有密度 1(0,1)​。区别在于三进制只用两个数字时，「空出来」的中间三分之一使得概率被挤到一个零测集上。

3. 判断：若 CDF 在每一点都连续并且几乎处处可导、导数为 0，则这个分布是退化的（集中在一点）。

点开看答案

错误。康托尔分布满足所有这些条件，却分布在不可数多个点上，方差是 81​。
