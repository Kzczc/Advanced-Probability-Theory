人话版一句话版

指数 p,q 满足 p1​+q1​=1 时，

E∣XY∣≤∥X∥p​∥Y∥q​.

乘积的平均，被两个因子各自的「大小」之积控制。证明分两步：先对数证明 Young 不等式 ab≤pap​+qbq​；再把 X、Y 各自除以范数（归一化），代入 Young，取期望。

  • 位置：第 4 部分第四页。前两页（第 24 页、第 25 页）控制「变换」Eφ(X)；本页控制「乘积」E∣XY∣。
  • 为什么需要：E∣XY∣ 要知道 X 和 Y 的联合分布才能算，而 ∥X∥p​、∥Y∥q​ 只需要各自的分布。Hölder 让我们在不知道两者如何关联的情况下，仍能给乘积画一个上限。
  • 最常用的特例：p=q=2 时就是柯西–施瓦茨不等式 E∣XY∣≤EX2​EY2​，它推出相关系数在 [−1,1] 之间。
  • 下一页：第 27 页 的 Minkowski 不等式（Lp 的三角不等式）就是「一次 Hölder 计算」。

先补基础

基础补课共轭指数：1/p + 1/q = 1
  • 满足 p1​+q1​=1 的一对 p,q∈(1,∞) 叫共轭指数（conjugate exponents）。由 p 解出 q=p−1p​。
  • 例：p=2⇒q=2；p=3⇒q=23​；p=4⇒q=34​。p 越接近 1，q 越大；p→1 时 q→∞。所以 (1,∞) 的「搭档」规定为 (∞,1)：11​+∞1​=1+0=1。
  • 两个下一页要用的恒等式：qp​=p−1（两边乘以 p：pp​+qp​=p），以及 (p−1)q=p。
基础补课对数与指数
  • 本课的 log 是自然对数，它是 ex 的反函数：logex=x，elogy=y（y>0）。
  • 运算规则：log(ab)=loga+logb，logap=ploga（a,b>0）。
  • log 和 ex 都严格递增，所以不等式两边同时取 log 或同时取指数，方向不变。
  • log 在 (0,∞) 上凹：(logx)′′=−x21​<0（第 23 页 的判别法）。即对 x,y>0、λ∈[0,1]：log(λx+(1−λ)y)≥λlogx+(1−λ)logy。
基础补课归一化与约定 0 · ∞ = 0
  • 归一化（normalize）：把一个量除以它自己的「大小」，使新量的大小恰好是 1。由齐次性 ∥cX∥p​=∣c∣∥X∥p​（第 22 页），当 0<∥X∥p​<∞ 时，∥X∥p​X​ 的 p-范数是 1。
  • 约定 0⋅∞=0（第 5 页）：Hölder 的右边可能出现「一个范数是 0、另一个是 ∞」，按此约定右边算作 0。下面会说明这时左边也确实是 0。

Theorem 25 (Hölder's inequality)

中文翻译

蓝条标题：Hölder 不等式是标量 Young 不等式的归一化形式。

定理 25（Hölder 不等式）（课件只印了名称，正文留白，见下一节。）

scalar Young｜标量 Young 不等式

  • scalar（标量）指普通的数，与随机变量相对。Young 指 Young 不等式：对非负数 a,b，ab≤pap​+qbq​。它是一个关于两个数的不等式，没有任何期望。

the normalized form｜归一化形式

  • 把 Young 不等式里的 a,b 换成 ∥X∥p​∣X(ω)∣​、∥Y∥q​∣Y(ω)∣​，对每个 ω 都成立；再取期望，右边的两项恰好都变成常数，加起来是 p1​+q1​=1。
  • 所以标题的意思是：Hölder 不等式没有新内容，它就是「归一化后的 Young 不等式取期望」。

Theorem 25 (Hölder's inequality)｜名字

  • Otto Hölder（德国数学家，1889 年）。Young 指英国数学家 W. H. Young。p=q=2 的特例更早，分别以 Cauchy（柯西，数列版本）和 Schwarz（施瓦茨，积分版本）命名。

引理（标量 Young 不等式）

设 1<p<∞，q=p−1p​（即 p1​+q1​=1）。则对所有 a,b≥0，

ab≤pap​+qbq​,

等号成立当且仅当 ap=bq。

推导Young 不等式的证明（用 log 的凹性）
  • a=0 或 b=0：左边是 0，右边 ≥0，成立。等号成立 ⟺ 右边也是 0 ⟺a=b=0，此时 ap=bq=0。
  • a,b>0：在 log 的凹性中取 λ=p1​（则 1−λ=q1​），x=ap，y=bq：
log(p1​ap+q1​bq) ≥ p1​logap+q1​logbq=loga+logb=log(ab).

两边取指数（ex 递增），得 pap​+qbq​≥ab。

  • 等号：log 严格凹（二阶导数严格为负），所以上式取等号当且仅当 x=y，即 ap=bq。

用 第 24 页 的语言说：令随机变量 Z 以概率 p1​ 取 ap、以概率 q1​ 取 bq，这一步就是凹函数 log 的 Jensen 不等式 ElogZ≤logEZ。

定理 25（Hölder 不等式）

设 (Ω,F,P) 是概率空间，X,Y 是实值随机变量。

  1. 若 1<p<∞，q=p−1p​，则
E∣XY∣≤∥X∥p​∥Y∥q​.
  1. 若 p=1，q=∞（或反过来），则 E∣XY∣≤∥X∥1​∥Y∥∞​。

两边都允许取 +∞，右边按 0⋅∞=0 约定。特别地，X∈Lp、Y∈Lq 时 XY∈L1，从而 ∣E[XY]∣≤E∣XY∣≤∥X∥p​∥Y∥q​。

p=q=2 的情形叫柯西–施瓦茨不等式（Cauchy–Schwarz）：E∣XY∣≤EX2​EY2​。

逐项解释：

  • 为什么必须是共轭指数：证明里取期望后，右边是 p1​+q1​，只有它等于 1 才能得到干净的结论。指数不共轭时结论可以失败（例 4）。
  • 左边是 E∣XY∣：先取绝对值再平均。它控制了 ∣E[XY]∣，因为 ∣EZ∣≤E∣Z∣（第 5 页 性质 4）。
  • 不需要 X、Y 有任何关系：没有独立性、没有同分布的要求。
推导证明思路

先处理「某个范数是 0 或 ∞」的边界情形；剩下的情形把 X、Y 归一化成范数为 1 的 X~、Y~，对每个 ω 用 Young 不等式，取期望得 E[X~Y~]≤p1​+q1​=1，最后乘回两个范数。

第 1 步：某个范数为 0。 若 ∥X∥p​=0，则 X=0 a.s.（第 22 页 第 3 条的解释），所以 ∣XY∣=0 a.s.，E∣XY∣=0。右边是 0⋅∥Y∥q​=0（即使 ∥Y∥q​=∞，也按约定算作 0）。不等式 0≤0 成立。∥Y∥q​=0 的情形完全一样。

第 2 步：某个范数为 ∞，另一个大于 0。 右边是 +∞，不等式自动成立。

第 3 步：归一化。 剩下的情形是 0<∥X∥p​<∞ 且 0<∥Y∥q​<∞。令

X~:=∥X∥p​∣X∣​,Y~:=∥Y∥q​∣Y∣​.

它们非负，并且

EX~p=∥X∥pp​E∣X∣p​=E∣X∣pE∣X∣p​=1,EY~q=1.

第 4 步：逐点用 Young。 对每个 ω，取 a=X~(ω)，b=Y~(ω)：

X~(ω)Y~(ω)≤pX~(ω)p​+qY~(ω)q​.

第 5 步：取期望。 两边都是非负随机变量。由单调性和非负随机变量期望的线性，

E[X~Y~]≤p1​EX~p+q1​EY~q=p1​+q1​=1.

第 6 步：乘回范数。 X~Y~=∥X∥p​∥Y∥q​∣XY∣​，所以第 5 步就是 ∥X∥p​∥Y∥q​E∣XY∣​≤1，两边乘以正数 ∥X∥p​∥Y∥q​：

E∣XY∣≤∥X∥p​∥Y∥q​.

p=1、q=∞ 的情形。 若 ∥Y∥∞​=∞：∥X∥1​>0 时右边是 ∞；∥X∥1​=0 时 X=0 a.s.，左边是 0。若 ∥Y∥∞​<∞：∣Y∣≤∥Y∥∞​ a.s.（第 22 页），所以 ∣XY∣≤∥Y∥∞​∣X∣ a.s.，取期望得 E∣XY∣≤∥Y∥∞​E∣X∣。证毕。

为什么一定要归一化：Young 不等式不是「齐次」的

Hölder 的两边在 X→cX（c>0）时都乘以 c，是齐次的；Young 的右边 pap​+qbq​ 却不是。直接把 a=∣X∣、b=∣Y∣ 代入 Young 并取期望，只能得到 E∣XY∣≤pE∣X∣p​+qE∣Y∣q​，这个界会随 X、Y 的单位而变，常常很差。

改进办法：对任意 c>0，∣XY∣=∣cX∣⋅∣Y/c∣，所以 E∣XY∣≤pcpE∣X∣p​+qcqE∣Y∣q​ 对每个 c 都成立，可以挑最好的 c。挑出来的最优值恰好使 cpE∣X∣p=c−qE∣Y∣q（两项的「大小」相等），代回去正好是 ∥X∥p​∥Y∥q​。归一化就是一步到位地选好了这个最优的尺度。

Hölder 的等号条件

设 0<∥X∥p​,∥Y∥q​<∞。若 E∣XY∣=∥X∥p​∥Y∥q​，则第 5 步取等号，D:=pX~p​+qY~q​−X~Y~≥0 的期望为 0，所以 D=0 a.s.（第 5 页 自测第 2 题）。由 Young 的等号条件，X~p=Y~q a.s.，即 ∣X∣p 与 ∣Y∣q 几乎必然成比例。p=q=2 时就是 ∣Y∣=c∣X∣ a.s.。

例 1：Young 不等式的数值检验
  • p=q=2：ab≤2a2+b2​，等价于 (a−b)2≥0。a=3、b=1：3≤5。
  • p=3，q=23​，a=2，b=1：左边 2，右边 38​+3/21​=38​+32​=310​≈3.33。
  • 等号：p=3，a=1，b=1 满足 ap=bq=1：左边 1，右边 31​+32​=1，恰好相等。
例 2：p = 3, q = 3/2 时检验 Hölder

U∼Unif(0,1)，取 X=Y=U。

  • 左边：E∣XY∣=EU2=31​≈0.3333。
  • 右边：∥U∥3​=(EU3)1/3=(41​)1/3≈0.6300；∥U∥3/2​=(EU3/2)2/3=(2.51​)2/3=0.42/3≈0.5429；乘积 ≈0.3420。

例 3：柯西–施瓦茨推出 |相关系数| ≤ 1

设 X,Y∈L2，均值 μX​,μY​，标准差 σX​,σY​>0。协方差 Cov(X,Y)=E[(X−μX​)(Y−μY​)]。对 X−μX​、Y−μY​ 用柯西–施瓦茨：

∣Cov(X,Y)∣≤E​(X−μX​)(Y−μY​)​≤E(X−μX​)2​E(Y−μY​)2​=σX​σY​.

所以相关系数 ρ=σX​σY​Cov(X,Y)​∈[−1,1]。数值：掷一颗骰子，X 是点数，Y=7−X 是背面的点数，Y−μY​=−(X−μX​)，Cov=−VarX=−1235​，ρ=−1，取到了下界（等号条件：∣Y−μY​∣=1⋅∣X−μX​∣）。

例 4（反例）：指数不共轭，结论会失败

取 p=q=1（11​+11​=2=1）。若「E∣XY∣≤E∣X∣E∣Y∣」成立，那么两个可积变量的乘积总可积。反例：X=Y=U−1/2，EX=EY=∫01​u−1/2du=2，但

E∣XY∣=EU−1=∫01​udu​=∞>2⋅2.

两个 L1 变量的乘积不一定在 L1 里；Hölder 说的是：要乘积可积，两个因子的可积性要「互补」，一个在 Lp，另一个在 Lq。

常见疑问与易错点

易错点问：Hölder 要求 X 和 Y 独立吗？

答：不要求。证明是逐个 ω 用 Young 不等式再取期望，与 X、Y 怎样关联无关。独立时有更精确的等式 E∣XY∣=E∣X∣E∣Y∣（以后会证）；Hölder 的价值恰恰在于不知道关联方式时也能用。

易错点问：为什么要先单独处理范数为 0 或 ∞ 的情形？

答：因为第 3 步要除以范数。除以 0 没有意义；除以 ∞ 会把 X~ 变成 0，得到的 EX~p=0=1，后面的计算就不对了。边界情形一句话就能处理，但不能省略。

易错点问：右边出现 0 · ∞ 怎么办？

答：按约定算作 0，而且这是对的：∥X∥p​=0 意味着 X=0 a.s.，乘积 XY 也几乎必然为 0，左边确实是 0。例：X=1{1/2}​（在 (0,1) 上，几乎必然为 0），Y 是柯西变量（∥Y∥2​=∞），E∣XY∣=0。

易错点问：Hölder 和上一页的单调性是什么关系？

答：Hölder 可以推出单调性：取 Y≡1，∥1∥q​=1，再把 X 换成 ∣X∣p、指数换成 pq​ 与它的共轭（第 25 页 的补充）。反过来，两者的证明都靠凹凸性：单调性用 yq/p 的凸性，Young 用 log 的凹性。

小结与自测

小结本页小结
  • Young：a,b≥0，p1​+q1​=1 时 ab≤pap​+qbq​，证明用 log 的凹性；等号 ⟺ap=bq。
  • Hölder（定理 25）：E∣XY∣≤∥X∥p​∥Y∥q​；p=1,q=∞ 也成立；X∈Lp、Y∈Lq 推出 XY∈L1。
  • 证明：处理范数为 0 / ∞ 的边界 → 归一化 → 逐点 Young → 取期望得 ≤p1​+q1​=1 → 乘回范数。
  • p=q=2 是柯西–施瓦茨，推出 ∣Cov(X,Y)∣≤σX​σY​，相关系数在 [−1,1] 中。

期望expectation随机变量对概率测度的积分 E[X] = ∫ X dP，也就是「加权平均」。
分布law / distributionX 把概率「推」到取值空间上得到的测度：L(X)(B) = P(X ∈ B)。
相关系数correlation coefficientρ = Cov(X, Y) / √(Var X · Var Y)，在 −1 到 1 之间，衡量线性相关的强弱。
函数function / mapf: A → B 给 A 中每个元素指定 B 中唯一一个元素。
Hölder 不等式Hölder's inequalityE|XY| ≤ ‖X‖_p ‖Y‖_q（1/p + 1/q = 1）；p = q = 2 就是柯西–施瓦茨不等式。
随机变量random variable从样本空间到实数的（可测）函数，把结局翻译成数字；随机性来自「实现了哪个 ω」。
Jensen 不等式Jensen's inequalityφ 凸时 φ(E X) ≤ E φ(X)，例如 (E X)² ≤ E X²。
概率空间probability space三元组 (Ω, 𝓕, P)：样本空间、事件的 σ-代数、概率测度。
独立independence任意有限个事件同时发生的概率等于各自概率的乘积。
几乎必然收敛almost sure convergence除了概率为 0 的结局以外，Xₙ(ω) 都收敛到 X(ω)。
协方差covarianceCov(X, Y) = E[(X − EX)(Y − EY)]，衡量两个变量一起变大或变小的倾向。独立 ⇒ 协方差为 0，反之一般不成立。
可积integrable (L¹)∫|f| dμ < ∞。全体可积函数记作 L¹(μ)。
阶矩momentE[|X|ᵖ] 叫 p 阶（绝对）矩；它有限与否反映尾部有多「重」。
