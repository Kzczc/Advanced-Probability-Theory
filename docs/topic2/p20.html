实数轴上的概率分布只有三种质量

Three kinds of mass in a real probability law

这一页在讲什么

人话版一句话版

实数轴上的任何概率分布，都可以唯一地拆成三部分：原子部分（集中在可数多个点上的「沙丘」）、绝对连续部分（有密度，按长度铺开的「沙层」）、奇异连续部分（没有沙丘，却全部落在一个长度为 0 的集合上，像康托尔分布）。

  • 位置：第 2 部分「用 CDF 计算期望」的总结页。前面分别见过：离散分布（只有原子）、有密度的分布（第 15 页、第 17 页）、混合型（第 13 页：原子 + 密度）、康托尔分布（第 19 页：既无原子也无密度）。这一页说：就这三种，没有第四种。
  • 为什么有用：遇到一个陌生的分布，先问三个问题：有没有跳跃？有没有密度部分？剩下的是什么？计算期望时也可以三部分分别算再相加。
  • 和第 3 讲的联系：把「绝对连续」与「奇异」分开，是第 3 讲 Radon–Nikodym 定理（第 27 页）讨论的「一个测度相对于另一个测度」问题的特例（这里「另一个测度」是勒贝格测度）。

先补基础

基础补课三个术语

设 μ 是 R 上的（有限）测度。

  • 原子（atom）：满足 μ({x})>0 的点 x。纯原子的：μ 的全部质量都在原子上，μ=∑i​pi​δxi​​（δx​ 是点 x 处的单位点质量）。
  • 绝对连续（关于勒贝格测度）：存在非负可积 f，使 μ(B)=∫B​fdx。等价地：勒贝格测度为 0 的集合，μ 也为 0。
  • 奇异（singular，关于勒贝格测度）：存在勒贝格零测集 N，使 μ 的全部质量都在 N 上，μ(Nc)=0。奇异连续：奇异，并且没有原子。
基础补课为什么原子最多可数个

总质量为 1 的分布，质量 >n1​ 的原子最多 n−1 个（否则总质量 >1）。所有原子 =⋃n​{质量 >n1​ 的原子}，是可数个有限集的并，所以最多可数个。

定理 20（原子、奇异连续与绝对连续部分）

R 上的每个概率测度 μ 都可以唯一地写成

μ=μd​+μac​+μsc​,

其中三部分都是（总质量可能小于 1 的）测度：

  • μd​=∑i​μ({xi​})δxi​​ 是纯原子部分，x1​,x2​,… 是 μ 的全部原子（最多可数个）；
  • μac​(B)=∫B​f(x)dx 是绝对连续部分，f≥0 可积；
  • μsc​ 是奇异连续部分：没有原子，并且集中在某个勒贝格零测集上。

对应地，CDF 分解为 F=Fd​+Fac​+Fsc​：一个只有跳跃的阶梯函数、一个密度的不定积分、一个连续且导数几乎处处为 0 的函数。

推导证明思路

先把原子「挖出来」，剩下的部分没有原子；再把剩下部分中「可以用密度表示」的那一块分出来（勒贝格分解定理），剩下的就是奇异连续部分。

第 1 步（原子部分）：令 {xi​} 为全部原子（最多可数个，见「先补基础」），μd​(B):=∑xi​∈B​μ({xi​})。它是测度（可数可加来自非负项级数可以重排）。

第 2 步（剩下的部分没有原子）：令 μc​:=μ−μd​。对每个 B，μd​(B)=μ(B∩{xi​})≤μ(B)，所以 μc​≥0 是测度；每个点 x：若 x 是原子，μc​({x})=μ({x})−μ({x})=0；否则本来就是 0。所以 μc​ 没有原子。

第 3 步（勒贝格分解，当作已知结论）：任何有限测度 ν 都能唯一地写成 ν=νac​+νs​，其中 νac​ 有密度，νs​ 集中在一个勒贝格零测集上。（证明要用 Radon–Nikodym 定理，第 3 讲 第 27 页 会陈述。）把它用在 ν=μc​ 上，得到 μac​ 和 μsc​:=νs​。μsc​≤μc​ 也没有原子，所以是奇异连续的。

第 4 步（唯一性的想法）：原子部分由「哪些点有正质量」唯一决定；绝对连续部分与奇异部分由勒贝格分解的唯一性决定。■

例 4：从 CDF 读出三部分

拿到一个 CDF F，可以这样拆：

  1. 找跳跃：每个跳跃点 x 处的跳跃高度 F(x)−F(x−) 就是原子质量，加起来得到 Fd​。
  2. 求导：F 几乎处处可导（单调函数的性质），f=F′ 就是绝对连续部分的密度，Fac​(x)=∫−∞x​f。
  3. 剩下的：Fsc​=F−Fd​−Fac​，它连续、单调、导数几乎处处为 0。若它不是常数，分布就有奇异连续部分。

对康托尔函数：第 1 步没有跳跃，第 2 步 F′=0，所以 Fsc​=F。

常见疑问与易错点

易错点问：离散分布、连续分布、混合分布，是不是就覆盖了所有情况？

答：如果「连续」指「有密度」，那就漏掉了奇异连续这一种。定理 20 的完整说法是三种：原子、绝对连续、奇异连续。实际应用中第三种很少出现，但它确实存在（康托尔分布），不能忽略。

易错点问：计算期望时可以三部分分开算吗？

答：可以。积分对测度是线性的：∫gdμ=∫gdμd​+∫gdμac​+∫gdμsc​（三部分非负，或 g 可积）。原子部分是 ∑i​g(xi​)μ({xi​})，绝对连续部分是 ∫gfdx，奇异连续部分没有简单公式，通常借助 CDF（第 12 页）或具体构造（第 19 页 例 2）来算。

易错点问：「奇异」和「连续」放在一起不矛盾吗？

答：不矛盾。「连续」说的是 CDF 没有跳跃（没有原子），「奇异」说的是质量集中在勒贝格零测集上。康托尔分布同时满足两者：每个点概率为 0，但全部概率都在测度为 0 的康托尔集上。

小结与自测

小结本页小结
  • 定理 20：R 上每个概率测度唯一分解为 μd​+μac​+μsc​（原子 / 绝对连续 / 奇异连续）。
  • 原子最多可数个；绝对连续部分有密度 f=F′；奇异连续部分没有原子、集中在零测集上。
  • CDF 对应分解为「跳跃阶梯 + 密度的积分 + 魔鬼阶梯式的连续函数」。
  • 例：骰子（纯原子）、指数（纯绝对连续）、康托尔（纯奇异连续）、第 13 页 例 12（原子 + 绝对连续）。
自测

1. 一个随机变量以 41​ 的概率取 2、以 43​ 的概率服从 exp(1)。写出它的三部分，并求 EX。

点开看答案

μd​=41​δ2​；μac​ 的密度是 43​e−x1{x>0}​；μsc​=0。EX=41​⋅2+43​⋅1=45​。

2. 判断：一个分布若没有原子，就一定有密度。

点开看答案

错误。没有原子只排除了 μd​，还可能有奇异连续部分，例如康托尔分布。

3. 为什么原子部分的点最多只有可数个？

点开看答案

总质量为 1，质量大于 n1​ 的原子少于 n 个；所有原子是对 n=1,2,… 取并，是可数个有限集合的并，所以最多可数。
