这一页在讲什么

人话版一句话版

期望不是新东西：它就是第 1 讲的勒贝格积分，只不过积分用的测度是概率 P。定义分两步：非负随机变量的期望总有定义（可以是 +∞）；可正可负的随机变量拆成「正部 − 负部」，只要两部分不同时为无穷，期望就有定义。

  • 位置：第 1 部分第 2 页。上一页 第 4 页 保证了随机变量是可测函数；本页说：可测函数就能积分，积分就是期望。
  • 要解决的问题：中学里的两个公式 ∑xp(x)（离散）和 ∫xf(x)dx（有密度）各管一种情形，遇到「既有跳跃又有连续部分」的随机变量（第 13 页）就不够用。本页给出一个统一的定义，两个中学公式都是它的特例。
  • 还要说清的事：期望什么时候不存在？什么叫可积？

先补基础

基础补课回顾：勒贝格积分是怎么造出来的

第 1 讲分三步造积分（测度记为 μ，这里 μ=P）：

  1. 示性函数：1A​(ω)=1（ω∈A），=0（ω∈/A）。规定 ∫1A​dμ=μ(A)（示性函数与简单函数）。
  2. 简单函数（只取有限个值的可测函数）s=∑i=1n​ai​1Ai​​（ai​≥0）：规定 ∫sdμ=∑i​ai​μ(Ai​)，即「每个台阶的高度 × 台阶底的大小」再相加。
  3. 非负可测函数 Y：∫Ydμ=sup{∫sdμ: s 简单, 0≤s≤Y}，即用台阶函数从下面逼近（非负函数的积分）。sup 读作「上确界」，意思是「最小的上界」；例如 {1−n1​:n≥1} 的上确界是 1。

配套结论：积分是线性的、单调的（Y≤Y′ 则 ∫Y≤∫Y′），并且有单调收敛定理（MCT）：0≤Yn​↑Y 时 ∫Yn​↑∫Y。

基础补课在 [0, ∞] 里怎么做加法和乘法
  • [0,∞] 是非负实数再加上一个点 +∞。约定：a+∞=∞；a⋅∞=∞（a>0）；0⋅∞=0（积分理论的标准约定：高度为 ∞ 但底为零测集的台阶，面积算 0）。
  • ∞−∞ 没有定义。这正是下面定义 3 要小心的地方。
基础补课正部与负部

对实数（或扩展实数）z，定义

z+=max(z,0),z−=max(−z,0).
  • 例：z=3 时 z+=3，z−=0；z=−2 时 z+=0，z−=2；z=0 时两者都是 0。
  • 负部也是非负的：z− 是「负的那部分的大小」，不是负数。
  • 两个恒等式：z=z+−z−，∣z∣=z++z−。理由：z≥0 时 z+=z、z−=0；z<0 时 z+=0、z−=−z=∣z∣。两种情况逐一代入即可验证。
  • 对随机变量 Z，Z+(ω)=max(Z(ω),0)。由上一页的「复合保持可测」，Z+、Z−、∣Z∣ 都是随机变量。

定义 2（非负随机变量的期望）

对可测的 Y:Ω→[0,∞]，定义

E[Y]:=∫Ω​YdP ∈[0,∞],

右边是第 1 讲定义的非负可测函数的勒贝格积分。

  • 它总有定义，值可以是 +∞。
  • 最小的例子：Y=1A​ 时 E[1A​]=P(A)。概率就是示性函数的期望，这一句后面第 28 页会变成估计概率的核心技巧。
  • 简单随机变量：若 Y=∑i=1n​ai​1Ai​​，则 E[Y]=∑i​ai​P(Ai​)。这正是中学的「取值 × 概率，求和」。
定义 3（扩展的期望与可积性）

设 Z 是扩展实值随机变量，令 Z+:=max(Z,0)，Z−:=max(−Z,0)，它们都是非负随机变量，EZ+、EZ− 由定义 2 给出。

  1. 若 EZ+ 与 EZ− 至少有一个有限，定义
    E[Z]:=E[Z+]−E[Z−] ∈[−∞,∞].
  2. 若 EZ+=EZ−=∞，则称 EZ 不存在（没有定义）。
  3. 若 E∣Z∣<∞，称 Z 可积（integrable），记作 Z∈L1。由于 ∣Z∣=Z++Z−，这等价于 EZ+<∞ 且 EZ−<∞；此时 EZ 是一个有限实数。

把四种可能列成表：

EZ+ EZ− EZ 可积吗
有限 有限 有限实数 可积
∞ 有限 +∞ 不可积，但期望有定义
有限 ∞ −∞ 不可积，但期望有定义
∞ ∞ 不存在 不可积

为什么这样定义：Z=Z+−Z−，自然希望 EZ=EZ+−EZ−。两个非负期望都已经定义好了，唯一的障碍是 ∞−∞；只要避开这种情况，减法就有意义。

推导：离散随机变量的期望公式

设 Y≥0 只取可数个不同的值 y1​,y2​,…，pk​=P(Y=yk​)，∑k​pk​=1。要证 EY=∑k​yk​pk​。

  1. 令 Yn​=∑k=1n​yk​1{Y=yk​}​。它是简单函数，EYn​=∑k=1n​yk​pk​（定义 2 的简单函数公式）。
  2. Yn​↑Y：固定 ω，它恰好满足某一个 Y(ω)=yk​；当 n<k 时 Yn​(ω)=0≤Y(ω)，当 n≥k 时 Yn​(ω)=yk​=Y(ω)。所以 Yn​(ω) 单调不减并最终等于 Y(ω)。
  3. 由单调收敛定理（MCT），EY=limn​EYn​=∑k=1∞​yk​pk​（级数可以是 +∞）。

对可正可负的离散 Z，分别用于 Z+ 和 Z−：EZ+=∑zk​>0​zk​pk​，EZ−=∑zk​<0​∣zk​∣pk​。

期望的基本性质（本讲后面反复使用）

因为期望就是积分，第 1 讲证明过的积分性质全部直接适用。下面列出最常用的几条，并注明理由：

  1. 常数：E[c]=c。理由：常数 c≥0 是简单函数 c1Ω​，期望为 cP(Ω)=c；负常数用正负部。这里用到了 P(Ω)=1，一般测度下 ∫cdμ=cμ(Ω)。
  2. 单调性：若 Y≤Y′（且期望有定义），则 EY≤EY′。理由：逼近 Y 的每个简单函数也在 Y′ 下方，所以上确界不会变小（非负函数的积分）；一般情形分正负部处理。
  3. 线性：若 Z1​,Z2​ 可积，a,b 是实数，则 aZ1​+bZ2​ 可积且 E[aZ1​+bZ2​]=aEZ1​+bEZ2​（L¹ 上的线性）。非负情形不需要可积：E[Y1​+Y2​]=EY1​+EY2​ 对任意非负 Y1​,Y2​ 成立，值可以是 ∞（非负函数的可加性）。
  4. 绝对值不等式：期望存在时 ∣EZ∣≤E∣Z∣。理由：∣EZ+−EZ−∣≤EZ++EZ−=E∣Z∣。
  5. 零概率集上改值无影响：若 P(Z=Z′)=0（称 Z=Z′ 几乎必然，almost surely，简写 a.s.），则两者期望同时存在且相等（a.e. 与 L¹）。概率论把「几乎处处」（a.e.）改叫「几乎必然」（a.s.），意思一样。

为什么先定义非负的、再定义一般的：非负函数的积分是「从下面用台阶逼近」，只涉及加法和上确界，永远不会出现 ∞−∞；一般函数的麻烦全部集中在「正、负两部分都无穷大」这一种情况，单独把它排除掉就行。这种「先非负、再拆正负部」的两步走，第 7 页证明 LOTUS 时还会再走一遍。

  2. 在每一段上方画出 Y(ω) 的高度。对骰子 X(ω)=ω，就是 6 根高度分别为 1、2、…、6 的柱子。
  3. 所有柱子的面积之和 =∑(高度×宽度)=∑k​k⋅61​=3.5，这就是 EX。

对一般的非负 Y，柱子变成「台阶」逼近（简单函数），面积的上确界就是 EY。所以期望 = Y 的图像在「总长为 1 的 Ω」上方围成的面积。面积可以无穷大（例 2）；对可正可负的 Z，就是「横轴上方的面积 − 横轴下方的面积」，两块都无穷大时无法相减（例 3）。

例 2：非负但期望为 +∞（圣彼得堡型）

抛公平硬币直到出现正面，若第 k 次才出现正面，奖金 Y=2k。则 P(Y=2k)=2−k（前 k−1 次反面、第 k 次正面），∑k≥1​2−k=1。由离散公式

EY=k=1∑∞​2k⋅2−k=1+1+1+⋯=+∞.

Y 每次都取有限值，但期望是 +∞：大奖虽然罕见，却大到足以拉高平均。按定义 2 这完全合法。

例 3：期望不存在——对称并不意味着期望是 0

令 P(Z=2k)=P(Z=−2k)=2−(k+1)，k=1,2,…（总概率 ∑k​2⋅2−(k+1)=1）。则

EZ+=k≥1∑​2k⋅2−(k+1)=21​+21​+⋯=∞,EZ−=∞  (同理).

两部分都是 ∞，EZ 不存在。虽然 Z 的分布关于 0 对称，也不能说 EZ=0：把正项和负项按不同顺序相加，部分和可以趋向任何你想要的值，所以「0」没有资格当平均值。

著名的连续例子是柯西分布（Cauchy），密度 π(1+x2)1​：EZ+=∫0∞​π(1+x2)x​dx=limM→∞​2πln(1+M2)​=∞，同理 EZ−=∞，期望不存在。

例 4：期望是 +∞ 但有定义

取例 2 的 Y，令 W=Y−10。

  • 负部：W−=max(10−Y,0)≤10，所以 EW−≤10<∞。
  • 正部：W+≥Y−10，即 W++10≥Y。由单调性和非负函数积分的可加性，EW++10≥EY=∞，所以 EW+=∞。

按定义 3 第 1 条，EW=∞−(有限数)=+∞，有定义，但 W 不可积。

常见疑问与易错点

易错点问：为什么不直接规定 𝔼Z = 𝔼Z⁺ − 𝔼Z⁻，遇到 ∞ − ∞ 就算 0？

答：因为这样会破坏期望最基本的性质。以例 3 的 Z 为例：Z+1 的正部、负部期望也都是 ∞，按「算 0」的规则 E(Z+1)=0；可我们希望 E(Z+1)=EZ+1=1。矛盾说明 ∞−∞ 没法给出一个合理的数，只能说「不存在」。

易错点问：𝔼Y < ∞ 能推出 Y 处处有限吗？

答：不能推出「处处」，但能推出「几乎必然」：P(Y=∞)=0。理由：Y≥∞⋅1{Y=∞}​，由单调性 EY≥∞⋅P(Y=∞)。若 P(Y=∞)>0，右边是 ∞，与 EY<∞ 矛盾。反过来，在一个概率为 0 的集合上把 Y 改成 ∞，期望不变（0⋅∞=0）。

易错点问：「可积」和「期望存在」是一回事吗？

答：不是。可积要求 E∣Z∣<∞，是更强的条件；期望存在只要求正部、负部不同时为 ∞。例 4 的 W 期望存在（=+∞）但不可积。以后说「EX 有限」「X∈L1」，指的都是可积。

易错点问：负部 Z⁻ 是负数吗？

答：不是。Z−=max(−Z,0)≥0。比如 Z=−5 时 Z−=5。写 Z=Z+−Z− 时，减号已经把「负」表达出来了。

小结与自测

小结本页小结
  • 非负随机变量：EY=∫Ω​YdP∈[0,∞]，永远有定义。E1A​=P(A)。
  • 一般随机变量：Z=Z+−Z−，只要 EZ+、EZ− 不同时为 ∞，EZ=EZ+−EZ−。
  • 可积 ⟺E∣Z∣<∞⟺ 正部、负部期望都有限；可积时期望是有限实数。
  • 期望可以是 +∞（圣彼得堡），也可以不存在（对称的 ±2k、柯西分布）。

期望expectation随机变量对概率测度的积分 E[X] = ∫ X dP，也就是「加权平均」。
勒贝格积分Lebesgue integral按函数值分块的积分：先定义简单函数的积分，再用下方的简单函数逼近取上确界。
测度measure给 σ-代数里的每个集合一个 [0, ∞] 中的「大小」，空集为 0，并且可数可加。
随机变量random variable从样本空间到实数的（可测）函数，把结局翻译成数字；随机性来自「实现了哪个 ω」。
正部positive / negative partf⁺ = max(f, 0)，f⁻ = max(−f, 0)，f = f⁺ − f⁻，|f| = f⁺ + f⁻。
可测函数measurable function对每个 a，集合 {f > a} 都可测；这样的函数才能积分。
函数function / mapf: A → B 给 A 中每个元素指定 B 中唯一一个元素。
可积integrable (L¹)∫|f| dμ < ∞。全体可积函数记作 L¹(μ)。
示性函数indicator function𝟏_A(x) 在 x ∈ A 时取 1，否则取 0；它的积分就是 A 的测度。
简单函数simple function只取有限个值的可测函数，是若干示性函数的线性组合，图像像台阶。
上确界supremum (sup)最小的上界。最大值不一定存在，但有上界的实数集一定有上确界。
单调收敛定理monotone convergence theorem (MCT)非负可测函数单调递增地收敛时，积分也收敛：∫fₙ ↑ ∫f。
零测集null set测度为 0 的集合，例如单点、有理数全体、康托尔集。
概率空间probability space三元组 (Ω, 𝓕, P)：样本空间、事件的 σ-代数、概率测度。
测度空间measure space三元组 (S, 𝓜, μ)：空间、σ-代数、测度。
可数countable元素能排成第 1 个、第 2 个、第 3 个……的一列（有限也算），例如自然数、有理数。
单调递增nondecreasing后一项不小于前一项；单调有界的数列一定有极限。
级数series无穷多项相加 a₁ + a₂ + …，它的值是前 n 项和在 n → ∞ 时的极限。
几乎必然收敛almost sure convergence除了概率为 0 的结局以外，Xₙ(ω) 都收敛到 X(ω)。
几乎处处almost everywhere (a.e.)除了一个测度为 0 的集合之外都成立；零测集上的值不影响积分。
事件event样本空间的（允许谈概率的）子集；实现的 ω 落在里面，就说事件发生。
黎曼积分Riemann integral大一学的定积分：按 x 轴切竖条求和取极限。
区间interval数轴上的一段，[a,b] 包含端点，(a,b) 不包含端点。
分布law / distributionX 把概率「推」到取值空间上得到的测度：L(X)(B) = P(X ∈ B)。
集合set把一些对象放在一起当成一个整体，例如 {1,2,3}。
次可加性subadditivity并集的测度不超过各部分测度之和：μ(A ∪ B) ≤ μ(A) + μ(B)。
