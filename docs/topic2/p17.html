这一页在讲什么

人话版一句话版

随机变量什么时候有密度（可以写成 P(X∈B)=∫B​f(x)dx）？答案是：当且仅当它的 CDF 绝对连续——比「连续」更强的一种连续：很多个小区间的总长度很小时，CDF 在这些区间上的总增量也很小。此时密度就是 CDF 的导数。

  • 位置：第 2 部分「用 CDF 计算期望」的后半段。前几页（第 12 页–第 16 页）只用 CDF 算期望，从不假设密度；这一页回答：密度到底什么时候存在。
  • 为什么需要：中学和大一的概率课默认「连续型随机变量有密度」。但下面两页会看到，存在 CDF 处处连续、却没有密度的随机变量（康托尔分布，第 19 页）。所以「连续」不是正确的条件，「绝对连续」才是。
  • 后面怎么用：第 20 页 会把任意分布拆成「原子 + 有密度 + 既无原子又无密度」三部分，本页给出的是中间那一部分的刻画。第 3 讲的 Radon–Nikodym 定理（第 27 页）是本页的抽象推广。

先补基础

基础补课密度是什么意思

说随机变量 X 有（勒贝格）密度 f，是指存在非负可积函数 f，使对每个博雷尔集 B：

P(X∈B)=∫B​f(x)dx.

特别地取 B=(−∞,x]：FX​(x)=∫−∞x​f(t)dt。直观上，f(x)dx 是「X 落在 x 附近长度为 dx 的小区间里」的概率。密度存在时，每个单点的概率都是 0（单点长度为 0），所以有原子（跳跃）的分布一定没有密度。

基础补课三种「连续」，一种比一种强
  • 连续：在每一点，x 变化一点，F(x) 也只变化一点。
  • 一致连续：同一个精度要求 δ 对所有位置都管用（只看一个小区间）。
  • 绝对连续：同一个 δ 对「有限多个互不相交的小区间，总长度 <δ」都管用——这些区间可以散落在各处，个数可以很多。

绝对连续 ⇒ 一致连续 ⇒ 连续（取只有一个区间的情形即可看出第一个箭头）；反过来都不成立。

基础补课微积分基本定理（回顾）

若 F 连续可导，则 F(b)−F(a)=∫ab​F′(x)dx。本页的「勒贝格版」把条件从「连续可导」放宽到「绝对连续」，结论只要求 F′ 几乎处处存在。

课件原文Absolute continuity is exactly the condition behind a density

Definition 16 (Absolutely continuous function) A function F:R→R is absolutely continuous if, for every ε>0, there exists δ>0 such that every finite pairwise disjoint collection of intervals (ak​,bk​) satisfying

k∑​(bk​−ak​)<δ

also satisfies

k∑​∣F(bk​)−F(ak​)∣<ε.

Lebesgue FTC used below Such an F has an a.e. derivative satisfying （留白） Conversely, an indefinite integral of an L1 function is absolutely continuous.

Theorem 17 (CDF-density equivalence) A real random variable X has a Lebesgue density if and only if FX​ is absolutely continuous. In that case fX​=FX′​ almost everywhere.

中文翻译

定义 16（绝对连续函数） 函数 F:R→R 叫绝对连续的，如果对每个 ε>0，都存在 δ>0，使得任何有限个两两不交的区间 (ak​,bk​)，只要总长度 ∑k​(bk​−ak​)<δ，就有 ∑k​∣F(bk​)−F(ak​)∣<ε。

下面要用的勒贝格微积分基本定理 这样的 F 几乎处处有导数，并且满足（留白）。反过来，一个 L1 函数的不定积分是绝对连续的。

定理 17（CDF–密度等价） 实值随机变量 X 有勒贝格密度，当且仅当 FX​ 绝对连续。此时 fX​=FX′​ 几乎处处成立。

Definition 16｜逐句拆开

  • for every ε > 0, there exists δ > 0：一场「你出题、我应答」的游戏：你要求总增量小于 ε，我能找到一个总长度门槛 δ。
  • every finite pairwise disjoint collection of intervals：区间个数不限（但有限），彼此不重叠，可以散落在实数轴上任何地方。
  • ∑k​(bk​−ak​)<δ：这些区间的总长度小于 δ。
  • ∑k​∣F(bk​)−F(ak​)∣<ε：F 在这些区间上的总增量（取绝对值相加）小于 ε。

一句话：「在总长度很小的地方，F 不可能攒下很多增长。」 对 CDF 来说，F(bk​)−F(ak​)=P(ak​<X≤bk​)，所以这句话就是「总长度很小的一堆区间，总概率也很小」——这正是「概率按长度摊开」的意思。

Lebesgue FTC｜补全留白

留白处应是勒贝格版微积分基本定理的公式，见下一节定理卡片。

Theorem 17｜两件事

  1. 等价：有密度 ⟺ CDF 绝对连续。
  2. 公式：密度就是 CDF 的导数，fX​=FX′​（几乎处处——密度在零测集上改值无所谓，第 43 页）。

定理勒贝格微积分基本定理（Lebesgue FTC，当作已知结论使用）
  1. 若 F:R→R 绝对连续，则 F 几乎处处可导，F′ 在每个有界区间上可积，并且
    F(b)−F(a)=∫ab​F′(x)dx对所有 a<b.
  2. 反过来，若 f∈L1(R)（或在每个有界区间上可积），则不定积分 G(x)=∫−∞x​f(t)dt（或 ∫ax​f）是绝对连续的，并且 G′=f 几乎处处。

这个定理的证明需要实分析里的「勒贝格微分定理」，超出本课范围，课件也说是 used below（下面直接使用）。我们只需理解它的意思：绝对连续的函数，正好是「某个可积函数的积分」。

定理 17（CDF–密度等价）

设 X 是实值随机变量，FX​ 是它的 CDF。则 X 有勒贝格密度 ⟺FX​ 绝对连续。此时 fX​=FX′​ 几乎处处。

推导证明思路

⇐：用 FTC 第 1 条，FX​ 的增量等于 FX′​ 的积分，所以 FX′​ 就是密度（还要检查它非负、总积分为 1，并从区间推广到所有博雷尔集）。⇒：有密度时 FX​ 是密度的不定积分，用 FTC 第 2 条。

（⇐）设 F=FX​ 绝对连续。

  1. 由 FTC，F′ 几乎处处存在，且 F(b)−F(a)=∫ab​F′。
  2. F′≥0：F 单调不减，差商 hF(x+h)−F(x)​≥0，极限也 ≥0（不可导的零测集上令 F′=0）。
  3. 总积分为 1：令 a→−∞、b→+∞，左边 F(b)−F(a)→1−0=1；右边 ∫ab​F′↑∫R​F′（非负函数，单调收敛定理 第 36 页）。所以 ∫R​F′=1。
  4. 两个测度在区间上相同：定义 ν(B)=∫B​F′(x)dx。它是概率测度（非负、可数可加由 MCT 保证、总质量为 1），并且对每个 (a,b]：
    ν((a,b])=∫ab​F′=F(b)−F(a)=P(a<X≤b).
  5. 推广到所有博雷尔集：两个概率测度在所有 (a,b] 上相等，那么在 B(R) 上处处相等（第 第 8 页 页「CDF 决定分布」用的就是这个事实）。所以 P(X∈B)=∫B​F′，F′ 就是密度。

（⇒）设 X 有密度 f。

  1. F(x)=P(X≤x)=∫−∞x​f(t)dt，是可积函数 f 的不定积分（∫R​f=1<∞）。
  2. 由 FTC 第 2 条，F 绝对连续，并且 F′=f 几乎处处。■
不用 FTC 第 2 条，直接看出「有密度 ⇒ 绝对连续」

关键是一个「积分的绝对连续性」：对可积的 f≥0 和任意 ε>0，存在 δ>0，使 Leb(A)<δ 时 ∫A​f<ε。

  • 截断：令 fM​=min(f,M)。由 MCT，∫(f−fM​)→0（M→∞），取 M 使 ∫(f−fM​)<ε/2。
  • 取 δ=ε/(2M)。若 Leb(A)<δ，则 ∫A​f≤∫A​fM​+∫(f−fM​)<Mδ+ε/2=ε。

把 A 取成 ⋃k​(ak​,bk​)，就得到 ∑k​(F(bk​)−F(ak​))=∫A​f<ε，这正是定义 16。

图解

人话版用「沙子」想象绝对连续

把概率想成撒在实数轴上的沙子，F(x) 是 x 左边沙子的总量。

  • 有密度：沙子均匀或不均匀地「铺」开，每一小段的沙子量 ≈ 密度 × 长度。总长度很小的一堆区间，装的沙子也很少——绝对连续。
  • 有原子：某一点上堆了一座「小沙丘」（正概率）。用一个极短的区间罩住这一点，沙子量不会变小——不连续，更不绝对连续。
  • 康托尔分布（第 19 页）：沙子全部撒在一个总长度为 0 的「尘埃」集合上，没有一处堆成沙丘（所以 CDF 连续），但用总长度任意小的一堆区间就能罩住全部沙子——连续但不绝对连续。

例子

例 1：均匀分布——绝对连续，密度为 1

X∼Unif(0,1)：F(x)=0（x<0），=x（0≤x<1），=1（x≥1）。

  • 对任意区间，∣F(b)−F(a)∣≤b−a（斜率不超过 1）。所以取 δ=ε：总长度 <ε 时总增量 <ε。绝对连续。✓
  • F′(x)=1（0<x<1），=0（x<0 或 x>1），在 0 和 1 两点不可导（零测集）。所以密度 f=1(0,1)​，与熟悉的结果一致。
例 2：指数分布——绝对连续

F(x)=1−e−λx（x≥0），0（x<0）。F′(x)=λe−λx≤λ，所以 ∣F(b)−F(a)∣≤λ(b−a)，取 δ=ε/λ 即可。密度 f(x)=λe−λx1{x>0}​（第 15 页）。

一般地：导数有界（「利普希茨」）的 CDF 一定绝对连续。

例 3（反例）：有跳跃——没有密度

第 13 页 的混合型 CDF 在 0 处从 0 跳到 21​。取 ε=41​：不管 δ 多小，单个区间 (−δ/2,δ/2) 的长度 <δ，增量却 ≥21​>ε。所以不绝对连续，由定理 17，X 没有密度——这和 第 13 页 说的「P(X=0)=21​>0，所以不可能有密度」一致。

例 4（预告）：连续却不绝对连续——康托尔函数

康托尔函数 F（第 19 页）连续、单调，在 [0,1] 上从 0 升到 1。但它的全部增长都发生在康托尔集 C 上（第 18 页）。第 n 步时，C 被 2n 个长度为 3−n 的闭区间盖住，总长度 (2/3)n 可以小于任何 δ，而 F 在这些区间上的总增量是 1（整个增长都在里面）。所以取 ε=21​ 时找不到 δ——不绝对连续，没有密度。

常见疑问与易错点

易错点问：「连续型随机变量」不就是有密度的随机变量吗？

答：在很多入门教材里是这么定义的，但严格地说，「CDF 连续」和「有密度」不是一回事。CDF 连续只说明没有原子；有密度还要求概率不能集中在零测集上。康托尔分布就是「连续但没有密度」的例子（第 19 页）。正确的说法是：有密度 ⟺ CDF 绝对连续。

易错点问：密度唯一吗？为什么说「几乎处处」？

答：在一个零测集上改变 f 的值，∫B​f 完全不变（第 43 页），所以密度只在「几乎处处」的意义下唯一。例如均匀分布的密度可以写 1(0,1)​，也可以写 1[0,1]​，两者都对。

易错点问：定义里为什么要「有限个、两两不交」的区间？

答：如果区间可以重叠，同一段长度会被重复计数，总长度的门槛失去意义。「有限个」是为了让求和是普通的有限和；事实上换成可数个也等价。关键在于允许多个区间——只看一个区间时，就退化成一致连续，康托尔函数也满足，无法排除它。

小结与自测

小结本页小结
  • 绝对连续：任何总长度 <δ 的有限个不交区间，F 的总增量 <ε。它比连续、一致连续都强。
  • 勒贝格 FTC：绝对连续 ⟺ 是可积函数的不定积分；此时 F(b)−F(a)=∫ab​F′。
  • 定理 17：X 有密度 ⟺ FX​ 绝对连续，且 fX​=FX′​ 几乎处处。
  • 有跳跃 ⇒ 不连续 ⇒ 没有密度；康托尔函数连续但不绝对连续 ⇒ 也没有密度。
自测

1. F(x)=x2（0≤x≤1），x<0 时为 0，x>1 时为 1。它是某个随机变量的 CDF 吗？有密度吗？密度是什么？

点开看答案

单调不减、右连续、两端为 0 和 1，是 CDF。在 [0,1] 上 ∣F(b)−F(a)∣=(b+a)(b−a)≤2(b−a)，取 δ=ε/2 即绝对连续，所以有密度 f(x)=F′(x)=2x（0<x<1），其余为 0。验证：∫01​2xdx=1。

2. 判断：若 CDF 在每一点都连续，则随机变量一定有密度。

点开看答案

错误。连续只保证没有原子。康托尔分布的 CDF 处处连续，却没有密度（概率全部集中在测度为 0 的康托尔集上）。

3. 设 X 有密度 f。用定义说明 P(X=c)=0 对每个 c 成立。

点开看答案

P(X=c)=∫{c}​f(x)dx。单点 {c} 的勒贝格测度为 0，非负函数在零测集上的积分为 0（第 43 页 零支撑原则），所以 P(X=c)=0。
