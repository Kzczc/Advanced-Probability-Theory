人话版一句话版

第 2、3 部分的成果汇总：勒贝格可测集组成的 σ-代数 L(R) 包含所有博雷尔集，但不是全部子集；勒贝格测度 m 在上面可数可加，区间的测度就是长度，而且是完备的。把它限制在 [0,1] 上，就得到均匀分布的概率 P。

这一页收尾第 3 部分：从 第 15 页 的路线图出发，经过外测度（第 18 页）、卡拉泰奥多里判别（第 20 页）、维塔利定理（第 21 页、第 22 页），终于得到了一个可以用来谈概率的连续测度。

先补基础

基础补课⊆ 与 ⊊
  • A⊆B：A 包含于 B（可能相等）。
  • A⊊B：A 包含于 B 而且不相等，即 B 里至少有一个元素不在 A 里。
基础补课博雷尔 σ-代数 𝓑(ℝ)

博雷尔 σ-代数 B(R) 是由所有开区间生成的 σ-代数（第 11 页）：包含开区间、闭区间、半开区间、单点、开集、闭集，以及它们的可数并、可数交、补集……日常能写出来的集合几乎都在里面。

课件原文逐句精读

课件原文Theorem 16 (Structure of Lebesgue measure)

The Lebesgue measurable sets and Lebesgue measure satisfy

B(R)⊆L(R)⊊2R,m([a,b])=b−a(a≤b),

and, for pairwise disjoint En​∈L(R),

m(n≥1⋃​En​)=n≥1∑​m(En​).

A measurable set Z with m(Z)=0 is called null. Lebesgue measure is complete: every subset N⊆Z is measurable and null.

中文翻译

定理 16（勒贝格测度的结构） 勒贝格可测集与勒贝格测度满足：B(R)⊆L(R)⊊2R，m([a,b])=b−a（a≤b）；并且对两两不交的 En​∈L(R)，m(⋃n≥1​En​)=∑n≥1​m(En​)。

测度为 0 的可测集 Z 称为零测集。勒贝格测度是完备的：零测集 Z 的每个子集 N⊆Z 都可测，而且也是零测集。

逐条解读：

  1. B(R)⊆L(R)：所有博雷尔集都勒贝格可测。理由：区间都通过卡拉泰奥多里判别（第 20 页 例 2），L(R) 是 σ-代数，而 B(R) 是包含区间的最小 σ-代数（第 11 页 的最小性），所以 B(R)⊆L(R)。
  2. L(R)⊊2R：不是所有子集都可测——维塔利集 V 就是反例（第 22 页）。
  3. m([a,b])=b−a：在区间上，勒贝格测度就是我们熟悉的长度。
  4. 可数可加：不交的可测集，测度可以相加。这正是 第 12 页 对测度的要求。
  5. 零测集与完备性：零测集的任何子集都可测且测度为 0（第 20 页 例 1 已经证明了这一点）。
课件原文Corollary 17 (Uniform probability)

Let L([0,1]):={E∩[0,1]:E∈L(R)}. Then

P(A):=m(A),A∈L([0,1]),

defines the uniform probability measure on [0,1].

中文翻译

推论 17（均匀概率） 令 L([0,1]):={E∩[0,1]:E∈L(R)}。那么 P(A):=m(A)（A∈L([0,1])）定义了 [0,1] 上的均匀概率测度。

  • L([0,1])：勒贝格可测集与 [0,1] 的交，也就是「[0,1] 里的可测子集」，它是 [0,1] 上的 σ-代数。
  • P(A)=m(A)：事件的概率就是它的长度。因为 m([0,1])=1，这是一个概率测度。
  • 于是得到概率空间 ([0,1], L([0,1]), P)：在 [0,1] 上「均匀随机取一个点」终于有了严格的数学模型。
定理 16 + 推论 17（整理）
(R, L(R), m) 是完备的测度空间,([0,1], L([0,1]), P=m) 是概率空间.

例子

例 1：用均匀概率计算

在 [0,1] 上均匀取一个点 X：

  • P(0.2≤X≤0.5)=m([0.2,0.5])=0.3；
  • P(X=0.5)=m({0.5})=0：取到任何一个具体的点，概率都是 0；
  • P(X 是有理数)=m(Q∩[0,1])=0（可数集是零测集，第 18 页）；
  • P(X 是无理数)=1−0=1；
  • P(X∈[0,0.1]∪[0.5,0.7])=0.1+0.2=0.3（两段不相交，可加）。
例 2：不可数但测度为 0 的集合

康托尔集：从 [0,1] 开始，挖掉中间三分之一 (31​,32​)，再从剩下两段各挖掉中间三分之一，无限进行下去。每一步剩下的总长是上一步的 32​，第 n 步剩 (32​)n→0，所以康托尔集的测度是 0；但它有不可数多个点。第 2 讲会用它构造「连续但没有密度」的分布（第 19 页）。零测集不一定可数。

例 3：完备性的用处

设某事件 Z 的概率为 0，而 N⊆Z 是它的一部分。完备性保证 N 也是事件，概率也为 0。例如「取到的点在康托尔集里」概率为 0，那么「取到的点在康托尔集的某个奇怪子集里」也是事件，概率为 0，不会出现「不可测」的尴尬。

补充一个漂亮的联系：均匀取点 = 无穷次抛硬币

把 [0,1) 里的数写成二进制小数 ω=0.b1​b2​b3​…（每个 bn​ 是 0 或 1）。在勒贝格测度下：

  • 「第 1 位 b1​=0」就是 ω∈[0,21​)，概率 21​；
  • 「前两位是 01」就是 ω∈[41​,21​)，概率 41​；
  • 一般地，前 n 位取定某个 0/1 串，对应一个长度 2−n 的区间，概率 2−n。

这和「独立抛 n 次公平硬币得到某个指定结果」的概率完全一样。所以在 [0,1) 上均匀取一个点，等价于无穷次独立抛公平硬币（把 1 当正面）。第 7 页 里的无穷次抛硬币模型，因此也有了严格的测度论基础——它就是 ([0,1),L,m) 换了一种读法。

常见疑问与易错点

易错点问：𝓑(ℝ) 和 𝓛(ℝ) 有什么区别？用哪个？

答：L(R) 比 B(R) 大：它还包含零测博雷尔集的所有子集（完备化）。概率论里两者通常可以互换使用，因为它们只差「零测集的子集」，不影响任何概率计算。第 2 讲定义随机变量时常用 B(R)。

易错点问：每个点的概率都是 0，为什么整个区间的概率是 1？

答：可数可加只允许可数个集合相加。[0,1] 是不可数个单点的并，不能把单点的概率加起来。这正是 第 1 页 例 1 提出的问题的答案：概率是直接给区间定的，而不是从单点拼出来的。

易错点问：测度为 0 的事件「不可能发生」吗？

答：不是。P(X=0.5)=0，但 X 取到 0.5 并非不可能——每个具体的点都是这样。概率为 0 意思是「可以忽略」，不是「绝不发生」。这就是后面「几乎处处」（第 43 页）的出发点。

小结与自测

小结本页小结
  • B(R)⊆L(R)⊊2R：博雷尔集都可测，但不是所有子集都可测。
  • 勒贝格测度 m：区间的测度是长度，可数可加，完备（零测集的子集可测且测度为 0）。
  • 限制在 [0,1] 上：P(A)=m(A) 是均匀概率，概率 = 长度。
  • 可数集是零测集；零测集不一定可数（康托尔集）；概率为 0 不等于不可能。
自测

1. 在 [0,1] 上均匀取点，求 P(X∈[0,41​)∪(43​,1]) 和 P(X=21​)。

点开看答案

两段不相交，概率 =41​+41​=21​。P(X=21​)=1−P(X=21​)=1−0=1。

2. 为什么 B(R)⊆L(R)？用「最小性」说明。

点开看答案

所有区间都勒贝格可测，而 L(R) 是 σ-代数，所以它是一个「包含所有区间的 σ-代数」。B(R) 是包含所有区间的最小 σ-代数，因此 B(R)⊆L(R)。

3. 判断：零测集一定是可数集。

点开看答案

错误。康托尔集测度为 0 但不可数。反过来是对的：可数集一定是零测集。
