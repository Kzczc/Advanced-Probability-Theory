这一页在讲什么

人话版一句话版

上一页用「且 ↔ 交、或 ↔ 并、非 ↔ 补」处理了抛两次硬币。这一页把硬币抛无穷多次，用可数多个集合的并和交，写出「至少一次正面」「从不出现正面」「出现无穷多次正面」「只出现有限次正面」这四个事件。最后一句话点题：样本点多到不可数时，没法再「给每个结局分一点概率」，必须改用测度。

这是一页纯手写的续页（课件上没有编号），是老师讲 第 6 页 时写满了屏幕，接着写的。它做了两件事：

  1. 事件的逻辑推广到无穷：第 6 页 只用到两个事件的交与并；这里要对 H1​,H2​,H3​,… 无穷多个事件一起取并、取交。这正是后面 第 9 页 要求 σ-代数对「可数并」封闭的原因——不然「无穷多次正面」这种最自然的事件都写不出来。
  2. 预告为什么需要测度：样本空间有限或可数时，给每个结局分配一个概率、再加起来就行；不可数时这条路走不通。下一页 第 8 页 就在此基础上给出概率的两条公理。

本页最难的是上极限、下极限（limsup / liminf）。别怕，下面会用具体的正反面序列，一个一个演示「对每个 N 都存在 n≥N」和「存在 N 使得所有 n≥N」是什么意思。

先补基础

基础补课自然数集 ℕ 与无穷序列
  • N={1,2,3,…} 是全体正整数（本课从 1 开始数），读作「自然数集」。
  • 无穷序列：一个接一个、永远不结束的一列东西，例如 H,T,H,T,…。写成 ω=(ω1​,ω2​,ω3​,…)，其中 ωn​ 是第 n 个位置上的东西。
  • 下标 n 在 ωn​ 里表示「第几个」：ω1​ 是第 1 次抛的结果，ω5​ 是第 5 次抛的结果。
  • {H,T}N：每个位置 n∈N 都从 {H,T} 里选一个，得到的所有无穷序列组成的集合。它是 第 5 页 里 An（长度为 n 的数组）的「无穷长」版本。
基础补课可数多个集合的并与交

设 A1​,A2​,A3​,… 是一列集合（无穷多个）。

  • ⋃n≥1​An​=A1​∪A2​∪A3​∪⋯：属于至少一个 An​ 的元素全体。即 ω∈⋃n≥1​An​ ⟺ 存在某个 n，使 ω∈An​。
  • ⋂n≥1​An​=A1​∩A2​∩A3​∩⋯：属于每一个 An​ 的元素全体。即 ω∈⋂n≥1​An​ ⟺ 对所有 n，都有 ω∈An​。
  • 下标里的 n≥N 表示只对 n=N,N+1,N+2,… 这些取并或取交。例如 ⋃n≥3​An​=A3​∪A4​∪⋯。
  • 例：An​={n,n+1,n+2,…}（从 n 开始的所有正整数）。⋃n≥1​An​={1,2,3,…}；⋂n≥1​An​=∅，因为任何正整数 k 都不属于 Ak+1​。
基础补课量词 ∀ 与 ∃
  • ∀ 读作「对所有」「对每一个」（for all）：∀N 表示「不管 N 取哪个值」。
  • ∃ 读作「存在」「至少能找到一个」（there exists）：∃n 表示「能找到某个 n」。
  • 顺序很重要。「∀N ∃n≥N」：你先随便给我一个 N，我再根据你的 N 去找一个 n。「∃N ∀n≥N」：我先挑定一个 N，然后从它往后的每一个 n 都要满足条件。
  • 否定的规则：「对所有 N 都……」不成立 ⟺「存在某个 N 不……」；「存在 n ……」不成立 ⟺「所有 n 都不……」。所以「∀」和「∃」在取否定时会互换。
  • 对照上面：交 ↔ 对所有（∀），并 ↔ 存在（∃）。
基础补课求和号 Σ、可数与不可数
  • ∑ω∈Ω​p(ω) 读作「对 Ω 里所有 ω，把 p(ω) 加起来」。例：Ω={1,2,3} 时就是 p(1)+p(2)+p(3)。
  • 可数（countable）：元素能排成一列 x1​,x2​,x3​,… 一个一个编号（有限集也算可数）。例如 N、全体整数、全体有理数都可数。
  • 不可数（uncountable）：无论怎么排，都排不完。例如区间 [0,1]、以及本页的 {H,T}N。
  • 无穷多项求和（级数）a1​+a2​+a3​+⋯ 的意思是：看前 n 项的和 a1​+⋯+an​，当 n 越来越大时它逼近哪个数。例：21​+41​+81​+⋯ 前 n 项和是 1−2−n，逼近 1，所以总和为 1。这种办法只能对排成一列（可数）的项使用。

老师板书在说什么

  1. Define infinite tosses.（定义无穷次抛掷）
  2. Ω∞​={H,T}N
  3. Hn​:={ω∈Ω∞​: ωn​=H}
  4. then we have
  5. ⋃n≥1​Hn​={at least one H}.（⋃ 上方用粉色写着 or）
  6. ⋂n≥1​Hnc​={no head even occurs}.（⋂ 上方用粉色写着 and）
  7. ⋂N≥1​⋃n≥N​Hn​={infinite many heads occur}.（左边的 ⋂N≥1​⋃n≥N​ 用粉色写；infinite 和 many 下面各有一个红点）
  8. 在第 7 行下标的正下方，用蓝色写着：∀N>0（对着 ⋂N≥1​）　∃n≥N（对着 ⋃n≥N​）
  9. n→∞limsup​Hn​
  10. (⋂N≥1​⋃n≥N​Hn​)c=⋃N≥1​⋂n≥N​Hnc​={finite many heads occurs}（左边整块和右边的 ⋃N≥1​⋂n≥N​ 用粉色写；finite 和 many 下面各有一个小黑点）

老师在第 6 行写的 no head even occurs，「even」应为「ever」（no head ever occurs：从来没有出现过正面），是手误。第 7、10 行的 infinite many / finite many 按英文语法应为 infinitely many / finitely many，意思不受影响。

下面按板书顺序，把它组织成六步。

第 1 步：无穷次抛硬币的样本空间（第 1–3 行）

  • 一个完整结局（第 5 页 的「完整可能世界」）现在是一整条无穷长的正反面序列，例如 ω=(H,T,T,H,…)。所以 Ω∞​={H,T}N。
  • Hn​:={ω∈Ω∞​: ωn​=H} 是「第 n 次是正面」这个事件：所有第 n 位是 H 的序列。它和 第 6 页 板书里的 A（第 1 次正面）、B（第 2 次正面）是同一个想法，只是现在有无穷多个：H1​,H2​,H3​,…。
  • Hnc​ 就是「第 n 次是反面」，因为每一位不是 H 就是 T。
  • 注意：Hn​ 只管第 n 位，其余位置随便。所以 Hn​ 里有无穷多条序列。

第 2 步：「至少一次正面」——可数并，对应 or（第 5 行）

n≥1⋃​Hn​=H1​∪H2​∪H3​∪⋯={至少出现一次正面}.

理由：ω∈⋃n≥1​Hn​ ⟺ 存在某个 n 使 ω∈Hn​ ⟺ 存在某一次是正面 ⟺ 至少一次正面。老师在 ⋃ 上写 or：「第 1 次正面，或第 2 次正面，或第 3 次正面，或……」。

第 3 步：「从不出现正面」——可数交，对应 and（第 6 行）

n≥1⋂​Hnc​=H1c​∩H2c​∩⋯={从来没有出现正面}={TTTT⋯}.

理由：ω∈⋂n≥1​Hnc​ ⟺ 对每个 n 都有 ω∈Hnc​ ⟺ 每一次都是反面。老师在 ⋂ 上写 and：「第 1 次反面，且第 2 次反面，且……」。满足它的序列只有一条：全是 T。

第 2、3 步的两个事件互为补集：「至少一次正面」不发生，恰好就是「从不出现正面」。这是 第 6 页 德摩根律的无穷版本：(⋃n​Hn​)c=⋂n​Hnc​。

第 4 步：「无穷多次正面」——先并后交，这就是上极限（第 7–9 行）

这是本页的核心。先把式子拆成两层来看。

内层：固定一个 N，令

BN​:=n≥N⋃​Hn​=HN​∪HN+1​∪⋯={从第 N 次起（含第 N 次），至少还有一次正面}.

外层：再对所有 N 取交，

N≥1⋂​BN​=N≥1⋂​n≥N⋃​Hn​.

ω 属于它 ⟺ 对每一个 N，ω∈BN​ ⟺ 不管从哪一次往后看，后面总还有正面。老师在下标下面写的 ∀N>0 ∃n≥N 就是这句话的符号版：交 ⋂N​ 对应「∀N」，并 ⋃n≥N​ 对应「∃n≥N」。（N 是正整数，所以 N>0 和 N≥1 是一回事。）

为什么「不管从哪往后看都还有正面」就等于「正面有无穷多次」？

  • 如果正面只有有限次，那么总有最后一次正面，设它在第 m 次（一次正面都没有就取 m=0）。从第 N=m+1 次往后看，一次正面都没有了，条件在这个 N 上失败。
  • 如果正面有无穷多次，那么任给一个 N，前 N−1 次只有有限个位置，装不下无穷多次正面，所以一定有某次正面出现在第 N 次或之后，条件对这个 N 成立。

这个集合有一个专门的名字，上极限（lim sup）：

n→∞limsup​Hn​:=N≥1⋂​n≥N⋃​Hn​={无穷多次正面}.

老师在 infinite many 下面点了红点，就是要你记住：上极限 = 发生无穷多次。英文常写作 {Hn​ i.o.}，i.o. 是 infinitely often（无穷多次）的缩写。

第 5 步：「只有有限次正面」——取补集，得到下极限（第 10–11 行）

「无穷多次正面」不发生，就是「只有有限次正面」。对第 4 步的集合取补集，用两次德摩根律（补集把「交」变「并」、把「并」变「交」）：

(N≥1⋂​n≥N⋃​Hn​)c​=N≥1⋃​(n≥N⋃​Hn​)c（外层：交的补 = 补的并）=N≥1⋃​n≥N⋂​Hnc​（内层：并的补 = 补的交）.​

读法：ω 属于它 ⟺ 存在某个 N，使得对所有 n≥N 都有 ω∈Hnc​ ⟺ 从某一次起，以后全是反面。这就是老师写的 ∃N ∀n≥N。和第 4 步相比，∀ 与 ∃ 的位置正好互换，这正是「否定会让量词互换」（见上面的基础补课）。

为什么「从某次起全是反面」等于「只有有限次正面」？从第 N 次起全是反面，那正面只可能出现在前 N−1 次里，最多 N−1 次，是有限次；反过来，只有有限次正面时，取 N 为最后一次正面的下一次即可。

这个集合也有名字，下极限（lim inf）：

n→∞liminf​Hnc​:=N≥1⋃​n≥N⋂​Hnc​={只有有限次正面}={从某次起一直是反面}.

英文常说「Hnc​ eventually」（最终一直发生）。老师在 finite many 下点了小黑点，和上面的 infinite many 形成对照。一句话总结第 4、5 步：

(n→∞limsup​Hn​)c=n→∞liminf​Hnc​.

第 6 步：概率质量怎么分配？有限、可数、不可数（第 12–15 行）

事件写好了，下一个问题是：怎么给事件分配概率？老师分三种情况：

  1. finite（有限）：Ω 只有有限个结局时，给每个结局 ω 一个非负权重 p(ω)，要求 ∑ω∈Ω​p(ω)=1，再规定 P(A)=∑ω∈A​p(ω)。例：两次抛币，每个结局 p=41​，则「至少一次正面」的概率是 41​⋅3=43​。
  2. countable（可数）：Ω 可以排成一列时，同样的做法还行，只是求和变成无穷级数。例：一直抛到第一次出现正面，记录抛了几次，Ω={1,2,3,…}，公平硬币下 p(k)=(21​)k，总和 21​+41​+81​+⋯=1。
  3. uncountable（不可数）：Ω∞​={H,T}N 就是不可数的。这时老师问：assign the mass?（质量怎么分配？） 答案写在下面：measure（测度）。

为什么不可数时「逐点分配」行不通？以公平硬币为例：

  • 任取一条序列 ω。「前 n 次都和 ω 一样」的概率是 (21​)n，而单点事件 {ω} 比它还小，所以 P({ω})≤(21​)n 对每个 n 都成立。n 越大，(21​)n 越接近 0，只能 P({ω})=0。
  • 于是每个结局的概率都是 0。要是还想用「把各点概率加起来」得到 P(Ω)=1，就成了「一大堆 0 加起来等于 1」，不可能。
  • 出路：不再从单点出发，而是直接给事件（集合）分配概率，例如规定 P(H1​)=21​、P(H1​∩H2​)=41​，再要求分配满足一致的规则（可数可加性，第 8 页）。这种「给集合分配质量的规则」就叫测度（第 12 页）。
展开：为什么 {H,T}^ℕ 不可数（康托尔对角线论证）

假设能把所有无穷正反面序列排成一列：ω(1),ω(2),ω(3),…。构造一条新序列 η：第 n 位取与 ω(n) 的第 n 位相反的结果（ωn(n)​=H 就令 ηn​=T，反之令 ηn​=H）。

那么 η 和 ω(1) 在第 1 位不同，和 ω(2) 在第 2 位不同……和每一个 ω(n) 都在第 n 位不同，所以 η 不在这一列里。可 η 明明也是一条正反面序列，与「排出了所有序列」矛盾。所以这个集合无法排成一列，是不可数的。

例 2：逐个 N 演示「∀N ∃n≥N」

检验 ω(1)=HTHTHT⋯ 是否属于 limsupHn​。 要对每个 N 找到一个 n≥N，使第 n 次是 H：

  • N=1：取 n=1（第 1 次是 H）。
  • N=2：第 2 次是 T，往后找，取 n=3。
  • N=100：第 100 次是 T，取 n=101（奇数，是 H）。
  • 一般的 N：N 是奇数就取 n=N，N 是偶数就取 n=N+1。

每个 N 都找得到，所以 ω(1)∈limsupHn​。

检验 ω(4)（平方数位置是 H）。 任给 N，取 n=N2。因为 N≥1，有 N2≥N，而第 N2 次正是 H。所以也属于 limsupHn​。正面越来越稀疏，但永远不会断，这就足够了。

检验 ω(2)=HHHTTTT⋯。 用 BN​=⋃n≥N​Hn​（「从第 N 次起还有正面」）逐个看：

N 1 2 3 4 5 6 …
ω(2)∈BN​？ 是（n=1） 是（n=2） 是（n=3） 否 否 否 否

到 N=4 就找不到了（第 4 次起全是 T）。「对所有 N」在 N=4 这里失败，所以 ω(2)∈/limsupHn​。

例 3：逐个 N 演示「∃N ∀n≥N」

检验 ω(2)=HHHTTTT⋯ 是否属于 liminfHnc​。 只需要找到一个 N，使从它往后全是 T：取 N=4，第 4、5、6……次全是 T，成立。所以 ω(2)∈liminfHnc​。（取 N=5、N=100 也都行，但找到一个就够了。）

检验 ω(1)=HTHTHT⋯。 试 N=1：第 1 次是 H，失败。试 N=2：第 3 次是 H，失败。试任何 N：从 N 往后总会碰到一个奇数位置，那里是 H，失败。一个合格的 N 都找不到，所以 ω(1)∈/liminfHnc​。

检验 ω(3)=TTTT⋯。 取 N=1 就成立。它既属于「从不正面」，也属于「有限次正面」（0 次也是有限次）。可见 ⋂n​Hnc​⊆liminfHnc​：「从一开始就全是反面」是「从某次起全是反面」的特例。

补充：上极限和下极限的一般定义

对任意一列事件 A1​,A2​,…（不必是抛硬币），定义

n→∞limsup​An​=N≥1⋂​n≥N⋃​An​={An​ 发生无穷多次},n→∞liminf​An​=N≥1⋃​n≥N⋂​An​={从某个 n 起 An​ 一直发生}.

总有 liminfAn​⊆limsupAn​：从某次起一直发生，当然就发生了无穷多次。反过来不一定：取 An​=Hn​，序列 ω(1)=HTHT⋯ 属于 limsupHn​（无穷多次正面），却不属于 liminfHn​（它从来没有「从某次起一直是正面」）；而 ω(5)=TTTHHH⋯ 两个都属于。第 3 讲的 Borel–Cantelli 引理，研究的就是 P(limsupAn​) 什么时候是 0、什么时候是 1。

推导：一步一步来

推导证明思路

要证 ⋂N≥1​⋃n≥N​Hn​={无穷多次正面}，按「追元素」的办法分两个方向：先证左边的序列都有无穷多次正面，再证有无穷多次正面的序列都在左边。然后用可数版本的德摩根律得到补集的公式。

记 I={无穷多次正面}，BN​=⋃n≥N​Hn​。

方向一：若 ω∈I，则 ω∈⋂N​BN​。

  1. 任取一个正整数 N。要证 ω∈BN​，即存在 n≥N 使 ωn​=H。
  2. 用反证：假设第 N 次及以后全是反面。那么正面只能出现在第 1,…,N−1 次，最多 N−1 次。
  3. 这和 ω∈I（正面有无穷多次）矛盾，所以一定存在 n≥N 使 ωn​=H，即 ω∈BN​。
  4. 第 1 步的 N 是任取的，所以对所有 N 都有 ω∈BN​，按交集的定义，ω∈⋂N​BN​。

方向二：若 ω∈⋂N​BN​，则 ω∈I。

  1. 用反证：假设 ω∈/I，即正面只有有限次。
  2. 若一次正面都没有，令 m=0；否则令 m 为最后一次正面所在的位置。
  3. 取 N=m+1。第 m+1 次及以后没有正面，所以 ω∈/Bm+1​。
  4. 但 ω∈⋂N​BN​ 要求 ω 属于每一个 BN​，包括 Bm+1​，矛盾。所以 ω∈I。

两个方向合起来，两个集合相等。

可数版本的德摩根律：对任意一列集合 C1​,C2​,…，

(N≥1⋃​CN​)c=N≥1⋂​CNc​,(N≥1⋂​CN​)c=N≥1⋃​CNc​.

证明第二个（第一个完全类似，也可以逐行写出）：

ω∈(N⋂​CN​)c​⟺「对所有 N，ω∈CN​」不成立（补集、交集的定义）⟺存在某个 N，使 ω∈/CN​（「并非全都」＝「有一个不」）⟺存在某个 N，使 ω∈CNc​（补集的定义）⟺ω∈N⋃​CNc​（并集的定义）.​

把 CN​=⋃n≥N​Hn​ 代进去，再对每个 CNc​ 用第一个公式，就得到第 5 步的 ⋃N​⋂n≥N​Hnc​。

常见疑问与易错点

易错点问：「∀N ∃n≥N」和「∃n ∀N」有什么区别？

答：差别很大。「∀N ∃n≥N」允许 n 随着 N 变：N=2 时找 n=3，N=100 时找 n=101。如果把顺序换成「存在一个固定的 n，对所有 N 都有 n≥N」，那就要求一个数比所有正整数都大，这不可能。所以写上极限时，量词的顺序一个也不能动。

易错点问：「无穷多次正面」和「从某次起一直是正面」是一回事吗？

答：不是。HTHTHT⋯ 有无穷多次正面，但从来没有「从某次起一直是正面」，因为正面后面总跟着反面。前者是 limsupHn​，后者是 liminfHn​，一般只有 liminfHn​⊆limsupHn​。本页板书里配对的是 limsupHn​ 和 liminfHnc​（注意有补集 c），它们才是互补的。

易错点问：为什么要先对 n ≥ N 取并，再对 N 取交？只用一层不行吗？

答：一层不够。只用一层并 ⋃n​Hn​，只能说「至少一次」；只用一层交 ⋂n​Hn​，说的是「每次都是正面」。「无穷多次」介于两者之间，需要两层：内层「从 N 往后还有」，外层「对每个 N 都如此」。这也说明：只允许有限次运算的事件族，连「无穷多次正面」都表达不了，σ-代数必须允许可数次并与交（第 9 页）。

易错点问：每条序列的概率都是 0，那「至少一次正面」的概率怎么可能是 1？

答：因为概率不再是「把单点概率加起来」。Ω∞​ 不可数，无法把所有单点排成一列求和。测度直接对事件定值：P(⋂n​Hnc​)=P({TTT⋯})=0，所以 P(⋃n​Hn​)=1−0=1。「每个点概率为 0，但整体概率为 1」在不可数空间里一点也不矛盾（第 8 页 用 [0,1] 上的均匀分布再讲一遍）。

小结与自测

小结本页小结
  • 无穷次抛币：Ω∞​={H,T}N，Hn​＝「第 n 次正面」。
  • 可数并 ↔ 或 ↔ 存在（∃）；可数交 ↔ 且 ↔ 对所有（∀）。⋃n​Hn​＝至少一次正面，⋂n​Hnc​＝从不正面。
  • 上极限 limsupHn​=⋂N​⋃n≥N​Hn​：∀N ∃n≥N，＝无穷多次正面。
  • 下极限 liminfHnc​=⋃N​⋂n≥N​Hnc​：∃N ∀n≥N，＝只有有限次正面；它是上一条的补集（德摩根律让 ∀、∃ 互换）。
  • 有限、可数的 Ω 可以逐点分配概率；不可数时每个点概率为 0，必须改为直接给事件分配概率——这就是测度。
