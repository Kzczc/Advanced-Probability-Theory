这一页在讲什么

人话版一句话版

两条「放心使用」的规则：在测度为 0 的集合上随便改函数值，积分不变；可积函数的线性组合仍可积，积分可以拆开。再加上一个很常用的不等式 ​∫f​≤∫∣f∣。老师最后用它们引出了控制收敛定理的核心想法。

  • 位置：第 5 部分，MCT（第 36 页）和 Fatou（第 41 页）之后、控制收敛定理（第 44 页）之前。前面的定理都只针对非负函数；这一页把积分推广到有正有负的可积函数，并说明它是「好用的」。
  • 为什么需要：DCT 处理的 fn​ 可以是负的；证明 DCT 时要把 ∫fn​−∫f 写成 ∫(fn​−f)（线性），还要用 ​∫(fn​−f)​≤∫∣fn​−f∣（三角不等式）。另外，「几乎处处收敛」之所以够用，靠的就是零支撑原则。
  • 板书的作用：把问题「fn​→f 时 ∫fn​→∫f 吗？」改写成「∫∣fn​−f∣→0 吗？」——这是 DCT 证明的出发点。

先补基础

基础补课正部、负部与有符号函数的积分（回顾 第 33 页）

任何函数 f 都可以拆成两个非负函数之差：

f+=max(f,0),f−=max(−f,0),f=f+−f−,∣f∣=f++f−.

例：f(x)=x−21​ 在 [0,1] 上，f+ 在 x>21​ 时等于 x−21​、否则为 0；f− 在 x<21​ 时等于 21​−x、否则为 0。

有符号函数的积分定义为 ∫f=∫f+−∫f−，前提是两项不同时为 ∞；若两项都有限，就说 f 可积，记作 f∈L1(μ)。因为 ∣f∣=f++f−，

f∈L1(μ)⟺∫∣f∣dμ<∞.
基础补课几乎处处（a.e.）

「某个说法几乎处处成立」，意思是：使它不成立的点，都落在某个测度为 0 的可测集里。例：在 [0,1] 上，「1Q​(x)=0」几乎处处成立，因为它只在有理点上不成立，而有理数是零测集（第 28 页）。

基础补课数的三角不等式

对实数 a,b：∣a+b∣≤∣a∣+∣b∣；对常数 α：∣αa∣=∣α∣∣a∣。逐点使用就得到函数版本 ∣αf+βg∣≤∣α∣∣f∣+∣β∣∣g∣。

课件原文On L¹, null changes and linear combinations are harmless

A statement holds μ-almost everywhere (a.e.) if its failure set is contained in a measurable set N with μ(N)=0.

Lemma 34 (Null-support principle) If h≥0 is measurable and h=0 a.e., then ∫hdμ=0. Indeed, every simple element of h is supported on a null set.

Proposition 35 (L1 is a stable linear domain) If f,g∈L1(μ) and α,β∈R, then

αf+βg∈L1(μ),∫(αf+βg)dμ=α∫fdμ+β∫gdμ,

and

​∫fdμ​≤∫∣f∣dμ.

The estimate ∣αf+βg∣≤∣α∣∣f∣+∣β∣∣g∣ gives integrability; nonnegative additivity applied to positive and negative parts gives linearity. Hence f=g a.e. implies ∫f=∫g.

中文翻译

引理 34（零支撑原则） 若 h≥0 可测且 h=0 a.e.，则 ∫hdμ=0。事实上，h 下方的每个简单函数都只在一个零测集上不为零。

命题 35（L1 是稳定的线性空间） 若 f,g∈L1(μ)，α,β∈R，则 αf+βg∈L1(μ)，∫(αf+βg)=α∫f+β∫g，并且 ​∫f​≤∫∣f∣。

不等式 ∣αf+βg∣≤∣α∣∣f∣+∣β∣∣g∣ 给出可积性；对正部和负部使用（非负函数的）可加性，就得到线性。因此 f=g a.e. 推出 ∫f=∫g。

这意味着……（后面是板书）

「几乎处处」的定义：为什么说「包含在」一个可测零测集里

  • 失败的点组成的集合 {x:命题在 x 处不成立} 本身不一定可测，所以定义只要求它被某个可测的零测集 N 盖住。
  • 「零测集上随便」的直观：测度为 0 的集合在积分里「没有重量」，上面发生什么都不影响面积。

Lemma 34：零支撑原则

  • 条件：h≥0 可测，并且除了一个零测集 N 之外 h=0。
  • 结论：∫h=0。
  • 课件给出的理由：非负函数的积分是下方简单函数积分的上确界（第 33 页）。任取简单函数 0≤s≤h：在 N 外 h=0，所以 s=0；s 只可能在 N 里取正值（这就是 supported on a null set）。于是 ∫s=∑k​ak​μ(Ak​) 中每个 ak​>0 的 Ak​⊆N，μ(Ak​)≤μ(N)=0，所以 ∫s=0。所有 ∫s 都是 0，上确界也是 0。

Proposition 35：可积函数的线性组合

  • 可积性：∣αf+βg∣≤∣α∣∣f∣+∣β∣∣g∣，两边积分（非负函数的单调性与可加性，第 38 页），右边 =∣α∣∫∣f∣+∣β∣∫∣g∣<∞。所以 αf+βg∈L1。
  • 线性：先对非负函数有可加性（第 38 页），再用正部、负部拼出一般情形（推导见下）。
  • ​∫f​≤∫∣f∣：积分的绝对值不超过绝对值的积分（老师把它框了起来，因为这是本页最常用的工具）。
  • Hence f=g a.e. ⇒ ∫f=∫g：把零支撑原则用在 ∣f−g∣ 上（推导见下）。
定理引理 34 + 命题 35（整理）
  1. h≥0 可测且 h=0 a.e. ⟹ ∫hdμ=0。
  2. f,g∈L1(μ)，α,β∈R ⟹ αf+βg∈L1(μ) 且 ∫(αf+βg)=α∫f+β∫g。
  3. f∈L1(μ) ⟹ ​∫fdμ​≤∫∣f∣dμ。
  4. f,g∈L1(μ) 且 f=g a.e. ⟹ ∫f=∫g。

第 1 行：要回答的问题

已知 fn​→f（逐点或几乎处处），在什么条件下能推出 ∫fn​→∫f？老师在箭头上写了 condition，下面打了问号——这就是下一页 DCT 要回答的问题。

第 2 行：先把目标改写

∫fn​→∫f 等价于 ∫fn​−∫f→0；由线性（命题 35），∫fn​−∫f=∫(fn​−f)；一个数列趋于 0 当且仅当它的绝对值趋于 0。所以

∫fn​→∫f⟺∫(fn​−f)dμ→0⟺​∫(fn​−f)dμ​→0.

第 3 行：一个更强、但更好验证的充分条件

由框起来的不等式，

​∫(fn​−f)dμ​≤∫∣fn​−f∣dμ.

所以只要 ∫∣fn​−f∣→0，就有 ∫fn​→∫f。老师写的是单向箭头「⇐」：这只是充分条件，不是必要的（例 5）。

为什么要换成 ∫∣fn​−f∣？因为 ∣fn​−f∣ 是非负的，而我们对非负函数有强大的工具 Fatou（第 41 页）。

圈出的「gn​≥fn​−f」是下一步的想法：如果能找到一个函数把差 ∣fn​−f∣ 压住（被「控制」），就能用 Fatou 证明 ∫∣fn​−f∣→0。

第 4 行：这就是控制收敛定理的基本思想

DCT（第 44 页）的条件「∣fn​∣≤g，g 可积」推出 ∣fn​−f∣≤2g，于是 2g−∣fn​−f∣≥0，对它用 Fatou 就得到 ∫∣fn​−f∣→0。下一页会完整展开。

h=1Q∩[0,1]​≥0，它只在有理点上不为 0，有理数是零测集，所以 h=0 a.e.，∫h=0。和 第 28 页 的直接计算一致。

f(x)=x2，g 与 f 相同，只是规定 g(21​)=100。两者只在一个点 {21​} 上不同，单点测度为 0，所以 f=g a.e.，∫01​g=∫01​f=31​。

例 3：线性的计算

在 [0,1] 上，∫(2x−3⋅1[0,1/2]​)dx=2∫xdx−3∫1[0,1/2]​dx=2⋅21​−3⋅21​=−21​。两个函数都可积，所以可以这样拆。

例 4：​∫f​ 可以严格小于 ∫∣f∣

f=1[0,1/2]​−1(1/2,1]​：正负相消，∫f=21​−21​=0；但 ∣f∣=1，∫∣f∣=1。所以 0<1。只有当 f 不变号（几乎处处 f≥0 或 f≤0）时，两边才相等。

例 5：∫fn​→∫f，但 ∫∣fn​−f∣→0

在 [0,1] 上令

fn​=n1(0,1/n)​−n1(1/n,2/n)​(n≥2).
  • 每个 x 处最终 fn​(x)=0（n>2/x 之后），所以 fn​→f=0 逐点。
  • ∫fn​=n⋅n1​−n⋅n1​=0=∫f：积分收敛。
  • 但 ∫∣fn​−f∣=∫∣fn​∣=1+1=2→0。

正负两个尖峰互相抵消，所以 ∫fn​ 碰巧收敛；但差的绝对值并不变小。这说明板书第 3 行的「⇐」不能反过来：∫∣fn​−f∣→0 是更强的要求。

推导：一步一步来

推导证明思路

引理 34：下方的每个简单函数积分都是 0。命题 35：可积性用三角不等式；线性先对正、负部分别用非负可加性，再移项；∣∫f∣≤∫∣f∣ 用 f=f+−f−；a.e. 相等则积分相等，是前面几条的组合。

(1) 引理 34。 见上文「课件原文逐句精读」中的论证：任何简单函数 0≤s≤h 都满足 ∫s=0，取上确界得 ∫h=0。

(2) 加法的线性。 设 f,g∈L1，令 u=f+g。一方面 u=u+−u−，另一方面 u=f+−f−+g+−g−。两式相等，移项使两边都只剩正的项：

u++f−+g−=u−+f++g+.

两边都是非负函数之和，对非负函数用可加性（第 38 页）：

∫u++∫f−+∫g−=∫u−+∫f++∫g+.

六个积分都有限（因为 u,f,g 都可积），可以移项：

∫u+−∫u−=(∫f+−∫f−)+(∫g+−∫g−),即∫(f+g)=∫f+∫g.

(3) 数乘的线性。 α≥0 时 (αf)+=αf+、(αf)−=αf−，由非负函数的 ∫cf=c∫f（第 33 页）得 ∫αf=α∫f；α<0 时 (αf)+=∣α∣f−、(αf)−=∣α∣f+，同样得到 ∫αf=α∫f。与 (2) 合起来就是 ∫(αf+βg)=α∫f+β∫g。

(4) 三角不等式。

​∫f​=​∫f+−∫f−​≤∫f++∫f−=∫(f++f−)=∫∣f∣.

中间用的是数的不等式 ∣a−b∣≤a+b（a,b≥0）和非负可加性。

(5) a.e. 相等则积分相等。 若 f=g a.e.，则 ∣f−g∣≥0 且 ∣f−g∣=0 a.e.，由引理 34，∫∣f−g∣=0。再由 (2)(3)(4)：

​∫f−∫g​=​∫(f−g)​≤∫∣f−g∣=0.■

常见疑问与易错点

易错点问：为什么线性要求 f、g 可积？非负函数不是也可以加吗？

答：非负函数确实总能相加（第 38 页，可以等于 ∞）。但有正有负时，∫f=∫f+−∫f− 可能出现 ∞−∞，没有意义，更谈不上拆开。可积（∫∣f∣<∞）正好保证每一项都有限，移项才合法。

易错点问：「几乎处处为 0」和「处处为 0」在积分里有区别吗？

答：对积分来说没有区别——这正是引理 34 说的。所以以后很多定理只要求条件「几乎处处」成立（例如 DCT 只要求 fn​→f a.e.）。但对函数本身来说是有区别的：1Q​ 几乎处处为 0，却不是处处为 0。

易错点问：既然 ∫|fₙ − f| → 0 比 ∫fₙ → ∫f 更难达到，为什么要去证它？

答：因为它对非负函数 ∣fn​−f∣ 说话，可以用 Fatou；而且它本身就是很有用的结论（叫 L1 收敛），比积分收敛提供更多信息（例 5 那样的抵消在 L1 收敛下不会发生）。DCT 的结论就同时包含了两者。

小结与自测

小结本页小结
  • 几乎处处：失败点被某个可测零测集盖住。
  • 零支撑原则：h≥0 且 h=0 a.e. ⇒ ∫h=0；推论：f=g a.e. ⇒ ∫f=∫g。零测集上改值不影响积分。
