这一页在讲什么

人话版一句话版

[0,1] 里的有理数 D 到处都是，但只有「可数」那么多。用有限个区间去盖它，只能把整个 [0,1] 盖住，花费至少是 1；用可数个区间，可以给每个有理数单独套一个极小的区间，总花费想多小就多小。

上一页 第 16 页 定义了乔丹容量，并预告它有软肋。这一页用一个具体的集合把软肋暴露出来：

D=Q∩[0,1](0 到 1 之间的全体有理数).
  • 乔丹的结论：内容量 J∗​(D)=0，外容量 J∗(D)=1，两者不等，D 不是乔丹可测的。乔丹容量回答不了「D 有多长」。
  • 可数覆盖的结论：允许用可数个区间，总长可以小于任意给定的 ε。所以用可数覆盖来量，D 的长度是 0——这正是下一页 第 18 页 定义勒贝格外测度的动机。

标题的意思：有限覆盖「看见」的只是 D 的稠密（它在 [0,1] 里到处都有），于是把它当成整个 [0,1]；可数覆盖能「跟住」每一个点，看出它其实是一堆孤零零的点。本页属于第 2 部分「从乔丹容量到外测度」。

先补基础

基础补课可数：把有理数排成一列

「可数」（第 7 页）就是能编号成 q1​,q2​,q3​,…。[0,1] 里的有理数可以按分母从小到大排，分母相同按分子排，重复的（如 42​=21​）跳过：

0, 1, 21​, 31​, 32​, 41​, 43​, 51​, 52​, 53​, 54​, 61​, 65​, …

每个分母只对应有限个分数，所以每个有理数迟早会被排到，得到一个确定的编号。课件第一句 Enumerate D={q1​,q2​,…}（把 D 枚举出来）就是这个意思。

基础补课稠密：任何小区间里都有有理数
  • 稠密（dense）：[0,1] 里任何一个长度大于 0 的小区间，无论多短，里面都有 D 的点。
  • 为什么：任取 0≤a<b≤1。取 n 大到 n1​<b−a，那么以 n1​ 为步长的刻度 0,n1​,n2​,… 一定有一个落在 (a,b) 里，它就是一个有理数。例：(0.3,0.31) 里有 0.305=20061​。
  • 同样，任何小区间里也都有无理数（例如在有理数上加一个很小的 N2​​）。有理数和无理数是「交织在一起」的。
基础补课闭包：把能被逼近的点也算进来
  • 集合 A 的闭包 A（上面一横）：所有能被 A 里的点任意逼近的点。等价地说，x∈A 当且仅当 x 周围无论多小的区间里都有 A 的点。
  • 例：(0,1)​=[0,1]（端点 0、1 能被区间内的点逼近）；{1,21​,31​,…}​={0,1,21​,31​,…}。
  • 例：D=[0,1]，因为 D 稠密：[0,1] 的每个点周围都有有理数。
  • 对有限个区间的并 O：闭包只是把有限个端点补上，所以 ∣O∣=∣O∣（单点长度为 0）。
基础补课ε 与「任意小」、等比级数
  • ε（epsilon）习惯上代表一个任意给定的正数，通常想象它很小，比如 0.01 或 10−6。「对任意 ε>0 都能做到 X」就是说「X 要多精确就能多精确」。
  • 等比级数：21​+41​+81​+⋯=1（第 8 页）。所以 ∑n≥1​ε⋅2−n=ε。

课件原文逐句精读

课件原文Finite covers see density; countable covers follow points

Enumerate D={q1​,q2​,…}.

（说明：这一页印刷的只有标题和这一句；D 的定义、两个结论和证明全是老师手写的。）

中文翻译

有限覆盖只看见「稠密」；可数覆盖能跟住每个点。　把 D 枚举为 D={q1​,q2​,…}。

老师把 D={q1​,q2​,…} 整个圈了出来：能够枚举是本页后半部分的关键，因为可数覆盖要给第 n 个点分配第 n 个区间。

Finite covers see density｜有限覆盖只看见「稠密」

  • 有限覆盖：乔丹外容量里的初等集 O，由有限个区间组成。
  • 只看见稠密：D 稠密，意味着 [0,1] 里到处都有 D 的点。有限个区间要盖住 D，就被迫盖住 [0,1] 的几乎每一处（最多漏掉有限个端点）。有限覆盖分不清「D」和「整个 [0,1]」，所以 J∗(D)=1，就好像 D 是整个区间一样。

Countable covers follow points｜可数覆盖能跟住每个点

  • 可数覆盖：允许用可数多个区间 I1​,I2​,…。
  • 跟住每个点：因为 D 可以编号，就给第 n 个点 qn​ 单独套一个区间 In​，第 n 个区间的长度按 ε⋅2−n 递减。每个区间只负责一个点，互不拖累，总长却不超过 ε。
  • 结论：从可数覆盖的角度看，D 的「长度」是 0。

老师板书在说什么

板书分三段：第 2 行给结论，第 3–7 行证明乔丹的两个容量，第 8–11 行演示可数覆盖。第 3 行的 elemenary 即 elementary；第 7 行的「D∈[0,1]」是笔误，应为 D⊆[0,1]（D 是 [0,1] 的子集，不是它的元素）。

第 3 行：内容量为 0

塞在 D 里面的初等集，长度只能是 0。 初等集由有限个区间组成。如果其中某个区间长度大于 0，那么它里面有无理数（稠密性），而无理数不在 D 里，这个区间就塞不进 D。所以塞得进去的初等集只能由单点（退化区间）组成，长度为 0。上确界也就是 0：J∗​(D)=0。

第 4–7 行：外容量为 1

  • 第 4–5 行：任取一个盖住 D 的初等集 O。老师说：「有限区间结构和稠密性」一起给出下一行的结论。
  • 第 6 行：[0,1]=D⊆O。
    • [0,1]=D：D 稠密，[0,1] 的每个点都能被有理数逼近。
    • D⊆O：D⊆O，能被 D 逼近的点当然也能被 O 逼近。
    • 1≤∣O∣=∣O∣：O 包含 [0,1]，长度至少是 1；O 只有有限个区间，闭包只多出有限个端点，长度不变。
  • 第 7 行：所以每个盖住 D 的初等集长度都 ≥1，下确界 J∗(D)≥1。另一方面 [0,1] 自己就是盖住 D 的初等集，J∗(D)≤1。合起来 J∗(D)=1。

这里「有限」用在哪儿？用在 ∣O∣=∣O∣，更用在 D⊆O 能推出「O 几乎盖住 [0,1]」这一点上：有限个闭区间的并是一个「没有缝」的结构，漏掉的部分只能是若干段完整的小区间，而任何小区间都含有理数。推导一节把这一点写成严格的证明。

第 8–11 行：可数覆盖——给每个点套一个小区间

  • qn​∈In​：第 n 个区间盖住第 n 个有理数。
  • ∣In​∣<ε⋅2−n：区间一个比一个短，长度减半地递减。
  • D⊆⋃n​In​：每个有理数都有编号，都被自己的区间盖住。
  • ∑n​∣In​∣<∑n​ε⋅2−n=ε：总长小于 ε。

ε 可以任意小，所以「用可数个区间盖住 D 的最小总长」是 0。和乔丹的 J∗(D)=1 对比：同一个集合，有限覆盖说它长 1，可数覆盖说它长 0。下一页的外测度采用可数覆盖，于是 m∗(D)=0。

图解

  • 数轴与刻度：向右的箭头是实数轴，q1​,q2​,q3​ 是枚举出的前三个有理数。老师为了好看把它们画成从左到右排列，实际上枚举顺序和大小顺序无关（例如 q1​=0、q2​=1、q3​=21​）。
  • 小括号：每个 qn​ 下面的小括号就是区间 In​，括号里的点表示 qn​ 在区间里（qn​∈In​）。
  • 括号的大小：图里三个括号差不多大，但按下方公式 ∣In​∣<ε⋅2−n，它们应该一个比一个小：第 1 个不到 2ε​，第 2 个不到 4ε​，第 3 个不到 8ε​……

例 2：有限集对乔丹来说没问题

E={0.2,0.5,0.9}。给每个点套一个长度 3ε​ 的小区间，三个区间是有限个，构成初等集，总长 ε。所以 J∗(E)=0；又 J∗​(E)=0，E 乔丹可测，长度 0。有限集和 D 的区别：它不稠密，有限覆盖可以只盖住这几个点附近。

例 3：无理数集同样不是乔丹可测的

E′=[0,1]∖Q（[0,1] 里的无理数）。

  • 内容量：任何长度大于 0 的区间都含有理数，塞不进 E′，所以 J∗​(E′)=0。
  • 外容量：E′ 也在 [0,1] 里稠密，同样的闭包论证给出 J∗(E′)=1。

有意思的是：D 和 E′ 不相交，拼起来是 [0,1]，而 J∗(D)+J∗(E′)=2=1。乔丹外容量把「长度」算重了。

例 4：乔丹外容量不是可数次可加的

D=⋃n≥1​{qn​}。每个单点 J∗({qn​})=0，所以 ∑n​J∗({qn​})=0；但 J∗(D)=1。于是

J∗(n⋃​An​)≤n∑​J∗(An​)

对可数个集合不成立（1≤0 是错的）。这就是 第 16 页 老师方框里的次可加性只能对有限个集合使用的原因。

推导：一步一步来

推导证明思路

三个结论：J∗​(D)=0 用「区间里有无理数」；J∗(D)≥1 用反证法，关键是「有限个正数的最小值还是正数」；可数覆盖的总长估计用等比级数。

结论 1：J∗​(D)=0。 设初等集 K=R1​∪⋯∪RN​⊆D。若某个 Rk​ 长度大于 0，由稠密性它含一个无理数 x，而 x∈/D，与 Rk​⊆K⊆D 矛盾。所以每个 Rk​ 都是单点或空集，∣K∣=0。所有候选值都是 0，上确界 J∗​(D)=0。

结论 2：若初等集 O⊇D，则 ∣O∣≥1。

  1. 写 O=R1​∪⋯∪RN​。把每个 Rk​ 换成它的闭区间 Rk​​=[ak​,bk​]，长度不变，记 C=R1​​∪⋯∪RN​​，∣C∣=∣O∣，C⊇O⊇D。
  2. 断言：[0,1]⊆C。 用反证：假设有 x∈[0,1] 但 x∈/C。
  3. x 不在任何一个闭区间 [ak​,bk​] 里，所以它和每个区间都有一个正的距离 dk​>0（到区间最近端点的距离）。
  4. 令 d=min(d1​,…,dN​)。因为只有有限个 dk​，最小值 d 仍然是正数。于是区间 (x−d,x+d) 和 C 完全不相交。
  5. (x−d,x+d)∩[0,1] 是一个长度大于 0 的区间（x∈[0,1]），由稠密性，它里面有一个有理数 q∈D。但 q∈/C，而 D⊆C，矛盾。
  6. 所以 [0,1]⊆C，∣O∣=∣C∣≥1。

第 4 步是「有限」起作用的地方。如果区间有无穷多个，距离 d1​,d2​,… 可能越来越小、下确界为 0，就找不到那个「安全的小区间」了——可数覆盖正是这样钻过去的：它的区间在每个有理数处都有，却可以在无理数处留下空隙。

结论 3：J∗(D)=1。 由结论 2，每个候选值 ≥1，所以 J∗(D)≥1；而 [0,1] 是一个盖住 D 的初等集，长度 1，所以 J∗(D)≤1。

结论 4：对任意 ε>0，存在可数个区间 In​ 盖住 D，且 ∑n​∣In​∣<ε。

  1. 对每个 n，取 In​=(qn​−ε2−n−2, qn​+ε2−n−2)，长度 ∣In​∣=ε2−n−1<ε2−n，并且 qn​∈In​。
  2. 每个 q∈D 都等于某个 qn​，所以 q∈In​，D⊆⋃n​In​。
  3. 总长：
n≥1∑​∣In​∣=n≥1∑​ε2−n−1=2ε​n≥1∑​2−n=2ε​<ε.

常见疑问与易错点

易错点问：这些小区间盖住了一个稠密的集合，为什么没有盖住整个 [0,1]？

答：「稠密」不等于「大」。⋃n​In​ 在每个有理数附近都有一小段，但总长不到 ε，[0,1] 中至少有 1−ε 的长度没被盖住，那些没盖住的点全是无理数。直觉上难以想象，是因为我们画不出「无穷多个越来越小的区间」；但例 1 的计算说明，总长确实只有 0.05。

易错点问：乔丹说 D 长 1，可数覆盖说 D 长 0，到底哪个对？

答：应该认为长度是 0。理由之一：D 是可数多个单点的并，每个单点长度为 0，如果长度可数可加（第 8 页 要求概率可数可加），D 的长度就只能是 0+0+⋯=0。乔丹的 1 来自「只能用有限个区间」这个人为限制，它把 D 和它的闭包 [0,1] 混为一谈了。

易错点问：为什么一定要先把 D 编号（枚举）？

答：可数覆盖要给「第 n 个点」分配「长度为 ε2−n 的第 n 个区间」，没有编号就没法分配，也没法保证总长是一个收敛的等比级数。如果集合不可数（比如 [0,1] 本身），就无法这样一个一个地跟住；事实上 [0,1] 的任何可数覆盖总长都 ≥1，这正是 第 23 页 里「m([a,b])=b−a」所保证的。

易错点问：稠密和可数有什么关系？

答：两者无关。D 既稠密又可数；{1,21​,31​,…} 可数但不稠密；无理数集稠密但不可数。本页的现象是：稠密让有限覆盖失效，可数让可数覆盖成功。

小结与自测

小结本页小结
  • D=Q∩[0,1] 可以枚举为 q1​,q2​,…，而且在 [0,1] 中稠密。
  • 乔丹：J∗​(D)=0（任何区间都含无理数）；J∗(D)=1（有限覆盖的闭包必须包含 D=[0,1]）。D 不是乔丹可测的。
  • 可数覆盖：qn​∈In​，∣In​∣<ε2−n，∑∣In​∣<ε，所以可数覆盖的最小代价是 0。
  • 「有限」起作用的地方：有限个正距离的最小值仍是正数；可数个就不一定了。
  • 乔丹外容量对可数个集合不次可加；这催生了下一页的勒贝格外测度。
自测

1. 用基础补课里的枚举顺序，写出 q6​ 到 q9​。

点开看答案

顺序是 0,1,21​,31​,32​,41​,43​,51​,52​,…，所以 q6​=41​，q7​=43​，q8​=51​，q9​=52​。（42​ 等于 21​，已经出现过，跳过。）

2. 判断：若 ε=0.001，可以用可数个区间盖住 D，使总长小于 0.001。

点开看答案

正确。取 ∣In​∣=0.001⋅2−n−1，总长 0.0005<0.001（结论 4）。ε 取多小都可以。

3. 为什么结论 2 的证明不能照搬到「可数个区间」的覆盖上？指出失效的具体步骤。

点开看答案

第 4 步。有限个正距离 d1​,…,dN​ 的最小值是正数；但可数个正距离 d1​,d2​,… 的下确界可能是 0（例如 x 附近有越来越小的区间越来越靠近它），就找不到一个与覆盖完全不相交的小区间 (x−d,x+d)，反证法做不下去。事实上结论 4 说明，可数覆盖的总长确实可以小于 1。
