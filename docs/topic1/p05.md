# 样本空间：概率模型从"所有可能的世界"开始

<p class="en-title">A probabilistic model starts with complete possible worlds</p>

<SlideFrame t="1" p="5" />

::: roadmap 30 秒看懂这一页
建立任何概率模型的**第一步**：先把"可能发生的所有结果"列成一个集合 $\Omega$（样本空间）。真实世界最后只会落在其中**一个**结果 $\omega$ 上。老师的手写批注用三个例子帮你落地：抛硬币、股票价格路径、随机过程。后面所有概念（事件、概率、随机变量、期望）都建立在这一页上。
:::

## 课件原文与翻译

::: slide Definition 1 (Sample point and sample space)
A probabilistic experiment is represented by a set $\Omega$. Exactly one element $\omega \in \Omega$ is realized. The element $\omega$ is a **sample point**, and $\Omega$ is the **sample space**.
:::

::: trans
一个概率试验用一个集合 $\Omega$ 来表示。$\Omega$ 里**恰好有一个**元素 $\omega$ 会真正发生（被"实现"）。这个元素 $\omega$ 叫作**样本点**，集合 $\Omega$ 叫作**样本空间**。
:::

> 翻译只是帮你读懂英文。下面的"逐句精讲"才是重点：每个词为什么这么说、背后是什么意思。

## 老师手写批注整理

老师在这页写了三组批注，按从上到下的顺序整理如下（手写原文 → 规范写法 → 中文意思）。

::: handnote 批注 ①：抛 1 枚硬币（Tossing 1 coin）
$$
\Omega=\{H,\,T\},\qquad \text{one realized outcome: } \omega = H,\qquad X(\omega)=1,
$$
$$
X:\ \Omega \to \{1,\,0\} \quad(\leftarrow\ \text{random variable})
$$

- $H$ = Head（正面），$T$ = Tail（反面）。
- "one realized outcome"：一个被实现的结果，这里假设真的抛出了正面，所以 $\omega = H$。
- 老师在 $X$ 上方写了 "random variable ↑"：$X$ 就是**随机变量**。
:::

::: handnote 批注 ②：一条价格路径（A pricing path, time $=0,1,\dots,T$）
$$
\Omega = (0,\infty)^{T+1}, \qquad \omega = (s_0,\, s_1,\, \dots,\, s_T)
$$
$$
S_t(\omega) := s_t
$$

- 大括号下写着 "one entire realized market pricing path"：$\omega$ 是**一整条**实际发生的市场价格路径。
- "fixed $t=1$：$S_1(\omega)=s_1$，r.v."：把时间固定在 $t=1$，$S_1$ 就是一个随机变量（r.v. = random variable）。
:::

::: handnote 批注 ③：随机过程
$$
S(\omega)(t) \;=\; \text{stochastic process}
$$

- 把 $\omega$ 和时间 $t$ 都当作输入，$S$ 就是一个**随机过程**（stochastic process）。
:::

## 逐句精讲

### 1. "A probabilistic experiment is represented by a set $\Omega$"

**概率试验（probabilistic experiment）**不一定是实验室里的实验，而是指任何"结果事先不确定"的过程：抛硬币、掷骰子、明天的天气、一年后的股价……

"用一个集合 $\Omega$ 来表示"的意思是：**把所有可能出现的结果，一个不漏地装进一个"袋子"里**，这个袋子就叫 $\Omega$（希腊字母，读作"欧米伽"，大写）。

::: prereq 什么是集合？花括号 $\{\ \}$ 怎么读？
**集合**就是"一堆东西放在一起"，里面的东西叫**元素**。用花括号列出元素：

- $\{H, T\}$：由 $H$ 和 $T$ 两个元素组成的集合；
- $\{1,2,3,4,5,6\}$：骰子的六个点数。

集合**不在乎顺序、不重复**：$\{H,T\}$ 和 $\{T,H\}$ 是同一个集合。
:::

### 2. "Exactly one element $\omega\in\Omega$ is realized"

这句话有两个关键点：

1. **$\omega \in \Omega$**：符号 $\in$ 读作"属于"，$\omega\in\Omega$ 就是"$\omega$ 是 $\Omega$ 里的一个元素"。$\omega$ 是小写的欧米伽。
2. **Exactly one（恰好一个）**：做完试验后，$\Omega$ 中**有且只有一个**结果成真。

"恰好一个"其实对 $\Omega$ 提出了两条要求：

| 要求 | 含义 | 反例 |
|---|---|---|
| **不漏**（至少一个） | 无论实际发生什么，都能在 $\Omega$ 里找到它 | 掷骰子只写 $\{1,2,3\}$：掷出 5 时找不到 |
| **不重**（至多一个） | 不同元素不能同时成真，彼此互斥 | 抛两次硬币写 $\{\text{有正面},\ \text{两次都正面}\}$：抛出"正正"时两个都成真 |

这就是标题里 **complete possible worlds（完整的可能世界）**的意思：每个 $\omega$ 都是一个**把所有细节都定下来的完整世界**，所有这样的世界放在一起就是 $\Omega$。

::: intuition 直观理解：$\Omega$ 是"剧本库"，$\omega$ 是"今天上演的那一集"
把 $\Omega$ 想成一部电视剧**所有可能的剧本**；每个剧本（$\omega$）把剧情从头到尾都写死了。开播前你不知道会播哪一个，但一定会播**恰好一个**。所谓"随机"，就是"不知道会是哪一个 $\omega$"——而**每个 $\omega$ 本身是完全确定的**。
:::

### 3. 样本点（sample point）与样本空间（sample space）

- **样本点 $\omega$**：一个具体的可能结果（一个剧本）。
- **样本空间 $\Omega$**：所有样本点组成的集合（剧本库）。

记法习惯：**大写 $\Omega$ 表示整个集合，小写 $\omega$ 表示其中一个元素**。整门课都会这样用，看到 $\omega$ 就想"某一个具体的结果"。

## 手写批注逐条讲解

### 批注 ①：抛硬币，以及第一次出现的"随机变量"

- 样本空间 $\Omega = \{H, T\}$：只有两个可能结果。
- 假设这次抛出了正面：实现的样本点 $\omega = H$。
- 老师接着写了 $X(\omega)=1$，并标注 $X:\Omega\to\{1,0\}$ 是**随机变量**。

::: prereq 函数（映射）记号 $X:\Omega\to\{1,0\}$ 怎么读？
$X:\Omega\to\{1,0\}$ 读作"$X$ 是从 $\Omega$ 到 $\{1,0\}$ 的一个函数（映射）"。意思是：**给 $X$ 一个 $\Omega$ 里的元素，它就吐出 1 或 0 中的一个**。$X(\omega)$ 就表示"把 $\omega$ 喂给 $X$ 得到的结果"。

这里老师隐含的规则是：
$$
X(H)=1,\qquad X(T)=0 .
$$
即"正面记 1 分，反面记 0 分"。
:::

**随机变量的本质**：它**不是**一个"会乱变的数"，而是一条**确定的规则**——"看一眼实际发生的结果 $\omega$，然后读出一个数"。随机性完全来自"$\omega$ 是哪个"，规则 $X$ 本身一点都不随机。

::: example 例 1：掷一颗骰子
- 样本空间：$\Omega=\{1,2,3,4,5,6\}$。
- 假设掷出 4：实现的样本点 $\omega=4$。
- 随机变量 $X(\omega)=\omega$（"点数本身"）：$X(4)=4$。
- 另一个随机变量 $Y(\omega)=\begin{cases}1,& \omega \text{ 是偶数}\\ 0,& \omega\text{ 是奇数}\end{cases}$（"是不是偶数"）：$Y(4)=1$。

**同一个 $\omega$，可以被不同的随机变量"读"出不同的数**——就像同一场比赛，可以统计"总进球数"，也可以统计"主队是否获胜"。
:::

### 批注 ②：股价路径——一个 $\omega$ 可以是一整条曲线

设想观察一只股票在时间 $t=0,1,\dots,T$（比如第 0 天到第 $T$ 天）的价格。

**什么是一个"可能结果"？** 不是某一天的价格，而是**从第 0 天到第 $T$ 天的整条价格记录**：
$$
\omega = (s_0, s_1, \dots, s_T),
$$
其中 $s_t$ 是第 $t$ 天的价格。老师特别写了 "one **entire** realized market pricing path"——强调"一整条"。

**样本空间是什么？** 每个价格都是正数（取值在区间 $(0,\infty)$ 里），一共有 $T+1$ 个时刻（$0$ 到 $T$ 共 $T+1$ 个数），所以
$$
\Omega = (0,\infty)^{T+1} = \underbrace{(0,\infty)\times(0,\infty)\times\cdots\times(0,\infty)}_{T+1\ \text{个}} .
$$

::: prereq 区间 $(0,\infty)$ 与"乘方"记号 $A^{n}$
- $(0,\infty)$ 表示**所有大于 0 的实数**。圆括号表示端点**不包含**在内（0 不算，$\infty$ 不是数）。
- $A\times B$（笛卡尔积）表示"第一个位置取自 $A$、第二个位置取自 $B$"的所有有序对 $(a,b)$。
- $A^{n}$ 是 $n$ 个 $A$ 连乘，即所有长度为 $n$ 的有序数组 $(a_1,\dots,a_n)$，每个 $a_i\in A$。

例如 $(0,\infty)^{2}$ 就是平面上第一象限（不含坐标轴）的所有点 $(x,y)$。
:::

**$S_t(\omega):=s_t$ 是什么意思？** 符号 $:=$ 读作"定义为"。这句话定义了一族函数 $S_0,S_1,\dots,S_T$：
$$
S_t:\ \Omega\to(0,\infty),\qquad S_t\big((s_0,s_1,\dots,s_T)\big) = s_t .
$$
也就是**从整条路径里取出第 $t$ 个坐标**——"查一下第 $t$ 天的价格"。

**"fixed $t=1$，$S_1(\omega)=s_1$，r.v."**：把时间固定在 $t=1$，$S_1$ 就是一个"输入整条路径 $\omega$、输出第 1 天价格"的函数，所以它是一个**随机变量**。

::: example 例 2：$T=2$ 的一条具体路径
设三天的价格依次为 100、103、98，那么这条路径（一个样本点）是
$$
\omega=(100,\ 103,\ 98)\in(0,\infty)^{3}.
$$
于是
$$
S_0(\omega)=100,\qquad S_1(\omega)=103,\qquad S_2(\omega)=98 .
$$
如果世界走了另一条路径 $\omega'=(100,\ 95,\ 97)$，则 $S_1(\omega')=95$。**同一个随机变量 $S_1$，在不同的世界里读出不同的数**，这正是"随机"的来源。
:::

### 批注 ③：随机过程 $S(\omega)(t)$

$S$ 现在有**两个输入**：世界 $\omega$ 和时间 $t$。从两个角度看它：

| 固定什么 | 得到什么 | 名称 |
|---|---|---|
| 固定时间 $t$，让 $\omega$ 变 | $\omega\mapsto S_t(\omega)$：一个随机变量 | 随机变量 $S_t$ |
| 固定世界 $\omega$，让 $t$ 变 | $t\mapsto S_t(\omega)$：一条具体的价格曲线 | 样本路径（sample path） |
| 两个都让它变 | 整体 $S$ | **随机过程**（stochastic process） |

所以**随机过程 = 一族按时间排列的随机变量 $(S_0,S_1,\dots,S_T)$**，也可以理解为"一条随机的曲线"：先由命运选一个 $\omega$，再画出这个世界里的价格曲线 $t\mapsto S_t(\omega)$。

::: figure 批注的结构图（文字版）
老师的板书从上到下是"由简到繁"的三层：

1. **一个数**：抛硬币，结果只有两个，$X$ 把结果变成 1 或 0；
2. **一个数组**：价格路径，一个结果就是 $T+1$ 个数排成一列，$S_t$ 取出其中第 $t$ 个；
3. **一个函数**：随机过程，把 $S_t(\omega)$ 看作 $t$ 的函数，一个结果对应一条曲线。

三层的共同点：**先有 $\Omega$ 和 $\omega$，再有"从 $\omega$ 读出信息"的函数**。这是整个概率论的基本架构。
:::

## 易错点

::: pitfall 常见误解
1. **"$\omega$ 是随机的"** —— 不准确。$\omega$ 是 $\Omega$ 中一个**确定的元素**；"随机"说的是**事先不知道会实现哪一个**。
2. **"随机变量是一个数"** —— 错。随机变量是**函数** $X:\Omega\to\mathbb{R}$；$X(\omega)$ 才是一个数。
3. **"样本空间越小越好"** —— 不对。$\Omega$ 必须"不漏不重"。股价例子里如果只记录最后一天的价格，就无法回答"第 1 天价格是多少"这样的问题，所以 $\omega$ 要取**整条路径**。
4. **$\Omega$ 与 $\omega$ 混用** —— 大写是集合，小写是元素，$\omega\in\Omega$ 不能写成 $\Omega\in\omega$。
:::

## 本页小结

::: summary 记住这四句话
1. **样本空间 $\Omega$**：所有可能结果的集合，要求"不漏不重"。
2. **样本点 $\omega$**：其中一个具体结果；试验结束后**恰好一个** $\omega$ 实现。
3. **随机变量**：函数 $X:\Omega\to\mathbb{R}$，"看 $\omega$、读一个数"；随机性来自 $\omega$，不来自 $X$。
4. **随机过程**：一族按时间排列的随机变量 $(S_t)$；固定 $\omega$ 得到一条样本路径。
:::

## 自测

:::: quiz 动手试一试
**第 1 题** 连续抛一枚硬币 3 次，写出样本空间 $\Omega$。它有几个元素？

::: details 点击查看答案
$\Omega=\{HHH,HHT,HTH,HTT,THH,THT,TTH,TTT\}$，共 $2^3=8$ 个元素。每个元素是"三次结果按顺序排好"的完整记录。
:::

**第 2 题** 价格路径 $T=3$，实现的样本点是 $\omega=(10,12,11,15)$。求 $S_2(\omega)$ 和 $S_3(\omega)$。

::: details 点击查看答案
下标从 0 开始数：$s_0=10,\ s_1=12,\ s_2=11,\ s_3=15$。所以 $S_2(\omega)=11$，$S_3(\omega)=15$。
:::

**第 3 题** 判断对错："随机变量 $X$ 是一个会随机变化的数。"

::: details 点击查看答案
错。$X$ 是从 $\Omega$ 到实数的**函数**，规则是固定的；只是我们事先不知道会实现哪个 $\omega$，所以不知道 $X(\omega)$ 会是多少。
:::

**第 4 题** 掷一颗骰子，有人把样本空间写成 $\Omega=\{\text{小于 4},\ \text{偶数}\}$。这样写有什么问题？

::: details 点击查看答案
违反"不重"也违反"不漏"：掷出 2 时"小于 4"和"偶数"同时成立（重了）；掷出 5 时两个都不成立（漏了）。
:::
::::
