这一页在讲什么

人话版一句话版

上一页（第 44 页）推到了 2∫g≤2∫g−limsup∫∣fn​−f∣。这一页用四个「⇒」把它推到底：∫∣fn​−f∣→0，从而 ∫fn​→∫f。老师写完打了「#」，DCT 证毕。

这是一页没有页码的手写续页，只有四行。下面先逐行讲清每个「⇒」的理由，再把 DCT 的完整证明串成一条链，最后给出「拿到题目时怎么用 DCT」的步骤和例题。

先补基础

基础补课非负数列：limsup ≤ 0 就意味着趋于 0

设 an​≥0。因为每一项都 ≥0，所以 0≤liminfan​≤limsupan​。若又有 limsupan​≤0，就被夹成

0≤liminfan​≤limsupan​≤0,

上下极限都等于 0，所以 an​→0。这是第 1–2 行用到的全部道理。

基础补课三角不等式（积分版，第 43 页）

​∫hdμ​≤∫∣h∣dμ。取 h=fn​−f，就能用 ∫∣fn​−f∣ 控制 ​∫fn​−∫f​。

老师板书在说什么

老师板书板书转写
  1. ⇒ 0≤nlimsup​∫∣fn​−f∣dμ≤0
  2. ⇒ ∫∣fn​−f∣dμ→0
  3. ⇒ ​∫fn​−fdμ​→0
  4. ⇒ ∫fn​→∫f.　　#

第 1 行：夹出 0

  • 右边的「≤0」来自上一页最后的不等式：2∫g≤2∫g−limsupn​∫∣fn​−f∣，两边减去有限数 2∫g 得 limsupn​∫∣fn​−f∣≤0。
  • 左边的「0≤」：∫∣fn​−f∣ 是非负函数的积分，每一项都 ≥0，所以上极限也 ≥0。

第 2 行：上极限为 0 ⇒ 收敛到 0

数列 an​=∫∣fn​−f∣dμ 非负、上极限为 0，由「先补基础」，an​→0。这就是 L1 收敛：fn​ 在「平均绝对误差」的意义下趋于 f。

第 3 行：积分之差的绝对值也趋于 0

板书里的 ∫fn​−fdμ 指 ∫(fn​−f)dμ。由三角不等式，

0≤​∫(fn​−f)dμ​≤∫∣fn​−f∣dμ→0,

夹逼得 ​∫(fn​−f)​→0。

第 4 行：结论

fn​ 和 f 都可积，积分可以拆开（线性，第 43 页）：∫(fn​−f)=∫fn​−∫f。差的绝对值趋于 0，就是 ∫fn​→∫f。老师写「#」表示证明结束。

推导：一步一步来

推导DCT 的完整证明（第 44 页 + 本页）

条件：fn​→f a.e.，∣fn​∣≤g，∫g<∞。

  1. ∣f∣≤g a.e. ⇒ f∈L1。
  2. ∣fn​−f∣≤∣fn​∣+∣f∣≤2g ⇒ hn​:=2g−∣fn​−f∣≥0。
  3. Fatou：∫liminfhn​≤liminf∫hn​。
  4. 左边：∣fn​−f∣→0 a.e. ⇒ liminfhn​=2g ⇒ 左边 =2∫g。
  5. 右边：liminf(2∫g−∫∣fn​−f∣)=2∫g−limsup∫∣fn​−f∣。
  6. 消去有限的 2∫g：limsup∫∣fn​−f∣≤0。
  7. 非负数列 ⇒ ∫∣fn​−f∣→0（本页第 1–2 行）。
  8. ​∫fn​−∫f​≤∫∣fn​−f∣→0 ⇒ ∫fn​→∫f（本页第 3–4 行）。■

整条链的结构是「MCT ⇒ Fatou ⇒ DCT」：Fatou 用 MCT 证明（第 41 页），DCT 用 Fatou 证明（这里）。下一页的 BCT 则是 DCT 的特例（第 46 页）。

例子：拿到题目时怎么用 DCT

人话版三步检查清单
  1. 逐点极限：对每个（或几乎每个）x，算出 f(x)=limn​fn​(x)。
  2. 找屋顶：找一个不依赖 n 的 g，使所有 ∣fn​∣≤g；常用办法是对 n 取上确界 supn​∣fn​(x)∣，或用初等不等式放大。
  3. 验证屋顶可积：∫g<∞。区间无穷时，常数通常不可积，要找会衰减的 g。

三步都通过，就可以写 lim∫fn​=∫limfn​=∫f。

例 1：n→∞lim​∫01​x+n1​​dx
  1. 逐点：x+n1​​→x​。
  2. 屋顶：x+n1​​≤x+1​≤2​。
  3. 常数 2​ 在 [0,1] 上可积。

DCT ⇒ 极限 =∫01​x​dx=32​。验证：∫01​x+n1​​dx=32​[(1+n1​)3/2−(n1​)3/2]→32​。✓

例 2：n→∞lim​∫0∞​x(1+x2)sin(x/n)​⋅ndx
  1. 逐点：nsin(x/n)→x（因为 sint≈t），所以被积函数 →x(1+x2)x​=1+x21​。
  2. 屋顶：∣sint∣≤∣t∣，所以 ​x(1+x2)nsin(x/n)​​≤x(1+x2)n⋅x/n​=1+x21​。
  3. ∫0∞​1+x2dx​=2π​<∞。

DCT ⇒ 极限 =∫0∞​1+x2dx​=2π​。这类题直接算原积分很难，用 DCT 一步就出来了。

例 3（失败的检查）：fn​=1[n,n+1]​ 在 R 上
  1. 逐点极限：每个 x 最终都在 [n,n+1] 左边，fn​(x)→0。
  2. 屋顶：要压住所有 fn​，至少要 g≥1[1,∞)​。
  3. ∫R​1[1,∞)​=∞：屋顶不可积，检查不通过。

结论确实不成立：∫fn​=1→0。方块一直「滑」向无穷远，质量没有消失，只是跑到了无穷远处。

例 4：在概率里用 DCT——期望的极限

设 X 在 (0,1) 上均匀分布，Xn​=X1/n。求 limn​E[Xn​]。

  1. 逐点：对每个 x∈(0,1)，x1/n=e(lnx)/n→e0=1，所以 Xn​→1 几乎必然。
  2. 屋顶：0<X1/n<1，取 g≡1。
  3. 概率测度总质量为 1，所以 E[g]=1<∞。

DCT ⇒ E[Xn​]→E[1]=1。验证：E[X1/n]=∫01​x1/ndx=1+1/n1​=n+1n​→1。✓

在概率空间上，有界的随机变量总能用常数当屋顶（总质量有限），这就是下一页有界收敛定理（第 46 页）的内容。

常见疑问与易错点

易错点问：DCT 的结论里，f 的可积性是假设还是结论？

答：是结论。我们没有事先假设 f 可积，而是由 ∣f∣≤g 推出来的（第 44 页 第 1 步）。这一点在应用中很方便：只要验证 fn​ 有共同的可积屋顶，极限函数的可积性就自动成立。

易错点问：第 1 行左边的「0 ≤」是怎么来的？好像证明里没写。

答：是因为 ∫∣fn​−f∣ 是非负函数的积分，每一项都 ≥0，所以它的上极限也 ≥0。老师把它直接写进第 1 行，和右边的 ≤0 一起「夹出」0。

易错点问：为什么结论里 ∫|fₙ − f| → 0 比 ∫fₙ → ∫f 更重要？

答：它更强（第 3 行由它推出积分收敛），而且不允许「正负抵消」（第 43 页 例 5 那种正负尖峰在 DCT 条件下不会出现）。概率里它意味着 E∣Xn​−X∣→0，即平均误差趋于 0。

易错点问：屋顶怎么找？有没有通用办法？

答：最自然的候选是 G(x)=supn​∣fn​(x)∣——它是最小的屋顶。如果 G 可积，DCT 就能用；如果 G 不可积，任何屋顶都不可积，DCT 一定用不了（例 3、第 44 页 例 3），只能另想办法（例如用 Fatou 得到一个方向的不等式）。

小结与自测

小结本页小结
  • 板书四步：0≤limsup∫∣fn​−f∣≤0 ⇒ ∫∣fn​−f∣→0 ⇒ ​∫(fn​−f)​→0 ⇒ ∫fn​→∫f。
  • 理由：非负数列的上极限 ≤0 就收敛到 0；三角不等式 ​∫h​≤∫∣h∣；积分的线性。
  • 用 DCT 的三步：求逐点极限 → 找不依赖 n 的屋顶 → 验证屋顶可积。
  • 证明链：MCT ⇒ Fatou ⇒ DCT ⇒ BCT。
自测

1. 若已知 ∫∣fn​−f∣→0，能否推出 ∫∣fn​∣→∫∣f∣？

点开看答案

能。逐点有 ​∣fn​∣−∣f∣​≤∣fn​−f∣（三角不等式），所以 ​∫∣fn​∣−∫∣f∣​≤∫​∣fn​∣−∣f∣​≤∫∣fn​−f∣→0。

2. 用 DCT 求 n→∞lim​∫01​1+xn1​dx。

点开看答案

逐点：0≤x<1 时 xn→0，被积函数 →1；只有 x=1 时等于 21​（零测集）。屋顶：1+xn1​≤1，在 [0,1] 上可积。DCT ⇒ 极限 =∫01​1dx=1。

3. 第 2 行能不能改成「liminf∫∣fn​−f∣≤0 ⇒ ∫∣fn​−f∣→0」？

点开看答案

不能。下极限为 0 只说明有一个子列趋于 0，整列可能不收敛（例如 0,1,0,1,…）。必须是上极限 ≤0，才能把整列夹到 0。这也是为什么证明里要把 liminf 换成 limsup（第 44 页 第 5 步）。
