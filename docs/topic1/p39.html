这一页在讲什么

人话版一句话版

MCT 说：非负函数递增地收敛，积分也跟着收敛。这一页问：去掉「递增」，只剩「逐点收敛」，还行吗？老师用一个尖峰函数列回答：不行。每个 fn​ 是一个越来越窄、越来越高的矩形，面积恒为 1；函数在每一点（除了 0）最终都变成 0，面积却没有变成 0——「质量」在极限中丢失了。

  • 位置：第 5 部分。前面 第 36 页–第 38 页 是 MCT 及其应用；这一页是一个反例，说明 MCT 的「单调」条件不能随便去掉。
  • 这里的「质量」（mass）就是积分，也就是函数图像下方的面积；在概率里就是期望。
  • 反例还告诉我们：没有单调性时，最多只能期望一个方向的不等式。下两页 第 40 页、第 41 页 用「尾部下确界」人为造出单调性，得到 Fatou 引理 ∫liminffn​≤liminf∫fn​。本页的尖峰正好是 Fatou 不等号严格成立的例子。
  • 再往后，第 44 页 的控制收敛定理给出另一种补救：只要所有 fn​ 被同一个可积函数压住，质量就跑不掉。

先补基础

基础补课函数列逐点收敛（pointwise convergence）
  • fn​→f 逐点（pointwise，老师缩写为 p.w.）：对每一个固定的点 x，数列 f1​(x),f2​(x),f3​(x),… 收敛到 f(x)。
  • 用 ε 语言写：对每个 x 和每个 ε>0，存在 N（可以依赖于 x），使得 n≥N 时 ∣fn​(x)−f(x)∣<ε。
  • 关键点：不同的点可以用不同的 N。本页的例子里，靠近 0 的点要等很久才变成 0，这正是质量能「躲」起来的原因。
  • 例：fn​(x)=nx​ 在 [0,1] 上逐点趋于 0：固定 x，0≤nx​≤n1​→0。
基础补课「推不出」⇏ 与「一个反例就够了」
  • A⇒B 读作「由 A 可以推出 B」：只要 A 成立，B 一定成立。
  • A⇏B（老师在箭头上画了一个红叉）读作「由 A 推不出 B」：存在 A 成立而 B 不成立的情形。
  • 要否定一个「对所有情形都成立」的断言，举出一个反例就够了。这一页就是一个反例：满足「非负、逐点收敛」，却不满足「积分收敛到极限函数的积分」。
基础补课测度空间 ([0,1], 𝓑[0,1], Leb) 与示性函数（回顾）
  • [0,1] 是空间；B[0,1] 是 [0,1] 上的博雷尔 σ-代数（由区间生成，第 11 页）；Leb 是勒贝格测度，区间的测度就是长度（第 23 页）。
  • 示性函数 1A​(x)：x∈A 时为 1，否则为 0（第 30 页）。所以 n1[0,1/n]​ 在 [0,n1​] 上等于 n，其余地方等于 0：一个宽 n1​、高 n 的矩形。
  • 积分公式：∫1A​dμ=μ(A)（第 30 页 推论 24）；常数可以提出来，∫chdμ=c∫hdμ（第 33 页 命题 28）。
  • 单点的长度是 0：Leb({0})=0，所以 [0,n1​]、(0,n1​]、(0,n1​) 的长度都是 n1​。

Pointwise convergence alone does not preserve mass｜标题逐词看

  • pointwise convergence：逐点收敛。
  • alone：单独、仅仅。意思是「只有逐点收敛这一个条件」，没有单调性，也没有别的条件。
  • preserve mass：保住质量。这里的 mass（质量）就是积分。把函数图像下面的区域想成铺了一层沙子，积分就是沙子的总量。「保住质量」是说：极限函数下面的沙子总量，等于 fn​ 下面沙子总量的极限。
  • 整句：仅凭逐点收敛，质量可能会丢失。

If there is no monotonic property, can we still hold the statement?｜问题本身

  • the statement（这个结论）指 MCT 的结论 ∫fn​→∫f（第 36 页）。
  • monotonic property（单调性）指 MCT 的条件 f1​≤f2​≤⋯。
  • 问题：去掉单调性，只留「非负 + 逐点收敛」，还能得到 ∫fn​→∫f 吗？老师的回答写在板书第一行：不能。
  • 英文小注：can we still hold the statement 更地道的说法是 does the statement still hold，意思一样。
人话版用沙子来想

想象每个 fn​ 都是一堆总量为 1 的沙子。第 n 步把沙子全部堆进 [0,n1​] 这个越来越窄的槽里，于是沙堆越来越高。站在任何一个点 x>0 看，槽迟早会从你脚下移走，你脚下的沙子变成 0；可是沙子的总量一直是 1。到了极限，所有的沙子都挤到了「点 0」上，而一个点的宽度是 0，积分就看不见它了。

例 1：逐点看、整体看——一张表

下表第一行固定一点 x=0.3，看 fn​(0.3) 怎样变化；第二行固定 x=0.01；第三行是积分。

n 1 2 3 4 5 10 100 101
fn​(0.3) 1 2 3 0 0 0 0 0
fn​(0.01) 1 2 3 4 5 10 100 0
∫fn​dLeb 1 1 1 1 1 1 1 1

计算理由：fn​(x)=n 当且仅当 x≤n1​，即 n≤x1​。x=0.3 时 x1​≈3.33，所以 n=1,2,3 时取值 n，n≥4 时为 0；x=0.01 时 x1​=100，所以要到 n=101 才变成 0。

读法：每一点最终都变成 0，但越靠近 0 的点「坚持」得越久，而且坚持时的值越来越大。任何时刻都有一小段区间 [0,n1​] 还在「扛着」全部质量 1。

动手试一试尖峰：面积恒为 1，每一点最终是 0

拖动 n：橙色矩形的宽是 n1​、高是 n，面积始终是 1；再看虚线 x=0.3 处的函数值——n≥4 以后它永远是 0。两件事同时成立，正是「逐点收敛推不出积分收敛」。

例 2：高度长得慢一点，结论就对了

把高度从 n 改成 n​：hn​=n​1(0,1/n)​。

  • 逐点：对 x∈(0,1]，n>x1​ 后 hn​(x)=0；又 hn​(0)=0。所以处处 hn​→0。
  • 积分：∫hn​dLeb=n​⋅n1​=n​1​→0=∫0dLeb。

这一次「先积分再取极限」和「先取极限再积分」都是 0。可见逐点收敛有时能保住质量，有时不能；本页只是说「仅凭逐点收敛不够」，并不是说它总会失败。反过来，高度改成 n2 时，∫n21(0,1/n)​dLeb=n→∞：质量不但没保住，积分还跑到了无穷。

例 3：质量也可以「横着」跑掉

在 (R,B,Leb) 上令 fn​=1[n,n+1]​：一块宽 1、高 1 的方块，每一步向右挪 1。

  • 逐点：固定 x，只要 n>x，x 就在方块左边，fn​(x)=0。所以 fn​→0 处处成立。
  • 积分：∫fn​dLeb=Leb([n,n+1])=1，恒为 1。

尖峰是质量竖着挤到一个点上，这里是质量横着跑到无穷远。两个例子都不单调，MCT 都不适用。这个例子在 第 46 页 还会出现：它说明有界收敛定理必须要求测度有限。

例 4：概率里的尖峰——一张「彩票」

在概率空间 ([0,1],B,Leb) 上，把 ω 看成一次抽签抽到的点。第 n 期的规则：ω 落在 (0,n1​) 里就得 n 元，否则得 0 元。即 Xn​(ω)=n1(0,1/n)​(ω)。

  • 期望：E[Xn​]=n⋅P((0,n1​))=n⋅n1​=1，每一期都是 1 元。
  • 对每个 ω∈(0,1]，从 n>ω1​ 那一期起 Xn​(ω)=0；而 ω=0 不在任何 (0,n1​) 里，每期都是 0。所以不管抽到哪个点，最终都再也拿不到钱：极限 X=0，E[X]=0。

每期的期望都是 1，极限的期望却是 0。在概率里这提醒我们：Xn​→X 并不自动给出 E[Xn​]→E[X]，需要单调、控制或有界这类额外条件（第 36 页、第 44 页、第 46 页）。

推导：一步一步来

推导证明思路

分别算出两个数：「先积分再取极限」得 1，「先取极限再积分」得 0。再指出这列函数不单调，所以和 MCT 不矛盾。

第 1 步：逐点极限。 取板书的 fn​=n1[0,1/n]​。

  • 设 x∈(0,1]。取正整数 N>x1​。当 n≥N 时 n1​≤N1​<x，所以 x∈/[0,n1​]，fn​(x)=0。于是 fn​(x)→0。
  • x=0 时 fn​(0)=n→∞。
  • 所以极限函数 f=limfn​ 在 (0,1] 上等于 0，在点 0 处等于 ∞。

第 2 步：极限函数的积分是 0。 f=∞⋅1{0}​。任取台阶 0≤s≤f：s 在 x=0 处只能是 0，在点 0 处是某个有限值 a，所以 ∫s=a⋅Leb({0})=0。所有台阶的积分都是 0，上确界 ∫fdLeb=0（与 第 33 页 例 4 相同）。

第 3 步：每个 fn​ 的积分是 1。 见板书第 5 行的三个等号。

第 4 步：比较两个顺序。

n→∞lim​∫fn​dLeb=n→∞lim​1=1 = 0=∫fdLeb=∫n→∞lim​fn​dLeb.

第 5 步：为什么和 MCT 不矛盾。 MCT 要求 fn​≤fn+1​ 处处成立。取 x∈(n+11​,n1​]：fn​(x)=n，而 fn+1​(x)=0，所以 fn​(x)>fn+1​(x)，单调性在这一段上失败。条件不满足，MCT 什么也没断言，没有矛盾。

第 6 步：质量只丢失、没有凭空增加。 这里 ∫limfn​=0<1=lim∫fn​：极限函数的积分偏小。对非负函数，这个方向不是偶然的——第 41 页 的 Fatou 引理会证明：非负函数列的下极限的积分，永远不超过积分的下极限。质量可以在极限中丢失，但不会凭空多出来。

常见疑问与易错点

易错点问：函数在每一点都趋于 0 了，面积为什么不趋于 0？

答：因为「每一点都趋于 0」允许不同的点在不同的时刻变成 0。任何时刻 n，区间 [0,n1​] 上的点都还没变成 0，而且那里的高度是 n；宽 × 高 =n1​×n=1。面积由「还没变成 0 的那一小块」扛着，这一块越来越窄，却越来越高，面积始终不变。

易错点问：这个反例和 MCT 矛盾吗？

答：不矛盾。MCT 要求逐点递增，而尖峰不是递增的（推导第 5 步）。MCT 在这里根本不适用。反例恰好说明 MCT 的单调性条件是必要的，不能省略。

易错点问：板书写的「fₙ → 0 p.w.」对吗？

答：差一个点。按老师的写法 fn​=n1[0,1/n]​，在 x=0 处 fn​(0)=n→∞。应说「在 (0,1] 上逐点收敛到 0」，或者把区间改成 (0,n1​]。这一点的长度是 0，不影响任何积分，所以结论 1=0 完全成立。

易错点问：有正有负的函数也会「丢质量」吗？会不会反过来「多出质量」？

答：会多出来。取 fn​=−n1(0,1/n)​，它逐点趋于 0，但 ∫fn​=−1（按 第 33 页 板书的「正部减负部」）。于是 lim∫fn​=−1<0=∫limfn​，方向和尖峰相反。这就是为什么 Fatou 引理（第 41 页）一定要求非负：只有非负时，才能保证「极限的积分不超过积分的极限」这一个方向。

易错点问：那到底在什么条件下才能交换极限和积分？

答：本讲给了三个充分条件：函数非负且单调递增（MCT，第 36 页）；被同一个可积函数控制（DCT，第 44 页）；测度有限且函数一致有界（BCT，第 46 页）。尖峰三个条件都不满足：不单调；[0,1] 的测度虽然有限，但高度 n→∞，不是一致有界；也找不到可积的控制函数（第 47 页 自测第 2 题算过）。

小结与自测

小结本页小结
  • 去掉单调性，逐点收敛推不出积分收敛：fn​→f⇏∫fn​→∫f。
  • 反例（尖峰）：([0,1],B,Leb) 上 fn​=n1[0,1/n]​，每个积分都是 1，逐点极限（点 0 除外）是 0，于是 lim∫fn​=1=0=∫limfn​。
  • 板书小疏漏：x=0 处 fn​(0)=n→∞，应说「在 (0,1] 上」收敛，或把区间改成 (0,n1​]；不影响结论。
  • 质量可以竖着挤到一个点（尖峰），也可以横着跑到无穷远（1[n,n+1]​）。
  • 对非负函数，极限只会「丢质量」，这就是下两页 Fatou 引理的不等号方向。
自测

1. 在 ([0,1],B,Leb) 上，fn​=n21(0,1/n)​。求逐点极限和 lim∫fn​。

点开看答案

逐点极限：对 x∈(0,1]，n>x1​ 后 fn​(x)=0；又 fn​(0)=0。所以处处趋于 0，∫limfn​=0。积分 ∫fn​=n2⋅n1​=n→∞。两种顺序的结果分别是 ∞ 和 0。

2. 判断：「若非负可测函数 fn​ 逐点收敛到 f，并且每个 ∫fn​=1，则 ∫f=1。」

点开看答案

错误。尖峰就是反例：每个 ∫fn​=1，但 ∫f=0。（由 Fatou 引理，能说的只有 ∫f≤1，见 第 41 页。）

3. 尖峰 fn​=n1(0,1/n)​ 为什么不满足 MCT 的条件？请在 x=0.3 处具体说明。

点开看答案

MCT 要求每个点上 f1​(x)≤f2​(x)≤⋯。在 x=0.3 处，f1​=1，f2​=2，f3​=3，f4​=0（因为 0.3≥41​，不在 (0,41​) 里）。从 3 掉到 0，数列不是递增的，所以 MCT 的条件不满足。
