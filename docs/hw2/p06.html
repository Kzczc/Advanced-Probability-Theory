Glivenko–Cantelli 定理：经验分布函数一致收敛到真实分布

The Glivenko–Cantelli theorem

这道题在问什么

人话版一句话版

从分布 F 中独立抽 n 个样本，统计「不超过 x 的样本所占的比例」，得到经验分布函数 Fn​(x)。强大数定律说：对每个固定的 x，Fn​(x)→F(x) 几乎必然。Glivenko–Cantelli 定理更强：所有 x 一起，supx​∣Fn​(x)−F(x)∣→0 几乎必然，也就是整条阶梯曲线一致地贴近真实的分布函数。它被称为「统计学基本定理」：样本足够多时，数据能还原出整个分布。证明的关键是把无穷多个 x 化成有限个分位点，再用分布函数的单调性夹逼。

  • 考点：强大数定律（讲义之外，作为已知结论）、分布函数的单调性与右连续性、左极限 F(x−)、分位点。
  • 出处：Durrett《Probability: Theory and Examples》定理 2.4.9，原解答几乎逐字照搬了它的证明。
  • 和讲义的关系：分布函数（第 2 讲 第 8 页）、分位数与逆变换（第 2 讲 第 14 页）、几乎必然收敛（第 3 讲 第 9 页）。

先补基础

基础补课分布函数的三条性质与左极限

F(x)=P(X≤x) 满足（第 2 讲 第 8 页）：单调不减；右连续；F(−∞)=0、F(∞)=1。

左极限 F(x−)=limy↑x​F(y)=P(X<x)。F 在 x 处有跳跃时，跳跃的高度是 F(x)−F(x−)=P(X=x)。例：公平骰子在 x=3 处 F(3)=21​，F(3−)=31​。

基础补课经验分布函数

Fn​(x)=n1​∑m=1n​1{Xm​≤x}​：样本中不超过 x 的比例。它是一个阶梯函数，在每个样本点处向上跳 n1​。例：样本 0.3,0.7,0.1（n=3），则 x<0.1 时 F3​=0，0.1≤x<0.3 时 31​，0.3≤x<0.7 时 32​，x≥0.7 时 1。同样定义 Fn​(x−)=n1​∑m​1{Xm​<x}​。

基础补课强大数定律（这里作为已知结论使用）

Y1​,Y2​,… i.i.d.，E∣Y1​∣<∞，则 n1​∑m=1n​Ym​→EY1​ 几乎必然。（Durrett 定理 2.4.1。）本题只用到 Ym​ 是示性函数（取 0、1）的情形，此时它也叫 Borel 强大数定律，可以用 Borel–Cantelli 引理较直接地证明。

基础补课可数个概率为 1 的事件，交仍然概率为 1

若 P(Ak​)=1（k=1,2,…），则 P(⋂k​Ak​)=1，因为 P(⋃k​Akc​)≤∑k​P(Akc​)=0。本题要让可数多个点上的收敛同时成立，靠的就是这一条。

题目与原解答

课件原文题目
  1. We define the empirical distribution functions as the following. Let X1​,X2​,… be i.i.d. with distribution F and let
Fn​(x)=n−1i=1∑d​1(Xm​≤x)​

Fn​(x) = the observed frequency of values that are ≤x, hence the name given above.

Prove the Glivenko-Cantelli theorem. As n→∞,

xsup​∣Fn​(x)−F(x)∣→0a.s.

(Hence, Fn​ converges uniformly to F as n→∞.)

中文翻译
  1. 定义经验分布函数如下：设 X1​,X2​,… i.i.d.，分布函数为 F，令 Fn​(x)=n1​∑m=1n​1{Xm​≤x}​，即观测值中不超过 x 的频率，因此得名。

证明 Glivenko–Cantelli 定理：n→∞ 时 supx​∣Fn​(x)−F(x)∣→0 几乎必然（于是 Fn​ 一致收敛到 F）。

  • 题目中求和写成 ∑i=1d​1(Xm​≤x)​，上限 d 和下标 i、m 都不一致，应为 ∑m=1n​1{Xm​≤x}​。

原解答的思路（左栏，即 Durrett 定理 2.4.9 的证明）：

  1. 固定 x，由强大数定律得 Fn​(x)→F(x)、Fn​(x−)→F(x−) 几乎必然；
  2. 取分位点 xj,k​=inf{y:F(y)≥kj​}，在这有限个点上同时让误差小于 k1​；
  3. 对两个分位点之间的 x，用 Fn​、F 的单调性夹逼，得到 supx​∣Fn​(x)−F(x)∣≤k2​。

证明是正确的，但跳过了几处需要说明的细节（见「原解答逐行对照」）。

思路：怎么想到的

  • 难点：「对每个 x 收敛」和「对所有 x 一致收敛」差别很大，因为有不可数多个 x，不能简单地把所有 x 的零测例外集并起来（不可数个零测集的并可以不是零测集）。
  • 办法：只看有限个精心选择的点。在两个相邻的点之间，Fn​ 和 F 都单调，它们的值被夹在端点的值之间；只要相邻端点处 F 的增长不超过 k1​，中间的误差就被端点的误差控制住。
  • 跳跃的麻烦：F 若有跳跃，一个跳跃可能比 k1​ 还高，相邻分位点之间的增长就控制不住。解决办法：在分位点处同时考虑 F(x) 和左极限 F(x−)，跳跃发生在这两者之间，不影响夹逼。

完整解答

第 1 步（逐点收敛，包括左极限）：固定 x。1{Xm​≤x}​（m=1,2,…）i.i.d.，均值 P(X1​≤x)=F(x)。由强大数定律，Fn​(x)→F(x) 几乎必然。同理 1{Xm​<x}​ 的均值是 F(x−)，所以 Fn​(x−)→F(x−) 几乎必然。

第 2 步（分位点）：固定正整数 k，对 1≤j≤k−1 令

xj,k​=inf{y:F(y)≥kj​}

（第 kj​ 分位点，第 2 讲 第 14 页），并令 x0,k​=−∞，xk,k​=+∞。由于 0<kj​<1，这些 xj,k​ 都是有限实数，并且 x0,k​≤x1,k​≤⋯≤xk,k​。

分位点的两个性质（1≤j≤k）：

  • F(xj,k​−)≤kj​：对 y<xj,k​，由下确界的定义 F(y)<kj​，取极限即得。（j=k 时右边是 1，自然成立。）
  • F(xj−1,k​)≥kj−1​：由右连续性，下确界处取得 F(xj−1,k​)≥kj−1​。（j=1 时左边按约定为 F(−∞)=0。）

两式相减：

F(xj,k​−)−F(xj−1,k​)≤k1​.(∗)

第 3 步（可数个点同时收敛）：由第 1 步，对每个 k 和每个 1≤j≤k−1，Fn​(xj,k​)→F(xj,k​) 和 Fn​(xj,k​−)→F(xj,k​−) 都几乎必然成立。所有 (j,k) 只有可数多对，由「可数个概率为 1 的事件之交仍概率为 1」，存在一个概率为 1 的事件 Ω0​，在 Ω0​ 上它们同时成立。下面固定 ω∈Ω0​。对每个 k，只有有限个点，所以存在 Nk​(ω)，使 n≥Nk​(ω) 时对所有 0≤j≤k，

∣Fn​(xj,k​)−F(xj,k​)∣<k1​,∣Fn​(xj,k​−)−F(xj,k​−)∣<k1​.

（j=0、j=k 时两边都是 0 或 1，自动成立。）

第 4 步（夹逼）：设 n≥Nk​(ω)。任取实数 x。

  • 若 x 恰好是某个 xj,k​：由第 3 步，∣Fn​(x)−F(x)∣<k1​。
  • 否则 x∈(xj−1,k​,xj,k​)，对某个 1≤j≤k。由单调性和 (∗)：
Fn​(x)≤Fn​(xj,k​−)≤F(xj,k​−)+k1​≤F(xj−1,k​)+k2​≤F(x)+k2​,
Fn​(x)≥Fn​(xj−1,k​)≥F(xj−1,k​)−k1​≥F(xj,k​−)−k2​≥F(x)−k2​.

（第一行第一个不等号：x<xj,k​，所以 Fn​(x)≤Fn​(xj,k​−)；最后一个：x>xj−1,k​，F 单调。第二行同理。）

所以对所有 x，∣Fn​(x)−F(x)∣≤k2​，即 supx​∣Fn​(x)−F(x)∣≤k2​（n≥Nk​(ω)）。

第 5 步（结论）：k 任意，所以在 Ω0​ 上 limsupn​supx​∣Fn​(x)−F(x)∣≤k2​ 对所有 k 成立，即 supx​∣Fn​(x)−F(x)∣→0。P(Ω0​)=1，定理得证。■

原解答逐行对照

  1. 「Fix x and let Yn​=1(Xn​≤x)​ ... the strong law of large numbers implies that Fn​(x)=n−1∑i=1d​Yi​→F(x) a.s.」：求和上限 d 应为 n。正确。
  2. 「In general, if Fn​ is a sequence of nondecreasing functions that converges pointwise to a bounded and continuous limit F then supx​∣Fn​(x)−F(x)∣→0. However, the distribution function F(x) may have jumps」：说明了为什么要处理左极限：F 连续时，只看 Fn​(xj,k​) 就够了（这个结论叫 Pólya 定理）；有跳跃时还要看 Fn​(xj,k​−)。
  3. 「Again, fix x and let Zn​=1(Xn​<x)​ ... Fn​(x−)=n−1∑i=1d​Zm​→F(x−) a.s.」：下标混用（i、m、d），意思正确。
  4. 「For 1≤j≤k−1 let xj,k​=inf{y:F(y)≥j/k}. The pointwise convergence ... imply that we can pick Nk​(ω) ...」：这里需要一个公共的概率为 1 的事件，使所有 k 和 j 的收敛同时成立（第 3 步）。原解答没有说明。
  5. 「If x∈(xj−1,k​,xj,k​) ... using ... F(xj,k​−)−F(xj−1,k​)≤k−1」：两处遗漏：① 不等式 (∗) 没有证明（它依赖分位点的两个性质：下确界给出 F(xj,k​−)≤kj​，右连续性给出 F(xj−1,k​)≥kj−1​）；② 只处理了开区间，x 恰好等于分位点的情形没有说（它由第 3 步的逐点估计直接覆盖）。
  6. 两行夹逼不等式与结论 supx​∣Fn​(x)−F(x)∣≤2k−1：正确。
易错点原解答的问题：「同时成立」需要一个公共的概率 1 事件

对每个固定的点，收敛都是几乎必然的，但例外的零测集依赖于这个点。证明里要在无穷多个 k、每个 k 下的 k−1 个点上同时使用收敛，必须先说明：这些点总共只有可数个，所以把可数个例外集并起来仍是零测集。原解答直接说「pick Nk​(ω)」，省略了这一步。这一步正是「把不可数个 x 化成可数个点」这个思路的意义所在。

易错点原解答的问题：关键不等式 (∗) 没有证明

F(xj,k​−)−F(xj−1,k​)≤k1​ 是整个夹逼的基础，也是处理跳跃的关键：跳跃的高度可能远大于 k1​，但它发生在 F(xj,k​−) 和 F(xj,k​) 之间，不在两个相邻分位点之间。原解答直接使用，没有给出理由（见第 2 步）。

例子与数值验证

例 1：一致误差随样本量的变化

从 (0,1) 上的均匀分布抽样，计算 Dn​=supx​∣Fn​(x)−x∣ 的平均值（模拟）：

n 10 100 1000 10000
Dn​ 的平均值（模拟） 0.264 0.085 0.0278 0.0085
0.8687/n​ 0.275 0.087 0.0275 0.0087

Dn​ 趋于 0，而且大约按 n​1​ 的速度：样本量乘 100，误差缩小到十分之一。

例 2：有跳跃的分布——掷骰子

掷 60 次公平骰子（固定随机种子），得到 F60​ 在 1,…,6 处的值 0.183, 0.350, 0.483, 0.633, 0.833, 1，真实值 61​,62​,…,1，最大误差 0.033。骰子的分布函数每处跳 61​，比证明中 k 较大时的 k1​ 高得多；证明之所以仍然有效，是因为跳跃夹在 F(x−) 与 F(x) 之间，两者都被单独控制了。

例 3：逐点收敛不等于一致收敛（非概率的例子）

函数列 gn​(x)=1[n,n+1)​(x)：对每个 x，gn​(x)→0，可 supx​∣gn​(x)∣=1 对所有 n 成立。这说明「每个 x 都收敛」推不出一致收敛。Glivenko–Cantelli 之所以成立，是因为 Fn​ 和 F 都单调有界，单调性把有限个点的信息「传播」到了所有 x。

拓展延伸

DKW 不等式：收敛速度的定量版本

Dvoretzky–Kiefer–Wolfowitz 不等式（Massart 给出了最优常数）：对任意 ε>0，

P(xsup​∣Fn​(x)−F(x)∣>ε)≤2e−2nε2.

例如 n=1000、ε=0.05 时，右边约为 0.0135。这比 Glivenko–Cantelli 更强：它给出了任意有限 n 下的概率上界，而且与 F 是什么分布无关。由它和 Borel–Cantelli 引理也能推出 Glivenko–Cantelli 定理。

Kolmogorov–Smirnov 检验

更精细地，n​supx​∣Fn​(x)−F(x)∣ 依分布收敛到一个与 F 无关的极限分布（Kolmogorov 分布，F 连续时），例 1 里的 0.8687 就是这个极限分布的均值 π/2​ln2。统计学中用它检验「数据是否来自某个指定的分布」：若 n​Dn​ 太大，就拒绝这个分布。

经验过程与 bootstrap

把 n​(Fn​−F) 看成一个随机函数，它收敛到「布朗桥」（Donsker 定理）。这是经验过程理论的起点。统计中的 bootstrap 方法，正是把未知的 F 换成经验分布 Fn​ 去重复抽样；Glivenko–Cantelli 定理保证了 Fn​ 是 F 的好替身。

常见疑问与易错点

易错点问：为什么不能对每个 x 用强大数定律，然后取 sup？

答：对每个 x，例外的零测集 Nx​ 不同；x 有不可数多个，⋃x​Nx​ 可能不是零测集，甚至可能不是事件。所以只能在可数多个点上使用强大数定律，再用单调性推广到所有 x。

易错点问：F 连续时证明能简化吗？

答：能。连续时 F(x−)=F(x)，只需在 xj,k​ 处用 Fn​(xj,k​)→F(xj,k​)，并取 xj,k​ 使 F(xj,k​)=kj​。这时就是原解答提到的 Pólya 定理。

易错点问：一致收敛有什么实际意义？

答：它保证用 Fn​ 估计任何区间的概率都同时准确：∣Pn​(a<X≤b)−P(a<X≤b)∣≤2supx​∣Fn​−F∣。如果只有逐点收敛，就不能保证所有区间同时可靠。

可数countable元素能排成第 1 个、第 2 个、第 3 个……的一列（有限也算），例如自然数、有理数。
不可数uncountable无论怎么排都排不成一列，例如区间 [0,1] 里的全体实数。
零测集null set测度为 0 的集合，例如单点、有理数全体、康托尔集。
逐点收敛pointwise convergence对定义域里的每一个点 x，数列 fₙ(x) 都收敛到 f(x)。
下确界infimum (inf)最大的下界。例如 (0,1] 没有最小值，但下确界是 0。
事件event样本空间的（允许谈概率的）子集；实现的 ω 落在里面，就说事件发生。
区间interval数轴上的一段，[a,b] 包含端点，(a,b) 不包含端点。
依分布收敛convergence in distribution在极限分布函数 F 的每个连续点 x 上，P(Xₙ ≤ x) → F(x)。它只比较分布，不要求 Xₙ 本身靠近 X。
