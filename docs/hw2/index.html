原解答问题速览12 道题 · 38 处

解答原页不是标准答案：下面是各题精讲里指出的笔误、跳步和错误（「题目」表示题面本身的问题）。点题目标题直接跳到那道题的「原解答逐行对照」，那里有正确写法。考前复习时，这些地方最容易丢分。

  1. 01几乎必然收敛 + 范数收敛 ⇒ Lᵖ 收敛（Fatou 引理的「减法技巧」）
    • 问题常数 2^{p/2} 应为 2^{p−1}
    • 问题「X̂ₙ = Xₙ a.s.」不对
    • 问题这个「化归」不成立
    • 问题左边应为 ∫|Xₙ − X̂ₙ|ᵖ
    • 问题MCT 用不上，结论要靠 Fatou + 范数条件
    • 问题主体部分 E|X̂ₙ − X|ᵖ → 0 从未证明
  2. 02i.i.d. 指数分布：Xₙ/log n 的上极限是 1，最大值 / log n 收敛到 1
    • 问题(i) 中的笔误
    • 问题(i) 的两处跳步
    • 问题前 N_ω 项的上界没有根据
    • 问题√(2 log n) 与上一行不一致
    • 问题「∑ e^{−n^ε} < ∞」没有给理由
  3. 03乘积的收敛：依概率收敛总能相乘，L¹ 收敛要靠 Hölder 配对指数
    • 问题(i) 的几处跳步
    • 问题两颗星的第二句没有回答
    • 问题最后的 Fatou 一行有三处错误
    • 问题「find such p, q」只隐含在推导里
    • 问题(v) 的反例验证不完整，附加条件没有给
  4. 04直接由中心极限定理推出弱大数定律：小因子 σ/√n 乘一个「很少很大」的量
    • 问题记号和假设没有交代
    • 问题lim 应为 lim sup，严格不等号的极限要说明
  5. 05均值无穷时 lim sup |Sₙ|/aₙ 只能是 0 或 ∞，由 ∑P(|X₁| ≥ aₙ) 是否有限决定
    • 问题第一部分的跳步
    • 问题为什么「只需检查这两件事」完全没有说明
    • 问题方差估计中的记号、常数与不等号
    • 问题均值估计中 N 的处理与下标
  6. 06Glivenko–Cantelli 定理：经验分布函数一致收敛到真实分布
    • 问题「同时成立」需要一个公共的概率 1 事件
    • 问题关键不等式 (∗) 没有证明
  7. 07高维球面上的均匀分布：每个坐标近似标准正态（Poincaré–Borel）
    • 题目对固定的 d，Xⁱ 不是正态
    • 问题「旋转不变 ⇒ 均匀」的论证不完整
  8. 08去掉 i.i.d.：相关性衰减得够快，弱大数定律照样成立
    • 问题对角线那一项被算了两次
    • 小问题max 应为 sup
  9. 09随机项数的中心极限定理（Anscombe 定理）
    • 问题分解式中间一项的符号写反了
    • 问题「≤ 8ε/δ²」对每个 n 不一定成立
    • 遗漏N 可以依赖于 X
  10. 10平方和减去 nσ² 是鞅：方差随时间线性增长
    • 小问题没有验证适应性和可积性
  11. 11Galton–Watson 分支过程：种群规模里藏着的鞅
    • 问题μ < 1 时用的不等式方向不对
    • 问题μ ≤ 1 时还需要 σ² > 0
  12. 12赌徒破产：用两个鞅算出破产概率与平均局数
    • 题目笔误财富应写成 Sₙ = b + X₁ + ⋯ + Xₙ
    • 问题E(S₀) = b，不是 0
    • 问题E T 的公式漏了 −b²
    • 问题没有验证可选停止定理的条件
