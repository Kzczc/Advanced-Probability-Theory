## 这一页在讲什么

::: idea 一句话版
两件事。**乘积测度定理**：对 σ-有限的测度空间，存在**唯一**一个测度 $\mu_1\times\mu_2$，在每个可测矩形上取值 $\mu_1(A_1)\mu_2(A_2)$。**截口**：固定第一个坐标 $\omega_1$，把二维集合 $A$「竖着切一刀」，切口 $A_{\omega_1}$ 是 $\Omega_2$ 的一个子集；横着切同理。下一页用截口把二维测度算成一维测度的积分。
:::

- **位置**：第 1 部分的核心页。[[p:6]] 定好了事件族 $\F_1\otimes\F_2$，这一页在上面放测度，并准备好计算工具「截口」。
- **课件省略的部分**：证明「需要 Dynkin 的 π-λ 定理」。下面补出定理的完整陈述，并讲清楚唯一性的思路：π-λ 定理是什么、为什么需要 σ-有限。
- **后面怎么用**：[[p:8]] 用截口给出 $(\mu_1\times\mu_2)(A)=\int\mu_2(A_{\omega_1})\dd\mu_1$；Fubini 定理（[[p:10]]）对函数的截口 $f_{\omega_1}$ 积分。

## 先补基础

::: basics 约定 0 · ∞ = 0
测度可以取 $+\infty$（例如 $\R$ 的长度）。乘积测度规定 $0\cdot\infty=0$。理由：平面上的线段 $\{0\}\times\R$ 是一条直线，宽度 0、长度 $\infty$，面积应该是 0。第 1 讲积分里用的也是这个约定（[[t1:p:30]]）。
:::

::: basics π-系与 λ-系（Dynkin 系）
- **π-系**：对**有限交**封闭的集族。例：可测矩形全体（[[p:6]]：两个矩形的交还是矩形）；$\R$ 上所有半直线 $(-\infty,a]$。
- **λ-系**（又叫 Dynkin 系）：包含全集，对「大集合减去包含于其中的小集合」封闭（$A\subseteq B$ 时 $B\setminus A$ 也在里面），对**递增**的可数并封闭。
- **π-λ 定理**（Dynkin）：若 π-系 $\mathcal P$ 包含于 λ-系 $\mathcal L$，则 $\sigma(\mathcal P)\subseteq\mathcal L$。
- 为什么有用：「两个测度相等的集合」天然组成一个 λ-系（相等关系经得起相减和递增极限），却不一定是 σ-代数。π-λ 定理说：只要它们在一个生成 σ-代数的 π-系上相等，就在整个 σ-代数上相等。
:::

::: basics 「好集合原理」
要证明某个性质对 $\sigma(\mathcal C)$ 里所有集合成立，常用的套路是：把具有这个性质的集合收集起来，叫「好集合」；证明①$\mathcal C$ 里的集合都是好集合，②好集合组成 σ-代数（或 λ-系）。那么好集合包含 $\sigma(\mathcal C)$。第 1 讲 [[t1:p:29]] 证明「检验生成元就够了」用的就是这个套路。
:::

### Theorem (Product measure)｜乘积测度定理

::: thm 定理（乘积测度）
设 $(\Omega_1,\F_1,\mu_1)$、$(\Omega_2,\F_2,\mu_2)$ 是 σ-有限的测度空间。则在乘积 σ-代数 $\F_1\otimes\F_2$ 上存在**唯一**的测度 $\mu_1\times\mu_2$，使得对所有可测矩形
$$
(\mu_1\times\mu_2)(A_1\times A_2)=\mu_1(A_1)\,\mu_2(A_2)\qquad(A_1\in\F_1,\ A_2\in\F_2),
$$
其中约定 $0\cdot\infty=0$。它叫 $\mu_1$ 与 $\mu_2$ 的**乘积测度**。若 $\mu_1=\P_1$、$\mu_2=\P_2$ 都是概率测度，则 $\P_1\times\P_2$ 也是概率测度。
:::

最后一句：$(\P_1\times\P_2)(\Omega_1\times\Omega_2)=\P_1(\Omega_1)\P_2(\Omega_2)=1\times1=1$。

::: proof 证明思路（课件略去，这里说明结构）
**存在性**有两条常见的路：
1. **用截口直接定义**：令 $\mu(A)=\int_{\Omega_1}\mu_2(A_{\omega_1})\dd\mu_1(\omega_1)$（下一页的公式）。在矩形上它确实给出 $\mu_1(A_1)\mu_2(A_2)$；可数可加性来自单调收敛定理（[[t1:p:36]]）：不交并的截口是截口的不交并，截口测度相加，再把求和与积分交换。
2. **用外测度延拓**：和第 1 讲从「区间长度」造出勒贝格测度（[[t1:p:18]]–[[t1:p:23]]）一样，先在矩形的有限不交并上定义，再用卡拉泰奥多里方法延拓到 $\F_1\otimes\F_2$。

**唯一性**用 π-λ 定理。先看两个都是有限测度的情形：设 $\nu,\nu'$ 是两个在所有矩形上都取 $\mu_1(A_1)\mu_2(A_2)$ 的测度。令 $\mathcal L=\{A\in\F_1\otimes\F_2:\nu(A)=\nu'(A)\}$。
- 矩形全体是 π-系，包含于 $\mathcal L$，并且包含全集 $\Omega_1\times\Omega_2$（它也是矩形）。
- $\mathcal L$ 是 λ-系：$A\subseteq B$ 都在 $\mathcal L$ 里时，$\nu(B\setminus A)=\nu(B)-\nu(A)=\nu'(B)-\nu'(A)=\nu'(B\setminus A)$（这里要求测度有限，才能相减）；递增并由从下连续性（[[t1:p:13]]）得到。
- 由 π-λ 定理，$\mathcal L\supseteq\sigma(\text{矩形})=\F_1\otimes\F_2$，即 $\nu=\nu'$。

σ-有限的情形：把 $\Omega_1=\bigcup E_n$、$\Omega_2=\bigcup F_m$ 拆成测度有限的递增块，在每个有限的方块 $E_n\times F_m$ 上用上面的论证，再用从下连续性取极限。**没有 σ-有限时，唯一性可以失败**（相减那一步无法进行），[[p:13]] 的计数测度正是这种情形。
:::

### Definition (A set and its slices)｜集合及其截口

::: def 定义（截口）
设 $A\subseteq\Omega_1\times\Omega_2$。对 $\omega_1\in\Omega_1$ 和 $\omega_2\in\Omega_2$，令
$$
A_{\omega_1}:=\{\omega_2\in\Omega_2:\ (\omega_1,\omega_2)\in A\}\subseteq\Omega_2,\qquad
A_{\omega_2}:=\{\omega_1\in\Omega_1:\ (\omega_1,\omega_2)\in A\}\subseteq\Omega_1 .
$$
$A_{\omega_1}$ 叫 $A$ 的 **$\omega_1$-截口**，$A_{\omega_2}$ 叫 **$\omega_2$-截口**。
:::

- **图像**：在平面上，$\Omega_1$ 是横轴、$\Omega_2$ 是纵轴。$A_{\omega_1}$ 是竖直线 $x=\omega_1$ 与 $A$ 的交，投到纵轴上；$A_{\omega_2}$ 是水平线 $y=\omega_2$ 与 $A$ 的交，投到横轴上。
- **记号提醒**：两种截口只靠下标的字母区分（$\omega_1$ 还是 $\omega_2$）。代入具体数值时容易混淆，有的教材把第二种写成 $A^{\omega_2}$。本站沿用课件写法，必要时用文字说明是哪个方向。

### Slices of a function｜函数的截口

::: def 定义（函数的截口）
设 $f:\Omega_1\times\Omega_2\to\R$。令
$$
f_{\omega_1}(\omega_2):=f(\omega_1,\omega_2)\quad(\omega_2\in\Omega_2),\qquad
f_{\omega_2}(\omega_1):=f(\omega_1,\omega_2)\quad(\omega_1\in\Omega_1).
$$
即固定一个变量，把 $f$ 看成另一个变量的一元函数。
:::

集合的截口与函数的截口一致：示性函数满足 $(\ind_A)_{\omega_1}=\ind_{A_{\omega_1}}$。

::: prop 命题（可测集的截口可测）
若 $A\in\F_1\otimes\F_2$，则对**每个** $\omega_1$，$A_{\omega_1}\in\F_2$；对每个 $\omega_2$，$A_{\omega_2}\in\F_1$。若 $f$ 关于 $\F_1\otimes\F_2$ 可测，则每个 $f_{\omega_1}$ 关于 $\F_2$ 可测，每个 $f_{\omega_2}$ 关于 $\F_1$ 可测。
:::

**证明**（好集合原理）：固定 $\omega_1$，令 $\mathcal G=\{A\in\F_1\otimes\F_2:\ A_{\omega_1}\in\F_2\}$。
1. **矩形是好集合**：$(A_1\times A_2)_{\omega_1}=A_2$（若 $\omega_1\in A_1$）或 $\varnothing$（若 $\omega_1\notin A_1$），都在 $\F_2$ 里。
2. **$\mathcal G$ 是 σ-代数**：截口和集合运算可以交换，$(A^c)_{\omega_1}=(A_{\omega_1})^c$，$\big(\bigcup_nA_n\big)_{\omega_1}=\bigcup_n(A_n)_{\omega_1}$；而 $\F_2$ 对补和可数并封闭，全集的截口是 $\Omega_2$。
3. 所以 $\mathcal G\supseteq\sigma(\text{矩形})=\F_1\otimes\F_2$。

对函数：$\{\omega_2:f_{\omega_1}(\omega_2)\in B\}=\big(f^{-1}(B)\big)_{\omega_1}$，右边是可测集的截口，由上面的结论可测。$\blacksquare$

这个证明完全没用到测度，所以截口的可测性与「有限、σ-有限」无关。

## 例子

::: ex 例 1：平面面积就是长度 × 长度
取 $\mu_1=\mu_2=\lambda$（$\R$ 上的勒贝格测度，即长度），它们 σ-有限。乘积测度 $\lambda\times\lambda$ 在矩形 $[a,b]\times[c,d]$ 上取 $(b-a)(d-c)$，正是面积。由唯一性，**二维勒贝格测度（面积）就是 $\lambda\times\lambda$**：任何一个在矩形上给出「长 × 宽」的测度，在所有平面博雷尔集上都和面积一致。
:::

::: ex 例 2：几种集合的截口
| 集合 $A$ | 竖截口 $A_x$（固定 $x$） | 横截口 $A_y$（固定 $y$） |
| --- | --- | --- |
| 矩形 $[0,2]\times[1,3]$ | $x\in[0,2]$ 时为 $[1,3]$，否则 $\varnothing$ | $y\in[1,3]$ 时为 $[0,2]$，否则 $\varnothing$ |
| 三角形 $\{0\le y\le x\le1\}$ | $x\in[0,1]$ 时为 $[0,x]$ | $y\in[0,1]$ 时为 $[y,1]$ |
| 单位圆盘 $\{x^2+y^2\le1\}$ | $\lvert x\rvert\le1$ 时为 $[-\sqrt{1-x^2},\sqrt{1-x^2}]$ | $\lvert y\rvert\le1$ 时为 $[-\sqrt{1-y^2},\sqrt{1-y^2}]$ |
| 对角线 $\{x=y\}$ | 单点 $\{x\}$ | 单点 $\{y\}$ |

圆盘的竖截口长度是 $2\sqrt{1-x^2}$，把它对 $x$ 从 $-1$ 积到 $1$ 得到 $\pi$，正是圆盘面积。这就是下一页的公式。
:::

::: ex 例 3：两颗骰子的乘积测度与截口
$\P_1=\P_2$ 为 $\{1,\dots,6\}$ 上的均匀分布。乘积测度给每个点 $(i,j)$ 的值是 $\frac1{36}$（单点是矩形 $\{i\}\times\{j\}$）。取 $A=\{(i,j):i+j=7\}$：
- 竖截口 $A_{i}=\{7-i\}$，对每个 $i$ 都是一个点，$\P_2(A_i)=\frac16$；
- 把六个竖截口的概率按 $\P_1$ 平均：$\sum_{i=1}^6\frac16\cdot\frac16=\frac16$，正好等于 $(\P_1\times\P_2)(A)=\frac6{36}$。
:::

::: ex 例 4：函数的截口
$f(x,y)=xy^2$。固定 $x=2$，$f_2(y)=2y^2$，是 $y$ 的抛物线；固定 $y=3$，$f_3(x)=9x$，是 $x$ 的直线。二重积分 $\int_0^1\int_0^1xy^2\dd y\dd x$ 先算内层 $\int_0^1f_x(y)\dd y=\frac x3$，再算 $\int_0^1\frac x3\dd x=\frac16$。Fubini 定理（[[p:10]]）说明这样算是对的。
:::

## 常见疑问与易错点

::: warn 问：既然只在矩形上规定了值，其他集合的测度从哪里来？
**答**：由唯一性自动确定。矩形生成整个 $\F_1\otimes\F_2$，而 π-λ 定理保证：在矩形上取值相同的两个（σ-有限）测度，在所有集合上都相同。所以「在矩形上取乘积」这一条规则就把乘积测度完全定下来了。至于怎么**算**一个具体集合的测度，用下一页的截口公式。
:::

::: warn 问：为什么一定要 σ-有限？
**答**：唯一性的证明要用到 $\nu(B\setminus A)=\nu(B)-\nu(A)$，测度无穷大时 $\infty-\infty$ 没有意义。σ-有限让我们把空间切成测度有限的小块分别处理。[[p:13]] 会看到：$[0,1]$ 上的计数测度不 σ-有限，这时连「先切哪个方向」都会影响结果。
:::

::: warn 问：A_{ω₁} 和 A_{ω₂} 写法太像，怎么分清？
**答**：看下标的**字母**：下标是 $\omega_1$（第一个坐标被固定），截口就是第二个空间 $\Omega_2$ 的子集；下标是 $\omega_2$，截口就是 $\Omega_1$ 的子集。代入数字时（如 $A_{1/2}$）要用文字说明是固定了哪个坐标。
:::

## 小结与自测

::: sum 本页小结
- 乘积测度定理：σ-有限时，存在唯一测度 $\mu_1\times\mu_2$ 使矩形上取 $\mu_1(A_1)\mu_2(A_2)$；概率测度的乘积仍是概率测度。
- 唯一性来自 π-λ 定理：矩形是生成 $\F_1\otimes\F_2$ 的 π-系；σ-有限保证可以相减。
- 截口：$A_{\omega_1}=\{\omega_2:(\omega_1,\omega_2)\in A\}$，$A_{\omega_2}=\{\omega_1:(\omega_1,\omega_2)\in A\}$；函数截口 $f_{\omega_1}(\cdot)=f(\omega_1,\cdot)$。
- 可测集的截口对每个点都可测，证明用好集合原理，不需要测度。
- 课件笔误：Dykin → Dynkin。
:::

::::quiz 自测
**1.** 设 $A=[0,1]\times[0,2]\cup[1,3]\times[0,1]$（一个 L 形）。写出 $A_x$（$x=0.5$ 和 $x=2$）以及它们的长度。

:::answer
$x=0.5$ 时竖线穿过第一块：$A_{0.5}=[0,2]$，长度 2。$x=2$ 时穿过第二块：$A_2=[0,1]$，长度 1。
:::

**2.** 为什么 $(A^c)_{\omega_1}=(A_{\omega_1})^c$？

:::answer
$\omega_2\in(A^c)_{\omega_1}\iff(\omega_1,\omega_2)\notin A\iff\omega_2\notin A_{\omega_1}\iff\omega_2\in(A_{\omega_1})^c$。
:::

**3.** 用乘积测度说明：平面上的直线 $\{2\}\times\R$ 面积为 0。

:::answer
它是矩形 $\{2\}\times\R$，乘积测度给它 $\lambda(\{2\})\lambda(\R)=0\cdot\infty=0$（约定 $0\cdot\infty=0$）。
:::
