## 这一页在讲什么

::: idea 一句话版
一元正态 $N(\mu,\sigma^2)$ 由均值和方差决定。**多元正态**描述一个随机向量 $(X_1,\dots,X_n)$，由**均值向量** $\mu$ 和**协方差矩阵** $\Sigma$ 决定，密度是 $\frac{1}{(2\pi)^{n/2}(\det\Sigma)^{1/2}}e^{-\frac12(x-\mu)^T\Sigma^{-1}(x-\mu)}$。二元时它是一座「山」，等高线是椭圆。这一页给出定义，并提出本讲最后两页要证明的结论：对多元正态，协方差为 0 ⇔ 独立。
:::

- **位置**：第 3 部分的最后一个主题，也是本讲目标 ④（[[p:3]]）。
- **为什么放在「独立性」里**：一般来说协方差为 0（不相关）推不出独立；多元正态是最重要的例外，而证明要用到 [[p:17]] 的「联合分布 = 乘积测度 ⇔ 独立」。
- **后面**：[[p:20]] 证明二元情形，[[p:21]] 证明多元情形。

## 先补基础

::: basics 向量、转置与矩阵乘法
- **列向量**：$x=\begin{pmatrix}x_1\\ \vdots\\ x_n\end{pmatrix}$，课件说「把 $\R^n$ 的元素看成列向量」就是这个意思。
- **转置** $x^T=(x_1,\dots,x_n)$：把列变成行。
- **矩阵乘向量**：$n\times n$ 矩阵 $A=(a_{ij})$ 乘 $x$，得到第 $i$ 个分量为 $\sum_ja_{ij}x_j$ 的列向量。
- **二次型** $x^TAx=\sum_{i,j}a_{ij}x_ix_j$，结果是一个数。例：$A=\begin{pmatrix}2&1\\1&3\end{pmatrix}$，$x^TAx=2x_1^2+2x_1x_2+3x_2^2$。
:::

::: basics 对称、行列式、逆矩阵（2×2 情形）
设 $A=\begin{pmatrix}a&b\\c&d\end{pmatrix}$。
- **对称**：$A^T=A$，即 $b=c$。
- **行列式**：$\det A=ad-bc$。
- **逆矩阵**：$\det A\ne0$ 时，$A^{-1}=\frac1{ad-bc}\begin{pmatrix}d&-b\\-c&a\end{pmatrix}$，满足 $AA^{-1}=I$（单位矩阵）。
- **对角矩阵**（只有对角线非零）：$\det=$ 对角元之积，逆矩阵 = 对角元取倒数。
:::

::: basics 正定矩阵
对称矩阵 $\Sigma$ **正定**（positive definite），指对每个非零向量 $x$，$x^T\Sigma x>0$。
- 2×2 情形的判别：$\Sigma=\begin{pmatrix}a&b\\b&d\end{pmatrix}$ 正定 ⇔ $a>0$ 且 $ad-b^2>0$。
- 例：$\begin{pmatrix}2&1\\1&2\end{pmatrix}$ 正定（$2>0$，$4-1=3>0$）；$\begin{pmatrix}1&2\\2&1\end{pmatrix}$ 不正定（$1-4<0$），取 $x=(1,-1)^T$ 得 $x^T\Sigma x=1-4+1=-2<0$。
- 正定保证 $\det\Sigma>0$、$\Sigma^{-1}$ 存在并且也正定，于是指数 $-\frac12(x-\mu)^T\Sigma^{-1}(x-\mu)\le0$，密度在 $x=\mu$ 处最大，往外衰减。
:::

::: basics 协方差与相关系数（回顾）
$\operatorname{Cov}(X,Y)=\E[(X-\E X)(Y-\E Y)]$；$\operatorname{Cov}(X,X)=\operatorname{Var}X$。**相关系数** $\rho=\frac{\operatorname{Cov}(X,Y)}{\sqrt{\operatorname{Var}X\operatorname{Var}Y}}\in[-1,1]$，衡量线性相关的强弱。「协方差为 0」也说成「**不相关**」（uncorrelated）。
:::

## 课件原文逐句精读

::: original Example: multivariate normal distribution
- A random vector $(X_1,\dots,X_n)$ taking values in $\R^n$ is said to be a gaussian random vector if there exists $\mu=(\mu_1,\dots,\mu_n)\in\R^n$ and an $n\times n$ positive definite real symmetric matrix $\Sigma:=(\sigma_{ij})_{1\le i,j\le n}$, denoting $\det\Sigma$ to be determinant of $\Sigma$, it follows
$$
\P\big((X_1,\dots,X_n)\in S\big)=\frac{1}{(2\pi)^{n/2}(\det\Sigma)^{1/2}}\int_Se^{-\frac12(x-\mu)^T\Sigma^{-1}(x-\mu)}\dd x,\quad x\in S,
$$
for all Borel sets $S\subset\R^n$ (where we identify elements of $\R^n$ with column vectors). The distribution of $(X_1,\dots,X_n)$ is called a **multivariate normal distribution**.
- If $(X_1,\dots,X_n)$ is a gaussian random vector and $1\le i,j\le n$:
- Bivariate case: show that $X_i$ and $X_j$ are pairwise independent if and only if the covariance $Cov(X_i,X_j)$ vanishes.
- Multivariate case: Furthermore, show that $(X_1,\dots,X_n)$ are jointly independent if and only if all the covariances $Cov(X_i,X_j)$ for $1\le i\ne j\le n$ vanish.
:::

::: zh
蓝条标题：例：多元正态分布。

- 取值于 $\R^n$ 的随机向量 $(X_1,\dots,X_n)$ 称为**高斯随机向量**，如果存在 $\mu=(\mu_1,\dots,\mu_n)\in\R^n$ 和一个 $n\times n$ 的正定实对称矩阵 $\Sigma=(\sigma_{ij})$（$\det\Sigma$ 记它的行列式），使得对 $\R^n$ 的所有博雷尔集 $S$（把 $\R^n$ 的元素看成列向量），上式成立。$(X_1,\dots,X_n)$ 的分布叫**多元正态分布**。
- 设 $(X_1,\dots,X_n)$ 是高斯随机向量，$1\le i,j\le n$：
- 二元情形：证明 $X_i$ 与 $X_j$ 独立，当且仅当协方差 $\operatorname{Cov}(X_i,X_j)=0$。
- 多元情形：进一步证明 $X_1,\dots,X_n$ 相互独立，当且仅当所有 $i\ne j$ 的协方差 $\operatorname{Cov}(X_i,X_j)$ 都为 0。
:::

逐句说明：

- **gaussian** 应大写为 Gaussian（高斯，人名），gaussian random vector 就是「服从多元正态的随机向量」。
- **公式的意思**：$(X_1,\dots,X_n)$ 有联合密度
$$
f(x)=\frac{1}{(2\pi)^{n/2}(\det\Sigma)^{1/2}}\exp\Big(-\frac12(x-\mu)^T\Sigma^{-1}(x-\mu)\Big),\qquad x\in\R^n,
$$
落在 $S$ 里的概率就是 $f$ 在 $S$ 上的积分。公式末尾的「$x\in S$」写在积分外面是排版问题，意思是积分变量 $x$ 跑遍 $S$。
- **前面的常数** $\frac{1}{(2\pi)^{n/2}(\det\Sigma)^{1/2}}$：让总概率等于 1 的归一化常数，和一元时的 $\frac1{\sqrt{2\pi}\sigma}$ 同一个作用。
- **两道题**：*pairwise independent* 对两个变量来说就是「独立」；*jointly independent* 就是 [[p:18]] 的「相互独立」；*vanishes* 是「等于 0」。

## 补全课件留白

::: note 说明
这一页的定义完整印出；以下对定义的展开、事实陈述与例子由本站依据标准教材补写，记号与课件一致，以老师课堂为准。
:::

### n = 1：回到熟悉的正态分布

$\Sigma=(\sigma^2)$ 是 $1\times1$ 矩阵，$\det\Sigma=\sigma^2$，$\Sigma^{-1}=\frac1{\sigma^2}$，$(x-\mu)^T\Sigma^{-1}(x-\mu)=\frac{(x-\mu)^2}{\sigma^2}$。密度变成
$$
f(x)=\frac{1}{\sqrt{2\pi}\,\sigma}e^{-\frac{(x-\mu)^2}{2\sigma^2}},
$$
正是 $N(\mu,\sigma^2)$。「正定」在这里就是 $\sigma^2>0$。

### n = 2：二元正态的显式公式

把协方差矩阵写成
$$
\Sigma=\begin{pmatrix}\sigma_1^2&\rho\sigma_1\sigma_2\\ \rho\sigma_1\sigma_2&\sigma_2^2\end{pmatrix},\qquad\sigma_1,\sigma_2>0,\ -1<\rho<1 .
$$
- 正定：$\sigma_1^2>0$，$\det\Sigma=\sigma_1^2\sigma_2^2(1-\rho^2)>0$（这正是要求 $|\rho|<1$ 的原因）。
- 逆矩阵：$\Sigma^{-1}=\dfrac{1}{\sigma_1^2\sigma_2^2(1-\rho^2)}\begin{pmatrix}\sigma_2^2&-\rho\sigma_1\sigma_2\\-\rho\sigma_1\sigma_2&\sigma_1^2\end{pmatrix}$。
- 记 $u=x_1-\mu_1$，$v=x_2-\mu_2$，二次型为
$$
(x-\mu)^T\Sigma^{-1}(x-\mu)=\frac{1}{1-\rho^2}\Big(\frac{u^2}{\sigma_1^2}-\frac{2\rho uv}{\sigma_1\sigma_2}+\frac{v^2}{\sigma_2^2}\Big).
$$
- 密度：
$$
f(x_1,x_2)=\frac{1}{2\pi\sigma_1\sigma_2\sqrt{1-\rho^2}}\exp\left[-\frac{1}{2(1-\rho^2)}\Big(\frac{u^2}{\sigma_1^2}-\frac{2\rho uv}{\sigma_1\sigma_2}+\frac{v^2}{\sigma_2^2}\Big)\right].
$$

### 参数的含义（事实，这里不证明）

若 $(X_1,\dots,X_n)$ 服从上面的多元正态分布，则
1. $\E X_i=\mu_i$，$\operatorname{Cov}(X_i,X_j)=\sigma_{ij}$：$\mu$ 是均值向量，$\Sigma$ 是**协方差矩阵**。二元时 $\operatorname{Var}X_1=\sigma_1^2$，$\operatorname{Var}X_2=\sigma_2^2$，相关系数就是 $\rho$。
2. 每个分量都是一元正态：$X_i\sim N(\mu_i,\sigma_{ii})$；任意几个分量组成的子向量也是多元正态，协方差矩阵取 $\Sigma$ 的相应行列。
3. 线性组合 $a^TX=\sum a_iX_i$ 服从 $N\big(a^T\mu,\ a^T\Sigma a\big)$。

对角的情形可以马上验证第 1、2 条：$\Sigma=\operatorname{diag}(\sigma_1^2,\dots,\sigma_n^2)$ 时，密度分解成 $n$ 个一元正态密度的乘积（[[p:21]] 会详细算），每个分量是 $N(\mu_i,\sigma_i^2)$，两两协方差为 0。

::: fig 图解：二元正态的「山」和椭圆等高线
把 $f(x_1,x_2)$ 画成曲面：
- 山顶在 $(\mu_1,\mu_2)$，高度 $\frac{1}{2\pi\sigma_1\sigma_2\sqrt{1-\rho^2}}$。
- **等高线**是二次型等于常数的曲线 $\frac{u^2}{\sigma_1^2}-\frac{2\rho uv}{\sigma_1\sigma_2}+\frac{v^2}{\sigma_2^2}=c$，是一族同心**椭圆**。
- $\rho=0$：椭圆的轴平行于坐标轴；再有 $\sigma_1=\sigma_2$ 时是圆。
- $\rho>0$：椭圆沿 $45°$ 方向（$y=x$ 方向）拉长，$X_1$ 大时 $X_2$ 也倾向于大；$\rho<0$ 时沿 $y=-x$ 方向拉长。
- $\rho\to\pm1$：椭圆被压扁成一条直线，分布集中到直线上，密度不再存在，和 [[p:4]] 的 $(U,U)$ 一样。
:::

## 例子

::: ex 例 1：标准二元正态，ρ 变化时山顶有多高
$\mu=0$，$\sigma_1=\sigma_2=1$。原点处的密度 $f(0,0)=\frac{1}{2\pi\sqrt{1-\rho^2}}$：

| $\rho$ | $0$ | $0.5$ | $0.9$ |
| --- | --- | --- | --- |
| $f(0,0)$ | $0.159$ | $0.184$ | $0.365$ |

$\rho$ 越接近 $\pm1$，概率越集中在一条直线附近，山越尖。$\rho=0$ 时 $f(x_1,x_2)=\frac1{2\pi}e^{-(x_1^2+x_2^2)/2}=\phi(x_1)\phi(x_2)$，是两个标准正态密度的乘积。
:::

::: ex 例 2：一个具体的协方差矩阵
$\mu=0$，$\Sigma=\begin{pmatrix}2&1\\1&2\end{pmatrix}$。
- $\det\Sigma=3$，$\Sigma^{-1}=\frac13\begin{pmatrix}2&-1\\-1&2\end{pmatrix}$。
- 二次型 $x^T\Sigma^{-1}x=\frac13(2x_1^2-2x_1x_2+2x_2^2)$。
- 密度 $f(x)=\frac{1}{2\pi\sqrt3}\exp\big(-\frac13(x_1^2-x_1x_2+x_2^2)\big)$，原点处约 $0.0919$。
- $\operatorname{Var}X_1=\operatorname{Var}X_2=2$，$\operatorname{Cov}=1$，相关系数 $\rho=\frac1{\sqrt{2\cdot2}}=\frac12$。
- 由事实 3，$X_1+X_2\sim N(0,\ 2+2+2\cdot1)=N(0,6)$，$X_1-X_2\sim N(0,\ 2+2-2)=N(0,2)$。
:::

::: ex 例 3：用两个独立的标准正态造出二元正态
设 $Z_1,Z_2$ 独立、都是 $N(0,1)$（[[p:17]] 保证它们存在）。令
$$
X_1=Z_1,\qquad X_2=\rho Z_1+\sqrt{1-\rho^2}\,Z_2 .
$$
- $\operatorname{Var}X_2=\rho^2+(1-\rho^2)=1$；$\operatorname{Cov}(X_1,X_2)=\rho\operatorname{Var}Z_1=\rho$（$Z_1,Z_2$ 独立，交叉项为 0）。
- 可以证明 $(X_1,X_2)$ 恰好服从相关系数为 $\rho$ 的标准二元正态。电脑模拟（$\rho=0.6$，20 万组）得到样本协方差约 $0.600$，样本方差约 $0.998$。
- $\rho=0$ 时 $X_2=Z_2$，$X_1,X_2$ 就是两个独立的标准正态，和下一页的结论一致。
:::

::: ex 例 4：相关如何改变「同时为正」的概率
标准二元正态有一个漂亮的公式（Sheppard 公式，这里不证明）：$\P(X_1>0,\ X_2>0)=\frac14+\frac{\arcsin\rho}{2\pi}$。

| $\rho$ | $-0.5$ | $0$ | $0.5$ | $0.9$ |
| --- | --- | --- | --- | --- |
| $\P(X_1>0,X_2>0)$ | $\frac16$ | $\frac14$ | $\frac13$ | $0.428$ |

只有 $\rho=0$ 时它等于 $\P(X_1>0)\P(X_2>0)=\frac14$。电脑模拟（每个 $\rho$ 40 万组）结果与公式相差不到 0.001。
:::

## 常见疑问与易错点

::: warn 问：为什么 Σ 必须正定？
**答**：密度公式里要用 $\Sigma^{-1}$ 和 $(\det\Sigma)^{1/2}$，必须 $\det\Sigma>0$。从概率上看，$a^T\Sigma a=\operatorname{Var}(a^TX)\ge0$ 对任何 $a$ 都成立；若某个 $a\ne0$ 使它等于 0，则 $a^TX$ 是常数，分布集中在一个低维平面上，没有密度（例如 $X_2=X_1$）。正定排除了这种「退化」情形；更一般的定义允许 $\Sigma$ 半正定，但那时就不能用这个密度公式了。
:::

::: warn 问：每个分量都是正态，向量就一定是多元正态吗？
**答**：不一定。[[p:20]] 会给出反例：$X\sim N(0,1)$，$Y=SX$（$S$ 是独立的随机正负号），$X$、$Y$ 都是标准正态，$(X,Y)$ 却不是二元正态，并且不相关但不独立。多元正态要求的是**联合**分布有这个密度，比「各分量正态」强得多。
:::

::: warn 问：「协方差为 0」和「独立」到底什么关系？
**答**：一般情况下：独立 ⇒ 协方差为 0（[[p:10]] 推论：$\E[XY]=\E X\,\E Y$），反之不成立。多元正态是重要的例外：协方差为 0 ⇒ 独立。下两页证明这件事，而且会看到证明的核心正是 [[p:17]]：密度分解成乘积 ⇒ 联合分布是乘积测度 ⇒ 独立。
:::

## 小结与自测

::: sum 本页小结
- 多元正态：密度 $\frac{1}{(2\pi)^{n/2}(\det\Sigma)^{1/2}}e^{-\frac12(x-\mu)^T\Sigma^{-1}(x-\mu)}$，$\mu$ 是均值向量，$\Sigma$（正定对称）是协方差矩阵。
- $n=1$ 回到 $N(\mu,\sigma^2)$；$n=2$ 时由 $\sigma_1,\sigma_2,\rho$ 决定，等高线是椭圆，$\rho$ 控制倾斜和扁平程度。
- 分量、子向量、线性组合仍是正态；但各分量正态不保证联合正态。
- 待证：联合正态时，不相关 ⇔ 独立（二元 [[p:20]]，多元 [[p:21]]）。
:::

::::quiz 自测
**1.** 写出 $\mu=0$、$\Sigma=\begin{pmatrix}1&0\\0&4\end{pmatrix}$ 的二元正态密度，并把它写成两个一元密度的乘积。

:::answer
$\det\Sigma=4$，$\Sigma^{-1}=\operatorname{diag}(1,\frac14)$，$f(x_1,x_2)=\frac{1}{2\pi\cdot2}e^{-\frac12(x_1^2+x_2^2/4)}=\Big(\frac1{\sqrt{2\pi}}e^{-x_1^2/2}\Big)\Big(\frac{1}{\sqrt{2\pi}\cdot2}e^{-x_2^2/8}\Big)$，即 $N(0,1)$ 与 $N(0,4)$ 的密度之积。
:::

**2.** $\begin{pmatrix}4&2\\2&1\end{pmatrix}$ 能作为多元正态的 $\Sigma$ 吗？

:::answer
不能。$\det=4-4=0$，不正定。取 $a=(1,-2)^T$，$a^T\Sigma a=4-8+4=0$，对应 $X_1-2X_2$ 方差为 0，即 $X_1=2X_2$（减去均值后），分布落在一条直线上，没有密度。
:::

**3.** 在例 3 中取 $\rho=-0.8$，$\operatorname{Cov}(X_1,X_2)$ 和 $\operatorname{Var}(X_1+X_2)$ 各是多少？

:::answer
$\operatorname{Cov}=-0.8$；$\operatorname{Var}(X_1+X_2)=1+1+2(-0.8)=0.4$。
:::
