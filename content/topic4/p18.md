## 这一页在讲什么

::: idea 一句话版
一族随机变量 $\{X_i\}_{i\in I}$（可以有无穷多个）**独立**，指从中任取**有限**个，它们同时落在各自集合里的概率等于各自概率的乘积。「任意两个独立」（**两两独立**）比这弱得多：课件的例子里三个事件两两独立，三个一起却不独立。
:::

- **位置**：第 3 部分。[[p:16]] 讲了两个对象的独立和 $n$ 个事件的独立，[[p:17]] 说明独立 ⇔ 乘积测度；这一页给出最一般的定义，并用例子划清「两两」与「相互」的界线。
- **后面怎么用**：[[p:20]] 证明多元正态的分量**两两**独立 ⇔ 协方差为 0；[[p:21]] 证明**相互**独立 ⇔ 所有协方差为 0。两页的区别正是本页的区别。

## 先补基础

::: basics 指标集
$\{X_i\}_{i\in I}$ 中的 $I$ 叫**指标集**，只是用来给随机变量编号的集合：可以是 $\{1,2,3\}$、$\N$，也可以是不可数集，例如 $[0,\infty)$（随时间连续变化的随机过程）。
:::

::: basics 取值空间 (Eᵢ, ℬᵢ)
随机变量不一定取实数值：$X_i:\Omega\to E_i$ 可以取向量、序列、颜色……只要 $E_i$ 带一个 σ-代数 $\mathcal B_i$，并且 $X_i$ 可测（每个 $\{X_i\in B\}$，$B\in\mathcal B_i$，都是事件）。取 $E_i=\R$、$\mathcal B_i=\mathcal B(\R)$ 就是通常的随机变量（[[t2:p:4]]）。
:::

::: basics 有限子集的个数
$n$ 个元素的集合有 $2^n$ 个子集，其中含至少两个元素的有 $2^n-n-1$ 个（去掉空集和 $n$ 个单元素集）。$n=3$ 时是 $8-3-1=4$ 个：三个两元子集和一个三元子集。
:::

## 课件原文逐句精读

::: original Independence
- **Definition (Independence of Random Variables).** A collection of random variables $X_i:(\Omega,\F,\P)\to(E_i,\mathcal B_i)$, $i\in I$ for some index set $I$, are independent if for any finite $J\subset I$ and any $B_j\in\mathcal B_j$,
$$
\P\left(X_j\in B_j\ \text{for}\ j\in J\right)=\prod_{j\in J}\P\left(X_j\in B_j\right).
$$
- Pairwise independence: Any two events in the collection are independent of each other. Joint/mutual independence: Each event is independent of any combination of others.
- **Example.** The sample space $\Omega$ consisting of four equally likely points, $a_1,a_2,a_3,a_4$. Let $A=\{a_1,a_2\}$, $B=\{a_2,a_3\}$, $C=\{a_3,a_1\}$. The three are not independent, but they are pairwise.
:::

::: zh
蓝条标题：独立性。

- **定义（随机变量的独立）.** 一族随机变量 $X_i:(\Omega,\F,\P)\to(E_i,\mathcal B_i)$，$i\in I$（$I$ 是某个指标集），称为独立的，如果对任意**有限**子集 $J\subset I$ 和任意 $B_j\in\mathcal B_j$，都有 $\P(X_j\in B_j\ \text{对所有}\ j\in J)=\prod_{j\in J}\P(X_j\in B_j)$。
- 两两独立：族中任意两个事件互相独立。联合（相互）独立：每个事件与其他事件的任何组合都独立。
- **例.** 样本空间 $\Omega$ 由四个等可能的点 $a_1,a_2,a_3,a_4$ 组成。令 $A=\{a_1,a_2\}$，$B=\{a_2,a_3\}$，$C=\{a_3,a_1\}$。这三个事件不（相互）独立，但两两独立。
:::

逐句说明：

- **定义里只看有限子集**：无穷多个事件的交的概率可以由有限交取极限得到（从上连续性），所以只需要对有限个提要求。例如无穷次抛硬币，「所有 $\omega_i$ 都是正面」的概率 $=\lim_n2^{-n}=0$（[[p:17]] 例 2），不需要单独规定。
- **「$X_j\in B_j$ for $j\in J$」**：指所有 $j\in J$ 同时满足，即事件 $\bigcap_{j\in J}\{X_j\in B_j\}$。
- **等价说法**：$\{X_i\}$ 独立 ⇔ 生成的 σ-代数族 $\{\sigma(X_i)\}$ 独立（[[p:16]] 命题 1 的推广），因为 $\sigma(X_i)$ 正是由所有 $\{X_i\in B\}$ 组成的。
- **「any combination of others」**：其他事件经过交、并、补得到的任何事件。相互独立时，例如 $A$ 与 $B\cap C$、$A$ 与 $B\cup C^c$ 都独立。

### 课件例子的验证

四个点等可能，每点概率 $\frac14$；$A,B,C$ 各含两点，概率都是 $\frac12$。

| 交集 | 包含的点 | 概率 | 乘积 | 相等？ |
| --- | --- | --- | --- | --- |
| $A\cap B$ | $a_2$ | $\frac14$ | $\frac12\times\frac12=\frac14$ | 是 |
| $B\cap C$ | $a_3$ | $\frac14$ | $\frac14$ | 是 |
| $A\cap C$ | $a_1$ | $\frac14$ | $\frac14$ | 是 |
| $A\cap B\cap C$ | 无 | $0$ | $\frac18$ | **否** |

三对都独立，所以**两两独立**；三个一起不满足乘积公式，所以**不相互独立**。直观上：知道 $A$、$B$ 都发生（结果是 $a_2$），就知道 $C$ 一定没发生，$A$ 与「$B$ 且 $C$」这个组合不独立。

::: def 定义（事件族的两两独立与相互独立）
事件族 $\{A_i\}_{i\in I}$：
- **两两独立**：对任意 $i\ne j$，$\P(A_i\cap A_j)=\P(A_i)\P(A_j)$；
- **相互独立**：对任意有限 $J\subseteq I$，$\P\big(\bigcap_{j\in J}A_j\big)=\prod_{j\in J}\P(A_j)$。
等价地，示性函数 $\{\ind_{A_i}\}$ 按课件的定义独立。
:::

相互独立 ⇒ 两两独立（取 $|J|=2$）；反过来不成立（课件的例子）。对 $n$ 个事件，相互独立要检查 $2^n-n-1$ 个等式，两两独立只检查其中 $\binom n2$ 个。

::: prop 命题（补集不破坏独立）
若 $A,B$ 独立，则 $A$ 与 $B^c$、$A^c$ 与 $B$、$A^c$ 与 $B^c$ 都独立。相互独立的事件族中，把任意几个换成补集，仍然相互独立。
:::

**证明**（以 $A$ 与 $B^c$ 为例）：$A=(A\cap B)\cup(A\cap B^c)$ 不交，所以
$$
\P(A\cap B^c)=\P(A)-\P(A\cap B)=\P(A)-\P(A)\P(B)=\P(A)\big(1-\P(B)\big)=\P(A)\P(B^c).
$$
多个事件时，对被换成补集的事件逐个用同样的减法即可。$\blacksquare$

这说明：课件定义里取 $B_j$ 为 $\{1\}$（事件发生）就够了，取 $\{0\}$（不发生）的情形自动成立。

## 例子

::: ex 例 1：两枚硬币和「两次相同」
抛两枚公平硬币，$A$ =「第一枚正面」，$B$ =「第二枚正面」，$C$ =「两枚相同」。四种结果等可能。
- $\P(A)=\P(B)=\P(C)=\frac12$（$C=\{\text{正正},\text{反反}\}$）。
- $A\cap B=A\cap C=B\cap C=\{\text{正正}\}$，概率都是 $\frac14$：两两独立。
- $A\cap B\cap C=\{\text{正正}\}$，概率 $\frac14\ne\frac18$：不相互独立。

原因：$A$、$B$ 一起完全决定了 $C$。单独知道 $A$ 对 $C$ 毫无帮助，两者一起知道就确定了 $C$。这和课件的例子是同一个结构。
:::

::: ex 例 2：随机变量版本——X、Y、XY
$X,Y$ 独立，各以 $\frac12$ 的概率取 $\pm1$，令 $Z=XY$。
- $Z$ 也以 $\frac12$ 的概率取 $\pm1$；例如 $\P(X=1,Z=1)=\P(X=1,Y=1)=\frac14=\P(X=1)\P(Z=1)$。逐一检查可知 $X,Y,Z$ **两两独立**。
- 但 $\P(X=1,Y=1,Z=-1)=0\ne\frac18$：**不相互独立**。
- 后果：$\E[XYZ]=\E[X^2Y^2]=1$，而 $\E X\,\E Y\,\E Z=0$。三个变量的乘积期望要拆开，必须**相互**独立。
:::

::: ex 例 3：反方向也不成立——三元乘积公式不保证两两独立
$\Omega=\{1,\dots,8\}$ 等可能，$A=B=\{1,2,3,4\}$，$C=\{1,5,6,7\}$。
- $\P(A\cap B\cap C)=\P(\{1\})=\frac18=\frac12\times\frac12\times\frac12$。
- 但 $\P(A\cap B)=\P(A)=\frac12\ne\frac14$：$A$、$B$ 不独立。

所以相互独立的定义要求**所有**有限子族，只验证「全部一起」的乘积公式是不够的。
:::

::: ex 例 4：两两独立有时就够用
若 $X_1,\dots,X_n$ 两两独立、方差有限，则
$$
\operatorname{Var}\Big(\sum_{i=1}^nX_i\Big)=\sum_{i=1}^n\operatorname{Var}X_i,
$$
因为展开平方后，交叉项 $\operatorname{Cov}(X_i,X_j)$ 只涉及两个变量，两两独立时都为 0（[[p:10]] 的推论）。于是 Chebyshev 型的弱大数定律（第 3 讲 [[t3:p:37]]）只需要两两独立。例 2 中 $\operatorname{Var}(X+Y+Z)=1+1+1=3$，可以直接验证。
:::

## 常见疑问与易错点

::: warn 问：为什么定义里只要求有限子集 J，不要求整个 I？
**答**：一方面，无穷多个事件同时发生的概率由有限交取极限确定，不需要另外规定；另一方面，无穷乘积 $\prod_{i\in I}\P(\cdot)$ 本身可能没有意义（例如不可数多个因子）。只看有限子集，定义对任何指标集都适用。
:::

::: warn 问：说「三个事件独立」时，默认是哪一种？
**答**：默认是**相互独立**。只要两两独立时要明说「两两独立」。教材、考试题都遵守这个约定。
:::

::: warn 问：两两独立的例子看起来都很「人造」，实际中重要吗？
**答**：重要。它提醒我们：每两个变量之间看不出任何关系，不等于整体上没有关系（例 2 中 $Z$ 完全由 $X$、$Y$ 决定）。在密码学和随机算法里，人们还专门利用两两独立的随机数，因为它们更容易生成，而且对方差计算已经够用（例 4）。
:::

## 小结与自测

::: sum 本页小结
- 定义：$\{X_i\}_{i\in I}$ 独立 ⇔ 对任意有限 $J\subseteq I$ 和 $B_j\in\mathcal B_j$，$\P(X_j\in B_j,\ j\in J)=\prod_{j\in J}\P(X_j\in B_j)$。
- 两两独立：任意两个独立；相互独立：任意有限个都满足乘积公式。相互 ⇒ 两两，反之不成立。
- 反例：四点空间的 $A,B,C$；两枚硬币与「两次相同」；$X,Y,XY$。
- 三元乘积公式也推不出两两独立；方差可加只需两两独立，乘积期望拆开需要相互独立。
:::

::::quiz 自测
**1.** 四个事件相互独立，要检查多少个等式？两两独立呢？

:::answer
相互独立：$2^4-4-1=11$ 个（6 个两元、4 个三元、1 个四元）。两两独立：$\binom42=6$ 个。
:::

**2.** 在课件的例子里，$A$ 与 $B\cap C$ 独立吗？

:::answer
不独立。$B\cap C=\{a_3\}$，$\P(B\cap C)=\frac14$；$A\cap(B\cap C)=\varnothing$，概率 0，不等于 $\frac12\times\frac14=\frac18$。
:::

**3.** 掷一颗公平骰子，$A$ =「偶数」，$B$ =「点数 $\le4$」。$A$、$B$ 独立吗？

:::answer
$\P(A)=\frac12$，$\P(B)=\frac23$，$A\cap B=\{2,4\}$，$\P(A\cap B)=\frac13=\frac12\times\frac23$。独立。
:::
