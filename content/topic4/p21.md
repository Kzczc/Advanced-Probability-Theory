## 这一页在讲什么

::: idea 一句话版
设 $(X_1,\dots,X_n)$ 是高斯随机向量。**$X_1,\dots,X_n$ 相互独立 ⇔ 所有 $i\ne j$ 的协方差都为 0 ⇔ 协方差矩阵 $\Sigma$ 是对角矩阵**。证明和二元时一样：对角的 $\Sigma$ 让密度分解成 $n$ 个一元正态密度的乘积，联合分布就是乘积测度。一个推论很值得记住：对联合正态，**两两独立就等于相互独立**，而一般的随机变量做不到这一点（[[p:18]]）。
:::

- **位置**：[[p:19]] 提出的第二道题，也是第 4 讲的最后一页。课件只有标题，内容全部留白。
- **和上一页的关系**：[[p:20]] 对每一对 $(X_i,X_j)$ 证明了「不相关 ⇔ 独立」，得到的是**两两**独立；这一页证明更强的**相互**独立。
- 页末附有第 4 讲的回顾。

## 先补基础

::: basics 对角矩阵的行列式、逆和二次型
$\Sigma=\operatorname{diag}(\sigma_1^2,\dots,\sigma_n^2)$（对角线以外全是 0）时：
- $\det\Sigma=\sigma_1^2\sigma_2^2\cdots\sigma_n^2$；
- $\Sigma^{-1}=\operatorname{diag}\big(\frac1{\sigma_1^2},\dots,\frac1{\sigma_n^2}\big)$；
- $(x-\mu)^T\Sigma^{-1}(x-\mu)=\sum_{i=1}^n\frac{(x_i-\mu_i)^2}{\sigma_i^2}$：没有交叉项。
:::

::: basics 指数把和变成积
$e^{a_1+a_2+\cdots+a_n}=e^{a_1}e^{a_2}\cdots e^{a_n}$。二次型没有交叉项时，它是 $n$ 项之和，密度里的指数函数就拆成 $n$ 个因子的乘积，每个因子只含一个变量。
:::

::: basics 相互独立的判别（回顾）
$X_1,\dots,X_n$ 相互独立 ⇔ 对所有博雷尔集 $B_1,\dots,B_n$，$\P(X_1\in B_1,\dots,X_n\in B_n)=\prod_i\P(X_i\in B_i)$ ⇔ 联合分布等于边缘分布的乘积测度（[[p:17]]）。只取一部分变量的情形，把其余的 $B_i$ 取成 $\R$ 即可。
:::

::: thm 定理（多元情形）
设 $(X_1,\dots,X_n)$ 服从均值 $\mu$、协方差矩阵 $\Sigma=(\sigma_{ij})$ 的多元正态分布。则以下三条等价：
1. $X_1,\dots,X_n$ 相互独立；
2. 对所有 $1\le i\ne j\le n$，$\operatorname{Cov}(X_i,X_j)=0$；
3. $\Sigma$ 是对角矩阵。
:::

这里用到 [[p:19]] 的事实 1：$\Sigma$ 就是协方差矩阵，$\operatorname{Cov}(X_i,X_j)=\sigma_{ij}$（二元情形已在 [[p:20]] 的引理中证明）。所以 2 ⇔ 3 只是换个说法。

**1 ⇒ 2**：相互独立推出两两独立，再由 [[p:10]] 的推论，$\operatorname{Cov}(X_i,X_j)=\E[(X_i-\mu_i)(X_j-\mu_j)]=\E[X_i-\mu_i]\,\E[X_j-\mu_j]=0$。这一方向不需要正态。

**3 ⇒ 1**：
1. **密度分解**：记 $\sigma_i^2=\sigma_{ii}$（正定保证 $\sigma_i^2>0$）。由「先补基础」，
$$
\frac{1}{(2\pi)^{n/2}(\det\Sigma)^{1/2}}=\prod_{i=1}^n\frac{1}{\sqrt{2\pi}\,\sigma_i},\qquad
e^{-\frac12(x-\mu)^T\Sigma^{-1}(x-\mu)}=\prod_{i=1}^ne^{-\frac{(x_i-\mu_i)^2}{2\sigma_i^2}},
$$
所以联合密度
$$
f(x_1,\dots,x_n)=\prod_{i=1}^n\phi_i(x_i),\qquad\phi_i(t)=\frac{1}{\sqrt{2\pi}\,\sigma_i}e^{-\frac{(t-\mu_i)^2}{2\sigma_i^2}}\ \ (N(\mu_i,\sigma_i^2)\ \text{的密度}).
$$
2. **乘积公式**：对博雷尔集 $B_1,\dots,B_n$，被积函数非负，由 Tonelli 定理（[[p:12]]，反复用 $n-1$ 次）逐个积分：
$$
\P(X_1\in B_1,\dots,X_n\in B_n)=\int_{B_1\times\cdots\times B_n}\prod_i\phi_i(x_i)\dd x=\prod_{i=1}^n\int_{B_i}\phi_i(t)\dd t .
$$
3. **边缘分布**：取 $B_j=\R$（$j\ne i$），每个 $\int_\R\phi_j=1$，得 $\P(X_i\in B_i)=\int_{B_i}\phi_i$，即 $X_i\sim N(\mu_i,\sigma_i^2)$。
4. 代回第 2 步：$\P(X_1\in B_1,\dots,X_n\in B_n)=\prod_i\P(X_i\in B_i)$，相互独立。等价地，联合分布 $=N(\mu_1,\sigma_1^2)\times\cdots\times N(\mu_n,\sigma_n^2)$（[[p:17]]）。$\blacksquare$

### 推论：联合正态时，两两独立 = 相互独立

::: prop 推论
对高斯随机向量，若 $X_1,\dots,X_n$ 两两独立，则它们相互独立。
:::

**证明**：两两独立 ⇒ 每对协方差为 0（定理中 1 ⇒ 2 的论证只用到两个变量）⇒ $\Sigma$ 对角 ⇒ 相互独立（3 ⇒ 1）。$\blacksquare$

对比 [[p:18]]：$X,Y$ 是独立的随机正负号、$Z=XY$，三者两两独立却不相互独立。那里的 $(X,Y,Z)$ 不是高斯向量，推论用不上。

::: ex 反例：三个标准正态，两两独立却不相互独立
取 $X,Y,W$ 独立、都是 $N(0,1)$，令
$$
Z=|W|\cdot\operatorname{sign}(XY)
$$
（$XY>0$ 时取 $+|W|$，否则取 $-|W|$）。
1. **$Z\sim N(0,1)$**：$\operatorname{sign}(XY)$ 以 $\frac12$ 的概率取 $\pm1$，且与 $|W|$ 独立，所以 $Z$ 是「随机正负号 × $|W|$」，和 $W$ 同分布。
2. **$X$ 与 $Z$ 独立**：已知 $X$ 时，$\operatorname{sign}(XY)$ 的正负只取决于 $Y$ 的符号，仍是公平的 $\pm1$；$|Z|=|W|$ 与 $X$ 无关。所以 $Z$ 的分布不受 $X$ 影响。$Y$ 与 $Z$ 同理；$X$ 与 $Y$ 本来独立。三者**两两独立**，两两协方差都是 0。
3. **不相互独立**：$XYZ=|XY|\cdot|W|\ge0$ 总成立，所以 $\P(X>0,\ Y>0,\ Z<0)=0\ne\frac18$。
4. 电脑模拟 30 万次：$\P(X>0,Z>0)\approx0.252$（理论 $\frac14$），而 $XYZ<0$ 一次也没有出现。

由推论，$(X,Y,Z)$ 不可能是高斯向量：三个坐标各自正态、两两独立，联合分布却不是多元正态。
:::

## 例子

::: ex 例 1：对角协方差矩阵，概率直接相乘
$(X_1,X_2,X_3)$ 是多元正态，$\mu=0$，$\Sigma=\operatorname{diag}(1,4,9)$。由定理，三者相互独立，$X_1\sim N(0,1)$，$X_2\sim N(0,4)$，$X_3\sim N(0,9)$。
- $\P(X_1>0,X_2>0,X_3>0)=\frac12\cdot\frac12\cdot\frac12=\frac18$。
- $\P(|X_1|\le1,\ |X_2|\le2,\ |X_3|\le3)=0.6827^3\approx0.318$（每个都是「落在一个标准差以内」）。
:::

::: ex 例 2：分块对角——一组与另一组独立
$\mu=0$，$\Sigma=\begin{pmatrix}1&0&0.5\\0&1&0\\0.5&0&1\end{pmatrix}$。
- 正定性：顺序主子式 $1$、$1$、$\det\Sigma=1\cdot1-0.5\cdot0.5=0.75$，都是正数。
- $X_2$ 与 $X_1$、$X_3$ 的协方差都是 0，但 $\operatorname{Cov}(X_1,X_3)=0.5\ne0$，所以三者**不**相互独立。
- 不过把 $X_1,X_3$ 放成一组，密度的二次型没有 $x_2$ 与 $x_1,x_3$ 的交叉项，密度分解成 $f_{13}(x_1,x_3)\cdot\phi(x_2)$，同样的论证说明：**$X_2$ 与向量 $(X_1,X_3)$ 独立**。一般地，$\Sigma$ 分块对角时，各块对应的子向量相互独立。
:::

::: ex 例 3：用独立正态造出任意多元正态
设 $Z_1,\dots,Z_n$ i.i.d. $N(0,1)$（[[p:17]] 保证存在），$A$ 是可逆的 $n\times n$ 矩阵。则 $X=\mu+AZ$ 是多元正态，协方差矩阵 $\Sigma=AA^T$（这里作为事实）。
- 取 $A=\operatorname{diag}(\sigma_1,\dots,\sigma_n)$，$X_i=\mu_i+\sigma_iZ_i$，$\Sigma=\operatorname{diag}(\sigma_i^2)$：各分量各用各的 $Z_i$，当然独立，和定理一致。
- 取 $n=2$，$A=\begin{pmatrix}1&0\\\rho&\sqrt{1-\rho^2}\end{pmatrix}$，就是 [[p:19]] 例 3 的构造，$AA^T=\begin{pmatrix}1&\rho\\\rho&1\end{pmatrix}$。
电脑模拟多元正态就是这样做的：先生成独立的标准正态，再乘一个矩阵。
:::

## 常见疑问与易错点

::: warn 问：为什么「协方差全为 0」就足够推出相互独立，而不需要检查三个、四个变量之间的关系？
**答**：多元正态分布完全由 $\mu$ 和 $\Sigma$ 决定，而 $\Sigma$ 只记录**两两**之间的协方差。没有「三个变量之间」的额外参数，所以两两的信息就是全部的信息。一般的分布没有这个性质（反例中的 $(X,Y,Z)$）。
:::

::: warn 问：分量各自是正态、两两协方差为 0，能推出相互独立吗？
**答**：不能。必须是**联合**正态。上面的反例三个分量都是 $N(0,1)$、两两独立，却不相互独立；[[p:20]] 的 $Y=SX$ 连两个变量的情形都不行。
:::

::: warn 问：Σ 对角时，为什么边缘分布不需要另外证明？
**答**：在证明第 3 步里，取其余的 $B_j=\R$，乘积公式直接给出每个 $X_i$ 的分布是 $N(\mu_i,\sigma_i^2)$。这和 [[p:5]] 里「坐标映射的分布就是 $\P_i$」是同一个道理：乘积测度的边缘就是各个因子。
:::

## 小结与自测

::: sum 本页小结
- 定理：高斯向量的分量相互独立 ⇔ 所有协方差为 0 ⇔ $\Sigma$ 对角。
- 证明：对角 $\Sigma$ ⇒ 二次型无交叉项 ⇒ 密度 = $\prod_i\phi_i(x_i)$ ⇒（Tonelli）乘积公式 ⇒ 相互独立。
- 推论：联合正态时，两两独立 ⇔ 相互独立；反例 $Z=|W|\operatorname{sign}(XY)$ 说明「各自正态」不够。
- 分块对角 ⇒ 各块子向量独立；$X=\mu+AZ$ 可以造出任意多元正态。
:::

::: sum 第 4 讲回顾
1. **乘积测度**（[[p:4]]–[[p:8]]）：边缘分布决定不了联合分布（$(U,U)$ 与 $(U,1-U)$）；乘积 σ-代数 $\F_1\otimes\F_2$ 由可测矩形生成；σ-有限时乘积测度存在且唯一（π-λ 定理）；截口公式 $(\mu_1\times\mu_2)(A)=\int\mu_2(A_{\omega_1})\dd\mu_1$。
2. **Fubini–Tonelli 定理**（[[p:9]]–[[p:15]]）：非负可测函数（Tonelli）或绝对可积函数（Fubini）的二重积分等于两种顺序的累次积分；证明走「示性函数 → 简单函数 → 非负函数 → 可积函数」四步；不 σ-有限（计数测度，[[p:13]]）或不可积（[[p:14]]、[[p:15]]）时交换顺序会出错；矩公式 $\E Y^p=\int_0^\infty py^{p-1}\P(Y>y)\dd y$ 一行可证。
3. **独立性**（[[p:16]]–[[p:21]]）：事件、随机变量、σ-代数的独立；独立 ⇔ 联合分布是乘积测度，并由此构造 i.i.d. 序列；两两独立 ≠ 相互独立；多元正态中不相关 ⇔ 独立。

**四讲连起来看**：第 1 讲建立测度与积分（[[t1:p:47]]），第 2 讲把它翻译成随机变量、期望和不等式（[[t2:p:32]]），第 3 讲研究无穷多个随机变量的极限与换测度（[[t3:p:47]]），第 4 讲搭出多个随机变量共同生活的乘积空间，给「独立」下了严格定义。至此，大数定律、中心极限定理所需的全部地基都已就位。
:::

::::quiz 自测
**1.** $(X_1,X_2,X_3)$ 是多元正态，$\Sigma=\begin{pmatrix}2&0&0\\0&3&1\\0&1&3\end{pmatrix}$。哪些变量之间独立？三者相互独立吗？

:::answer
$X_1$ 与 $X_2$、$X_1$ 与 $X_3$ 的协方差为 0，所以 $X_1$ 与它们各自独立（实际上 $X_1$ 与向量 $(X_2,X_3)$ 独立，分块对角）。$\operatorname{Cov}(X_2,X_3)=1\ne0$，三者不相互独立。
:::

**2.** $X_1,\dots,X_n$ i.i.d. $N(0,1)$。写出 $(X_1,\dots,X_n)$ 的 $\mu$、$\Sigma$ 和联合密度。

:::answer
$\mu=0$，$\Sigma=I$（单位矩阵），联合密度 $f(x)=(2\pi)^{-n/2}e^{-\frac12(x_1^2+\cdots+x_n^2)}=\prod_i\frac1{\sqrt{2\pi}}e^{-x_i^2/2}$。
:::

**3.** 在反例中，为什么 $\P(XYZ<0)=0$？

:::answer
$Z$ 的符号就是 $XY$ 的符号，所以 $XYZ=XY\cdot|W|\operatorname{sign}(XY)=|XY|\cdot|W|\ge0$。
:::
