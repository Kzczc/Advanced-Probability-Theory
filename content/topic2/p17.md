## 这一页在讲什么

::: idea 一句话版
随机变量什么时候有**密度**（可以写成 $\P(X\in B)=\int_Bf(x)\dd x$）？答案是：当且仅当它的 CDF **绝对连续**——比「连续」更强的一种连续：**很多个小区间的总长度很小时，CDF 在这些区间上的总增量也很小**。此时密度就是 CDF 的导数。
:::

- **位置**：第 2 部分「用 CDF 计算期望」的后半段。前几页（[[p:12]]–[[p:16]]）只用 CDF 算期望，从不假设密度；这一页回答：**密度到底什么时候存在**。
- **为什么需要**：中学和大一的概率课默认「连续型随机变量有密度」。但下面两页会看到，存在 CDF **处处连续、却没有密度**的随机变量（康托尔分布，[[p:19]]）。所以「连续」不是正确的条件，「绝对连续」才是。
- **后面怎么用**：[[p:20]] 会把任意分布拆成「原子 + 有密度 + 既无原子又无密度」三部分，本页给出的是中间那一部分的刻画。第 3 讲的 Radon–Nikodym 定理（[[t3:p:27]]）是本页的抽象推广。

## 先补基础

::: basics 密度是什么意思
说随机变量 $X$ 有（勒贝格）**密度** $f$，是指存在非负可积函数 $f$，使对每个博雷尔集 $B$：
$$
\P(X\in B)=\int_Bf(x)\dd x .
$$
特别地取 $B=(-\infty,x]$：$F_X(x)=\int_{-\infty}^xf(t)\dd t$。直观上，$f(x)\dd x$ 是「$X$ 落在 $x$ 附近长度为 $\dd x$ 的小区间里」的概率。密度存在时，**每个单点的概率都是 0**（单点长度为 0），所以有原子（跳跃）的分布一定没有密度。
:::

::: basics 三种「连续」，一种比一种强
- **连续**：在每一点，$x$ 变化一点，$F(x)$ 也只变化一点。
- **一致连续**：同一个精度要求 $\delta$ 对所有位置都管用（只看**一个**小区间）。
- **绝对连续**：同一个 $\delta$ 对「**有限多个**互不相交的小区间，总长度 $<\delta$」都管用——这些区间可以散落在各处，个数可以很多。

绝对连续 ⇒ 一致连续 ⇒ 连续（取只有一个区间的情形即可看出第一个箭头）；反过来都不成立。
:::

::: basics 微积分基本定理（回顾）
若 $F$ 连续可导，则 $F(b)-F(a)=\int_a^bF'(x)\dd x$。本页的「勒贝格版」把条件从「连续可导」放宽到「绝对连续」，结论只要求 $F'$ 几乎处处存在。
:::

## 课件原文逐句精读

::: original Absolute continuity is exactly the condition behind a density
**Definition 16 (Absolutely continuous function)** A function $F:\R\to\R$ is absolutely continuous if, for every $\eps>0$, there exists $\delta>0$ such that every finite pairwise disjoint collection of intervals $(a_k,b_k)$ satisfying
$$
\sum_k(b_k-a_k)<\delta
$$
also satisfies
$$
\sum_k|F(b_k)-F(a_k)|<\eps .
$$

**Lebesgue FTC used below** Such an $F$ has an a.e. derivative satisfying （留白） Conversely, an indefinite integral of an $L^1$ function is absolutely continuous.

**Theorem 17 (CDF-density equivalence)** A real random variable $X$ has a Lebesgue density if and only if $F_X$ is absolutely continuous. In that case $f_X=F_X'$ almost everywhere.
:::

::: zh
**定义 16（绝对连续函数）** 函数 $F:\R\to\R$ 叫绝对连续的，如果对每个 $\eps>0$，都存在 $\delta>0$，使得任何**有限个两两不交**的区间 $(a_k,b_k)$，只要总长度 $\sum_k(b_k-a_k)<\delta$，就有 $\sum_k|F(b_k)-F(a_k)|<\eps$。

**下面要用的勒贝格微积分基本定理** 这样的 $F$ 几乎处处有导数，并且满足（留白）。反过来，一个 $L^1$ 函数的不定积分是绝对连续的。

**定理 17（CDF–密度等价）** 实值随机变量 $X$ 有勒贝格密度，当且仅当 $F_X$ 绝对连续。此时 $f_X=F_X'$ 几乎处处成立。
:::

### Definition 16｜逐句拆开

- **for every ε > 0, there exists δ > 0**：一场「你出题、我应答」的游戏：你要求总增量小于 $\eps$，我能找到一个总长度门槛 $\delta$。
- **every finite pairwise disjoint collection of intervals**：区间个数不限（但有限），彼此不重叠，可以散落在实数轴上任何地方。
- **$\sum_k(b_k-a_k)<\delta$**：这些区间的**总长度**小于 $\delta$。
- **$\sum_k|F(b_k)-F(a_k)|<\eps$**：$F$ 在这些区间上的**总增量**（取绝对值相加）小于 $\eps$。

一句话：**「在总长度很小的地方，$F$ 不可能攒下很多增长。」** 对 CDF 来说，$F(b_k)-F(a_k)=\P(a_k<X\le b_k)$，所以这句话就是「总长度很小的一堆区间，总概率也很小」——这正是「概率按长度摊开」的意思。

### Lebesgue FTC｜补全留白

留白处应是勒贝格版微积分基本定理的公式，见下一节定理卡片。

### Theorem 17｜两件事

1. **等价**：有密度 ⟺ CDF 绝对连续。
2. **公式**：密度就是 CDF 的导数，$f_X=F_X'$（几乎处处——密度在零测集上改值无所谓，[[t1:p:43]]）。

::: thm 勒贝格微积分基本定理（Lebesgue FTC，当作已知结论使用）
1. 若 $F:\R\to\R$ 绝对连续，则 $F$ 几乎处处可导，$F'$ 在每个有界区间上可积，并且
   $$
   F(b)-F(a)=\int_a^bF'(x)\dd x\qquad\text{对所有 }a<b .
   $$
2. 反过来，若 $f\in L^1(\R)$（或在每个有界区间上可积），则不定积分 $G(x)=\int_{-\infty}^xf(t)\dd t$（或 $\int_a^xf$）是绝对连续的，并且 $G'=f$ 几乎处处。
:::

这个定理的证明需要实分析里的「勒贝格微分定理」，超出本课范围，课件也说是 *used below*（下面直接使用）。我们只需理解它的意思：**绝对连续的函数，正好是「某个可积函数的积分」**。

::: thm 定理 17（CDF–密度等价）
设 $X$ 是实值随机变量，$F_X$ 是它的 CDF。则 $X$ 有勒贝格密度 $\iff F_X$ 绝对连续。此时 $f_X=F_X'$ 几乎处处。
:::

::: proof 证明思路
⇐：用 FTC 第 1 条，$F_X$ 的增量等于 $F_X'$ 的积分，所以 $F_X'$ 就是密度（还要检查它非负、总积分为 1，并从区间推广到所有博雷尔集）。⇒：有密度时 $F_X$ 是密度的不定积分，用 FTC 第 2 条。
:::

**（⇐）设 $F=F_X$ 绝对连续。**

1. 由 FTC，$F'$ 几乎处处存在，且 $F(b)-F(a)=\int_a^bF'$。
2. **$F'\ge0$**：$F$ 单调不减，差商 $\frac{F(x+h)-F(x)}h\ge0$，极限也 $\ge0$（不可导的零测集上令 $F'=0$）。
3. **总积分为 1**：令 $a\to-\infty$、$b\to+\infty$，左边 $F(b)-F(a)\to1-0=1$；右边 $\int_a^bF'\uparrow\int_\R F'$（非负函数，单调收敛定理 [[t1:p:36]]）。所以 $\int_\R F'=1$。
4. **两个测度在区间上相同**：定义 $\nu(B)=\int_BF'(x)\dd x$。它是概率测度（非负、可数可加由 MCT 保证、总质量为 1），并且对每个 $(a,b]$：
   $$
   \nu((a,b])=\int_a^bF'=F(b)-F(a)=\P(a<X\le b).
   $$
5. **推广到所有博雷尔集**：两个概率测度在所有 $(a,b]$ 上相等，那么在 $\mathcal B(\R)$ 上处处相等（[[p:8]]「CDF 决定分布」用的就是这个事实）。所以 $\P(X\in B)=\int_BF'$，$F'$ 就是密度。

**（⇒）设 $X$ 有密度 $f$。**

1. $F(x)=\P(X\le x)=\int_{-\infty}^xf(t)\dd t$，是可积函数 $f$ 的不定积分（$\int_\R f=1<\infty$）。
2. 由 FTC 第 2 条，$F$ 绝对连续，并且 $F'=f$ 几乎处处。$\blacksquare$

::: more 不用 FTC 第 2 条，直接看出「有密度 ⇒ 绝对连续」
关键是一个「积分的绝对连续性」：对可积的 $f\ge0$ 和任意 $\eps>0$，存在 $\delta>0$，使 $\Leb(A)<\delta$ 时 $\int_Af<\eps$。

- 截断：令 $f_M=\min(f,M)$。由 MCT，$\int(f-f_M)\to0$（$M\to\infty$），取 $M$ 使 $\int(f-f_M)<\eps/2$。
- 取 $\delta=\eps/(2M)$。若 $\Leb(A)<\delta$，则 $\int_Af\le\int_Af_M+\int(f-f_M)<M\delta+\eps/2=\eps$。

把 $A$ 取成 $\bigcup_k(a_k,b_k)$，就得到 $\sum_k\big(F(b_k)-F(a_k)\big)=\int_Af<\eps$，这正是定义 16。
:::

## 图解

::: idea 用「沙子」想象绝对连续
把概率想成撒在实数轴上的沙子，$F(x)$ 是 $x$ 左边沙子的总量。

- **有密度**：沙子均匀或不均匀地「铺」开，每一小段的沙子量 ≈ 密度 × 长度。总长度很小的一堆区间，装的沙子也很少——绝对连续。
- **有原子**：某一点上堆了一座「小沙丘」（正概率）。用一个极短的区间罩住这一点，沙子量不会变小——不连续，更不绝对连续。
- **康托尔分布**（[[p:19]]）：沙子全部撒在一个总长度为 0 的「尘埃」集合上，没有一处堆成沙丘（所以 CDF 连续），但用总长度任意小的一堆区间就能罩住全部沙子——**连续但不绝对连续**。
:::

## 例子

::: ex 例 1：均匀分布——绝对连续，密度为 1
$X\sim\mathrm{Unif}(0,1)$：$F(x)=0$（$x<0$），$=x$（$0\le x<1$），$=1$（$x\ge1$）。

- 对任意区间，$|F(b)-F(a)|\le b-a$（斜率不超过 1）。所以取 $\delta=\eps$：总长度 $<\eps$ 时总增量 $<\eps$。绝对连续。✓
- $F'(x)=1$（$0<x<1$），$=0$（$x<0$ 或 $x>1$），在 0 和 1 两点不可导（零测集）。所以密度 $f=\ind_{(0,1)}$，与熟悉的结果一致。
:::

::: ex 例 2：指数分布——绝对连续
$F(x)=1-e^{-\lambda x}$（$x\ge0$），$0$（$x<0$）。$F'(x)=\lambda e^{-\lambda x}\le\lambda$，所以 $|F(b)-F(a)|\le\lambda(b-a)$，取 $\delta=\eps/\lambda$ 即可。密度 $f(x)=\lambda e^{-\lambda x}\ind_{\{x>0\}}$（[[p:15]]）。

一般地：**导数有界（「利普希茨」）的 CDF 一定绝对连续**。
:::

::: ex 例 3（反例）：有跳跃——没有密度
[[p:13]] 的混合型 CDF 在 0 处从 0 跳到 $\tfrac12$。取 $\eps=\tfrac14$：不管 $\delta$ 多小，单个区间 $(-\delta/2,\delta/2)$ 的长度 $<\delta$，增量却 $\ge\tfrac12>\eps$。所以不绝对连续，由定理 17，$X$ 没有密度——这和 [[p:13]] 说的「$\P(X=0)=\tfrac12>0$，所以不可能有密度」一致。
:::

::: ex 例 4（预告）：连续却不绝对连续——康托尔函数
康托尔函数 $F$（[[p:19]]）连续、单调，在 $[0,1]$ 上从 0 升到 1。但它的全部增长都发生在康托尔集 $C$ 上（[[p:18]]）。第 $n$ 步时，$C$ 被 $2^n$ 个长度为 $3^{-n}$ 的闭区间盖住，总长度 $(2/3)^n$ 可以小于任何 $\delta$，而 $F$ 在这些区间上的总增量是 **1**（整个增长都在里面）。所以取 $\eps=\tfrac12$ 时找不到 $\delta$——不绝对连续，没有密度。
:::

## 常见疑问与易错点

::: warn 问：「连续型随机变量」不就是有密度的随机变量吗？
**答**：在很多入门教材里是这么定义的，但严格地说，「CDF 连续」和「有密度」不是一回事。CDF 连续只说明**没有原子**；有密度还要求概率不能集中在零测集上。康托尔分布就是「连续但没有密度」的例子（[[p:19]]）。正确的说法是：**有密度 ⟺ CDF 绝对连续**。
:::

::: warn 问：密度唯一吗？为什么说「几乎处处」？
**答**：在一个零测集上改变 $f$ 的值，$\int_Bf$ 完全不变（[[t1:p:43]]），所以密度只在「几乎处处」的意义下唯一。例如均匀分布的密度可以写 $\ind_{(0,1)}$，也可以写 $\ind_{[0,1]}$，两者都对。
:::

::: warn 问：定义里为什么要「有限个、两两不交」的区间？
**答**：如果区间可以重叠，同一段长度会被重复计数，总长度的门槛失去意义。「有限个」是为了让求和是普通的有限和；事实上换成可数个也等价。关键在于允许**多个**区间——只看一个区间时，就退化成一致连续，康托尔函数也满足，无法排除它。
:::

## 小结与自测

::: sum 本页小结
- 绝对连续：任何总长度 $<\delta$ 的有限个不交区间，$F$ 的总增量 $<\eps$。它比连续、一致连续都强。
- 勒贝格 FTC：绝对连续 ⟺ 是可积函数的不定积分；此时 $F(b)-F(a)=\int_a^bF'$。
- 定理 17：$X$ 有密度 ⟺ $F_X$ 绝对连续，且 $f_X=F_X'$ 几乎处处。
- 有跳跃 ⇒ 不连续 ⇒ 没有密度；康托尔函数连续但不绝对连续 ⇒ 也没有密度。
:::

::::quiz 自测
**1.** $F(x)=x^2$（$0\le x\le1$），$x<0$ 时为 0，$x>1$ 时为 1。它是某个随机变量的 CDF 吗？有密度吗？密度是什么？

:::answer
单调不减、右连续、两端为 0 和 1，是 CDF。在 $[0,1]$ 上 $|F(b)-F(a)|=(b+a)(b-a)\le2(b-a)$，取 $\delta=\eps/2$ 即绝对连续，所以有密度 $f(x)=F'(x)=2x$（$0<x<1$），其余为 0。验证：$\int_0^12x\dd x=1$。
:::

**2.** 判断：若 CDF 在每一点都连续，则随机变量一定有密度。

:::answer
错误。连续只保证没有原子。康托尔分布的 CDF 处处连续，却没有密度（概率全部集中在测度为 0 的康托尔集上）。
:::

**3.** 设 $X$ 有密度 $f$。用定义说明 $\P(X=c)=0$ 对每个 $c$ 成立。

:::answer
$\P(X=c)=\int_{\{c\}}f(x)\dd x$。单点 $\{c\}$ 的勒贝格测度为 0，非负函数在零测集上的积分为 0（[[t1:p:43]] 零支撑原则），所以 $\P(X=c)=0$。
:::
