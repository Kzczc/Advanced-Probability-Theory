## 这一页在讲什么

::: idea 一句话版
用无穷次抛硬币决定「在康托尔集里往左走还是往右走」，得到一个随机点 $X$。它的 CDF（著名的「魔鬼阶梯」）**处处连续**，却**没有密度**：全部概率都落在长度为 0 的康托尔集上，导数几乎处处是 0。
:::

- **位置**：第 2 部分的关键反例。[[p:17]] 说「有密度 ⟺ CDF 绝对连续」，[[p:18]] 准备了「不可数、长度为 0」的康托尔集 $C$。这一页把两者结合：造一个分布，**没有原子**（所以 CDF 连续），**又没有密度**（所以 CDF 不绝对连续）。
- **它打破的直觉**：「CDF 连续就有密度」「CDF 几乎处处导数为 0 就是常数」——两条都错。
- **后面怎么用**：[[p:20]] 把它作为分布的「第三种成分」（奇异连续部分）的标准例子；第 1 讲 [[t1:p:42]] 与第 3 讲 [[t3:p:47]] 用它说明 $\int_0^1F'<F(1)-F(0)$ 可以严格。

## 先补基础

::: basics 独立的公平硬币
$\xi_1,\xi_2,\ldots$ 是**独立**的公平硬币：每个 $\xi_k$ 以概率 $\tfrac12$ 取 0、$\tfrac12$ 取 1，并且前 $n$ 个取某一串指定值的概率是 $2^{-n}$（例如 $\P(\xi_1=1,\xi_2=0,\xi_3=1)=\tfrac18$）。独立性的正式定义在第 3 讲 [[t3:p:6]]；这里只用「前 $n$ 位取定的概率是 $2^{-n}$」这一点。第 1 讲 [[t1:p:23]] 的注释还说明了：这样的硬币序列可以严格地在 $[0,1)$ 上用勒贝格测度造出来。
:::

::: basics 回顾：康托尔集的编码（[[p:18]]）
$C$ 中的点恰好是三进制展开只用 0 和 2 的数，$\Phi(b_1,b_2,\ldots)=\sum_k2b_k3^{-k}$ 是从 0/1 序列到 $C$ 的双射。第 $k$ 位决定「在当前小区间里走左边三分之一（$b_k=0$）还是右边三分之一（$b_k=1$）」。
:::

::: ex 反例 19（康托尔分布）
设 $\xi_1,\xi_2,\ldots$ 是独立的公平 0/1 硬币，令
$$
X=\sum_{k\ge1}\frac{2\xi_k}{3^k}.
$$
$X$ 的分布叫**康托尔分布**，它的 CDF $F$ 叫**康托尔函数**。则：

1. $X\in C$（康托尔集）恒成立，所以 $\P(X\in C)=1$；
2. 对每个 $x\in\R$，$\P(X=x)=0$，所以 **$F$ 处处连续**；
3. $X$ **没有**勒贝格密度，所以 **$F$ 不是绝对连续的**；
4. $F'(x)=0$ 对几乎所有 $x$ 成立，但 $F(0)=0$、$F(1)=1$。
:::

::: proof 证明思路
第 1 条是编码的直接结果；第 2 条因为「命中一个具体的点」需要无穷多位都对上，概率是 $2^{-n}\to0$；第 3 条用反证：若有密度，在零测集 $C$ 上积分只能是 0，与 $\P(X\in C)=1$ 矛盾；第 4 条因为 $F$ 在每个被删掉的区间上是常数。
:::

**第 1 步（$X$ 总在康托尔集里）**：$X$ 的三进制数字是 $t_k=2\xi_k\in\{0,2\}$，由 [[p:18]] 的刻画，$X\in C$。所以 $\P(X\in C)=1$。

**第 2 步（没有原子）**：任取 $x$。若 $x\notin C$，则 $\P(X=x)=0$。若 $x\in C$，它对应唯一的序列 $b=\Phi^{-1}(x)$（双射），于是 $X=x$ 意味着 $\xi_k=b_k$ 对**所有** $k$ 成立，所以
$$
\P(X=x)\le\P(\xi_1=b_1,\ldots,\xi_n=b_n)=2^{-n}\qquad\text{对每个 }n,
$$
只能是 0。由 [[p:8]]，$\P(X=x)=F(x)-F(x-)$，所以 $F$ 没有跳跃、处处连续。

**第 3 步（没有密度）**：反设 $X$ 有密度 $f$。则
$$
1=\P(X\in C)=\int_Cf(x)\dd x=0,
$$
最后一步因为 $\Leb(C)=0$，非负函数在零测集上积分为 0（[[t1:p:43]]）。矛盾。由 [[p:17]] 的定理 17，$F$ 不绝对连续。

**第 4 步（导数几乎处处为 0）**：被删掉的每个开区间（如 $(\tfrac13,\tfrac23)$、$(\tfrac19,\tfrac29)$……）都与 $C$ 不相交，$X$ 落在里面的概率是 0，所以 $F$ 在这些区间上**是常数**，导数为 0。这些区间的总长度是 $1-\Leb(C)=1$，所以 $F'=0$ 几乎处处。而 $F(0)=\P(X\le0)=\P(X=0)=0$，$F(1)=1$。$\blacksquare$

### 康托尔函数长什么样：「魔鬼阶梯」

- $X\le\tfrac13$ 当且仅当 $\xi_1=0$（第一步走左边），所以 $F(\tfrac13)=\tfrac12$；同理 $F(\tfrac23)=\P(X\le\tfrac23)=\P(\xi_1=0)=\tfrac12$。所以在整个 $[\tfrac13,\tfrac23]$ 上 $F=\tfrac12$——一级平台。
- 第二层：$F(\tfrac19)=F(\tfrac29)=\tfrac14$，$F(\tfrac79)=F(\tfrac89)=\tfrac34$——又多了两级平台。
- 一般地，若 $x\in C$ 的三进制数字是 $t_k\in\{0,2\}$，则
  $$
  F(x)=\sum_{k\ge1}\frac{t_k/2}{2^k}\qquad(\text{把三进制的 }2\text{ 换成 }1\text{，当成二进制读}).
  $$
  例：$x=\tfrac14=0.0202\ldots_{(3)}$，$F(\tfrac14)=0.0101\ldots_{(2)}=\tfrac13$。

图像是一道有无穷多级平台的楼梯：平台占满了几乎全部长度，楼梯却从 0 连续地爬到 1——所有「爬升」都发生在长度为 0 的康托尔集上。所以叫**魔鬼阶梯**（devil's staircase）。

## 例子

::: ex 例 1：计算几个概率
- $\P(X\le\tfrac13)=\tfrac12$，$\P(\tfrac13<X<\tfrac23)=0$（被删掉的区间）。
- $\P(X\in[\tfrac29,\tfrac13])=\P(\xi_1=0,\xi_2=1)=\tfrac14$。
- $\P(X>\tfrac89)=\P(\xi_1=1,\xi_2=1)=\tfrac14$（$x=\tfrac89$ 本身概率为 0）。
:::

::: ex 例 2：均值与方差（期望是线性的，独立变量的方差可加）
- $\E X=\sum_k\frac{2\E\xi_k}{3^k}=\sum_k\frac{1}{3^k}=\frac{1/3}{1-1/3}=\frac12$。也可以由对称性看出：$1-X=\sum_k\frac{2(1-\xi_k)}{3^k}$ 与 $X$ 同分布，所以均值是 $\tfrac12$。
- $\operatorname{Var}X=\sum_k\frac{4\operatorname{Var}\xi_k}{9^k}=\sum_k\frac{4\cdot\frac14}{9^k}=\frac{1/9}{1-1/9}=\frac18$。

（交换期望与无穷求和用的是单调收敛定理 [[t1:p:36]]；方差相加用到独立性，见第 3 讲。）对比：$[0,1]$ 上均匀分布的方差是 $\tfrac1{12}\approx0.083$，康托尔分布 $\tfrac18=0.125$ 更大——它的质量更多地挤向两端。
:::

::: ex 例 3：用 [[p:12]] 的公式算均值，不需要密度
$\E X=\int_0^1(1-F(x))\dd x$。由对称性 $F(1-x)=1-F(x)$（除可数个点外），所以 $\int_0^1F=\int_0^1(1-F)$，两者相加为 1，各为 $\tfrac12$。和例 2 一致。这再次说明：**用 CDF 算期望的公式不依赖于密度是否存在**。
:::

## 常见疑问与易错点

::: warn 问：F′ = 0 几乎处处，为什么 F 不是常数？
**答**：微积分基本定理「$F(1)-F(0)=\int_0^1F'$」需要 $F$ 绝对连续（[[p:17]]）。康托尔函数不绝对连续，所以 $\int_0^1F'=0\ne1=F(1)-F(0)$。导数「看不见」发生在零测集上的增长。
:::

::: warn 问：现实中会遇到这种分布吗？
**答**：很少直接遇到，但它的意义在于**划清概念的边界**：「没有原子」和「有密度」是两回事，中间还有一类「奇异连续」的分布。下一页的分解定理说：一般分布就是这三种成分的混合。
:::

::: warn 问：X 是不可数多个值中的一个，每个值概率都是 0，概率加起来怎么会是 1？
**答**：可数可加只对**可数**个不交事件成立；康托尔集不可数，不能把单点概率相加。这和 $[0,1]$ 上均匀分布的情形一样（[[t1:p:23]]）。
:::

## 小结与自测

::: sum 本页小结
- 康托尔分布：$X=\sum_k2\xi_k/3^k$，$\xi_k$ 独立公平 0/1，$X\in C$ 恒成立。
- 没有原子（$\P(X=x)\le2^{-n}\to0$）⇒ CDF 连续；但 $\P(X\in C)=1$、$\Leb(C)=0$ ⇒ 没有密度 ⇒ CDF 不绝对连续。
- 康托尔函数（魔鬼阶梯）：在每个被删区间上是常数，$F'=0$ a.e.，却从 0 连续地升到 1。
- $\E X=\tfrac12$，$\operatorname{Var}X=\tfrac18$。
:::

::::quiz 自测
**1.** 求 $\P(X\le\tfrac19)$ 和 $F(\tfrac12)$。

:::answer
$X\le\tfrac19$ ⟺ $\xi_1=\xi_2=0$，概率 $\tfrac14$。$\tfrac12$ 落在被删掉的 $(\tfrac13,\tfrac23)$ 里，$F$ 在那里恒为 $\tfrac12$，所以 $F(\tfrac12)=\tfrac12$。
:::

**2.** 若改成 $Y=\sum_k\xi_k/2^k$（二进制而不是三进制），$Y$ 的分布是什么？有密度吗？

:::answer
$Y$ 的二进制数字就是 $\xi_k$，前 $n$ 位取定对应一个长 $2^{-n}$ 的区间，概率恰好 $2^{-n}$，所以 $Y\sim\mathrm{Unif}(0,1)$，有密度 $\ind_{(0,1)}$。区别在于三进制只用两个数字时，「空出来」的中间三分之一使得概率被挤到一个零测集上。
:::

**3.** 判断：若 CDF 在每一点都连续并且几乎处处可导、导数为 0，则这个分布是退化的（集中在一点）。

:::answer
错误。康托尔分布满足所有这些条件，却分布在不可数多个点上，方差是 $\tfrac18$。
:::
