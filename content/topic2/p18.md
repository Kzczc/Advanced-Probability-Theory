## 这一页在讲什么

::: idea 一句话版
从 $[0,1]$ 开始，一遍遍挖掉每段中间的三分之一，剩下的点组成**康托尔集** $C$。它的总长度是 0，却有**不可数**多个点——因为每个点都对应一串 0/1 的无穷序列（这就是标题里的「二进编码」）。
:::

- **位置**：第 2 部分，为下一页的反例做准备。[[p:17]] 说「有密度 ⟺ CDF 绝对连续」；[[p:19]] 要造一个 CDF 连续、却没有密度的分布，它需要一个「点多到不可数、长度却为 0」的集合来存放全部概率——康托尔集正好合适。
- **要澄清的误解**：直觉上「长度为 0 的集合，点很少（可数个）」。康托尔集说明这是错的：**零测集可以不可数**。
- **第 1 讲的回顾**：可数集一定是零测集（[[t1:p:17]]、[[t1:p:23]]）；本页给出反方向的反例。

## 先补基础

::: basics 三进制小数
就像十进制小数 $0.d_1d_2d_3\ldots$ 表示 $\sum_kd_k10^{-k}$，**三进制**小数 $0.t_1t_2t_3\ldots_{(3)}$（每个 $t_k\in\{0,1,2\}$）表示
$$
x=\sum_{k\ge1}\frac{t_k}{3^k}=\frac{t_1}{3}+\frac{t_2}{9}+\frac{t_3}{27}+\cdots .
$$
- 第一位 $t_1$ 告诉你 $x$ 在 $[0,1]$ 的哪个三分之一里：$t_1=0$ 在 $[0,\tfrac13]$，$t_1=1$ 在 $[\tfrac13,\tfrac23]$，$t_1=2$ 在 $[\tfrac23,1]$。
- 例：$\tfrac13=0.1000\ldots_{(3)}=0.0222\ldots_{(3)}$（和十进制的 $0.1=0.0999\ldots$ 一样，有些数有两种写法）；$\tfrac14=0.020202\ldots_{(3)}$（因为 $\tfrac29\cdot\frac1{1-1/9}=\tfrac29\cdot\tfrac98=\tfrac14$）。
:::

::: basics 二进制与 0/1 序列
二进制小数 $0.b_1b_2b_3\ldots_{(2)}=\sum_kb_k2^{-k}$（$b_k\in\{0,1\}$）能表示 $[0,1]$ 里的每个数。所有无穷 0/1 序列 $(b_1,b_2,\ldots)$ 组成的集合记作 $\{0,1\}^{\N}$。它是**不可数**的（[[t1:p:7]] 的无穷次抛硬币就是它；对角线论证见 [基础补课](../basics.html)）。
:::

::: basics 闭集
「闭集」可以简单理解为「包含了自己所有边界点」的集合，例如闭区间 $[a,b]$。**闭集的交仍是闭集**，有限个闭区间的并也是闭集。闭集都是博雷尔集，所以可以谈测度。
:::

## 课件原文逐句精读

::: original The Cantor set and its binary encoding
**Definition 18 (Middle-thirds Cantor set)** Start with $C_0=[0,1]$. To obtain $C_{n+1}$, delete the *open middle third* of every interval in $C_n$, keeping all endpoints. Thus
$$
\begin{aligned}
C_1&=[0,\tfrac13]\cup[\tfrac23,1],\\
C_2&=[0,\tfrac19]\cup[\tfrac29,\tfrac13]\cup[\tfrac23,\tfrac79]\cup[\tfrac89,1].
\end{aligned}
$$
Define $C:=\bigcap_{n\ge0}C_n$. Each $C_n$ contains $2^n$ disjoint closed intervals of length $3^{-n}$. Hence $C$ is closed, and
$$
0\le\Leb(C)\le\Leb(C_n)=(2/3)^n\to0 .
$$
:::

::: zh
**定义 18（三分康托尔集）** 从 $C_0=[0,1]$ 开始。要得到 $C_{n+1}$，就把 $C_n$ 中每个区间的**开的中间三分之一**删掉，保留所有端点。于是 $C_1=[0,\tfrac13]\cup[\tfrac23,1]$，$C_2=[0,\tfrac19]\cup[\tfrac29,\tfrac13]\cup[\tfrac23,\tfrac79]\cup[\tfrac89,1]$。

定义 $C:=\bigcap_{n\ge0}C_n$。每个 $C_n$ 由 $2^n$ 个互不相交、长度为 $3^{-n}$ 的闭区间组成。因此 $C$ 是闭集，并且 $0\le\Leb(C)\le\Leb(C_n)=(2/3)^n\to0$。

（后面的「二进编码」课件留白，见下一节。）
:::

### delete the open middle third, keeping all endpoints｜每一步做什么

- **open middle third**（开的中间三分之一）：从 $[0,1]$ 删掉 $(\tfrac13,\tfrac23)$，**不含**端点 $\tfrac13,\tfrac23$，所以端点留下。
- 每一步，**每个**剩下的区间都一分为三、删掉中间那份、保留两边两份：区间个数翻倍，每段长度变成原来的 $\tfrac13$。

| 步数 $n$ | 区间个数 | 每段长度 | 总长度 $\Leb(C_n)$ | 这一步删掉的总长度 |
| --- | --- | --- | --- | --- |
| 0 | 1 | 1 | 1 | — |
| 1 | 2 | $1/3$ | $2/3$ | $1/3$ |
| 2 | 4 | $1/9$ | $4/9$ | $2/9$ |
| 3 | 8 | $1/27$ | $8/27$ | $4/27$ |
| $n$ | $2^n$ | $3^{-n}$ | $(2/3)^n$ | $2^{n-1}/3^n$ |

### Define C := ⋂ Cₙ｜康托尔集是什么

- $C$ 是**所有步都没被删掉**的点。$C_0\supseteq C_1\supseteq C_2\supseteq\cdots$ 一层层缩小。
- **$C$ 是闭集**：每个 $C_n$ 是有限个闭区间的并，是闭集；闭集的交还是闭集。
- **$\Leb(C)=0$**：$C\subseteq C_n$，测度单调（[[t1:p:12]]），所以 $\Leb(C)\le(2/3)^n$ 对每个 $n$ 成立，只能是 0。（也可以用从上连续 [[t1:p:14]]：$\Leb(C_n)\downarrow\Leb(C)$。）
- 被删掉的总长度：$\tfrac13+\tfrac29+\tfrac4{27}+\cdots=\tfrac13\cdot\frac1{1-2/3}=1$，**全部长度都被删光了**。

::: prop 康托尔集的二进编码
1. **三进制刻画**：$x\in C$ 当且仅当 $x$ 有一个三进制展开 $x=\sum_{k\ge1}t_k3^{-k}$，其中**每一位 $t_k\in\{0,2\}$**（不出现 1）。
2. **与 0/1 序列一一对应**：映射
   $$
   \Phi:\{0,1\}^{\N}\to C,\qquad (b_1,b_2,\ldots)\mapsto\sum_{k\ge1}\frac{2b_k}{3^k}
   $$
   是双射（把三进制数字里的 2 换成 1，就得到二进制数字）。
3. **因此 $C$ 不可数**，但 $\Leb(C)=0$。
:::

::: proof 证明思路
第 $k$ 步删掉的正是「第 $k$ 位三进制数字只能是 1」的那些点，所以留下来的点每一位都可以选 0 或 2；而「每一位二选一」的方式和 0/1 序列一样多。
:::

**第 1 步（第一位）**：$x\in[0,1]$ 的第一位三进制数字 $t_1$ 决定它在哪个三分之一里。删掉的开区间 $(\tfrac13,\tfrac23)$ 里的点，第一位**只能**是 1（没有别的写法）；留下的 $[0,\tfrac13]$ 可以写成 $t_1=0$，$[\tfrac23,1]$ 可以写成 $t_1=2$。端点 $\tfrac13=0.0222\ldots_{(3)}$ 也能避开 1。所以 $x\in C_1\iff$ 有一个展开使 $t_1\in\{0,2\}$。

**第 2 步（逐位归纳）**：在 $C_1$ 的每个小区间里重复同样的论证，第二位 $t_2$ 决定在这个小区间的哪个三分之一里，删掉的中间三分之一恰好是 $t_2$ 只能为 1 的点。一般地，$x\in C_n\iff$ 有展开使 $t_1,\ldots,t_n\in\{0,2\}$。对所有 $n$ 取交，就得到第 1 条。

**第 3 步（双射）**：

- 映射 $\Phi$ 把 $(b_k)$ 送到三进制数字为 $t_k=2b_k\in\{0,2\}$ 的数，由第 1 条它落在 $C$ 里。
- **满射**：$C$ 里每个点都有只含 0、2 的展开，令 $b_k=t_k/2$ 即可。
- **单射**：两个只含 0、2 的不同序列，在第一个不同的位置 $k$ 上，一个是 0、一个是 2；后面所有位的差最多是 $\sum_{j>k}2\cdot3^{-j}=3^{-k}$，而第 $k$ 位造成的差是 $2\cdot3^{-k}$，所以两个数之差至少是 $2\cdot3^{-k}-3^{-k}=3^{-k}>0$，两数不同。

**第 4 步（不可数）**：$\{0,1\}^{\N}$ 不可数，$\Phi$ 是双射，所以 $C$ 不可数。$\blacksquare$

::: fig 图解：前三步挖去的区间
用数轴想象（每一行是一步，粗线是留下的部分）：

- $C_0$：$[0,1]$ 整条线。
- $C_1$：$[0,\tfrac13]$ 与 $[\tfrac23,1]$ 两段，中间的 $(\tfrac13,\tfrac23)$ 空了。
- $C_2$：四段 $[0,\tfrac19]$、$[\tfrac29,\tfrac13]$、$[\tfrac23,\tfrac79]$、$[\tfrac89,1]$，每段长 $\tfrac19$。
- $C_3$：八段，每段长 $\tfrac1{27}$。

每往下一行，每段都「掰成两半、扔掉中间」。课件上没有画图，这张想象图就是定义 18 的全部内容。注意：**留下来的点越来越「稀」，但永远不会被删光**——每一步的端点永远留下。

## 例子

::: ex 例 1：哪些点在康托尔集里？
- $0$、$1$、$\tfrac13$、$\tfrac23$、$\tfrac19$、$\tfrac29$……：所有步骤的端点都在 $C$ 里（它们从不被删掉），这样的点有可数多个。
- $\tfrac14=0.020202\ldots_{(3)}$：每一位都是 0 或 2，所以 $\tfrac14\in C$。但它**不是**任何一步的端点（端点都是 $\tfrac{m}{3^n}$ 的形式）。所以康托尔集里不只有端点。
- $\tfrac12=0.1111\ldots_{(3)}$：第一位就是 1，而且没有别的写法，所以 $\tfrac12\notin C$（它在第一步就被删掉了）。
:::

::: ex 例 2：用编码读出位置
序列 $b=(1,0,1,0,\ldots)$（交替）对应 $x=\Phi(b)=\tfrac23+\tfrac2{27}+\tfrac2{243}+\cdots=\tfrac23\cdot\frac{1}{1-1/9}=\tfrac34$。验证：$\tfrac34=0.2020\ldots_{(3)}$，每一位都是 0 或 2，确实在 $C$ 里。读法：第 1 位是 1（二进制）→「走右边的三分之一」，第 2 位是 0 →「在其中走左边的三分之一」……编码就是一份「每一步往左还是往右」的路线图。
:::

::: ex 例 3：长度与点数的对比
| 集合 | 点的个数 | 勒贝格测度 |
| --- | --- | --- |
| 有理数 $\Q\cap[0,1]$ | 可数 | 0 |
| 康托尔集 $C$ | **不可数** | 0 |
| $[0,1]$ | 不可数 | 1 |

所以「测度为 0」和「可数」不是一回事：可数 ⇒ 测度 0，但测度 0 ⇏ 可数。
:::

## 常见疑问与易错点

::: warn 问：每一步都删掉了点，最后会不会什么都不剩？
**答**：不会。每一步删的是开区间，所有端点都永远保留，所以 $C$ 至少包含可数多个端点；由二进编码，它甚至有不可数多个点。「长度被删光」和「点被删光」是两回事。
:::

::: warn 问：既然 C 的长度为 0，为什么它能「装下」不可数多个点？
**答**：长度是对集合的「宽度」的度量，不是对点数的计数。单个点长度为 0；可数多个点用 $\eps/2^n$ 的技巧也能盖住；康托尔集说明，即使不可数多个点，只要排列得足够「稀疏」，也能被总长度任意小的区间盖住（第 $n$ 步的 $2^n$ 段，总长 $(2/3)^n$）。
:::

::: warn 问：为什么编码要用 0 和 2，而不是 0 和 1？
**答**：三进制数字 1 恰好对应「被删掉的中间三分之一」，所以康托尔集里的点**不用**数字 1；剩下的两种选择 0、2 与二进制的 0、1 一一对应。这就是标题 *binary encoding*（二进编码）的意思。
:::

## 小结与自测

::: sum 本页小结
- 康托尔集 $C=\bigcap_nC_n$：每步删掉每段的开的中间三分之一；$C_n$ 有 $2^n$ 段、每段长 $3^{-n}$。
- $C$ 是闭集，$\Leb(C)\le(2/3)^n\to0$，所以测度为 0；删掉的总长度恰好是 1。
- 二进编码：$x\in C\iff$ 三进制展开只用 0 和 2；把 2 换成 1 得到与 $\{0,1\}^{\N}$ 的双射，所以 $C$ 不可数。
- 零测集可以不可数——这是下一页构造「连续但无密度」分布的关键。
:::

::::quiz 自测
**1.** $C_3$ 有几段？总长度是多少？它比 $C_2$ 少了多长？

:::answer
$2^3=8$ 段，每段长 $\tfrac1{27}$，总长度 $\tfrac8{27}$。$C_2$ 总长 $\tfrac49=\tfrac{12}{27}$，所以第 3 步删掉了 $\tfrac4{27}$。
:::

**2.** $\tfrac{1}{10}$ 在康托尔集里吗？（提示：$\tfrac1{10}$ 在 $[0,\tfrac19]$ 吗？）

:::answer
$\tfrac19\approx0.111>\tfrac1{10}=0.1$，所以 $\tfrac1{10}\in[0,\tfrac19]$，前两步都留下了。再看第 3 步：$[0,\tfrac19]$ 被分成 $[0,\tfrac1{27}]$、$(\tfrac1{27},\tfrac2{27})$、$[\tfrac2{27},\tfrac19]$，而 $\tfrac1{27}\approx0.037$，$\tfrac2{27}\approx0.074$，$0.1$ 落在 $[\tfrac2{27},\tfrac19]$，留下。继续下去需要算三进制：$\tfrac1{10}=0.00220022\ldots_{(3)}$（循环节 0022），每一位都是 0 或 2，所以 $\tfrac1{10}\in C$。
:::

**3.** 判断：测度为 0 的集合一定只有可数多个点。

:::answer
错误。康托尔集测度为 0，但通过二进编码与 $\{0,1\}^{\N}$ 一一对应，是不可数集。
:::
