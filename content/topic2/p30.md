## 这一页在讲什么

::: idea 一句话版
如果 $\E|X|^p<\infty$，那么尾概率 $\P(|X|>t)$ 不仅不超过 $\E|X|^p/t^p$（这是 Markov），而且**比 $t^{-p}$ 衰减得还快**：$t^p\,\P(|X|>t)\to0$。
:::

- **位置**：第 5 部分第三页。上一页（[[p:29]]）的 $p$ 阶矩版 Markov 给出 $\P(|X|>t)\le\E|X|^p/t^p$，即「$t^p\P(|X|>t)$ 有界」。这一页改进成「$t^p\P(|X|>t)$ 趋于 0」。
- **为什么值得一页**：它给出一个**必要条件**：要想 $\E|X|^p<\infty$，尾巴必须比 $t^{-p}$ 衰减得更快。用它可以快速判断某些矩**不存在**（例 2）。
- **反方向不成立**：下一页（[[p:31]]）会给出一个尾巴比 $t^{-p}$ 衰减得快、$p$ 阶矩却仍然无穷的反例。

## 先补基础

::: basics 「趋于 0」比「有界」更强
- $t^p\P(|X|>t)\le C$（有界）：尾概率最多像 $C/t^p$ 那样衰减，记作 $O(t^{-p})$。
- $t^p\P(|X|>t)\to0$：尾概率比 $t^{-p}$ 还小一截，记作 $o(t^{-p})$（「小 o」）。
- 例：$t^{-3}$ 是 $o(t^{-2})$，因为 $t^2\cdot t^{-3}=1/t\to0$；而 $t^{-2}$ 是 $O(t^{-2})$ 但不是 $o(t^{-2})$。
:::

::: basics 控制收敛定理（回顾 [[t1:p:44]]）
若 $Y_n\to Y$ 几乎处处，$|Y_n|\le Z$，$\E Z<\infty$，则 $\E Y_n\to\E Y$。参数是连续变量 $t\to\infty$ 时，对任意一列 $t_n\to\infty$ 用 DCT 即可（极限对每一列都一样，就是连续意义下的极限）。
:::

::: prop 命题 28（一个可积矩带来的尾部衰减）
若 $X\in L^p$（$p>0$），则
$$
t^p\,\P(|X|>t)\le\E\big[|X|^p\ind_{\{|X|>t\}}\big]\xrightarrow[t\to\infty]{}0 .
$$
特别地，$\P(|X|>t)=o(t^{-p})$。
:::

::: proof 证明思路
在事件 $\{|X|>t\}$ 上，$t<|X|$，所以 $t^p\le|X|^p$——但这次**不扔掉**事件，保留示性函数，得到一个比 Markov 更细的界。然后用 DCT 说明它趋于 0。
:::

**第 1 步（逐点不等式）**：在 $\{|X|>t\}$ 上，$t^p<|X|^p$；在事件外两边都是 0。所以
$$
t^p\ind_{\{|X|>t\}}\le|X|^p\ind_{\{|X|>t\}} .
$$

**第 2 步（取期望）**：$t^p\P(|X|>t)\le\E\big[|X|^p\ind_{\{|X|>t\}}\big]$。

**第 3 步（右边趋于 0，用 DCT）**：令 $Y_t=|X|^p\ind_{\{|X|>t\}}$。

- **逐点极限**：$\E|X|^p<\infty$ 推出 $|X|<\infty$ 几乎必然（否则在正概率事件上 $|X|^p=\infty$，期望也是 $\infty$）。对这样的 $\omega$，只要 $t>|X(\omega)|$，就有 $Y_t(\omega)=0$。所以 $Y_t\to0$ 几乎必然。
- **控制**：$0\le Y_t\le|X|^p$，且 $\E|X|^p<\infty$。

DCT ⇒ $\E Y_t\to0$。所以 $t^p\P(|X|>t)\to0$。$\blacksquare$

::: idea 和 Markov 的区别在哪里
Markov：$t^p\P(|X|>t)\le\E|X|^p$——把整个期望都拿来当上界。本命题：$t^p\P(|X|>t)\le\E[|X|^p;\ |X|>t]$——只用**尾部那一块**期望。$t$ 越大，尾部那一块越小（被「挤」到 0），所以得到的不仅是有界，而且趋于 0。
:::

## 图解

::: fig 图解：被挤到 0 的「尾部面积」
以 $p=1$、$X\ge0$ 为例。由 [[p:12]]，$\E X=\int_0^\infty\P(X>s)\dd s$ 是尾概率曲线下的总面积，它有限。

- 把横轴在 $t$ 处切一刀，**$t$ 右边的那块面积** $\int_t^\infty\P(X>s)\dd s$ 是一个有限积分的「尾巴」，所以 $t\to\infty$ 时它趋于 0。
- 同时，$\E[X\ind_{\{X>t\}}]=t\,\P(X>t)+\int_t^\infty\P(X>s)\dd s$（把 $X\ind_{\{X>t\}}$ 的尾概率曲线画出来就能看出：它在 $[0,t)$ 上是常数 $\P(X>t)$，在 $[t,\infty)$ 上和原曲线一样）。
- 所以 $t\,\P(X>t)\le\E[X\ind_{\{X>t\}}]$，右边是「尾部的期望」，随 $t$ 增大被挤向 0。

直观地说：**面积有限的曲线，尾巴不能太「胖」**。如果 $\P(X>t)$ 一直像 $c/t$ 那么大，曲线下面积就是 $\int c/t\dd t=\infty$，与 $\E X<\infty$ 矛盾。
:::

## 例子

::: ex 例 0：具体算一遍——$\P(X>t)=t^{-3}$（$t\ge1$）
这是 $\alpha=3$ 的 Pareto 分布（[[p:16]]），密度 $f(x)=3x^{-4}$（$x\ge1$）。取 $p=2$：

1. **矩有限**：$\E X^2=\int_1^\infty x^2\cdot3x^{-4}\dd x=3\int_1^\infty x^{-2}\dd x=3$。
2. **命题中的上界**：对 $t\ge1$，
   $$
   \E\big[X^2\ind_{\{X>t\}}\big]=\int_t^\infty x^2\cdot3x^{-4}\dd x=3\int_t^\infty x^{-2}\dd x=\frac3t\to0 .
   $$
3. **左边**：$t^2\,\P(X>t)=t^2\cdot t^{-3}=\frac1t\to0$，并且确实 $\frac1t\le\frac3t$。
4. **对比 Markov**：Markov 只给出 $t^2\P(X>t)\le\E X^2=3$，看不出趋于 0；命题 28 的界 $\frac3t$ 会随 $t$ 消失。
:::

::: ex 例 1：指数分布——所有矩都有限，尾巴衰减得极快
$X\sim\exp(1)$：$\P(X>t)=e^{-t}$。对任意 $p>0$，$t^pe^{-t}\to0$（指数衰减比任何幂次都快）。和命题 28 一致：所有 $\E X^p$ 都有限。
:::

::: ex 例 2：用逆否命题判断矩不存在——Pareto
[[p:16]] 的 Pareto 变量：$\P(X_\alpha>t)=t^{-\alpha}$（$t\ge1$）。

- $p<\alpha$：$t^p\cdot t^{-\alpha}=t^{p-\alpha}\to0$，与 $\E X_\alpha^p<\infty$ 一致。
- $p=\alpha$：$t^\alpha\cdot t^{-\alpha}=1\not\to0$。由命题 28 的**逆否命题**（若 $t^p\P(|X|>t)\not\to0$，则 $X\notin L^p$），$\E X_\alpha^\alpha=\infty$。这与 [[p:16]] 直接计算的结果一致，但这里不用算积分。
:::

::: ex 例 3：标准柯西分布没有均值
柯西分布的尾巴 $\P(|X|>t)\approx\frac{2}{\pi t}$（$t$ 很大时）。取 $p=1$：$t\cdot\frac2{\pi t}=\frac2\pi\not\to0$，所以 $\E|X|=\infty$，柯西分布没有均值。
:::

## 常见疑问与易错点

::: warn 问：既然 t^p P(|X| > t) → 0 是必要条件，它是不是也是充分条件？
**答**：不是。下一页（[[p:31]]）构造了 $\P(V_p>t)=\frac{e^p}{t^p\log t}$：$t^p\P(V_p>t)=\frac{e^p}{\log t}\to0$，满足必要条件，但 $\E V_p^p=\infty$。对数因子 $\log t$ 增长得太慢，救不了积分的发散。
:::

::: warn 问：第 3 步为什么要先说明 |X| 几乎必然有限？
**答**：逐点极限「$Y_t\to0$」需要：对每个 $\omega$，$t$ 终将超过 $|X(\omega)|$。如果 $|X(\omega)|=\infty$，$t$ 永远追不上，$Y_t(\omega)=\infty$ 不趋于 0。$X\in L^p$ 保证这样的 $\omega$ 只组成零测集。
:::

## 小结与自测

::: sum 本页小结
- 命题 28：$X\in L^p$ ⇒ $t^p\P(|X|>t)\le\E[|X|^p\ind_{\{|X|>t\}}]\to0$，即尾概率是 $o(t^{-p})$。
- 证明：在尾部事件上 $t^p\le|X|^p$；尾部期望由 DCT 趋于 0（控制函数 $|X|^p$）。
- 逆否命题可以判断矩不存在：$t^p\P(|X|>t)\not\to0$ ⇒ $\E|X|^p=\infty$（Pareto、柯西）。
- 但反过来不成立（[[p:31]]）。
:::

::::quiz 自测
**1.** 若 $\P(|X|>t)=t^{-3}$（$t\ge1$），哪些 $p$ 使 $t^p\P(|X|>t)\to0$？由此能确定 $\E|X|^3$ 吗？

:::answer
$t^{p-3}\to0$ 当且仅当 $p<3$。$p=3$ 时 $t^3\cdot t^{-3}=1\not\to0$，由逆否命题 $\E|X|^3=\infty$。（对 $p<3$，命题 28 本身不能断定 $\E|X|^p<\infty$，但直接用矩–尾恒等式 [[p:21]] 可以验证它确实有限。）
:::

**2.** 判断：若 $X\in L^2$，则 $\P(|X|>t)\le\E X^2/t^2$，并且 $t^2\P(|X|>t)\to0$。

:::answer
正确。前者是二阶矩版 Markov，后者是命题 28（$p=2$）。
:::

**3.** 命题 28 的证明用到了第 1 讲的哪个定理？控制函数是什么？

:::answer
控制收敛定理（DCT）。控制函数是 $|X|^p$，它可积正是因为假设 $X\in L^p$。
:::
