## 这一页在讲什么

::: idea 一句话版
实数轴上的**任何**概率分布，都可以唯一地拆成三部分：**原子部分**（集中在可数多个点上的「沙丘」）、**绝对连续部分**（有密度，按长度铺开的「沙层」）、**奇异连续部分**（没有沙丘，却全部落在一个长度为 0 的集合上，像康托尔分布）。
:::

- **位置**：第 2 部分「用 CDF 计算期望」的总结页。前面分别见过：离散分布（只有原子）、有密度的分布（[[p:15]]、[[p:17]]）、混合型（[[p:13]]：原子 + 密度）、康托尔分布（[[p:19]]：既无原子也无密度）。这一页说：**就这三种，没有第四种**。
- **为什么有用**：遇到一个陌生的分布，先问三个问题：有没有跳跃？有没有密度部分？剩下的是什么？计算期望时也可以三部分分别算再相加。
- **和第 3 讲的联系**：把「绝对连续」与「奇异」分开，是第 3 讲 Radon–Nikodym 定理（[[t3:p:27]]）讨论的「一个测度相对于另一个测度」问题的特例（这里「另一个测度」是勒贝格测度）。

## 先补基础

::: basics 三个术语
设 $\mu$ 是 $\R$ 上的（有限）测度。

- **原子**（atom）：满足 $\mu(\{x\})>0$ 的点 $x$。**纯原子的**：$\mu$ 的全部质量都在原子上，$\mu=\sum_ip_i\delta_{x_i}$（$\delta_x$ 是点 $x$ 处的单位点质量）。
- **绝对连续**（关于勒贝格测度）：存在非负可积 $f$，使 $\mu(B)=\int_Bf\dd x$。等价地：勒贝格测度为 0 的集合，$\mu$ 也为 0。
- **奇异**（singular，关于勒贝格测度）：存在勒贝格零测集 $N$，使 $\mu$ 的全部质量都在 $N$ 上，$\mu(N^c)=0$。**奇异连续**：奇异，并且没有原子。
:::

::: basics 为什么原子最多可数个
总质量为 1 的分布，质量 $>\tfrac1n$ 的原子最多 $n-1$ 个（否则总质量 $>1$）。所有原子 $=\bigcup_n\{$质量 $>\tfrac1n$ 的原子$\}$，是可数个有限集的并，所以**最多可数个**。
:::

::: thm 定理 20（原子、奇异连续与绝对连续部分）
$\R$ 上的每个概率测度 $\mu$ 都可以**唯一地**写成
$$
\mu=\mu_{\mathrm d}+\mu_{\mathrm{ac}}+\mu_{\mathrm{sc}},
$$
其中三部分都是（总质量可能小于 1 的）测度：

- $\mu_{\mathrm d}=\sum_i\mu(\{x_i\})\,\delta_{x_i}$ 是**纯原子**部分，$x_1,x_2,\ldots$ 是 $\mu$ 的全部原子（最多可数个）；
- $\mu_{\mathrm{ac}}(B)=\int_Bf(x)\dd x$ 是**绝对连续**部分，$f\ge0$ 可积；
- $\mu_{\mathrm{sc}}$ 是**奇异连续**部分：没有原子，并且集中在某个勒贝格零测集上。

对应地，CDF 分解为 $F=F_{\mathrm d}+F_{\mathrm{ac}}+F_{\mathrm{sc}}$：一个只有跳跃的阶梯函数、一个密度的不定积分、一个连续且导数几乎处处为 0 的函数。
:::

::: proof 证明思路
先把原子「挖出来」，剩下的部分没有原子；再把剩下部分中「可以用密度表示」的那一块分出来（勒贝格分解定理），剩下的就是奇异连续部分。
:::

**第 1 步（原子部分）**：令 $\{x_i\}$ 为全部原子（最多可数个，见「先补基础」），$\mu_{\mathrm d}(B):=\sum_{x_i\in B}\mu(\{x_i\})$。它是测度（可数可加来自非负项级数可以重排）。

**第 2 步（剩下的部分没有原子）**：令 $\mu_{\mathrm c}:=\mu-\mu_{\mathrm d}$。对每个 $B$，$\mu_{\mathrm d}(B)=\mu(B\cap\{x_i\})\le\mu(B)$，所以 $\mu_{\mathrm c}\ge0$ 是测度；每个点 $x$：若 $x$ 是原子，$\mu_{\mathrm c}(\{x\})=\mu(\{x\})-\mu(\{x\})=0$；否则本来就是 0。所以 $\mu_{\mathrm c}$ 没有原子。

**第 3 步（勒贝格分解，当作已知结论）**：任何有限测度 $\nu$ 都能唯一地写成 $\nu=\nu_{\mathrm{ac}}+\nu_{\mathrm s}$，其中 $\nu_{\mathrm{ac}}$ 有密度，$\nu_{\mathrm s}$ 集中在一个勒贝格零测集上。（证明要用 Radon–Nikodym 定理，第 3 讲 [[t3:p:27]] 会陈述。）把它用在 $\nu=\mu_{\mathrm c}$ 上，得到 $\mu_{\mathrm{ac}}$ 和 $\mu_{\mathrm{sc}}:=\nu_{\mathrm s}$。$\mu_{\mathrm{sc}}\le\mu_{\mathrm c}$ 也没有原子，所以是奇异**连续**的。

**第 4 步（唯一性的想法）**：原子部分由「哪些点有正质量」唯一决定；绝对连续部分与奇异部分由勒贝格分解的唯一性决定。$\blacksquare$

## 例子

::: ex 例 1：只有一种成分的三个典型
| 分布 | $\mu_{\mathrm d}$ | $\mu_{\mathrm{ac}}$ | $\mu_{\mathrm{sc}}$ |
| --- | --- | --- | --- |
| 掷骰子（取 $1,\dots,6$） | 全部质量 | 0 | 0 |
| 指数分布 $\exp(\lambda)$（[[p:15]]） | 0 | 全部质量，密度 $\lambda e^{-\lambda x}$ | 0 |
| 康托尔分布（[[p:19]]） | 0 | 0 | 全部质量 |
:::

::: ex 例 2：混合型——[[p:13]] 的例 12
$F$ 在 0 处跳 $\tfrac12$，在 $[1,2)$ 上以斜率 $\tfrac12$ 爬升：
$$
\mu=\tfrac12\delta_0+\mu_{\mathrm{ac}},\qquad\mu_{\mathrm{ac}}(B)=\int_{B\cap[1,2]}\tfrac12\dd x,\qquad\mu_{\mathrm{sc}}=0 .
$$
CDF 的分解：$F_{\mathrm d}(x)=\tfrac12\ind_{\{x\ge0\}}$；$F_{\mathrm{ac}}(x)=\tfrac12\min(\max(x-1,0),1)$。验证：$x=1.5$ 时 $F_{\mathrm d}+F_{\mathrm{ac}}=\tfrac12+\tfrac14=\tfrac34=\tfrac{1.5}2$。✓
:::

::: ex 例 3：三种成分都有
先抛一个三面的「骰子」：以 $\tfrac13$ 的概率令 $X=0$；以 $\tfrac13$ 的概率令 $X\sim\mathrm{Unif}(0,1)$；以 $\tfrac13$ 的概率令 $X$ 服从康托尔分布。则
$$
\mu=\tfrac13\delta_0+\tfrac13\,\Leb|_{[0,1]}+\tfrac13\,\mu_{\mathrm{Cantor}} .
$$
- $\P(X=0)=\tfrac13$（原子）；
- $F(\tfrac12)=\tfrac13\cdot1+\tfrac13\cdot\tfrac12+\tfrac13\cdot\tfrac12=\tfrac23$；
- $\E X=\tfrac13\cdot0+\tfrac13\cdot\tfrac12+\tfrac13\cdot\tfrac12=\tfrac13$（三部分的期望分别算再按权重相加）。
:::

::: ex 例 4：从 CDF 读出三部分
拿到一个 CDF $F$，可以这样拆：

1. **找跳跃**：每个跳跃点 $x$ 处的跳跃高度 $F(x)-F(x-)$ 就是原子质量，加起来得到 $F_{\mathrm d}$。
2. **求导**：$F$ 几乎处处可导（单调函数的性质），$f=F'$ 就是绝对连续部分的密度，$F_{\mathrm{ac}}(x)=\int_{-\infty}^xf$。
3. **剩下的**：$F_{\mathrm{sc}}=F-F_{\mathrm d}-F_{\mathrm{ac}}$，它连续、单调、导数几乎处处为 0。若它不是常数，分布就有奇异连续部分。

对康托尔函数：第 1 步没有跳跃，第 2 步 $F'=0$，所以 $F_{\mathrm{sc}}=F$。
:::

## 常见疑问与易错点

::: warn 问：离散分布、连续分布、混合分布，是不是就覆盖了所有情况？
**答**：如果「连续」指「有密度」，那就漏掉了奇异连续这一种。定理 20 的完整说法是三种：原子、绝对连续、奇异连续。实际应用中第三种很少出现，但它确实存在（康托尔分布），不能忽略。
:::

::: warn 问：计算期望时可以三部分分开算吗？
**答**：可以。积分对测度是线性的：$\int g\dd\mu=\int g\dd\mu_{\mathrm d}+\int g\dd\mu_{\mathrm{ac}}+\int g\dd\mu_{\mathrm{sc}}$（三部分非负，或 $g$ 可积）。原子部分是 $\sum_ig(x_i)\mu(\{x_i\})$，绝对连续部分是 $\int g f\dd x$，奇异连续部分没有简单公式，通常借助 CDF（[[p:12]]）或具体构造（[[p:19]] 例 2）来算。
:::

::: warn 问：「奇异」和「连续」放在一起不矛盾吗？
**答**：不矛盾。「连续」说的是 CDF 没有跳跃（没有原子），「奇异」说的是质量集中在勒贝格零测集上。康托尔分布同时满足两者：每个点概率为 0，但全部概率都在测度为 0 的康托尔集上。
:::

## 小结与自测

::: sum 本页小结
- 定理 20：$\R$ 上每个概率测度唯一分解为 $\mu_{\mathrm d}+\mu_{\mathrm{ac}}+\mu_{\mathrm{sc}}$（原子 / 绝对连续 / 奇异连续）。
- 原子最多可数个；绝对连续部分有密度 $f=F'$；奇异连续部分没有原子、集中在零测集上。
- CDF 对应分解为「跳跃阶梯 + 密度的积分 + 魔鬼阶梯式的连续函数」。
- 例：骰子（纯原子）、指数（纯绝对连续）、康托尔（纯奇异连续）、[[p:13]] 例 12（原子 + 绝对连续）。
:::

::::quiz 自测
**1.** 一个随机变量以 $\tfrac14$ 的概率取 2、以 $\tfrac34$ 的概率服从 $\exp(1)$。写出它的三部分，并求 $\E X$。

:::answer
$\mu_{\mathrm d}=\tfrac14\delta_2$；$\mu_{\mathrm{ac}}$ 的密度是 $\tfrac34e^{-x}\ind_{\{x>0\}}$；$\mu_{\mathrm{sc}}=0$。$\E X=\tfrac14\cdot2+\tfrac34\cdot1=\tfrac54$。
:::

**2.** 判断：一个分布若没有原子，就一定有密度。

:::answer
错误。没有原子只排除了 $\mu_{\mathrm d}$，还可能有奇异连续部分，例如康托尔分布。
:::

**3.** 为什么原子部分的点最多只有可数个？

:::answer
总质量为 1，质量大于 $\tfrac1n$ 的原子少于 $n$ 个；所有原子是对 $n=1,2,\ldots$ 取并，是可数个有限集合的并，所以最多可数。
:::
