## 这道题在问什么

::: idea 一句话版
均值无穷时，$S_n/n$ 没有有限极限（[[hw1:p:3]]）。那么换一个更快增长的尺度 $a_n$，$S_n/a_n$ 会怎样？本题（Durrett 定理 2.5.13）给出完整答案：只要 $a_n/n$ 递增，$\limsup_n|S_n|/a_n$ **要么是 0，要么是 $\infty$**，没有中间值；分界线就是**单独一项** $|X_n|$ 是否会无穷多次超过 $a_n$，即 $\sum_n\P(|X_1|\ge a_n)$ 是否有限。直观意思：均值无穷时，和 $S_n$ 的大小由最大的那几项决定，「单项冲不过 $a_n$」就等于「和冲不过 $a_n$」。
:::

- **考点**：两个 Borel–Cantelli 引理；截断；方差求和；Kolmogorov 一级数定理与 Kronecker 引理（强大数定律的经典证法）；尾级数判别；交换求和次序。
- **要用的讲义结论**：「无穷多次」（第 3 讲 [[t3:p:3]]）；第一、第二 Borel–Cantelli 引理（第 3 讲 [[t3:p:4]]、[[t3:p:7]]）；独立性（第 3 讲 [[t3:p:6]]）；尾级数判别（第 3 讲 [[t3:p:12]]）；一阶矩无穷时 $\limsup|X_n|/n=\infty$（第 3 讲 [[t3:p:13]]）；独立变量和的方差（第 3 讲 [[t3:p:37]]）。
- **讲义没有讲过、这里作为已知结论使用的**：Kolmogorov 极大不等式、Kolmogorov 一级数定理、Kronecker 引理（见「先补基础」）。
- **与其他题的关系**：
  - 取 $a_n=n$ 就回到第 3 讲 [[t3:p:13]] 和 [[hw1:p:3]]，而且结论更强：$\limsup|S_n|/n=\infty$（例 1）。第一部分的证明就是那两页论证的推广。
  - [[p:2]] 用同样的「单项超过门槛的概率之和」判别上极限；[[p:4]] 讨论均值有限、方差有限时的大数定律。

## 先补基础

::: basics 「aₙ/n 递增」能推出的五件事
设 $a_n>0$，$\frac{a_n}n$ 单调不减（「increasing」在这里指不减）。
1. **$a_n$ 本身不减**：$a_n=n\cdot\frac{a_n}n$，两个正的不减数列之积不减。
2. **$a_{kn}\ge ka_n$**（$k$ 是正整数）：$\frac{a_{kn}}{kn}\ge\frac{a_n}n$，两边乘 $kn$。
3. **$a_n\ge\frac nma_m$**（$n\ge m$）：$\frac{a_n}n\ge\frac{a_m}m$。
4. **$\frac m{a_m}$ 不增**：它是 $\frac{a_m}m$ 的倒数。
5. **$a_n\to\infty$**：$a_n\ge na_1\to\infty$。

**例**：$a_n=n^c$（$c\ge1$）、$a_n=n\log(n+1)$、$a_n=n(\log(n+1))^2$ 都满足；$a_n=\sqrt n$ 不满足（$\frac{a_n}n=n^{-1/2}$ 递减）。
:::

::: basics Borel–Cantelli 引理与「lim sup = ∞」（回顾）
- **BC I**（第 3 讲 [[t3:p:4]]）：$\sum\P(A_n)<\infty\Rightarrow\P(A_n\ \text{i.o.})=0$，不需要独立。
- **BC II**（第 3 讲 [[t3:p:7]]）：$A_n$ 相互独立且 $\sum\P(A_n)=\infty\Rightarrow\P(A_n\ \text{i.o.})=1$。
- **证明 $\limsup=\infty$ 的标准写法**：对每个正整数 $k$ 证明「$\ge k$ 无穷多次」的概率为 1，再对可数个 $k$ 取交（可数个概率 1 事件之交概率仍为 1，见[[p:2]] 的基础部分）。
:::

::: basics 尾级数判别（回顾第 3 讲 p12）
对 $Y\ge0$：$\E Y<\infty\iff\sum_{n\ge1}\P(Y>n)<\infty$（第 3 讲 [[t3:p:12]]）。本题用它的**缩放版本**：若 $\E|X|=\infty$，则对每个常数 $c>0$，取 $Y=|X|/c$（$\E Y=\infty$），得
$$
\sum_{n\ge1}\P(|X|\ge cn)\ge\sum_{n\ge1}\P(|X|>cn)=\sum_{n\ge1}\P(Y>n)=\infty .
$$
**例**：$\P(|X|\ge x)=x^{-1/2}$（$x\ge1$）时 $\E|X|=\infty$，$\sum_n\P(|X|\ge cn)=\sum_n(cn)^{-1/2}=\infty$。
:::

::: basics 截断：把「没有矩」的变量变成有界变量
令 $Y_n=X_n\ind_{\{|X_n|<a_n\}}$：$|X_n|<a_n$ 时保留，否则换成 0。
- $|Y_n|<a_n$，所以 $Y_n$ 有界，**任何阶矩都存在**，可以算方差。
- $Y_n$ 只依赖 $X_n$，所以 $Y_1,Y_2,\dots$ 仍然独立（但不同分布，截断水平 $a_n$ 随 $n$ 变）。
- 代价：$X_n\ne Y_n$ 的事件是 $\{|X_n|\ge a_n\}$。若它只发生有限次，那么 $S_n$ 与 $T_n=Y_1+\dots+Y_n$ 只差一个**固定的有限数**（有限个差的和），除以 $a_n\to\infty$ 后消失。
:::

::: basics 非负二重级数可以交换求和次序
若 $c_{m,n}\ge0$，则 $\sum_n\sum_mc_{m,n}=\sum_m\sum_nc_{m,n}$（两边可以同时为 $\infty$）。这是 Tonelli 定理对计数测度的特例（第 4 讲 [[t4:p:12]]）。本题用它证明一个恒等式：令 $a_0=0$，$p_m=\P(a_{m-1}\le|X_1|<a_m)$，则
$$
\sum_{m\ge1}m\,p_m=\sum_{m\ge1}\sum_{n=1}^mp_m=\sum_{n\ge1}\sum_{m\ge n}p_m=\sum_{n\ge1}\P(|X_1|\ge a_{n-1}).\qquad(\ast)
$$
最后一步：$a_m$ 不减且 $\to\infty$，区间 $[a_{m-1},a_m)$（$m\ge n$）恰好拼成 $[a_{n-1},\infty)$。又 $\P(|X_1|\ge a_0)=1$，所以 $(\ast)$ 的右边 $=1+\sum_{n\ge1}\P(|X_1|\ge a_n)$。
:::

::: basics Kolmogorov 极大不等式（这里作为已知结论使用）
**定理**（Durrett《Probability: Theory and Examples》第 5 版定理 2.5.5）：设 $Z_1,\dots,Z_n$ 独立，$\E Z_i=0$，$\operatorname{Var}Z_i<\infty$，$W_k=Z_1+\dots+Z_k$。则对 $x>0$，
$$
\P\Big(\max_{1\le k\le n}|W_k|\ge x\Big)\le\frac{\operatorname{Var}W_n}{x^2}.
$$
- **和 Chebyshev 比较**：Chebyshev 只控制终点 $\P(|W_n|\ge x)$；这里右边一样，左边却控制了**整条路径上的最大值**。代价是需要独立（Chebyshev 不需要）。
- **例**：$Z_i=\pm1$ 各一半，$n=100$，$x=30$：路径在前 100 步中**任何时刻**偏离 0 达到 30 的概率 $\le\frac{100}{900}\approx0.11$。
:::

::: basics Kolmogorov 一级数定理（这里作为已知结论使用）
**定理**（Durrett 定理 2.5.6）：设 $Z_1,Z_2,\dots$ 独立，$\E Z_n=0$，$\sum_n\operatorname{Var}Z_n<\infty$，则随机级数 $\sum_nZ_n$ 几乎必然收敛（部分和收敛到一个有限的随机变量）。
- **为什么对**：由极大不等式，从第 $M$ 项往后，部分和的最大摆动超过 $\eps$ 的概率 $\le\eps^{-2}\sum_{n>M}\operatorname{Var}Z_n\to0$，部分和几乎必然是 Cauchy 列（详见「拓展延伸」）。
- **例（随机符号的调和级数）**：$\sum_n\frac{\pm1}n$，符号独立、各一半。$\sum\frac1n=\infty$，但 $\sum\operatorname{Var}\frac{\pm1}n=\sum\frac1{n^2}<\infty$，所以几乎每一种随机符号都让级数收敛。
:::

::: basics Kronecker 引理（这里作为已知结论使用）
**引理**（Durrett 定理 2.5.9）：设 $0<a_n\uparrow\infty$，实数列 $(x_n)$ 使 $\sum_n\frac{x_n}{a_n}$ 收敛，则 $\frac1{a_n}\sum_{m=1}^nx_m\to0$。
- **意思**：「除以 $a_n$ 后可求和」推出「前 $n$ 项之和相对 $a_n$ 可以忽略」。它把**级数收敛**（一级数定理的结论）翻译成**平均值趋于 0**（大数定律式的结论）。
- **例**：$a_n=n$，$x_n=(-1)^n$。$\sum\frac{(-1)^n}n$ 收敛（交错级数），而 $\frac1n\sum_{m\le n}(-1)^m$ 等于 0 或 $-\frac1n$，确实 $\to0$。
- 证明是「分部求和」，见「拓展延伸」。
:::

## 题目与原解答

::: original 题目
**5.** Let $X_1,X_2,\dots$ be i.i.d. with $\E(|X_1|)=\infty$ and let $S_n=X_1+\dots+X_n$. Let $a_n$ be a sequence of positive numbers with $\frac{a_n}n$ increasing. Then
$$
\limsup_{n\to\infty}\frac{|S_n|}{a_n}=0\ \text{or}\ \infty\ \text{ if }\ \sum_n\P(|X_1|\ge a_n)<\infty\ \text{or}\ =\infty,\ \text{respectively}.
$$
\* Durrett, Theorem 2.5.13.
:::

::: zh
**5.** 设 $X_1,X_2,\dots$ 独立同分布，$\E|X_1|=\infty$，$S_n=X_1+\dots+X_n$。设 $a_n$ 是一列正数，$\frac{a_n}n$ 递增。则：若 $\sum_n\P(|X_1|\ge a_n)<\infty$，$\limsup_n\frac{|S_n|}{a_n}=0$；若 $\sum_n\P(|X_1|\ge a_n)=\infty$，$\limsup_n\frac{|S_n|}{a_n}=\infty$（都是几乎必然）。

（题注：Durrett《Probability: Theory and Examples》第 5 版定理 2.5.13。Durrett 说它比定理 2.3.7（即作业 1 第 3 题）更强。）
:::

**原解答的思路**（左栏，基本照搬 Durrett 的证明）：

1. **$\sum=\infty$ 的情形**：由 $\frac{a_n}n$ 递增，$\sum_n\P(|X_1|\ge ka_n)\ge\frac1k\sum_{m\ge k}\P(|X_1|\ge a_m)=\infty$；由 Borel–Cantelli，$\limsup|X_n|/a_n=\infty$；再由 $\max(|S_{n-1}|,|S_n|)\ge\frac{|X_n|}2$ 得到结论。
2. **$\sum<\infty$ 的情形**：截断 $Y_n=X_n\ind(|X_n|<a_n)$，「只需检查」$\sum\operatorname{Var}(Y_n/a_n)<\infty$ 和 $\frac1{a_n}\sum\E Y_i\to0$。
3. **方差**：交换求和次序，用 $a_n\ge\frac{na_m}m$ 把 $\sum_{n\ge m}a_n^{-2}$ 估成 $C\frac m{a_m^2}$，归结为 $\sum_mm\P(a_{m-1}\le|X_1|<a_m)<\infty$。
4. **均值**：先说明 $\frac{a_n}n\uparrow\infty$，把 $\frac1{a_n}\sum\E|Y_m|$ 拆成 $\frac{na_N}{a_n}$ 和一个尾部和，后者是收敛级数的尾巴。

框架完全正确，但**最关键的一步**（为什么检查这两件事就够了）一句没说；另有多处下标笔误、常数与不等号的问题，见「原解答逐行对照」。

## 思路：怎么想到的

1. **$\infty$ 的方向：一项就够**。和 $S_n$ 里只要有一项 $|X_n|$ 非常大，$S_n$ 和 $S_{n-1}$ 就不可能同时小（它们的差就是 $X_n$）。所以「单项无穷多次超过 $ka_n$」直接推出「和无穷多次超过 $\frac k2a_n$」。单项超过门槛是独立事件，正好用 BC II。
2. **0 的方向：抄强大数定律的证明**。要证 $S_n/a_n\to0$，经典路线是「截断 → 方差可求和 → 一级数定理 → Kronecker」。截断是因为 $X_n$ 没有任何矩；截断水平选 $a_n$，是因为 $\sum\P(|X_n|\ge a_n)<\infty$ 恰好保证截断只改动有限项（BC I）。
3. **条件「$a_n/n$ 递增」用在哪里**：$a_n$ 至少线性增长、而且增长率不倒退，这样 $\sum_{n\ge m}a_n^{-2}$ 被第 $m$ 项控制（方差估计），$\frac m{a_m}$ 递减（均值估计）。

## 完整解答

::: thm 命题（Durrett 定理 2.5.13）
设 $X_1,X_2,\dots$ i.i.d.，$\E|X_1|=\infty$，$S_n=X_1+\dots+X_n$；$a_n>0$，$\frac{a_n}n$ 不减。则几乎必然
$$
\limsup_{n\to\infty}\frac{|S_n|}{a_n}=\begin{cases}0,&\sum_n\P(|X_1|\ge a_n)<\infty\quad(\text{此时 }S_n/a_n\to0),\\ \infty,&\sum_n\P(|X_1|\ge a_n)=\infty .\end{cases}
$$
:::

::: proof 证明思路
发散的情形：对每个整数 $k$，BC II 给出 $|X_n|\ge ka_n$ 无穷多次，而 $|X_n|\le|S_n|+|S_{n-1}|$。收敛的情形：截断 $Y_n=X_n\ind(|X_n|<a_n)$，BC I 说截断只改动有限项；$\sum\operatorname{Var}(Y_n/a_n)<\infty$ 加一级数定理、Kronecker 引理，得 $(T_n-\E T_n)/a_n\to0$；再证 $\E T_n/a_n\to0$。
:::

### 第一部分：∑P(|X₁| ≥ aₙ) = ∞ ⇒ lim sup = ∞

**第 1 步（门槛放大 $k$ 倍，级数仍发散）**：固定正整数 $k$。由「先补基础」第 2 条，$a_{kn}\ge ka_n$，所以 $\{|X_1|\ge a_{kn}\}\subseteq\{|X_1|\ge ka_n\}$。又 $a_m$ 不减，$kn\le m<k(n+1)$ 时 $\P(|X_1|\ge a_m)\le\P(|X_1|\ge a_{kn})$，即一项 $\P(|X_1|\ge a_{kn})$ 不小于这 $k$ 项的平均。于是
$$
\sum_{n\ge1}\P(|X_1|\ge ka_n)\ge\sum_{n\ge1}\P(|X_1|\ge a_{kn})\ge\sum_{n\ge1}\frac1k\sum_{m=kn}^{kn+k-1}\P(|X_1|\ge a_m)=\frac1k\sum_{m\ge k}\P(|X_1|\ge a_m)=\infty,
$$
最后一步：发散级数去掉前 $k-1$ 项仍发散。

**第 2 步（BC II）**：事件 $A_n^{(k)}=\{|X_n|\ge ka_n\}$ 只依赖 $X_n$，相互独立；同分布给出 $\P(A_n^{(k)})=\P(|X_1|\ge ka_n)$，由第 1 步其和发散。由 BC II，$\P(A_n^{(k)}\ \text{i.o.})=1$。令 $\Omega^*=\bigcap_{k\ge1}\{A_n^{(k)}\ \text{i.o.}\}$，它是可数个概率 1 事件之交，$\P(\Omega^*)=1$。

**第 3 步（从单项到和）**：令 $S_0=0$。$X_n=S_n-S_{n-1}$，由三角不等式 $|X_n|\le|S_n|+|S_{n-1}|\le2\max(|S_n|,|S_{n-1}|)$。固定 $\omega\in\Omega^*$ 和 $k$，对无穷多个 $n\ge2$ 有 $|X_n|\ge ka_n$，于是 $|S_n|\ge\frac k2a_n$ 或 $|S_{n-1}|\ge\frac k2a_n\ge\frac k2a_{n-1}$（用 $a_{n-1}\le a_n$）。总之存在下标 $m\in\{n-1,n\}$ 使 $\frac{|S_m|}{a_m}\ge\frac k2$；$n$ 有无穷多个，这样的 $m$ 也有无穷多个，所以 $\limsup_m\frac{|S_m|}{a_m}\ge\frac k2$。

**第 4 步**：$k$ 任取，在 $\Omega^*$ 上 $\limsup|S_n|/a_n=\infty$。$\blacksquare$（这一部分没有用到 $\E|X_1|=\infty$。）

### 第二部分：∑P(|X₁| ≥ aₙ) < ∞ ⇒ Sₙ/aₙ → 0

记 $a_0=0$，$p_m=\P(a_{m-1}\le|X_1|<a_m)$。由恒等式 $(\ast)$ 和假设，
$$
\sum_{m\ge1}m\,p_m=1+\sum_{n\ge1}\P(|X_1|\ge a_n)<\infty .\qquad(\ast\ast)
$$

**第 1 步（截断只改动有限项）**：令 $Y_n=X_n\ind_{\{|X_n|<a_n\}}$，$T_n=Y_1+\dots+Y_n$。$\sum_n\P(X_n\ne Y_n)=\sum_n\P(|X_1|\ge a_n)<\infty$，由 BC I，几乎必然只有有限个 $n$ 使 $X_n\ne Y_n$。在这样的 $\omega$ 上，$S_n-T_n=\sum_{m\le n}(X_m-Y_m)$ 从某一项起不再变化，是一个固定的有限数 $R(\omega)$；$a_n\to\infty$，所以 $\frac{S_n-T_n}{a_n}\to0$。**只需证明 $\frac{T_n}{a_n}\to0$ 几乎必然。**

**第 2 步（方差可求和）**：$\operatorname{Var}\frac{Y_n}{a_n}\le\frac{\E Y_n^2}{a_n^2}$，且由同分布和 $a_0=0$，
$$
\E Y_n^2=\E\big[X_1^2\ind_{\{|X_1|<a_n\}}\big]=\sum_{m=1}^n\E\big[X_1^2\ind_{\{a_{m-1}\le|X_1|<a_m\}}\big].
$$
交换求和次序（各项非负）：
$$
\sum_{n\ge1}\frac{\E Y_n^2}{a_n^2}=\sum_{m\ge1}\E\big[X_1^2\ind_{\{a_{m-1}\le|X_1|<a_m\}}\big]\sum_{n\ge m}\frac1{a_n^2}.
$$
由「先补基础」第 3 条，$n\ge m$ 时 $a_n\ge\frac nma_m$，所以
$$
\sum_{n\ge m}\frac1{a_n^2}\le\frac{m^2}{a_m^2}\sum_{n\ge m}\frac1{n^2}\le\frac{m^2}{a_m^2}\cdot\frac2m=\frac{2m}{a_m^2},
$$
其中 $\sum_{n\ge m}\frac1{n^2}\le\frac2m$：$m=1$ 时左边 $=\frac{\pi^2}6<2$；$m\ge2$ 时 $\sum_{n\ge m}\frac1{n^2}\le\sum_{n\ge m}\big(\frac1{n-1}-\frac1n\big)=\frac1{m-1}\le\frac2m$。又在 $\{a_{m-1}\le|X_1|<a_m\}$ 上 $X_1^2<a_m^2$。合起来，由 $(\ast\ast)$，
$$
\sum_{n\ge1}\operatorname{Var}\frac{Y_n}{a_n}\le\sum_{m\ge1}a_m^2\,p_m\cdot\frac{2m}{a_m^2}=2\sum_{m\ge1}m\,p_m<\infty .
$$

**第 3 步（一级数定理 + Kronecker）**：$Z_n=\frac{Y_n-\E Y_n}{a_n}$ 独立、均值 0、$\sum\operatorname{Var}Z_n<\infty$（第 2 步）。由 Kolmogorov 一级数定理，$\sum_nZ_n$ 几乎必然收敛。对这样的 $\omega$，把 Kronecker 引理用在 $x_n=Y_n(\omega)-\E Y_n$ 上（$a_n\uparrow\infty$ 由「先补基础」第 1、5 条），得
$$
\frac{T_n-\E T_n}{a_n}=\frac1{a_n}\sum_{m=1}^n(Y_m-\E Y_m)\to0\qquad\text{几乎必然}.
$$

**第 4 步（$\frac{a_n}n\to\infty$：这里用到 $\E|X_1|=\infty$）**：$\frac{a_n}n$ 不减，若它有有限的极限 $c$，则 $a_n\le cn$，$\P(|X_1|\ge a_n)\ge\P(|X_1|\ge cn)$。由尾级数判别的缩放版本，$\sum_n\P(|X_1|\ge cn)=\infty$，与假设 $\sum_n\P(|X_1|\ge a_n)<\infty$ 矛盾。所以 $\frac{a_n}n\uparrow\infty$。

**第 5 步（均值项 $\frac{\E T_n}{a_n}\to0$）**：$|Y_m|<a_m$，$\E Y_m$ 有限，$|\E T_n|\le\sum_{m=1}^n\E\big[|X_1|\ind_{\{|X_1|<a_m\}}\big]$。固定正整数 $N$。对 $m\le n$（$a_m\le a_n$），把 $\{|X_1|<a_m\}$ 拆成 $\{|X_1|<a_N\}$ 和 $\{a_N\le|X_1|<a_n\}$ 两部分（$m\le N$ 时后一部分只会让上界更松）：
$$
\E\big[|X_1|\ind_{\{|X_1|<a_m\}}\big]\le a_N+\E\big[|X_1|\ind_{\{a_N\le|X_1|<a_n\}}\big].
$$
对 $m=1,\dots,n$ 求和并除以 $a_n$：
$$
\frac{|\E T_n|}{a_n}\le a_N\cdot\frac n{a_n}+\frac n{a_n}\E\big[|X_1|\ind_{\{a_N\le|X_1|<a_n\}}\big].
$$
- **第一项**：$N$ 固定，$a_N$ 是常数，由第 4 步 $\frac n{a_n}\to0$，所以它 $\to0$（$n\to\infty$）。
- **第二项**：把 $[a_N,a_n)$ 拆成 $[a_{m-1},a_m)$（$m=N+1,\dots,n$），并用 $\frac n{a_n}\le\frac m{a_m}$（「先补基础」第 4 条）和区间上 $|X_1|<a_m$：
$$
\frac n{a_n}\E\big[|X_1|\ind_{\{a_N\le|X_1|<a_n\}}\big]\le\sum_{m=N+1}^n\frac m{a_m}\E\big[|X_1|\ind_{\{a_{m-1}\le|X_1|<a_m\}}\big]\le\sum_{m>N}m\,p_m=:r_N .
$$
$r_N$ 是收敛级数 $(\ast\ast)$ 的尾巴，不依赖 $n$，且 $r_N\to0$（$N\to\infty$）。

所以 $\limsup_n\frac{|\E T_n|}{a_n}\le r_N$ 对每个 $N$ 成立；令 $N\to\infty$，$\frac{\E T_n}{a_n}\to0$。

**第 6 步（合起来）**：$\frac{S_n}{a_n}=\frac{S_n-T_n}{a_n}+\frac{T_n-\E T_n}{a_n}+\frac{\E T_n}{a_n}$，由第 1、3、5 步三项都几乎必然趋于 0，所以 $\frac{S_n}{a_n}\to0$，$\limsup\frac{|S_n|}{a_n}=0$。$\blacksquare$

**每个假设用在哪里**：

| 假设 | 用在 |
| --- | --- |
| 独立 | 第一部分 BC II；第二部分一级数定理 |
| 同分布 | 把所有概率、期望换成 $X_1$ 的 |
| $a_n/n$ 不减 | 第一部分第 1 步；第二部分第 2 步（$a_n\ge\frac nma_m$）、第 5 步（$\frac m{a_m}$ 不增） |
| $\E\lvert X_1\rvert=\infty$ | 只在第二部分第 4 步（$a_n/n\to\infty$） |

最后一行说明：若 $\E|X_1|<\infty$，第二部分可能失败。例：$X_i\equiv1$，$a_n=n$，$\sum\P(|X_1|\ge n)=1<\infty$，但 $S_n/n=1\not\to0$；问题正出在 $\frac{a_n}n=1$ 不趋于 $\infty$，均值项 $\frac{\E T_n}{a_n}$ 不趋于 0。

## 原解答逐行对照

3. 再加上均值条件 $\frac{\E T_n}{a_n}\to0$ 才得到 $\frac{T_n}{a_n}\to0$。

另外 $\sum_{i=1}^d$ 应为 $\sum_{i=1}^n$（$d$ 是笔误，第 6 题的原解答也有同样的笔误）。

**第 4–6 行（方差）**：$\sum_n\operatorname{Var}(\frac{Y_n}{a_n})\le\sum_n\frac{\E[Y_n^2]}{a_n^2}=\sum_m\int_{[a_{m-1},a_m)}y^2\dd F(y)\sum_{n\ge m}a_n^{-2}$；「since $a_n\ge\frac{na_m}m$, $\sum_{n\ge m}a_n^{-2}\le\frac{m^2}{a_m^2}\sum_{n\ge m}n^{-2}\le$ (sufficiently) $\frac m{a_m^2}$」；于是 $\sum_m\operatorname{Var}(\frac{Y_n}{a_n})\le$ (sufficiently) $\sum_mm\P(a_{m-1}\le|X_i|<a_m)=\sum_m\P(|X_i|>a_{m-1})<\infty$。

::: warn 原解答的问题：方差估计中的记号、常数与不等号
1. **$F$ 没有定义**：应为 $|X_1|$ 的分布函数（积分区间 $[a_{m-1},a_m)$ 指的是 $|X_1|$ 的取值）。还必须约定 $a_0=0$，否则 $m=1$ 的那一项没有意义。第一个等号是「拆分 + 交换求和次序」，要说明各项非负才能交换。

3. **从 $\int y^2\dd F$ 到 $m\P(\cdot)$ 用了 $y^2<a_m^2$**，原文没写。
4. **左边的求和下标**应为 $n$（$\sum_n\operatorname{Var}\frac{Y_n}{a_n}$），不是 $m$。
5. **最后的等号应为 $\sum_n\P(|X_1|\ge a_{n-1})$**（恒等式 $(\ast)$ 里是 $\ge$）。写成 $>$ 时右边变小，等号不再成立。它有限的理由也应写出：$=1+\sum_{n\ge1}\P(|X_1|\ge a_n)<\infty$。

**第 7 行**：「since $\E|X_i|=\infty$ and $\sum_n\P(|X_i|>a_n)<\infty$, we have $\frac{a_n}n\uparrow\infty$.」结论正确，理由（完整解答第 4 步的反证：否则 $a_n\le cn$，尾级数判别给出矛盾）没有写。

**第 8–9 行（均值）**：$\big|\frac1{a_n}\sum_{i=1}^d\E[Y_i]\big|\le\frac1{a_n}\sum_{i=1}^d\E[|X_m|\cdot1(|X_m|<a_m)]\le\frac{na_N}{a_n}+\frac n{a_n}\E[|X_1|\cdot1(a_N\le|X_1|\le a_n)]$；「If $N$ grows sufficiently slowly, the first term tends to 0」。

1. **下标混乱**：$\sum_{i=1}^d\E[|X_m|\cdots]$ 应为 $\sum_{m=1}^n\E\big[|X_m|\ind(|X_m|<a_m)\big]$。

3. **「$\le a_n$」应为「$<a_n$」**：$|X_m|<a_m\le a_n$；而且下一行把 $[a_N,a_n)$ 拆成 $[a_{m-1},a_m)$ 时，端点 $a_n$ 不在里面。
4. 下一行的 $\frac n{a_n}\E[\cdots]\le\sum_{m=N+1}^n\frac m{a_m}\E[\cdots]$ 用了 $\frac m{a_m}$ 不增（由 $\frac{a_m}m$ 不减），原文没说。

**第 10–11 行**：「Since $\sum_mm\P(a_{m-1}\le|X_1|<a_m)=\sum_n\P(|X_1|\ge a_{n-1})<\infty$, the latter tends to 0 as $N\to\infty$.」正确，就是恒等式 $(\ast\ast)$ 与「收敛级数的尾巴趋于 0」。恒等式本身（交换求和次序）原文没有证明。

## 例子与数值验证

::: ex 例 1：aₙ = n——回到作业 1 第 3 题，而且更强
$a_n=n$，$\frac{a_n}n=1$ 不减。$\E|X_1|=\infty$ 时由尾级数判别 $\sum_n\P(|X_1|\ge n)=\infty$，所以永远落在 $\infty$ 的情形：
$$
\limsup_n\frac{|S_n|}n=\infty\qquad\text{几乎必然}.
$$
[[hw1:p:3]] 只说「$S_n/n$ 没有有限极限」，这里说 $|S_n|/n$ 会无穷多次超过任何给定的数。第一部分的证明也就是第 3 讲 [[t3:p:13]]（单项 $|X_n|/n$）加上「从单项到和」的一步。
:::

::: ex 例 2：幂律尾部——分界线 c = 1/α，以及 Marcinkiewicz–Zygmund
设 $\P(|X_1|\ge x)=x^{-\alpha}$（$x\ge1$），$0<\alpha\le1$（$\E|X_1|=\infty$）。取 $a_n=n^c$，$c\ge1$：$\P(|X_1|\ge n^c)=n^{-c\alpha}$，级数收敛 $\iff c\alpha>1$。所以
$$
\limsup_n\frac{|S_n|}{n^c}=0\ (c>\tfrac1\alpha),\qquad=\infty\ (1\le c\le\tfrac1\alpha).
$$
例如 $\alpha=\frac12$：$S_n/n^{2.5}\to0$，但 $\limsup|S_n|/n^2=\infty$。和的「真实尺度」是 $n^{1/\alpha}$，恰好是单项最大值 $\max_{k\le n}|X_k|$ 的尺度（参照[[p:2]] 例 5 的 Pareto 分布）。

**一般推论**：对 $0<p<1$，取 $a_n=n^{1/p}$，$\sum_n\P(|X_1|\ge n^{1/p})=\sum_n\P(|X_1|^p\ge n)$，由尾级数判别它有限 $\iff\E|X_1|^p<\infty$。所以（$\E|X_1|=\infty$ 时）
$$
\frac{S_n}{n^{1/p}}\to0\ \text{几乎必然}\iff\E|X_1|^p<\infty .
$$
这就是 Marcinkiewicz–Zygmund 强大数定律在 $0<p<1$ 时的内容（Durrett 第 2.5 节讨论了这一族结论，$1<p<2$ 的情形另需 $\E X_1=0$）。
:::

::: ex 例 3：Cauchy 分布——在对数尺度上精确地分界
标准 Cauchy：$\P(|X_1|\ge x)=1-\frac2\pi\arctan x\approx\frac2{\pi x}$。
- $a_n=n\log(n+1)$：$\sum\P(|X_1|\ge a_n)\approx\sum\frac2{\pi n\log(n+1)}=\infty$，所以 $\limsup\frac{|S_n|}{n\log(n+1)}=\infty$。
- $a_n=n(\log(n+1))^2$：$\sum\frac2{\pi n\log^2(n+1)}<\infty$，所以 $\frac{S_n}{n\log^2(n+1)}\to0$。

有意思的是：$\frac{S_n}n$ 对每个 $n$ 都是标准 Cauchy（[[p:4]] 例 4），所以 $\frac{S_n}{n\log(n+1)}=\frac{S_n/n}{\log(n+1)}$ **依概率**趋于 0；可它的上极限几乎必然是 $\infty$。造成这件事的是极少数巨大的单项。用 Python 计算「$n\le N$ 中单项超过门槛的期望次数」$\sum_{n\le N}\P(|X_1|\ge a_n)$：

| $N$ | $10^3$ | $10^5$ | $10^7$ |
| --- | --- | --- | --- |
| $a_n=n$ | 4.59 | 7.52 | 10.45 |
| $a_n=n\log(n+1)$ | 2.08 | 2.40 | 2.62 |
| $a_n=n\log^2(n+1)$ | 1.44 | 1.48 | 1.49 |

第二行趋于无穷，但慢得惊人（大约按 $\frac2\pi\log\log N$ 增长），$10^7$ 步里平均也只有 2–3 次；第三行收敛（总和约 1.53）。所以这类结论很难靠模拟「看到」，必须靠证明。
:::

::: ex 例 4：模拟——同一个分布，两个尺度
取 $X=U^{-2}$（$U$ 均匀，$\P(X\ge x)=x^{-1/2}$，$\alpha=\frac12$）。用 Python 模拟 400 条路径（固定随机种子），在每个十倍区间 $(10^j,10^{j+1}]$ 上记录 $\max S_n/a_n$：

| 区间 | $(10^2,10^3]$ | $(10^3,10^4]$ | $(10^4,10^5]$ | $(10^5,10^6]$ |
| --- | --- | --- | --- | --- |
| $a_n=n^2$：中位数 | 32.2 | 30.8 | 23.5 | 30.2 |
| $a_n=n^2$：超过 10 的路径比例 | 0.72 | 0.71 | 0.71 | 0.73 |
| $a_n=n^{2.5}$：中位数 | 2.33 | 0.698 | 0.178 | 0.064 |
| $a_n=n^{2.5}$：超过 0.1 的路径比例 | 0.99 | 0.87 | 0.63 | 0.42 |

$a_n=n^{2.5}$ 时（级数 $\sum n^{-5/4}$ 收敛）每个区间的最大值稳定下降，大约每十倍缩小 3 倍：趋于 0。$a_n=n^2$ 时（级数 $\sum n^{-1}$ 发散）每个区间都有约 70% 的路径超过 10，不随区间衰减：比值永远不会安定下来，这与 $\limsup=\infty$ 一致（真正冲到无穷要非常长的时间，见例 3）。
:::

## 拓展延伸

::: more Kronecker 引理的证明：分部求和
令 $b_0=0$，$b_n=\sum_{m\le n}\frac{x_m}{a_m}\to b_\infty$（有限）。则 $x_m=a_m(b_m-b_{m-1})$，令 $a_0=0$，分部求和：
$$
\frac1{a_n}\sum_{m=1}^nx_m=\frac1{a_n}\sum_{m=1}^na_m(b_m-b_{m-1})=b_n-\frac1{a_n}\sum_{m=1}^n(a_m-a_{m-1})\,b_{m-1}.
$$
权重 $\frac{a_m-a_{m-1}}{a_n}\ge0$ 加起来等于 1，所以第二项是 $b_0,\dots,b_{n-1}$ 的加权平均。$a_n\to\infty$ 意味着任何固定的前几项权重都趋于 0，加权平均于是趋于 $b_\infty$。两项之差 $\to b_\infty-b_\infty=0$。
:::

::: more 一级数定理的证明：极大不等式 ⇒ 部分和是 Cauchy 列
令 $W_N=\sum_{n\le N}Z_n$。对 $M<N$，把极大不等式用在 $Z_{M+1},\dots,Z_N$ 上：
$$
\P\Big(\max_{M<k\le N}|W_k-W_M|\ge\eps\Big)\le\frac1{\eps^2}\sum_{n=M+1}^N\operatorname{Var}Z_n\le\frac1{\eps^2}\sum_{n>M}\operatorname{Var}Z_n .
$$
令 $N\to\infty$（事件递增，从下连续），左边趋于 $\P(\exists\,k>M:|W_k-W_M|\ge\eps)$；而 $\{\sup_{k>M}|W_k-W_M|>\eps\}$ 包含在这个事件里（上确界严格大于 $\eps$，就有某一项 $\ge\eps$），所以 $\P(\sup_{k>M}|W_k-W_M|>\eps)\le\eps^{-2}\sum_{n>M}\operatorname{Var}Z_n\to0$（$M\to\infty$）。记 $w_M=\sup_{j,k>M}|W_j-W_k|\le2\sup_{k>M}|W_k-W_M|$，它随 $M$ 递减到某个 $w_\infty$，且 $\P(w_\infty>2\eps)\le\P(w_M>2\eps)\le\P(\sup_{k>M}|W_k-W_M|>\eps)\to0$。$\eps$ 任意，$w_\infty=0$ 几乎必然，即部分和是 Cauchy 列，几乎必然收敛。

更一般的 **Kolmogorov 三级数定理**（Durrett 定理 2.5.8）给出独立级数 $\sum Z_n$ 几乎必然收敛的充要条件：对某个 $A>0$，$\sum\P(|Z_n|>A)$、$\sum\E[Z_n\ind_{\{|Z_n|\le A\}}]$、$\sum\operatorname{Var}(Z_n\ind_{\{|Z_n|\le A\}})$ 三个级数都收敛。本题第二部分的结构（截断概率可求和、均值项、方差项）正是它的影子。
:::

::: more 为什么只能是 0 或 ∞？0-1 律给出「常数」，本题给出「是哪个常数」
改动有限个 $X_i$，$S_n$ 只变一个固定的有限量，除以 $a_n\to\infty$ 后不影响上极限。所以 $L=\limsup|S_n|/a_n$ 是「尾随机变量」，由 Kolmogorov 0-1 律（Durrett 定理 2.5.3，[[quiz2:p:4]]）它几乎必然是一个常数（可以是 $\infty$）。0-1 律不告诉我们是哪个常数；本题说，均值无穷时这个常数**不可能**落在 $(0,\infty)$ 里。

对比均值有限、方差有限的情形：$\E X_1=0$，$\operatorname{Var}X_1=\sigma^2$ 时，**重对数律**（Hartman–Wintner，这里只介绍）给出 $\limsup\frac{S_n}{\sqrt{2n\log\log n}}=\sigma$，一个有限正数。均值无穷时没有这种「恰好合适」的尺度：和被少数巨大的项支配，尺度稍微小一点就是 $\infty$，稍微大一点就是 0。
:::

::: more 第二部分就是强大数定律的证明
若 $\E|X_1|<\infty$，同样的「截断 + 方差求和 + 一级数定理 + Kronecker」（取 $a_n=n$，截断 $Y_n=X_n\ind(|X_n|\le n)$）证明强大数定律 $\frac{S_n}n\to\E X_1$（Durrett 第 2.5 节给出的强大数定律的第二种证明）。区别在均值项：那里 $\frac{\E T_n}n\to\E X_1$（由控制收敛），而不是 0。
:::

## 常见疑问与易错点

::: warn 问：为什么一定要截断？直接对 Xₙ/aₙ 用一级数定理不行吗？
**答**：$\E|X_1|=\infty$，$X_n$ 的方差和均值都不存在，一级数定理无从用起。截断后 $Y_n$ 有界，所有矩都有；截断水平选 $a_n$，代价（$X_n\ne Y_n$）的概率之和恰好是题目假设里的级数，有限，BC I 说代价只付有限次。截断水平选得太低（例如固定常数），代价会付无穷多次；选得太高，方差和会发散。
:::

::: warn 问：0 的情形 Sₙ/aₙ → 0，是不是说 Sₙ 很小？
**答**：不是。$S_n$ 本身可以趋于无穷，而且增长得比 $n$ 快得多（均值无穷）。结论只说 $a_n$ 增长得更快。例 2 中 $\alpha=\frac12$ 时 $S_n$ 大约是 $n^2$ 的量级，$S_n/n^{2.5}\to0$ 只说明它比 $n^{2.5}$ 小。
:::

::: warn 问：第一部分里，为什么不能只看 k = 1？
**答**：$k=1$ 只给出 $|X_n|\ge a_n$ 无穷多次，从而 $\limsup|S_n|/a_n\ge\frac12$，是一个有限的下界。要得到 $\infty$，必须对每个 $k$ 都有 $|X_n|\ge ka_n$ 无穷多次；第 1 步的不等式 $\sum\P(|X_1|\ge ka_n)\ge\frac1k\sum_{m\ge k}\P(|X_1|\ge a_m)$ 正是为此准备的，它用到 $a_{kn}\ge ka_n$，即 $\frac{a_n}n$ 不减。
:::

::: warn 问：既然 Sₙ/(n log n) 对 Cauchy 依概率趋于 0，为什么上极限却是 ∞？
**答**：依概率收敛只看每个固定时刻（第 3 讲 [[t3:p:14]]）：$\frac{S_n}{n\log(n+1)}$ 大的概率趋于 0。上极限看整条路径：只要单项 $|X_n|\ge kn\log(n+1)$ 无穷多次发生（概率之和发散，独立，BC II），路径就会无穷多次冲高。两者并不矛盾，这和打字机序列（第 3 讲 [[t3:p:15]]）是同一种现象。
:::

## 小结与自测

::: sum 本题小结
- 结论：i.i.d.，$\E|X_1|=\infty$，$\frac{a_n}n$ 不减，则 $\limsup|S_n|/a_n$ 几乎必然为 0 或 $\infty$，按 $\sum\P(|X_1|\ge a_n)$ 有限或无穷而定。
- $\infty$：$\sum\P(|X_1|\ge ka_n)\ge\frac1k\sum_{m\ge k}\P(|X_1|\ge a_m)=\infty$，BC II 给出 $|X_n|\ge ka_n$ 无穷多次，再用 $|X_n|\le|S_n|+|S_{n-1}|$。
- 0：截断 $Y_n=X_n\ind(|X_n|<a_n)$（BC I 只改动有限项）；$\sum\operatorname{Var}(Y_n/a_n)\le2\sum mp_m<\infty$；一级数定理 + Kronecker 给出 $(T_n-\E T_n)/a_n\to0$；$a_n/n\to\infty$（这里用 $\E|X_1|=\infty$）给出 $\E T_n/a_n\to0$。
- 原解答：照搬 Durrett，但「为什么检查这两件事就够」（一级数定理、Kronecker、截断只改有限项）没有说明；$d$ 应为 $n$；$F$、$a_0$ 未定义；「(sufficiently)」应为常数 2；$>$ 应为 $\ge$；$N$ 应先固定再趋于无穷。
:::

::::quiz 自测
**1.** 设 $\P(|X_1|\ge x)=x^{-1/2}$（$x\ge1$）。求 $\limsup|S_n|/n^3$ 和 $\limsup|S_n|/n^2$。

:::answer
$\sum\P(|X_1|\ge n^3)=\sum n^{-3/2}<\infty$，所以 $\limsup|S_n|/n^3=0$（$S_n/n^3\to0$）。$\sum\P(|X_1|\ge n^2)=\sum n^{-1}=\infty$，所以 $\limsup|S_n|/n^2=\infty$。两个尺度都满足 $\frac{a_n}n$ 不减。
:::

**2.** 判断：若 $\E|X_1|=\infty$，则对任何满足 $\frac{a_n}n$ 不减的 $a_n$，$S_n/a_n$ 都不收敛到 0。

:::answer
错误。第 1 题就是反例：$a_n=n^3$ 时 $S_n/a_n\to0$。$\E|X_1|=\infty$ 只排除了 $a_n=n$（以及 $a_n/n$ 有界）的情形：那时 $\sum\P(|X_1|\ge a_n)\ge\sum\P(|X_1|\ge cn)=\infty$。
:::

**3.** 第二部分第 5 步里，为什么要先固定 $N$、让 $n\to\infty$，再让 $N\to\infty$？

:::answer
第一项 $a_N\frac n{a_n}$ 只有在 $a_N$ 固定时才能由 $\frac n{a_n}\to0$ 推出趋于 0；第二项的界 $r_N$ 不依赖 $n$，只有让 $N\to\infty$ 才变小。所以先对固定 $N$ 得到 $\limsup_n\frac{|\E T_n|}{a_n}\le r_N$，左边不依赖 $N$，再令 $N\to\infty$。原解答「$N$ grows sufficiently slowly」是让 $N$ 随 $n$ 变化，这也能做，但它没有说明 $N$ 怎样选，两个极限的关系就没交代清楚。
:::
