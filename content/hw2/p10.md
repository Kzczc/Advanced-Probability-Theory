## 这道题在问什么

::: idea 一句话版
$Y_1,Y_2,\dots$ 独立、均值 0、方差都是 $\sigma^2$，部分和 $S_n=Y_1+\cdots+Y_n$。$S_n$ 本身是鞅（公平游戏），但 $S_n^2$ **不是**：平均来说它每一步增长 $\sigma^2$。把这个确定的增长扣掉，$X_n=S_n^2-n\sigma^2$ 就成了鞅。它说明「随机游走离原点的平方距离，平均按时间线性增长」，是计算停时期望（例如赌徒破产的平均局数，[[p:12]]）的关键工具。
:::

- **考点**：验证鞅的三条性质；条件期望的「已知量提出」和「独立量等于普通期望」两条规则。
- **讲义里没有讲过**：条件期望与鞅，见「先补基础」（[[p:12]] 有更详细的说明）。
- **和其他题的关系**：第 12 题的 $N_n=S_n^2-n$ 是本题 $\sigma^2=1$ 的特例；[[p:9]] 用到的 Kolmogorov 极大不等式，背后正是 $S_n^2$ 的这种结构。

## 先补基础

::: basics 条件期望与鞅（简要回顾）
$\F_n=\sigma(Y_1,\dots,Y_n)$。$\E[Z\mid\F_n]$ 是已知前 $n$ 步时对 $Z$ 的最佳猜测（这里作为已知结论使用，详见[[p:12]]）。本题只用三条规则：
1. **线性**；
2. **已知的可以提出来**：$W$ 关于 $\F_n$ 可测时，$\E[WZ\mid\F_n]=W\,\E[Z\mid\F_n]$（只要 $WZ$、$Z$ 可积）；
3. **独立的等于普通期望**：$Z$ 与 $\F_n$ 独立时，$\E[Z\mid\F_n]=\E Z$。

**鞅**：适应（$X_n$ 由前 $n$ 步决定）、可积、$\E[X_{n+1}\mid\F_n]=X_n$。
:::

::: basics 独立随机变量和的方差
$Y_j$ 独立、均值 0 时，$\E S_n^2=\operatorname{Var}S_n=\sum_{j=1}^n\operatorname{Var}Y_j=n\sigma^2$。理由：展开平方，交叉项 $\E[Y_iY_j]=\E Y_i\,\E Y_j=0$（$i\ne j$，第 4 讲 [[t4:p:10]] 的推论）。所以 $\E X_n=\E S_n^2-n\sigma^2=0$：本题的鞅从 0 出发，期望始终为 0。
:::

## 题目与原解答

::: original 题目
10. Let $(Y_n\mid n\ge1)$ be a sequence of independent random variables with mean 0 and variance $\sigma^2$. Show that
$$
\Big(X_n:=\Big(\sum_{j=1}^nY_j\Big)^2-n\sigma^2\ \Big|\ n\ge1\Big)
$$
is a martingale.
:::

::: zh
10. 设 $(Y_n)_{n\ge1}$ 是一列独立的随机变量，均值都是 0，方差都是 $\sigma^2$。证明 $X_n:=\big(\sum_{j=1}^nY_j\big)^2-n\sigma^2$（$n\ge1$）是鞅。
:::

- 「鞅」总是相对于某个 σ-代数流说的，这里取自然的 $\F_n=\sigma(Y_1,\dots,Y_n)$（原解答也是这样取的）。
- $Y_n$ 只要求独立、均值 0、方差相同，**不要求同分布**。

**原解答的思路**（左栏）：把 $X_{n+1}$ 写成 $S_n^2+2Y_{n+1}S_n+Y_{n+1}^2-(n+1)\sigma^2$；由独立性 $\E[Y_{n+1}\mid\F_n]=0$、$\E[Y_{n+1}^2\mid\F_n]=\sigma^2$，逐项取条件期望得到 $X_n$。原解答的计算是正确的，只是没有验证鞅定义中的「适应」和「可积」两条，也没有说明每一步用的是哪条规则。

## 思路：怎么想到的

- $S_{n+1}=S_n+Y_{n+1}$：明天的位置 = 今天的位置 + 一个与过去无关、均值 0 的增量。
- 平方后多出两项：交叉项 $2S_nY_{n+1}$（今天已知 × 明天的增量，条件期望为 0）和 $Y_{n+1}^2$（条件期望为 $\sigma^2$）。
- 所以 $S_n^2$ 每一步平均增加 $\sigma^2$，扣掉 $n\sigma^2$ 就平衡了。

::: fig 图解：一团越摊越开的「云」
想象很多个独立的随机游走同时从原点出发，第 $n$ 步时把它们的位置画成一团点云：
- 云的**中心**一直在原点（$\E S_n=0$，$S_n$ 是鞅）；
- 云的**宽度**（标准差）是 $\sigma\sqrt n$，越来越宽，所以平方距离的平均 $\E S_n^2=n\sigma^2$ 线性增长；
- $X_n=S_n^2-n\sigma^2$ 量的是「这一条路径比云的平均宽度偏离得多还是少」，它的平均值始终是 0。

步数翻 4 倍，云只宽 2 倍：这就是随机游走的 $\sqrt n$ 尺度律。
:::

## 完整解答

记 $S_n=\sum_{j=1}^nY_j$，$\F_n=\sigma(Y_1,\dots,Y_n)$，$X_n=S_n^2-n\sigma^2$。

**第 1 步（适应）**：$X_n$ 是 $Y_1,\dots,Y_n$ 的连续函数，关于 $\F_n$ 可测。

**第 2 步（可积）**：$\E|X_n|\le\E S_n^2+n\sigma^2=2n\sigma^2<\infty$（用了「独立随机变量和的方差」）。

**第 3 步（展开）**：
$$
X_{n+1}=(S_n+Y_{n+1})^2-(n+1)\sigma^2=S_n^2+2S_nY_{n+1}+Y_{n+1}^2-n\sigma^2-\sigma^2 .
$$

**第 4 步（逐项取条件期望）**：
- $\E[S_n^2\mid\F_n]=S_n^2$：$S_n^2$ 已知（规则 2）。
- $\E[S_nY_{n+1}\mid\F_n]=S_n\,\E[Y_{n+1}\mid\F_n]=S_n\,\E Y_{n+1}=0$：先把已知的 $S_n$ 提出来（规则 2；$S_nY_{n+1}$ 可积，因为由 Cauchy–Schwarz，$\E|S_nY_{n+1}|\le\sqrt{\E S_n^2\,\E Y_{n+1}^2}<\infty$），再用 $Y_{n+1}$ 与 $\F_n$ 独立（规则 3）。
- $\E[Y_{n+1}^2\mid\F_n]=\E Y_{n+1}^2=\sigma^2$：$Y_{n+1}^2$ 与 $\F_n$ 独立（规则 3）；均值 0 时 $\E Y_{n+1}^2=\operatorname{Var}Y_{n+1}=\sigma^2$。

**第 5 步（合起来）**：
$$
\E[X_{n+1}\mid\F_n]=S_n^2+0+\sigma^2-n\sigma^2-\sigma^2=S_n^2-n\sigma^2=X_n .
$$
三条性质都满足，$(X_n)$ 是关于 $(\F_n)$ 的鞅。$\blacksquare$

## 原解答逐行对照

1. **「we need to verify the martingale property $\E[X_{n+1}\mid\F_n]=X_n$ where $\F_n$ is the σ-algebra generated by $Y_1,\dots,Y_n$」**：鞅的定义还要求适应和可积，原解答只验证了第三条。本题中前两条很容易（上面第 1、2 步），但考试时最好写出来。
2. **展开 $X_{n+1}$ 的三行**：正确。
3. **「Since $Y_{n+1}$ is independent of $\F_n$, it implies $\E[Y_{n+1}\mid\F_n]=0$, $\E[Y_{n+1}^2\mid\F_n]=\sigma^2$」**：正确，用的是规则 3。
4. **「$=\big(\sum Y_j\big)^2+2\E[Y_{n+1}\mid\F_n]\sum Y_j+\E[Y_{n+1}^2\mid\F_n]-(n+1)\sigma^2$」**：这一步把已知的 $\sum_{j\le n}Y_j$ 从条件期望里提了出来（规则 2），原解答没有点明。
5. 最后得到 $X_n$。正确。

::: warn 原解答的小问题：没有验证适应性和可积性
鞅的定义有三条。可积性在这里需要方差有限：如果 $Y_j$ 的方差是无穷，$S_n^2$ 不可积，$X_n$ 根本没有定义。题目给了方差 $\sigma^2$，所以没有问题，但应该写出 $\E|X_n|\le2n\sigma^2$。
:::

## 例子与数值验证

::: ex 例 1：简单随机游走
$Y_j=\pm1$ 各以概率 $\frac12$（$\sigma^2=1$）：$S_n^2-n$ 是鞅。例如 $n=2$：$S_2\in\{-2,0,2\}$，概率 $\frac14,\frac12,\frac14$，$\E S_2^2=4\cdot\frac14\cdot2=2$，$\E X_2=2-2=0$。
:::

::: ex 例 2：不同分布、同一方差
$Y_j$ 交替地取「$\pm1$ 各半」和「$(-\sqrt3,\sqrt3)$ 上的均匀分布」（两者方差都是 1）。它们独立、不同分布，本题结论照样成立。电脑模拟 $Y_j$ 全取 $(-\sqrt3,\sqrt3)$ 上的均匀分布，$n=20$，10 万次：$\E X_{20}$ 的估计约为 $0.04$，与理论值 0 相差在随机误差之内：$X_{20}$ 的标准差可以算出约为 $27.9$，10 万次平均的误差约为 $27.9/\sqrt{10^5}\approx0.09$。
:::

::: ex 例 3：去掉独立性，结论可能失败
设 $Y_1=\pm1$ 各半；$\eps=\pm1$ 各半且与 $Y_1$ 独立；$Y_2=\sqrt2\,\eps\,\ind_{\{Y_1=1\}}$。
- $\E Y_2=0$，$\operatorname{Var}Y_2=2\cdot\frac12=1$，$\E[Y_1Y_2]=0$：均值 0、方差 1、与 $Y_1$ 不相关。
- 但 $\E[Y_2^2\mid\F_1]=2\ind_{\{Y_1=1\}}$，不是常数 1。于是
$$
\E[X_2\mid\F_1]=Y_1^2+2\ind_{\{Y_1=1\}}-2=\begin{cases}1, & Y_1=1,\\-1, & Y_1=-1,\end{cases}
$$
而 $X_1=Y_1^2-1=0$。$X_n$ **不是**鞅。原因：$Y_2$ 的「波动大小」依赖于 $Y_1$，不独立。
:::

## 拓展延伸

::: more 方差不同的情形与 Doob 分解
若 $Y_j$ 独立、均值 0、方差 $\sigma_j^2$ 各不相同，同样的计算给出：$S_n^2-\sum_{j=1}^n\sigma_j^2$ 是鞅。

更一般地，任何（平方可积的）鞅 $S_n$ 都有 **Doob 分解**：$S_n^2=(\text{鞅})+A_n$，其中 $A_n=\sum_{j\le n}\E[(S_j-S_{j-1})^2\mid\F_{j-1}]$ 是一个**可预测的递增过程**，叫 $S$ 的「二次变差的补偿子」。本题中 $A_n=n\sigma^2$ 是确定的；例 3 中 $A_2=1+2\ind_{\{Y_1=1\}}$ 是随机的，所以要扣掉的不再是 $2$。
:::

::: more 应用：离开区间要多长时间
简单随机游走从 0 出发，$T=\inf\{n:|S_n|=a\}$。对 $S_n^2-n$ 用可选停止定理（与[[p:12]] 同样的有界性论证）：$\E S_T^2-\E T=0$，而 $S_T^2=a^2$，所以 $\E T=a^2$。模拟（4 万次）：$a=3$ 时 $9.03$，$a=5$ 时 $25.04$，$a=10$ 时 $99.5$，与 $a^2$ 吻合。走出距离 $a$ 平均需要 $a^2$ 步，这就是「扩散」的尺度律。
:::

::: more 应用：Kolmogorov 极大不等式
对独立、均值 0、方差有限的 $Y_j$，
$$
\P\Big(\max_{k\le n}|S_k|\ge\lambda\Big)\le\frac{\operatorname{Var}S_n}{\lambda^2}.
$$
它比 Chebyshev 强：控制的是整条路径的最大值，而不只是终点。证明的关键是 $S_k^2$ 是下鞅（期望只增不减），本题的鞅 $S_n^2-n\sigma^2$ 正是这一结构的精确版本。[[p:9]] 会用到这个不等式。
:::

## 常见疑问与易错点

::: warn 问：为什么 Sₙ² 不是鞅？
**答**：$\E[S_{n+1}^2\mid\F_n]=S_n^2+\sigma^2>S_n^2$：平方距离平均每步增加 $\sigma^2$，它是一个**下鞅**（submartingale），不是鞅。直观上，随机游走越走越远，平方距离的期望线性增长。
:::

::: warn 问：只要 Yⱼ 两两不相关就够了吗？
**答**：不够（例 3）。需要的是 $\E[Y_{n+1}\mid\F_n]=0$ 和 $\E[Y_{n+1}^2\mid\F_n]=\sigma^2$。独立性保证了这两条；不相关只保证无条件的二阶矩关系。
:::

::: warn 问：σ² = 0 时会怎样？
**答**：方差为 0 且均值为 0，每个 $Y_j=0$ 几乎必然，$X_n=0$，平凡的鞅。
:::

## 小结与自测

::: sum 本题小结
- $X_{n+1}=S_n^2+2S_nY_{n+1}+Y_{n+1}^2-(n+1)\sigma^2$；交叉项条件期望为 0，$Y_{n+1}^2$ 的条件期望为 $\sigma^2$，所以 $\E[X_{n+1}\mid\F_n]=X_n$。
- 鞅定义的三条都要验证：适应、可积（$\E|X_n|\le2n\sigma^2$）、鞅性质。
- 独立性不能换成不相关（例 3）；方差不同时扣掉 $\sum\sigma_j^2$（Doob 分解）。
- 应用：随机游走离开 $(-a,a)$ 的平均时间是 $a^2$；赌徒破产的平均局数（第 12 题）。
:::

::::quiz 自测
**1.** $Y_j$ 独立，$\P(Y_j=2)=\P(Y_j=-2)=\frac12$。哪个过程是鞅：$S_n^2-n$、$S_n^2-2n$、$S_n^2-4n$？

:::answer
$\sigma^2=\E Y_j^2=4$，所以 $S_n^2-4n$ 是鞅。
:::

**2.** 简单随机游走从 0 出发，求离开 $(-4,4)$（第一次 $|S_n|=4$）的平均步数。

:::answer
$\E T=a^2=16$。
:::

**3.** 若 $Y_j$ 独立、均值 0、$\operatorname{Var}Y_j=j$，写出一个由 $S_n^2$ 构造的鞅。

:::answer
$S_n^2-\sum_{j=1}^nj=S_n^2-\frac{n(n+1)}{2}$。
:::
