## 这道题在问什么

::: idea 一句话版
$X_n$ 只取 0 和 1，取 1 的概率是 $p_n$。「依概率收敛到 0」只看**每一项单独**取 1 的概率，所以它等价于 $p_n\to0$；「几乎必然收敛到 0」要求**每条路径上只出现有限个 1**，这由两个 Borel–Cantelli 引理精确判定：$\sum p_n<\infty$ 时只有有限个 1（第一引理），$\sum p_n=\infty$ 且独立时有无穷多个 1（第二引理）。$p_n=\frac1n$ 夹在两者之间：依概率收敛，却几乎必然不收敛。
:::

- **考点**：依概率收敛的定义（第 3 讲 [[t3:p:14]] 定义 10）；几乎必然收敛与误差事件（第 3 讲 [[t3:p:9]] 命题 B）；两个 Borel–Cantelli 引理（第 3 讲 [[t3:p:4]]、[[t3:p:7]]）。
- **这道题的意义**：它给出「依概率收敛但不几乎必然收敛」的最简单的例子，也是[[quiz2:p:1]] 里的第二个反例。而且它说明：两种收敛的差距，恰好是「$p_n\to0$」与「$\sum p_n<\infty$」的差距。
- **和其他题的关系**：[[p:2]]、[[p:5]] 同样是「第一引理管有限次、第二引理（加独立）管无穷多次」。本题的独立性只在 (ii) 的一个方向上用到，例 4 说明去掉它会怎样。

## 先补基础

::: basics 伯努利随机变量就是示性函数
- **伯努利随机变量**（Bernoulli random variable）：只取 1 和 0 的随机变量，$\P(X=1)=p$，$\P(X=0)=1-p$。可以想成一枚「正面概率为 $p$」的硬币，正面记 1。
- 记 $A=\{X=1\}$，则 $X=\ind_A$：$\omega\in A$ 时为 1，否则为 0。所以关于 $X$ 的问题都可以换成关于事件 $A$ 的问题。
- 本题第 $n$ 枚硬币的正面概率是 $p_n$，可以随 $n$ 变化。例如 $p_n=\frac1n$：第 1 枚必出正面，第 2 枚一半一半，第 100 枚只有 1% 的机会出正面。
:::

::: basics 依概率收敛（第 3 讲 p14）
$X_n\to X$ **依概率**（in probability），是说对**每个** $\eps>0$，
$$
\P\big(|X_n-X|>\eps\big)\to0\qquad(n\to\infty).
$$
人话：对任何容忍度 $\eps$，「误差超过 $\eps$」的概率越来越小。它只看每个 $n$ 单独的概率，**不关心**同一个 $\omega$ 在不同 $n$ 上的表现。例：$X_n$ 在 $[0,1]$ 上均匀分布再除以 $n$，$\P(X_n>\eps)=\max(1-n\eps,0)\to0$，所以 $X_n\to0$ 依概率。
:::

::: basics 几乎必然收敛，以及 0-1 数列什么时候收敛到 0
- $X_n\to0$ **几乎必然**：$\P(\{\omega:X_n(\omega)\to0\})=1$（第 3 讲 [[t3:p:9]] 定义 6）。等价说法（同页命题 B）：对每个 $\eps>0$，$\P(|X_n|>\eps\ \text{i.o.})=0$。
- **只取 0、1 的数列** $a_1,a_2,\dots$ 收敛到 0，当且仅当其中**只有有限个 1**。理由：若有无穷多个 1，则 $|a_n-0|=1$ 无穷多次，不收敛；若只有有限个 1，最后一个 1 之后全是 0，当然收敛到 0。
- 例：$1,0,1,0,1,0,\dots$ 不收敛；$1,1,0,1,0,0,0,\dots$（第 4 项以后全是 0）收敛到 0。
:::

::: basics 两个 Borel–Cantelli 引理（回顾）
- **第一引理**（第 3 讲 [[t3:p:4]] 定理 2）：$\sum_n\P(A_n)<\infty\Rightarrow\P(A_n\ \text{i.o.})=0$。对任何事件列成立，**不需要独立**。
- **第二引理**（第 3 讲 [[t3:p:7]] 定理 4）：$A_n$ **相互独立**且 $\sum_n\P(A_n)=\infty\Rightarrow\P(A_n\ \text{i.o.})=1$。
- $X_n$ 相互独立时，事件 $A_n=\{X_n=1\}=\{X_n\in\{1\}\}$ 相互独立（第 3 讲 [[t3:p:6]] 补充定义，$\{1\}$ 是博雷尔集）。
:::

::: basics 级数：各项趋于 0 不等于和有限
- 若 $\sum_np_n<\infty$，则 $p_n\to0$：部分和 $s_n=p_1+\cdots+p_n$ 收敛，$p_n=s_n-s_{n-1}\to0$。
- 反过来不对：**调和级数** $\sum_n\frac1n=\infty$，虽然 $\frac1n\to0$。部分和大约是 $\ln n+0.577$：Python 算得 $\sum_{n\le10^6}\frac1n\approx14.39$，增长极慢但没有上限。
- **$p$-级数**：$\sum_n\frac1{n^s}<\infty\iff s>1$。所以 $\sum\frac1{n^2}=\frac{\pi^2}{6}$ 有限，$\sum\frac1{\sqrt n}=\infty$。
- 更细的分界：$\sum_{n\ge2}\frac{1}{n\ln n}=\infty$，$\sum_{n\ge2}\frac{1}{n(\ln n)^2}<\infty$（用积分 $\int\frac{\dd x}{x\ln x}=\ln\ln x$、$\int\frac{\dd x}{x(\ln x)^2}=-\frac1{\ln x}$ 比较）。
:::

## 题目与原解答

::: original 题目
4. Let $X_1,X_2,\dots$ be independent with $\P(X_n=1)=p_n$ and $\P(X_n=0)=1-p_n$. Show that

(i) $X_n\to0$ in probability if and only if $p_n\to0$, and

(ii) $X_n\to0$ a.s. if and only if $\sum p_n<\infty$.
:::

::: zh
4. 设 $X_1,X_2,\dots$ 相互独立，$\P(X_n=1)=p_n$，$\P(X_n=0)=1-p_n$。证明：

(i) $X_n\to0$ 依概率成立，当且仅当 $p_n\to0$；

(ii) $X_n\to0$ 几乎必然成立，当且仅当 $\sum p_n<\infty$。
:::

- 题设的「independent」只在 (ii) 的「⇒」方向用到；(i) 和 (ii) 的「⇐」对任何相关结构都成立。
- 结论 (ii) 里的「⇒」是说：几乎必然收敛 ⇒ 级数有限。通常证它的逆否命题：级数无穷 ⇒ 不几乎必然收敛。

**原解答的思路**（左栏）：

1. (i)：$0<\eps<1$ 时 $\P(|X_n|>\eps)=p_n$，所以依概率收敛 $\iff p_n\to0$；
2. (ii)：令 $A_n=\{|X_n|>\eps\}$，则 $\P(A_n\ \text{i.o.})=0\iff\sum\P(A_n)=\sum p_n<\infty$，并注明「⇒」用了独立性。

结论都对，但写得太省：没有交代 $\eps\ge1$ 的情形，没有说明「几乎必然收敛」和「$\P(A_n\ \text{i.o.})=0$」为什么等价，也没有点明两个方向分别用哪个引理。见「原解答逐行对照」。

## 思路：怎么想到的

1. **0-1 变量的误差事件只有一个**。$X_n$ 只取 0、1，所以对 $0<\eps<1$，「$|X_n|>\eps$」就是「$X_n=1$」，和 $\eps$ 无关；对 $\eps\ge1$，它是空集。于是所有问题都归结为事件 $A_n=\{X_n=1\}$。
2. **(i) 只看单个概率**：依概率收敛就是 $\P(A_n)=p_n\to0$。
3. **(ii) 看「发生几次」**：路径收敛到 0 ⟺ 只有有限个 1 ⟺ $\omega\notin\{A_n\ \text{i.o.}\}$。于是几乎必然收敛 ⟺ $\P(A_n\ \text{i.o.})=0$，而这个概率正是 Borel–Cantelli 引理计算的对象：和有限时为 0，和无穷且独立时为 1。

## 完整解答

::: thm 命题（独立伯努利序列的两种收敛）
设 $X_1,X_2,\dots$ 相互独立，$\P(X_n=1)=p_n=1-\P(X_n=0)$。则

1. $X_n\to0$ 依概率 $\iff p_n\to0$（不需要独立）；
2. $X_n\to0$ 几乎必然 $\iff\sum_np_n<\infty$（「⇐」不需要独立）。

而且 $\P(X_n\to0)$ 只能是 0 或 1：$\sum p_n<\infty$ 时为 1，$\sum p_n=\infty$ 时为 0。
:::

::: proof 证明思路
先把误差事件 $\{|X_n|>\eps\}$ 算出来：$0<\eps<1$ 时就是 $A_n=\{X_n=1\}$，$\eps\ge1$ 时是空集。(i) 直接由定义得到。(ii) 先证 $\{X_n\to0\}=\{A_n\ \text{i.o.}\}^c$，再用第一引理（⇐）和第二引理的逆否（⇒）。
:::

**预备：误差事件。** 令 $A_n=\{X_n=1\}$。因为 $X_n$ 只取 0、1：
- 若 $0<\eps<1$：$|X_n|>\eps\iff X_n=1$，所以 $\{|X_n|>\eps\}=A_n$，$\P(|X_n|>\eps)=p_n$；
- 若 $\eps\ge1$：$|X_n|\le1\le\eps$ 总成立，所以 $\{|X_n|>\eps\}=\varnothing$，概率为 0。

### (i) 依概率收敛 ⇔ pₙ → 0

- **（⇐）** 设 $p_n\to0$。任给 $\eps>0$：若 $\eps<1$，$\P(|X_n|>\eps)=p_n\to0$；若 $\eps\ge1$，$\P(|X_n|>\eps)=0$。所以对每个 $\eps$ 都趋于 0，即 $X_n\to0$ 依概率。
- **（⇒）** 设 $X_n\to0$ 依概率。在定义中取 $\eps=\frac12$：$p_n=\P(|X_n|>\frac12)\to0$。

整个过程只用了每个 $X_n$ 自己的分布，**没有用独立性**。

### (ii) 几乎必然收敛 ⇔ ∑ pₙ < ∞

**第 1 步：收敛集就是「只有有限个 1」。** 固定 $\omega$。数列 $X_1(\omega),X_2(\omega),\dots$ 只取 0、1，由「先补基础」，它收敛到 0 当且仅当只有有限个 $n$ 使 $X_n(\omega)=1$，即 $\omega\notin\{A_n\ \text{i.o.}\}$。所以
$$
\{X_n\to0\}=\{A_n\ \text{i.o.}\}^c,\qquad\P(X_n\to0)=1-\P(A_n\ \text{i.o.}).
$$

**第 2 步（⇐，不需要独立）。** 设 $\sum_np_n<\infty$，即 $\sum_n\P(A_n)<\infty$。由第一 Borel–Cantelli 引理，$\P(A_n\ \text{i.o.})=0$，所以 $\P(X_n\to0)=1$。

**第 3 步（⇒，用独立性）。** 证逆否命题：设 $\sum_np_n=\infty$。$X_n$ 相互独立，所以事件 $A_n=\{X_n\in\{1\}\}$ 相互独立；又 $\sum_n\P(A_n)=\infty$。由第二 Borel–Cantelli 引理，$\P(A_n\ \text{i.o.})=1$，所以 $\P(X_n\to0)=0\ne1$，$X_n$ 不几乎必然收敛到 0。

**第 4 步：结论。** 第 2、3 步合起来就是 (ii)；顺便得到 $\P(X_n\to0)$ 只能是 1（级数有限）或 0（级数无穷）。$\blacksquare$

**第 1 步的另一种写法（用命题 B）**：由第 3 讲 [[t3:p:9]] 命题 B，$X_n\to0$ a.s. ⟺ 对每个 $\eps>0$，$\P(|X_n|>\eps\ \text{i.o.})=0$。由预备，$\eps\ge1$ 时事件是空集，自动成立；$0<\eps<1$ 时事件都是同一个 $\{A_n\ \text{i.o.}\}$。所以条件化为一句话：$\P(A_n\ \text{i.o.})=0$。

## 原解答逐行对照

**(i)** *For $0<\eps<1$, $\P(|X_n|>\eps)=p_n\to0\iff p_n\to0$.*

想说的是：$0<\eps<1$ 时误差概率就是 $p_n$，所以「误差概率趋于 0」等价于「$p_n\to0$」。

::: warn 原解答的问题：(i) 漏了 ε ≥ 1，而且写法像循环论证
- 依概率收敛要求**每个** $\eps>0$。原解答只讨论了 $0<\eps<1$，应补一句：$\eps\ge1$ 时 $\{|X_n|>\eps\}=\varnothing$，概率恒为 0，自动趋于 0。
- 「$=p_n\to0\iff p_n\to0$」把要证的结论写在了等价号两边，读起来像「$A\iff A$」。应写成：$X_n\to0$ 依概率 $\iff$ 对每个 $\eps\in(0,1)$，$\P(|X_n|>\eps)\to0$ $\iff p_n\to0$（第一个等价用了 $\eps\ge1$ 的情形自动成立，第二个等价用了 $\P(|X_n|>\eps)=p_n$）。
:::

**(ii)** *Let $A_n=\{|X_n|>\eps\}$. Then, $\P(A_n\ \text{i.o.})=0\iff\sum_{n=1}^\infty\P(A_n)=\sum_{n=1}^\infty p_n<\infty$.*

想说的是：用两个引理判定 $\P(A_n\ \text{i.o.})$。

::: warn 原解答的问题：ε 没有限定，也没说明 a.s. 收敛为什么等价于 P(Aₙ i.o.) = 0
- 这里的 $\eps$ 必须取在 $(0,1)$ 里。若 $\eps\ge1$，$A_n=\varnothing$，$\sum\P(A_n)=0$，等价式的右边永远成立，和 $p_n$ 无关。
- 原解答直接写「$\P(A_n\ \text{i.o.})=0\iff\cdots$」，却没说明左边为什么等价于「$X_n\to0$ a.s.」。需要补：0-1 数列收敛到 0 ⟺ 只有有限个 1（完整解答第 1 步），或者用命题 B 并指出 $A_n$ 对所有 $\eps\in(0,1)$ 是同一个事件。
- 等价号的两个方向用的是不同的引理：「⇐」是第一引理（不需要独立），「⇒」是第二引理的逆否命题（需要独立）。应当分开写。
:::

**Note** *Note that ($\Rightarrow$) holds since $X_n$'s are independent.*

方向标注是对的：在「$\P(A_n\ \text{i.o.})=0\Rightarrow\sum p_n<\infty$」这个方向上，要用第二引理的逆否命题，所以需要独立。最好写全：「若 $\sum p_n=\infty$，由独立性和第二 Borel–Cantelli 引理，$\P(A_n\ \text{i.o.})=1\ne0$」。

## 例子与数值验证

::: ex 例 1：几种 pₙ 一览
| $p_n$ | $p_n\to0$？ | $\sum p_n$ | 依概率收敛到 0 | 几乎必然收敛到 0 |
| --- | --- | --- | --- | --- |
| $\frac12$ | 否 | $\infty$ | 否 | 否 |
| $\frac1{\sqrt n}$ | 是 | $\infty$ | 是 | 否 |
| $\frac1n$ | 是 | $\infty$ | 是 | 否 |
| $\frac{1}{n\ln n}$（$n\ge2$） | 是 | $\infty$ | 是 | 否 |
| $\frac{1}{n(\ln n)^2}$（$n\ge2$） | 是 | 有限 | 是 | 是 |
| $\frac1{n^2}$ | 是 | $\frac{\pi^2}{6}$ | 是 | 是 |

读表：几乎必然收敛的分界线落在 $\frac{1}{n\ln n}$ 与 $\frac{1}{n(\ln n)^2}$ 之间，非常精细；依概率收敛的分界线只是「趋于 0」。$\sum_{n\ge2}\frac1{n\ln n}$ 发散得比调和级数还慢：Python 算得到 $10^3$ 时部分和约 $2.73$，到 $10^7$ 时也只有约 $3.57$，大致像 $\ln\ln n$ 那样增长，但没有上限。
:::

::: ex 例 2：pₙ = 1/n，一条路径上的 1 越来越稀，但永不消失
Python 模拟一条路径，前 $10^6$ 项中 $X_n=1$ 的位置是
$$
1,\ 4,\ 7,\ 25,\ 33,\ 38,\ 115,\ 1208,\ 8256,\ 8546,\ 27637,\ 44397,
$$
共 12 个（理论平均 $\sum_{n\le10^6}\frac1n\approx14.39$ 个）。相邻两个 1 之间的间隔越来越长，可按第二引理，几乎每条路径上的 1 都有无穷多个。另一方面，任意固定的 $n$，$\P(X_n=1)=\frac1n$ 都很小，这就是依概率收敛。

一个精确的计算：从第 $m$ 项到第 $M$ 项全是 0 的概率是 $\prod_{n=m}^{M}\big(1-\frac1n\big)=\prod_{n=m}^{M}\frac{n-1}{n}=\frac{m-1}{M}$（相邻项约掉），$M\to\infty$ 时趋于 0：再长的「全 0」都会被打断。
:::

::: ex 例 3：pₙ = 1/n²，最后一个 1 出现在哪里
从第 $m$ 项（$m\ge2$）起全是 0 的概率：
$$
\prod_{n\ge m}\Big(1-\frac1{n^2}\Big)=\prod_{n\ge m}\frac{(n-1)(n+1)}{n\cdot n}=\frac{m-1}{m}.
$$
所以「最后一个 1 的位置 $\le m-1$」的概率是 $\frac{m-1}{m}$。注意 $p_1=1$，第 1 项必为 1。Python 模拟 2 万条路径（每条看前 2000 项）：最后一个 1 就是第 1 项的比例为 $0.504$（理论 $\frac12$），最后一个 1 在前 9 项的比例为 $0.902$（理论 $\frac{9}{10}$）。

注意「最后一个 1」可以很晚：由上式，$\P(\text{最后一个 1 的位置}\ge k)=\frac1k$，只是以 $\frac1k$ 的速度变小。所以 2 万条路径里，平均约有 $20000\times\frac1{2001}\approx10$ 条路径的最后一个 1 落在第 2000 项**之后**，前 2000 项的模拟看不到它们（模拟中「看得见的」最晚一个 1 在第 1893 项，就是被这个观察窗口截住的）。尽管如此，每条路径都只有有限个 1，几乎必然收敛。
:::

::: ex 例 4（反例）：去掉独立，(ii) 的「⇒」失败
设 $U$ 在 $(0,1)$ 上均匀，令 $X_n=\ind_{\{U<1/n\}}$。
- **边缘分布和例 2 完全一样**：$\P(X_n=1)=\P(U<\frac1n)=\frac1n$，$\sum p_n=\infty$。
- **但几乎必然收敛到 0**：$X_n(\omega)=1\iff n<1/U(\omega)$。对固定的 $\omega$，满足这个条件的 $n$ 只有有限个（最后一个是 $\lfloor1/U(\omega)\rfloor$，当 $1/U(\omega)$ 不是整数时）。例如 $U(\omega)=0.247$ 时，$1/U\approx4.04$，只有 $X_1,\dots,X_4$ 是 1。所以每个 $\omega$ 上 $X_n(\omega)\to0$。
- 证明坏在第 3 步：事件 $\{U<\frac1n\}$ 一个套一个，不独立，第二引理用不上。
- 对照[[quiz2:p:1]] 的**打字机序列**：它也是 $p_n\to0$、$\sum p_n=\infty$（第 $m$ 层的 $2^m$ 项各为 $2^{-m}$），却是**每个** $\omega$ 都碰到无穷多个 1。同样的边缘分布，可以「全收敛」也可以「全不收敛」：**只知道每个 $p_n$，判断不了几乎必然收敛；独立性把联合结构定死了，才有本题的判别法。**
:::

## 拓展延伸

::: more 推广：独立序列几乎必然收敛到 0 的判别法
同样的论证对一般的独立随机变量成立：
$$
X_n\ \text{独立}:\qquad X_n\to0\ \text{a.s.}\iff\text{对每个}\ \eps>0,\ \sum_n\P(|X_n|>\eps)<\infty .
$$
「⇐」是第 3 讲 [[t3:p:10]] 推论 7（偏差概率可求和），不需要独立；「⇒」：若某个 $\eps$ 使级数发散，独立 + 第二引理给出 $|X_n|>\eps$ 无穷多次（概率 1），不可能收敛到 0。本题的 0-1 变量是最简单的特例，因为它的误差事件不依赖 $\eps$。
:::

::: more Lᵖ 收敛和子列
- $\E|X_n|^p=\P(X_n=1)=p_n$，所以对任何 $p>0$，$X_n\to0$ 在 $L^p$ 中 $\iff p_n\to0\iff$ 依概率收敛。
- 依概率收敛的序列一定有几乎必然收敛的子列（第 3 讲 [[t3:p:16]]）。在 $p_n=\frac1n$ 时可以直接看出来：取子列 $n_k=k^2$，$\sum_kp_{k^2}=\sum_k\frac1{k^2}<\infty$，由第一引理，$X_{k^2}\to0$ a.s.。整个序列不收敛，但抽稀之后就收敛了。
:::

::: more 0-1 律
本题的副产品「$\P(X_n\to0)\in\{0,1\}$」是 **Kolmogorov 0-1 律**的特例（这里作为已知结论介绍，见 Durrett《Probability: Theory and Examples》第 2.5 节）：独立序列的尾事件（改动有限项不影响其是否发生的事件）概率只能是 0 或 1。$\{X_n\to0\}$ 就是尾事件。0-1 律只告诉我们「是 0 或 1」，Borel–Cantelli 引理则告诉我们「到底是哪一个」。
:::

## 常见疑问与易错点

::: warn 问：(i) 用到独立性了吗？
**答**：没有。依概率收敛只涉及每个 $n$ 单独的概率 $\P(|X_n|>\eps)$，与 $X_n$ 之间的关系无关。例 4 中的 $X_n=\ind_{\{U<1/n\}}$ 不独立，(i) 照样成立。
:::

::: warn 问：∑pₙ = ∞ 时，Xₙ 只是「不几乎必然收敛到 0」，还是「几乎必然不收敛」？
**答**：后者，而且更强：几乎每条路径上都有无穷多个 1。若再有 $p_n\to0$，则 $\sum(1-p_n)=\infty$，同样由第二引理，几乎每条路径上也有无穷多个 0，所以路径在 0、1 之间无穷次跳动，根本不收敛（到任何数）。
:::

::: warn 问：为什么说两种收敛的差距就是「pₙ → 0」和「∑pₙ < ∞」的差距？
**答**：由本题，依概率收敛 ⟺ $p_n\to0$，几乎必然收敛 ⟺ $\sum p_n<\infty$。级数有限 ⇒ 各项趋于 0，所以几乎必然收敛 ⇒ 依概率收敛（与第 3 讲 [[t3:p:14]] 命题 11 一致）；反过来，$p_n=\frac1n$ 各项趋于 0 而级数发散，正好是依概率收敛而不几乎必然收敛。
:::

::: warn 问：如果 pₙ 不单调（比如忽大忽小），结论还对吗？
**答**：对。证明里从没用到单调性。例如 $p_n=\frac1n$（$n$ 是完全平方数）、$p_n=\frac1{n^2}$（其他 $n$）：$\sum_np_n\le\sum_k\frac1{k^2}+\sum_n\frac1{n^2}<\infty$，所以几乎必然收敛。
:::

## 小结与自测

::: sum 本题小结
- 0-1 变量的误差事件：$0<\eps<1$ 时是 $\{X_n=1\}$，$\eps\ge1$ 时是空集。
- (i) 依概率收敛 ⟺ $p_n\to0$，不需要独立。
- (ii) 收敛集 $=\{X_n=1\ \text{i.o.}\}^c$；$\sum p_n<\infty$ ⇒ 第一引理 ⇒ a.s. 收敛（不需要独立）；$\sum p_n=\infty$ + 独立 ⇒ 第二引理 ⇒ $\P(X_n\to0)=0$。
- 去掉独立，(ii) 的「⇒」失败（$X_n=\ind_{\{U<1/n\}}$）。
- 原解答要补的地方：$\eps\ge1$ 的情形；$\eps$ 要限定在 $(0,1)$；「a.s. 收敛 ⟺ $\P(A_n\ \text{i.o.})=0$」的理由；两个方向分别用哪个引理。
:::

::::quiz 自测
**1.** $X_n$ 独立，$p_n=\frac{1}{\sqrt n}$。$X_n$ 依概率收敛到 0 吗？几乎必然呢？

:::answer
依概率收敛：$p_n=\frac1{\sqrt n}\to0$。不几乎必然收敛：$\sum_n\frac1{\sqrt n}=\infty$（$p$-级数，$s=\frac12\le1$），由独立性和第二引理，$X_n=1$ 无穷多次（概率 1）。
:::

**2.** $X_n$ 独立，$p_n=\frac{1}{n^{1.01}}$。$X_n$ 几乎必然收敛到 0 吗？记 $E_m$ 为「从第 $m$ 项起全是 0」，$\P(E_m)$ 在 $m\to\infty$ 时趋于多少？

:::answer
几乎必然收敛到 0：$\sum_np_n<\infty$（$p$-级数，$s=1.01>1$），由第一引理，几乎每条路径只有有限个 1。$E_m$ 随 $m$ 递增（从第 $m$ 项起全是 0，从第 $m+1$ 项起当然也全是 0），并起来是「只有有限个 1」，概率为 1。由从下连续（第 1 讲 [[t1:p:13]]），$\P(E_m)\to1$。
:::

**3.** 设 $U$ 在 $(0,1)$ 上均匀，$X_n=\ind_{\{U<p_n\}}$，$p_n\to0$。证明 $X_n\to0$ a.s.，不管 $\sum p_n$ 是否有限。这和本题矛盾吗？

:::answer
取 $\omega$ 使 $U(\omega)>0$（概率 1）。$p_n\to0$，所以 $n$ 足够大时 $p_n<U(\omega)$，此后 $X_n(\omega)=0$，收敛到 0。不矛盾：这些 $X_n$ 不独立（$p_n$ 递减时事件一个套一个），本题 (ii) 的「⇒」方向需要独立。
:::
