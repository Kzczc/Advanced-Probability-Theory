## 这道题在问什么

::: idea 一句话版
$f_n\to f$ 逐点收敛，积分不一定跟着收敛：质量可能「越来越窄、越来越高」地挤在一个点附近，最后在极限里消失。Fatou 引理说积分**只会在极限处变小**：$\int f\le\liminf\int f_n$。所以真正的危险是 $\int f_n$ **太大**。三个附加条件里，只有 (iii)「$f_n\le f$」从上面把 $\int f_n$ 压住了，因此只有 (iii) 成立；(i)、(ii) 都可以举出反例。
:::

- **考点**：Fatou 引理（第 1 讲 [[t1:p:41]]）、单调收敛定理 MCT（[[t1:p:36]]）、控制收敛定理 DCT（[[t1:p:44]]）各自的条件；尖峰反例（[[t1:p:39]]）。
- **题型**：判断题。「成立」要给证明，「不成立」要给**一个**具体反例，并逐条验证反例满足题目的全部条件。
- **和其他题的关系**：[[p:10]] 是推广的 DCT：控制函数也可以随 $n$ 变。本题 (iii) 是另一种推广：控制函数 $f$ 甚至可以不可积。

## 先补基础

::: basics 三个收敛定理各要什么条件
设 $f_n\ge0$ 可测，$f_n\to f$ 逐点。
- **Fatou 引理**（[[t1:p:41]]）：**没有额外条件**，总有 $\int\liminf_nf_n\le\liminf_n\int f_n$。逐点收敛时 $\liminf_nf_n=f$，所以 $\int f\le\liminf_n\int f_n$。
- **MCT**（[[t1:p:36]]）：$0\le f_1\le f_2\le\cdots$ **递增**，则 $\int f_n\to\int f$（允许 $=\infty$）。
- **DCT**（[[t1:p:44]]）：存在**可积**的 $g$ 使 $|f_n|\le g$，则 $\int f_n\to\int f$。

**记忆方法**：Fatou 只给下界。要得到收敛，还需要一个上界：MCT 用的是「$f_n\le f$」（递增序列自动满足），DCT 用的是「$f_n\le g$ 且 $\int g<\infty$」。
:::

::: basics 非负函数积分的单调性与 ∞
- $0\le u\le v$ 处处成立，则 $\int u\le\int v$（第 1 讲 [[t1:p:33]]）。
- 非负函数的积分可以是 $+\infty$。例：$\int_0^1\frac1x\dd x=\infty$，因为对任何 $\eps\in(0,1)$，$\int_\eps^1\frac1x\dd x=\ln\frac1\eps$，$\eps\to0$ 时趋于 $\infty$。
- 「$\int f_n\to\int f$」也允许两边都是 $\infty$：例如 $\int f_n\to\infty=\int f$ 也算收敛。
:::

::: basics 尖峰：逐点趋于 0，积分却始终是 1
$h_n=n\ind_{(0,1/n)}$ 是一个宽 $\frac1n$、高 $n$ 的矩形，面积 $\int h_n=1$。对每个固定的 $x\in(0,1]$，只要 $n>\frac1x$，$x$ 就不在 $(0,\frac1n)$ 里，$h_n(x)=0$；在 $x=0$ 处 $h_n(0)=0$（开区间不含 0）。所以 $h_n\to0$ 逐点，但 $\int h_n=1\not\to0$（第 1 讲 [[t1:p:39]]）。质量全部挤向 $x=0$，在极限里「消失」了。
:::

## 题目与原解答

::: original 题目
11. Let $f$ and $f_n$, $n=1,2,\dots$, be non-negative measurable functions on $[0,1]$ such that $f_n\to f$ pointwise. Under each of the following additional assumptions, either prove that $\int_{[0,1]}f\dd\mu\to\int_{[0,1]}f\dd\mu$ or given a counter example to show that this is not generally true.

(i) $f_n\ge f$ and $\int_{[0,1]}|f_n|\dd\mu<\infty$ for all $n$.

(ii) $f_n\ge f_{n+1}$ for all $n$.

(iii) $f_n\le f$ for all $n$.
:::

::: zh
11. 设 $f$ 和 $f_n$（$n=1,2,\dots$）是 $[0,1]$ 上的非负可测函数，$f_n\to f$ 逐点成立。在下列每个附加条件下，或者证明 $\int_{[0,1]}f_n\dd\mu\to\int_{[0,1]}f\dd\mu$，或者举出反例说明这一般不成立。

(i) 对所有 $n$，$f_n\ge f$ 且 $\int_{[0,1]}|f_n|\dd\mu<\infty$。

(ii) 对所有 $n$，$f_n\ge f_{n+1}$（递减）。

(iii) 对所有 $n$，$f_n\le f$。
:::

- 原题的「prove that $\int f\dd\mu\to\int f\dd\mu$」是笔误，应为 $\int f_n\dd\mu\to\int f\dd\mu$；「given」应为「give」。
- $\mu$ 是 $[0,1]$ 上的 Lebesgue 测度。

**原解答的思路**（左栏）：(i) 不成立，反例 $f_n=n\ind_{(0,1/n)}$、$f=0$。(ii) 不成立，反例 $f_n(x)=\frac1{nx}$、$f=0$（每个 $\int f_n=\infty$）。(iii) 成立：由 $f_n\le f$ 得 $\limsup\int f_n\le\int f$，由 Fatou 得 $\int f\le\liminf\int f_n$。三问的结论都对；(ii) 的反例在 $x=0$ 处需要补一个定义，(iii) 少了最后一句结论。

## 思路：怎么想到的

- **先问 Fatou 给了什么**：任何情况下都有 $\int f\le\liminf\int f_n$。所以只需检查：附加条件能不能挡住 $\int f_n$ 偏大。
- **(i)**：$f_n\ge f$ 是**下界**，和 Fatou 同一个方向，挡不住 $\int f_n$ 偏大。「每个 $\int f_n$ 有限」也挡不住：尖峰的积分始终是 1，有限但不趋于 0。
- **(ii)**：递减的 $f_n$ 若有一个 $\int f_N<\infty$，那么 $f_N$ 就是可积的控制函数，DCT 给出收敛。所以反例必须让**每个** $\int f_n=\infty$，而极限 $f$ 的积分有限。$\frac1{nx}$ 正好如此：在 $0$ 附近不可积，乘上 $\frac1n$ 也救不回来。
- **(iii)**：$f_n\le f$ 是**上界**，与 Fatou 的下界合起来夹住 $\int f_n$。

::: fig 图解：积分从哪一边「漏掉」
（描述）把 $\int f_n$ 画成数轴上的一列点，把 $\int f$ 画成一个固定点。
- Fatou：这列点最终不会明显落到 $\int f$ **左边**（$\liminf\int f_n\ge\int f$）。
- (iii) 的条件 $f_n\le f$：每个点都在 $\int f$ **左边或正好在上面**。左右两边都被挡住，点列只能收敛到 $\int f$。
- (i)、(ii)：点可以一直停在 $\int f$ **右边**。(i) 的尖峰停在 1，而 $\int f=0$；(ii) 的点停在 $\infty$，而 $\int f=0$。
:::

## 完整解答

**(i) 不成立。** 取 $f=0$，$f_n=n\ind_{(0,1/n)}$。逐条验证：
- 非负可测：$f_n$ 是可测集的示性函数乘以常数。
- $f_n\to f$ 逐点：见「先补基础」的尖峰。
- $f_n\ge f=0$；$\int|f_n|=n\cdot\frac1n=1<\infty$。
- 结论不成立：$\int f_n=1$ 对所有 $n$ 成立，而 $\int f=0$。

**(ii) 不成立。** 取 $f=0$，$f_n(x)=\frac1{nx}$（$0<x\le1$），$f_n(0)=0$。逐条验证：
- 非负可测：在 $(0,1]$ 上连续，在单点 $0$ 处取 0。
- 递减：$\frac1{nx}\ge\frac1{(n+1)x}$；在 $0$ 处都是 0。
- $f_n\to0$ 逐点：固定 $x\in(0,1]$，$\frac1{nx}\to0$；$x=0$ 处恒为 0。
- 结论不成立：$\int f_n=\frac1n\int_0^1\frac1x\dd x=\infty$ 对所有 $n$ 成立，而 $\int f=0$。

**(iii) 成立。** 设 $0\le f_n\le f$ 且 $f_n\to f$ 逐点。
- **上界**：由积分的单调性，$\int f_n\le\int f$ 对每个 $n$ 成立，所以 $\limsup_n\int f_n\le\int f$。
- **下界**：$f_n\to f$ 逐点，所以 $\liminf_nf_n=f$。由 Fatou 引理，$\int f=\int\liminf_nf_n\le\liminf_n\int f_n$。
- **合起来**：$\int f\le\liminf_n\int f_n\le\limsup_n\int f_n\le\int f$，四个量全相等，所以 $\lim_n\int f_n$ 存在且等于 $\int f$。
- 这里允许 $\int f=\infty$：此时由下界，$\liminf\int f_n\ge\infty$，即 $\int f_n\to\infty=\int f$。$\blacksquare$

## 原解答逐行对照

1. **「(i) False: $f_n(x)=n1_{(0,1/n)}$ and $f=0$.」**：反例正确。最好写出验证：逐点收敛（$x=0$ 处用到开区间）、$f_n\ge f$、$\int f_n=1$。
2. **「(ii) False: $f_n(x)=\frac1{nx}$ and $f=0$. (Note that $\int_0^1f_n\dd\mu=\infty$ for all $n$.)」**：反例的思路正确。小问题：$\frac1{n\cdot0}$ 没有定义。若约定 $f_n(0)=+\infty$，则 $f_n(0)\not\to0=f(0)$，「逐点收敛」在 $x=0$ 处失败。所以应规定 $f_n(0)=0$（或任何趋于 $f(0)$ 的值）。单点是零测集，不影响积分。
3. **「(iii) True. $f$ might not be integrable, DCT is not applicable.」**：正确而且重要。若 $\int f<\infty$，$f$ 就是可积的控制函数，直接用 DCT；但题目没有保证这一点。
4. **「we can compute that $\int f_n\le\int f$, then $\limsup_n\int f_n\le\int f$」**：正确（积分的单调性）。
5. **「Moreover, by Fatou's Lemma $\int f=\int\liminf f_n\le\liminf\int f_n$」**：正确，用到 $\liminf f_n=f$（逐点收敛）。
6. **缺的一句**：应写出「所以 $\liminf=\limsup=\int f$，$\int f_n\to\int f$」，并指出 $\int f=\infty$ 时同样成立。

::: warn 原解答的小问题
- 题目里「$\int f\dd\mu\to\int f\dd\mu$」是笔误，应为 $\int f_n\to\int f$。
- (ii) 的反例在 $x=0$ 处没有定义，要补上 $f_n(0)=0$。
- (iii) 最后没有写出结论，也没有说明 $\int f=\infty$ 的情形。
:::

## 例子与数值验证

::: ex 例 1：(ii) 的积分真的是 ∞
截掉 $0$ 附近：$\int_\eps^1\frac1{nx}\dd x=\frac1n\ln\frac1\eps$。$n=100$ 时：$\eps=10^{-3}$ 得 $0.069$，$\eps=10^{-9}$ 得 $0.207$，$\eps=10^{-100}$ 得 $2.30$。$\eps\to0$ 时趋于 $\infty$，增长极慢，但没有上界。所以无论 $n$ 多大，$\int f_n=\infty$。
:::

::: ex 例 2：(ii) 加上 ∫f₁ < ∞ 就成立
$f_n(x)=\frac{x}{n}$：递减，$\to0$ 逐点，$\int f_1=\frac12<\infty$。$0\le f_n\le f_1$，$f_1$ 可积，DCT 给出 $\int f_n=\frac1{2n}\to0$。一般地，递减序列只要**某一个** $\int f_N<\infty$ 就成立（从第 $N$ 项起用 $f_N$ 作控制函数）。所以 (ii) 的反例**必须**让每个 $\int f_n=\infty$。
:::

::: ex 例 3：(iii) 中 ∫f = ∞ 的情形
$f(x)=\frac1x$（$f(0)=0$），$f_n=\min(f,n)$。$0\le f_n\le f$，$f_n\uparrow f$ 逐点。计算：
$$
\int f_n=\int_0^{1/n}n\dd x+\int_{1/n}^1\frac1x\dd x=1+\ln n .
$$
$n=10,100,1000$ 时分别是 $3.30$、$5.61$、$7.91$，趋于 $\infty=\int f$。DCT 用不了（$f$ 不可积），但 (iii) 的结论照样成立。
:::

::: ex 例 4：(iii) 不要求单调
$f\equiv1$，$f_n=1-\ind_{(\frac1{n+1},\frac1n)}$：在一个越来越窄、向 0 移动的小区间上挖掉。每个 $x$ 至多被挖一次，所以 $f_n(x)\to1$ 逐点，但对固定的 $x$，$f_n(x)$ 不单调（先是 1，某一步变成 0，再变回 1），MCT 用不上。$f_n\le f$，所以 (iii) 适用：$\int f_n=1-\big(\frac1n-\frac1{n+1}\big)$，$n=1,2,5,10$ 时为 $0.5$、$0.833$、$0.967$、$0.991$，趋于 $1=\int f$。
:::

## 拓展延伸

::: more 统一的观点：Fatou + 上界 = 收敛
三个经典定理可以统一地看成「Fatou 给下界，再找一个上界」：
- **MCT**：$f_n\uparrow f$ 自动满足 $f_n\le f$，是 (iii) 的特例。
- **DCT**：对 $g-f_n\ge0$ 和 $g+f_n\ge0$ 各用一次 Fatou（[[p:10]] 的写法），需要 $\int g<\infty$ 才能把 $\int g$ 从两边消掉。
- **(iii)**：上界直接来自 $f_n\le f$，所以 $f$ 不可积也没关系。

反过来，(i)、(ii) 失败的原因都是：附加条件只提供下界（(ii) 中递减也意味着 $f_n\ge f$），与 Fatou 同方向，没有上界。
:::

::: more 递减序列的单调收敛定理
若 $f_1\ge f_2\ge\cdots\ge0$、$f_n\to f$，且 $\int f_1<\infty$，则 $\int f_n\to\int f$。证明：$f_1-f_n\ge0$ 递增到 $f_1-f$，对它用 MCT，得 $\int(f_1-f_n)\to\int(f_1-f)$；因为 $\int f_1<\infty$，两边可以减去 $\int f_1$。(ii) 的反例说明，条件「$\int f_1<\infty$」不能去掉：没有它，就会出现「$\infty-\infty$」。
:::

::: more (i) 加什么条件就成立：Scheffé 引理
(i) 的情形下，Fatou 已给出 $\int f\le\liminf\int f_n$。如果再知道 $\int f_n\to\int f<\infty$，能推出更强的 $\int|f_n-f|\to0$：这就是 Scheffé 引理（第 3 讲 [[t3:p:22]]）。在 (i) 的条件 $f_n\ge f$ 下，这一步是显然的：$\int|f_n-f|=\int(f_n-f)=\int f_n-\int f\to0$。
:::

::: more 概率里的对应：期望不一定随随机变量收敛
把 $[0,1]$ 看成概率空间，$f_n$ 看成随机变量 $X_n$：(i) 的尖峰就是 $X_n=n\ind_{\{U<1/n\}}$（$U$ 是均匀分布），$X_n\to0$ 几乎必然，但 $\E X_n=1$（第 3 讲 [[t3:p:19]]）。概率论中保证 $\E X_n\to\E X$ 的标准条件是**一致可积**；有界、被可积变量控制、$\sup_n\E X_n^2<\infty$ 都是它的充分条件。
:::

## 常见疑问与易错点

::: warn 问：(iii) 为什么不能直接用 DCT？
**答**：DCT 要求控制函数**可积**。$f$ 可能不可积（例 3：$f=\frac1x$），这时 DCT 不适用，只能用 Fatou + 单调性。$\int f<\infty$ 时两种方法都可以。
:::

::: warn 问：(i) 的条件「∫|fₙ| < ∞」难道没用？
**答**：它保证每个 $\int f_n$ 是有限数，但不能阻止它们一直比 $\int f$ 大一截。尖峰的积分始终等于 1：有限，但不趋于 0。要阻止这种情况，需要「同一个」可积函数控制所有 $f_n$（DCT），或一致可积。
:::

::: warn 问：反例是不是越简单越好？
**答**：是，但必须逐条验证题目的**全部**条件：非负、可测、逐点收敛（包括端点 $x=0$）、附加条件。原解答 (ii) 的反例就在 $x=0$ 处漏了定义。
:::

## 小结与自测

::: sum 本题小结
- Fatou 永远给出下界 $\int f\le\liminf\int f_n$；收敛与否取决于有没有上界。
- (i) 不成立：尖峰 $n\ind_{(0,1/n)}$，积分恒为 1。
- (ii) 不成立：$\frac1{nx}$（规定 $f_n(0)=0$），积分恒为 $\infty$。反例必须让每个 $\int f_n=\infty$。
- (iii) 成立：$\int f_n\le\int f$（上界）加 Fatou（下界），$\int f=\infty$ 也成立，不需要 $f$ 可积，不需要单调。
:::

::::quiz 自测
**1.** 在 (ii) 的条件下再加上 $\int f_5<\infty$。$\int f_n\to\int f$ 是否成立？

:::answer
成立。$n\ge5$ 时 $0\le f_n\le f_5$，$f_5$ 可积，由 DCT（或递减版本的 MCT），$\int f_n\to\int f$。前面有限项不影响极限。
:::

**2.** 举一个满足 $f_n\ge f$、$\int f_n<\infty$、$f_n\to f$ 逐点，且 $\int f_n\to\infty$ 的例子。

:::answer
$f=0$，$f_n=n^2\ind_{(0,1/n)}$：逐点趋于 0，$\int f_n=n\to\infty$。
:::

**3.** 设 $0\le f_n\le f$，$f_n\to f$ 逐点，$\int f=5$。$\int f_n$ 的极限是多少？若只知道 $f_n\ge f$ 呢？

:::answer
前者：由 (iii)，极限是 5。后者：只能由 Fatou 得 $\liminf\int f_n\ge5$，极限可能不存在，也可能大于 5（在 $f$ 上叠加一个尖峰即可）。
:::
