## 这道题在问什么

::: idea 一句话版
一致可积（上一题 [[p:2]]）还有另一种等价说法，由两个条件组成：(i) **总量一致有界**：所有 $\E|X_t|$ 都不超过同一个常数；(ii) **一致绝对连续**：只要事件 $F$ 的概率足够小（小于同一个 $\delta$），**所有**成员在 $F$ 上的贡献 $\E[|X_t|\ind_F]$ 都很小。前者说「没有成员太大」，后者说「没有成员能把质量集中在小概率事件上」。
:::

- **考点**：在两种「一致」的说法之间来回翻译。⇒ 方向把 $\E[|X_t|\ind_F]$ 拆成「$|X_t|$ 不大」和「$|X_t|$ 很大」两部分；⇐ 方向用 Markov 不等式说明「$|X_t|$ 很大」本身就是一个小概率事件。
- **和讲义的关系**：Markov 不等式（第 2 讲 [[t2:p:29]]）；单个可积函数的绝对连续性（[[hw1:p:8]]，那是本题只有一个成员时的情形）。
- **为什么有用**：条件 (ii) 常常比原定义更容易验证；它也是 Vitali 收敛定理证明里真正用到的性质。

## 先补基础

::: basics 一致可积（回顾上一题）
$\{X_t\}$ UI：对任意 $\eps>0$，存在 $\lambda$，使对**所有** $t$，$\E\big[|X_t|\ind_{\{|X_t|>\lambda\}}\big]\le\eps$。
:::

::: basics 把期望按事件拆开
对任意事件 $A$，$\ind_A+\ind_{A^c}=1$，所以 $\E[Y]=\E[Y\ind_A]+\E[Y\ind_{A^c}]$。本题反复用 $A=\{|X_t|\le\lambda\}$ 来拆：「小的部分」和「大的部分」分开估计。
:::

::: basics 绝对连续：单个变量的情形
若 $\E|X|<\infty$，则对任意 $\eps>0$，存在 $\delta>0$，使 $\P(F)<\delta$ ⇒ $\E[|X|\ind_F]<\eps$（[[hw1:p:8]]）。意思是：可积变量不能在一个很小的事件上积累很多期望。「一致」绝对连续要求同一个 $\delta$ 对所有成员管用。
:::

## 题目与原解答

::: original 题目
3. Proof the statement: A family $\{X_t:t\in T\}$ of integrable random variables defined on some probability space $(\Omega,\F,\P)$ is uniformly integrable (UI) if and only if the following two statements hold true.

(i) The family $X_t$ is bounded in $L^1$.

(ii) For any $\eps>0$, there exists $\delta>0$ such that
$$
\text{for any }F\in\F,\ \P(F)<\delta\ \text{then}\ \E\big[|X_t|\ind_F\big]<\eps\quad\text{for all }t\in T.
$$
:::

::: zh
3. 证明：概率空间 $(\Omega,\F,\P)$ 上的一族可积随机变量 $\{X_t:t\in T\}$ 一致可积，当且仅当下面两条同时成立：

(i) 这族随机变量在 $L^1$ 中有界，即 $\sup_t\E|X_t|<\infty$；

(ii) 对任意 $\eps>0$，存在 $\delta>0$，使得对任意事件 $F$，只要 $\P(F)<\delta$，就有 $\E[|X_t|\ind_F]<\eps$ 对所有 $t\in T$ 成立。
:::

- *Proof the statement* 应为 *Prove the statement*。
- (ii) 里的关键：$\delta$ 只依赖于 $\eps$，**不依赖于 $t$，也不依赖于 $F$**。这叫**一致绝对连续**（uniformly absolutely continuous）；原解答称之为 *uniform continuity property*。

**原解答的思路**（左栏方框）：
- **⇒**：取 UI 定义中的 $\lambda$；$\E|X_t|\le\lambda+\eps$ 得 (i)；$\E[|X_t|\ind_F]\le\lambda\P(F)+\eps$，取 $\delta=\eps/\lambda$ 得 (ii)。
- **⇐**：由 (i) 和 Markov 不等式，$\P(|X_t|>\lambda)\le M/\lambda$ 对所有 $t$ 一致地小；把 (ii) 用在事件 $\{|X_t|>\lambda\}$ 上即得 UI。

原解答是正确的。下面补全细节，特别是 ⇐ 方向里「事件随 $t$ 变化」为什么没有问题。

## 思路：怎么想到的

- **⇒**：UI 告诉我们：「$|X_t|$ 很大」的部分对期望贡献很小。任意事件 $F$ 上的贡献，可以拆成「$|X_t|\le\lambda$」的部分（此时 $|X_t|$ 不超过 $\lambda$，贡献不超过 $\lambda\P(F)$，$F$ 小它就小）和「$|X_t|>\lambda$」的部分（UI 保证它小）。
- **⇐**：要说明「$|X_t|>\lambda$」部分贡献小。由 (ii)，只要这个事件的**概率**足够小。而 (i) 加 Markov 不等式恰好说明：$\lambda$ 大时，$\P(|X_t|>\lambda)$ 对所有 $t$ 一致地小。

## 完整解答

### (⇒) UI ⇒ (i) 且 (ii)

**(i)**：在 UI 定义中取 $\eps=1$，得到 $\lambda_1$，使 $\E[|X_t|;|X_t|>\lambda_1]\le1$ 对所有 $t$ 成立。于是
$$
\E|X_t|=\E\big[|X_t|;|X_t|\le\lambda_1\big]+\E\big[|X_t|;|X_t|>\lambda_1\big]\le\lambda_1\cdot1+1 .
$$
（第一项里 $|X_t|\le\lambda_1$，概率空间总概率为 1。）右边与 $t$ 无关，所以 $\sup_t\E|X_t|\le\lambda_1+1<\infty$。

**(ii)**：给定 $\eps>0$。由 UI，取 $\lambda>0$ 使 $\E[|X_t|;|X_t|>\lambda]\le\frac\eps2$ 对所有 $t$ 成立。令 $\delta=\frac{\eps}{2\lambda}$。对任意事件 $F$ 和任意 $t$，
$$
\E\big[|X_t|\ind_F\big]=\E\big[|X_t|\ind_{F\cap\{|X_t|\le\lambda\}}\big]+\E\big[|X_t|\ind_{F\cap\{|X_t|>\lambda\}}\big]\le\lambda\P(F)+\E\big[|X_t|;|X_t|>\lambda\big].
$$
第一项：在 $\{|X_t|\le\lambda\}$ 上被积函数 $\le\lambda$，再丢掉条件 $|X_t|\le\lambda$ 只会让集合变大；第二项：丢掉 $F$ 只会让集合变大。若 $\P(F)<\delta$，则
$$
\E\big[|X_t|\ind_F\big]<\lambda\cdot\frac{\eps}{2\lambda}+\frac\eps2=\eps\qquad\text{对所有 }t .
$$
$\delta$ 只依赖于 $\eps$（经由 $\lambda$），与 $t$、$F$ 无关，这就是 (ii)。

### (⇐) (i) 且 (ii) ⇒ UI

记 $M:=\sup_t\E|X_t|<\infty$（由 (i)）。给定 $\eps>0$，由 (ii) 取对应的 $\delta>0$。

**第 1 步（大值事件的概率一致地小）**：由 Markov 不等式，对任意 $\lambda>0$ 和所有 $t$，
$$
\P\big(|X_t|>\lambda\big)\le\frac{\E|X_t|}{\lambda}\le\frac M\lambda .
$$
取 $\lambda_0=\frac{M}{\delta}$（若 $M=0$，所有 $X_t=0$ a.s.，结论显然）。当 $\lambda>\lambda_0$ 时，$\P(|X_t|>\lambda)<\delta$ 对**所有** $t$ 成立。

**第 2 步（用 (ii)）**：固定 $\lambda>\lambda_0$ 和任意 $t$，令 $F_t:=\{|X_t|>\lambda\}$。由第 1 步，$\P(F_t)<\delta$，所以由 (ii)，
$$
\E\big[|X_t|\ind_{\{|X_t|>\lambda\}}\big]=\E\big[|X_t|\ind_{F_t}\big]<\eps .
$$
这对所有 $t$ 成立，所以 $\sup_t\E[|X_t|;|X_t|>\lambda]\le\eps$ 对所有 $\lambda>\lambda_0$ 成立，即 UI。$\blacksquare$

**关键细节**：第 2 步用到的事件 $F_t$ 随 $t$ 而变。这没有问题，因为 (ii) 说的是「**任意**概率小于 $\delta$ 的事件」，对所有 $t$ 都成立，而 $\delta$ 是在选定 $t$ 之前就定好的。

## 原解答逐行对照

1. **⇒「Given any $\eps>0$, there exists $\lambda>0$ such that $\E[|X_t|\ind_{\{|X_t|>\lambda\}}]\le\eps$ for any $t$」**：UI 的定义。
2. **「$\E|X_t|=\E[|X_t|\ind_{\{|X_t|\le\lambda\}}]+\E[|X_t|\ind_{\{|X_t|>\lambda\}}]\le\lambda+\eps$」**：得 (i)。正确。
3. **「$\E[|X_t|\ind_F]\le\lambda\P(F)+\E[|X_t|\ind_{\{|X_t|>\lambda\}}]<\lambda\P(F)+\eps$」**：正确（最后一个「$<$」应为「$\le$」，无关紧要）。
4. **「Take $\delta\triangleq\eps/\lambda$. For $\P(F)<\delta$, it holds $\E[|X_t|\ind_F]<2\eps$」**：得到的是 $2\eps$ 而不是 $\eps$。因为 $\eps$ 是任意的，这等价于 (ii)；更整齐的写法是一开始就用 $\frac\eps2$（上面的写法）。
5. **⇐「by Markov's inequality, $\P(|X_t|>\lambda)\le\frac1\lambda\E|X_t|\le\frac1\lambda M$」**：正确。
6. **「given $\eps>0$ there exists $\lambda>0$ such that $\hat\lambda>\lambda\Rightarrow\P(|X_t|>\hat\lambda)<\delta$, then $\E[|X_t|\ind_{\{|X_t|>\hat\lambda\}}]<\eps$」**：意思正确，即上面的第 1、2 步。原解答没有说明 $\delta$ 是由 (ii) 对这个 $\eps$ 给出的，也没有指出 $F$ 依赖于 $t$ 不碍事。

::: warn 原解答的小问题：⇒ 方向得到的是 2ε
原解答证明的是「$\P(F)<\delta$ ⇒ $\E[|X_t|\ind_F]<2\eps$」。因为 $\eps$ 任意，这已经足够（把 $\eps$ 换成 $\eps/2$ 重来一遍即可），但考试时最好直接写成严格的 $\eps$ 形式，避免阅卷人扣「没有得到要证的不等式」。
:::

## 例子与数值验证

::: ex 例 1：尖峰族违反 (ii)
$X_n=n\ind_{(0,1/n)}$ 在 $[0,1]$ 上。(i) 成立：$\E X_n=1$。但 (ii) 不成立：对任意 $\delta>0$，取 $n>\frac1\delta$，$F=(0,\frac1n)$，$\P(F)=\frac1n<\delta$，可 $\E[X_n\ind_F]=1$。所以不可能对 $\eps<1$ 找到合适的 $\delta$，与「不一致可积」（上一题例 2）一致。
:::

::: ex 例 2：为什么 (i) 不能省——单点空间
设 $\Omega=\{\omega_0\}$，$\P(\{\omega_0\})=1$，$X_n\equiv n$。
- (ii) 成立：概率小于 $\delta\le1$ 的事件只有空集，$\E[|X_n|\ind_\varnothing]=0$。
- (i) 不成立：$\E|X_n|=n\to\infty$。
- 也不一致可积：$\lambda<n$ 时 $\E[X_n;X_n>\lambda]=n$。
所以单靠 (ii) 推不出 UI，必须加 (i)。
:::

::: ex 例 3：被控制的族，δ 可以具体算出来
设 $|X_t|\le Y$，$Y\sim\mathrm{Exp}(1)$。对 $\eps=0.1$：
- 取 $\lambda$ 使 $\E[Y;Y>\lambda]=(\lambda+1)e^{-\lambda}\le0.05$，$\lambda=5$ 时约 $0.0404$，可以。
- $\delta=\frac{\eps}{2\lambda}=\frac{0.1}{10}=0.01$：任何概率小于 0.01 的事件上，所有 $|X_t|$ 的贡献都小于 0.1。
:::

## 拓展延伸

::: more 无原子空间上 (ii) 推出 (i)
例 2 依赖于「单点空间有一个概率为 1 的原子」。如果概率空间**无原子**（例如 $[0,1]$ 上的长度：任何事件都能切成任意小的若干块），那么 (ii) 自己就推出 (i)：把 $\Omega$ 切成 $N$ 块概率都小于 $\delta$ 的事件，$\E|X_t|\le N\eps$ 对所有 $t$ 成立。
:::

::: more Dunford–Pettis 定理（了解）
在 $L^1$ 中，一族函数一致可积，当且仅当它在「弱拓扑」下相对紧（每个序列都有弱收敛的子列）。这是泛函分析里一致可积最深刻的刻画，说明一致可积是 $L^1$ 中「紧性」的正确替代品。
:::

::: more 一致绝对连续与作业 1 第 8 题
那道作业题（[[hw1:p:8]]）证明的是：**单个**可积函数在小测度集合上的积分很小。本题的 (ii) 是它的「一致」版本。由本题，任何有限族都满足 (ii)：对每个成员取 $\delta_i$，再取最小值。
:::

## 常见疑问与易错点

::: warn 问：(ii) 和单个变量的绝对连续性有什么区别？
**答**：单个变量的版本是「对每个 $t$，存在 $\delta_t$」；(ii) 是「存在 $\delta$，对每个 $t$」。尖峰族的每个成员都满足前者（每个都可积），但不满足后者。
:::

::: warn 问：⇐ 方向为什么要用 (i)？
**答**：用来保证「$|X_t|>\lambda$」这个事件的概率对所有 $t$ 一致地小（Markov 不等式需要 $\E|X_t|$ 有统一的上界 $M$）。没有 (i)，例 2 就是反例。
:::

::: warn 问：λ 取多大合适？
**答**：⇐ 方向只要 $\lambda>M/\delta$。这个下界是具体的：$M$ 来自 (i)，$\delta$ 来自 (ii)。证明「存在」时不需要最优的 $\lambda$，只要给出一个能用的。
:::

## 小结与自测

::: sum 本题小结
- UI ⇔ (i) $\sup_t\E|X_t|<\infty$ 且 (ii) 一致绝对连续（$\P(F)<\delta$ ⇒ 对所有 $t$，$\E[|X_t|\ind_F]<\eps$）。
- ⇒：$\E[|X_t|\ind_F]\le\lambda\P(F)+\E[|X_t|;|X_t|>\lambda]$，取 $\delta=\frac{\eps}{2\lambda}$。
- ⇐：Markov 给出 $\P(|X_t|>\lambda)\le M/\lambda<\delta$，再把 (ii) 用到 $F_t=\{|X_t|>\lambda\}$ 上。
- (i) 不能省（单点空间），(ii) 不能省（尖峰族）。
:::

::::quiz 自测
**1.** 设 $\sup_t\E|X_t|=2$，且 (ii) 对 $\eps=0.1$ 给出 $\delta=0.05$。取多大的 $\lambda$ 能保证 $\sup_t\E[|X_t|;|X_t|>\lambda]<0.1$？

:::answer
需要 $\P(|X_t|>\lambda)\le\frac2\lambda<0.05$，即 $\lambda>40$。
:::

**2.** 在 ⇒ 方向的证明中，若 UI 给出的 $\lambda=20$（对 $\frac\eps2=0.05$），对应的 $\delta$ 是多少？

:::answer
$\delta=\frac{\eps}{2\lambda}=\frac{0.1}{40}=0.0025$。
:::

**3.** 判断：一族随机变量若在 $L^2$ 中有界，则满足 (ii)。

:::answer
正确。$L^2$ 有界 ⇒ UI（上一题例 1 第 4 条）⇒ 由本题满足 (ii)。也可以直接用 Cauchy–Schwarz：$\E[|X_t|\ind_F]\le\sqrt{\E X_t^2}\sqrt{\P(F)}\le\sqrt K\sqrt\delta$。
:::
