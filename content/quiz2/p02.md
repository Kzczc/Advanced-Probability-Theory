## 这道题在问什么

::: idea 一句话版
一族随机变量 $\{X_t\}$ 叫**一致可积**（uniformly integrable，UI），如果「绝对值超过 $\lambda$ 的那部分」对期望的贡献，**对所有成员一起**随 $\lambda\to\infty$ 趋于 0：
$$
\lim_{\lambda\to\infty}\ \sup_{t\in T}\ \E\big[|X_t|\ind_{\{|X_t|>\lambda\}}\big]=0 .
$$
它的意义：没有任何成员能把一块「质量」藏到越来越远的地方。这正是「依概率收敛能不能推出期望收敛」的**充要条件**。
:::

- **考点**：一致可积的准确定义；和「单个随机变量可积」的区别（多了「一致」，即同一个 $\lambda$ 对所有成员管用）。
- **为什么重要**：第 3 讲的尖峰反例（第 3 讲 [[t3:p:19]]）说明逐点收敛推不出期望收敛；控制收敛定理（[[quiz1:p:1]]）给出一个充分条件；一致可积给出**充要**条件（见「拓展延伸」的 Vitali 定理）。
- **和其他题的关系**：下一题 [[p:3]] 证明 UI 的一个等价刻画；[[hw1:p:8]] 是「单个可积函数」的类似性质。

## 先补基础

::: basics 记号 E[X; A]
$\E[X;A]:=\E[X\ind_A]$，即「只在事件 $A$ 发生时计入 $X$」的期望。例：$X$ 是骰子点数，$A=\{X\ge5\}$，$\E[X;A]=\frac{5+6}{6}=\frac{11}6$。
:::

::: basics 单个可积随机变量的尾巴会变小
若 $\E|X|<\infty$，则 $\E\big[|X|\ind_{\{|X|>\lambda\}}\big]\to0$（$\lambda\to\infty$）。

**理由**：$|X|\ind_{\{|X|>\lambda\}}\to0$ 逐点成立（$|X|$ 几乎必然有限），并且被可积的 $|X|$ 控制，用控制收敛定理。

例：$X\sim\mathrm{Exp}(1)$，$\E[X;X>\lambda]=\int_\lambda^\infty xe^{-x}\dd x=(\lambda+1)e^{-\lambda}$：$\lambda=1$ 时 $0.736$，$\lambda=5$ 时 $0.040$，$\lambda=10$ 时 $0.0005$。
:::

::: basics sup：一族数的上确界
$\sup_{t\in T}a_t$ 是这族数的最小上界（[[t1:p:5]] 前后的基础补课）。「$\sup_t\E[\,\cdot\,]\to0$」意味着**最坏的那个成员**也被管住了。
:::

## 思路：定义里的每个词是什么意思

- **「可积」**：每个成员 $\E|X_t|<\infty$。
- **「一致」**：不只是每个成员的尾巴各自变小（那是可积本身就保证的），而是存在**同一个** $\lambda$，使**所有**成员的尾部贡献都不超过 $\eps$。
- 对比：「每个 $X_t$ 的尾巴都会变小」相当于「对每个 $t$，存在 $\lambda_t$」；「一致可积」是「存在 $\lambda$，对每个 $t$」。量词的顺序换了。

::: fig 图解：把「尾部贡献」看成一块面积
把 $\E|X|$ 想成一个装满沙子的长条：横轴是 $|X|$ 的取值，沙子的多少代表这个取值对期望的贡献。$\E[|X|;|X|>\lambda]$ 是竖线 $|X|=\lambda$ **右边**的沙子。
- 单个可积的 $X$：竖线往右推，右边的沙子越来越少，最后趋于 0。
- 一族 $\{X_t\}$：每个成员都有自己的一条长条。一致可积要求**一根竖线**同时让所有长条右边的沙子都少于 $\eps$。
- 尖峰族不行：$X_n$ 把全部沙子（总量 1）都堆在 $n$ 这个位置；无论竖线放在哪里，总有 $n$ 更大的成员把沙子堆在竖线右边。
:::

| 一族随机变量 | $L^1$ 有界？ | 一致可积？ | 原因 |
| --- | --- | --- | --- |
| 有限个可积变量 | 是 | 是 | 取各自 $\lambda$ 的最大值 |
| $\lvert X_t\rvert\le Y$，$\E Y<\infty$ | 是 | 是 | 尾巴被 $Y$ 的尾巴控制 |
| $\sup_t\E X_t^2<\infty$ | 是 | 是 | 尾部贡献 $\le K/\lambda$ |
| 尖峰 $n\ind_{(0,1/n)}$ | 是 | **否** | 质量逃向无穷远 |
| $[0,n]$ 上的均匀分布 | 否 | 否 | 期望本身就发散 |

## 完整解答

::: def 定义（一致可积）
设 $\{X_t:t\in T\}$ 是概率空间 $(\Omega,\F,\P)$ 上的一族可积随机变量（$T$ 是任意指标集，可以不可数）。若
$$
\lim_{\lambda\to\infty}\ \sup_{t\in T}\ \E\big[|X_t|\ind_{\{|X_t|>\lambda\}}\big]=0,
$$
即：对任意 $\eps>0$，存在 $\lambda>0$，使得**对所有** $t\in T$，$\E\big[|X_t|\ind_{\{|X_t|>\lambda\}}\big]\le\eps$，则称这族随机变量**一致可积**。
:::

- 写成 $\eps$-$\lambda$ 形式时，「存在 $\lambda$」写在「对所有 $t$」**前面**，这就是「一致」。
- 用 $\{|X_t|>\lambda\}$ 还是 $\{|X_t|\ge\lambda\}$ 都可以，结论一样。
- 有的教材（特别是一般测度空间上）会另外要求 $\sup_t\E|X_t|<\infty$；在概率空间上它可以由上面的定义推出（下一题 [[p:3]] 的第一步）。

## 例子与数值验证

::: ex 例 1：一致可积的典型情形
1. **有限族**：$\{X_1,\dots,X_N\}$ 每个都可积 ⇒ UI。取 $\lambda=\max_i\lambda_i$，其中 $\lambda_i$ 管住第 $i$ 个。
2. **被一个可积变量控制**：$|X_t|\le Y$，$\E Y<\infty$ ⇒ UI。因为 $\{|X_t|>\lambda\}\subseteq\{Y>\lambda\}$，所以 $\E[|X_t|;|X_t|>\lambda]\le\E[Y;Y>\lambda]\to0$，右边与 $t$ 无关。
3. **一致有界**：$|X_t|\le C$ ⇒ $\lambda>C$ 时尾部贡献都是 0，UI。
4. **$L^p$ 有界（$p>1$）**：$\sup_t\E|X_t|^p=K<\infty$ ⇒ UI。在 $\{|X_t|>\lambda\}$ 上 $|X_t|=\frac{|X_t|^p}{|X_t|^{p-1}}\le\frac{|X_t|^p}{\lambda^{p-1}}$，所以 $\E[|X_t|;|X_t|>\lambda]\le\frac{K}{\lambda^{p-1}}\to0$。
:::

::: ex 例 2：尖峰——L¹ 有界但不一致可积
在 $[0,1]$ 上取 $X_n=n\ind_{(0,1/n)}$。$\E X_n=1$，$L^1$ 有界。但对任何 $\lambda$，只要 $n>\lambda$，就有 $\{X_n>\lambda\}=(0,\frac1n)$，$\E[X_n;X_n>\lambda]=n\cdot\frac1n=1$。所以 $\sup_n\E[X_n;X_n>\lambda]=1$ 对所有 $\lambda$ 成立，**不一致可积**。直观上，每个 $X_n$ 都把全部质量藏在越来越高的地方。
:::

::: ex 例 3：把尖峰压矮一点就一致可积了
$Y_n=\sqrt n\ind_{(0,1/n)}$：$\E Y_n^2=1$，$L^2$ 有界，由例 1 第 4 条一致可积。直接验证：$n>\lambda^2$ 时 $\E[Y_n;Y_n>\lambda]=\sqrt n\cdot\frac1n=\frac1{\sqrt n}<\frac1\lambda$，所以 $\sup_n\E[Y_n;Y_n>\lambda]\le\frac1\lambda\to0$（$\lambda=10$ 时 $\le0.1$）。并且 $Y_n\to0$ 几乎必然、$\E Y_n=\frac1{\sqrt n}\to0$，期望跟着极限走。
:::

## 拓展延伸

::: more Vitali 收敛定理：一致可积为什么重要
设 $X_n\to X$ 依概率，$X_n$ 可积。则以下等价：
1. $\{X_n\}$ 一致可积；
2. $X$ 可积且 $\E|X_n-X|\to0$（$L^1$ 收敛）；
3. $X$ 可积且 $\E|X_n|\to\E|X|$。

所以「依概率收敛 + 一致可积」⇔「$L^1$ 收敛」：一致可积**恰好**是让期望跟着极限走的条件。控制收敛定理是它的特例（被可积变量控制 ⇒ UI，例 1 第 2 条），[[quiz1:p:3]] 是 1 ⇔ 3 中 2 ⇔ 3 那一部分（在几乎处处收敛的前提下）。
:::

::: more de la Vallée-Poussin 判别法
$\{X_t\}$ 一致可积，当且仅当存在递增的凸函数 $G\ge0$，满足 $\frac{G(x)}{x}\to\infty$（$x\to\infty$），使 $\sup_t\E G(|X_t|)<\infty$。例 1 第 4 条是 $G(x)=x^p$ 的情形；$G(x)=x\log(1+x)$ 说明「$\E|X_t|\log(1+|X_t|)$ 一致有界」也够用。
:::

::: more 鞅论里的一致可积
在鞅论中（作业 2 第 10–12 题），一致可积决定了「鞅的极限的期望」是否等于初值，以及可选停止定理在什么条件下成立。例如赌徒破产问题（[[hw2:p:12]]）中，停止前的财富有界，因而一致可积，可选停止定理可以放心使用。
:::

## 常见疑问与易错点

::: warn 问：每个 Xₜ 都可积，这族就一致可积吗？
**答**：不一定。尖峰族（例 2）每个成员都可积（期望都是 1），但不一致可积。可积只保证「每个成员的尾巴各自变小」，速度可以因成员而异，没有统一的 $\lambda$。
:::

::: warn 问：L¹ 有界够不够？
**答**：不够（例 2 正是 $L^1$ 有界的反例）。$L^p$ 有界（$p>1$）才够（例 1 第 4 条）。$L^1$ 有界再加上下一题的「一致绝对连续」，就等价于一致可积。
:::

::: warn 问：λ 应该写成依赖于 t 吗？
**答**：不能。$\lambda$ 只能依赖于 $\eps$，不能依赖于 $t$。如果允许 $\lambda$ 依赖 $t$，条件就退化成「每个成员可积」。
:::

## 小结与自测

::: sum 本题小结
- 定义：$\lim_{\lambda\to\infty}\sup_t\E[|X_t|\ind_{\{|X_t|>\lambda\}}]=0$；$\lambda$ 只依赖 $\eps$，对所有 $t$ 通用。
- 一致可积的典型来源：有限族、被可积变量控制、一致有界、$L^p$ 有界（$p>1$）。
- 反例：尖峰 $n\ind_{(0,1/n)}$ 每个都可积、$L^1$ 有界，但不一致可积。
- Vitali 定理：依概率收敛时，一致可积 ⇔ $L^1$ 收敛 ⇔ $\E|X_n|\to\E|X|$。
:::

::::quiz 自测
**1.** $X_n$ 服从 $[0,n]$ 上的均匀分布。$\{X_n\}$ 一致可积吗？

:::answer
不。$\E X_n=\frac n2\to\infty$，连 $L^1$ 都不有界；而一致可积在概率空间上推出 $L^1$ 有界（下一题），所以不可能一致可积。
:::

**2.** 设 $|X_t|\le Y$，$\E Y=3$，$\E[Y;Y>10]=0.05$。估计 $\sup_t\E[|X_t|;|X_t|>10]$。

:::answer
$\le\E[Y;Y>10]=0.05$，因为 $\{|X_t|>10\}\subseteq\{Y>10\}$ 且 $|X_t|\le Y$。
:::

**3.** 若 $\sup_t\E X_t^2\le4$，求一个 $\lambda$ 使 $\sup_t\E[|X_t|;|X_t|>\lambda]\le0.1$。

:::answer
由例 1 第 4 条（$p=2$），$\E[|X_t|;|X_t|>\lambda]\le\frac{4}{\lambda}$，取 $\lambda=40$ 即可。
:::
