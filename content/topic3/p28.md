## 这一页在讲什么

::: idea 一句话版
如果两个函数 $L$、$L'$ 都能当 $\Q$ 关于 $\P$ 的密度，那么它们**几乎必然相等**：$\P(L\ne L')=0$。证明的诀窍是只看「$L$ 比 $L'$ 大」的那个事件——在那里两者之差是正的，积分却是 0，于是这个事件的概率只能是 0。
:::

- 上一页 [[p:27]] 的定理 18 保证密度**存在**；这一页证明它**唯一**（在「可以差一个零概率事件」的意义下）。
- 有了唯一性，才可以说「**那个**」Radon–Nikodym 导数 $\frac{\mathrm d\Q}{\mathrm d\P}$，而不是「某一个」。
- 唯一性还是一个很实用的**识别工具**：只要找到**任何一个**满足 $\Q(A)=\int_A\widetilde L\dd\P$（对所有 $A$）的 $\widetilde L$，它就一定是 $\frac{\mathrm d\Q}{\mathrm d\P}$。第 [[p:34]] 页的链式法则、第 [[p:35]] 页的倒数密度都靠这一招。

## 先补基础

::: basics 事件 {L > L′} 以及它为什么是事件
- $\{L>L'\}$ 是 $\{\omega\in\Omega:\ L(\omega)>L'(\omega)\}$ 的简写：所有「$L$ 的值比 $L'$ 大」的样本点。
- 它属于 $\F$（是合法的事件）。理由：若 $L(\omega)>L'(\omega)$，两者之间一定夹着一个有理数 $r$；反过来 $L(\omega)>r>L'(\omega)$ 也推出 $L(\omega)>L'(\omega)$。所以
  $$
  \{L>L'\}=\bigcup_{r\ \text{为有理数}}\big(\{L>r\}\cap\{L'<r\}\big),
  $$
  而有理数只有可数个，每个 $\{L>r\}$、$\{L'<r\}$ 都是事件（$L$、$L'$ 可测，[[t1:p:29]]），σ-代数对可数并、交封闭（[[t1:p:9]]）。
:::

::: basics 零积分原理：非负函数积分为 0 ⇒ 几乎处处为 0
**陈述**：若 $g\ge0$ 可测且 $\int g\dd\P=0$，则 $\P(g>0)=0$。（这是 [[t1:p:43]] 的内容，下面给一个只用已学知识的证明。）

1. 对每个正整数 $k$：$g\ge\frac1k\ind_{\{g>1/k\}}$。理由：在 $\{g>\frac1k\}$ 上右边是 $\frac1k<g$；在别处右边是 $0\le g$。
2. 两边积分（单调性）：$0=\int g\dd\P\ge\frac1k\P(g>\frac1k)$，所以 $\P(g>\frac1k)=0$。
3. $\{g>0\}=\bigcup_{k\ge1}\{g>\frac1k\}$，而且这些事件随 $k$ 增大而变大。由从下连续性（[[t1:p:13]]），$\P(g>0)=\lim_k\P(g>\frac1k)=0$。
:::

::: basics 可积函数的线性
- 若 $\int|f|\dd\P<\infty$、$\int|g|\dd\P<\infty$（都**可积**），则 $\int(f-g)\dd\P=\int f\dd\P-\int g\dd\P$（[[t1:p:43]]）。
- 「可积」这个前提不能少：如果两个积分都是 $+\infty$，右边就成了没有意义的 $\infty-\infty$。
:::

**唯一性：一个密度比另一个大的那个事件**
:::

- 这个小标题把证明的**关键一步**直接写出来了：要证明两个密度 $L$、$L'$ 几乎相等，就去看事件 $\{L>L'\}$（「一个密度比另一个大」的地方）。
- 为什么偏偏看这个事件？因为在这个事件上，$L-L'$ **符号是确定的**（都是正的）。一个**符号确定**的函数积分为 0，就只能几乎处处为 0；而一个正负都有的函数积分为 0，完全可能是正负抵消（例如 $\int_0^1(2x-1)\dd x=0$，可 $2x-1$ 并不是 0）。
- 蓝条标题 *Uniqueness of the Radon–Nikodym derivative*：Radon–Nikodym 导数的唯一性。

### Uniqueness: the event where one density is larger｜唯一性：一个密度比另一个大的那个事件

::: prop 命题（Radon–Nikodym 导数的唯一性）
设 $\P$、$\Q$ 是 $(\Omega,\F)$ 上的概率测度，$L$、$L'$ 都是 $\F$-可测的非负函数，并且
$$
\int_A L\dd\P=\Q(A)=\int_A L'\dd\P\qquad\text{对所有 }A\in\F .
$$
那么 $L=L'$ $\P$-几乎必然，即 $\P(L\ne L')=0$。
:::

::: proof 证明思路
先证 $\P(L>L')=0$：在事件 $A=\{L>L'\}$ 上，$L-L'>0$，但它在 $A$ 上的积分等于 $\Q(A)-\Q(A)=0$，由零积分原理 $\P(A)=0$。再把 $L$、$L'$ 对调，得 $\P(L'>L)=0$。两部分合起来就是 $\P(L\ne L')=0$。
:::

一步一步来：

1. **取事件**：令 $A=\{L>L'\}$。由「先补基础」，$A\in\F$，所以可以把它代入假设。
2. **两个积分都有限**：$\int_A L\dd\P=\Q(A)\le1$，$\int_A L'\dd\P=\Q(A)\le1$。所以 $L\ind_A$、$L'\ind_A$ 都是可积函数。**这里用到了 $\Q$ 是概率（总量有限）。**
3. **差的积分为 0**：由可积函数的线性，
   $$
   \int(L-L')\ind_A\dd\P=\int_A L\dd\P-\int_A L'\dd\P=\Q(A)-\Q(A)=0 .
   $$
4. **被积函数非负，并且恰好在 $A$ 上为正**：令 $g=(L-L')\ind_A$。在 $A$ 上 $L>L'$，所以 $g>0$；在 $A$ 外 $g=0$。因此 $g\ge0$ 处处成立，并且 $\{g>0\}=A$。
5. **用零积分原理**（[[t1:p:43]]）：$g\ge0$ 且 $\int g\dd\P=0$，所以 $\P(A)=\P(g>0)=0$。
6. **对称**：把 $L$ 和 $L'$ 的角色对调（假设对两者是对称的），同样得到 $\P(B)=0$，其中 $B=\{L'>L\}$。
7. **合起来**：$\{L\ne L'\}=A\cup B$，所以 $\P(L\ne L')\le\P(A)+\P(B)=0$。

证毕。

::: idea 画一张图想一想
在 $\Omega=[0,1]$、$\P=\lambda$ 的情形，把 $L$ 和 $L'$ 画成两条曲线。事件 $A=\{L>L'\}$ 就是「$L$ 的曲线在 $L'$ 上方」的那些横坐标。第 3 步说：在 $A$ 上方，两条曲线**夹出来的面积是 0**。可是在 $A$ 上两条曲线确实分开了（上面那条严格高），夹出面积为 0 的唯一可能是：$A$ 这片横坐标的**总长度是 0**。这就是第 5 步。
:::

### 为什么只能是「几乎必然」唯一

反过来也成立：**如果 $L'$ 和一个密度 $L$ 只在一个 $\P$-零概率事件 $N$ 上不同，那么 $L'$ 也是密度。** 理由：对每个 $A$，$L\ind_A$ 和 $L'\ind_A$ 只在 $N$ 上可能不同，而零概率事件上的改动不影响积分（[[t1:p:43]]），所以 $\int_A L'\dd\P=\int_A L\dd\P=\Q(A)$。

所以「几乎必然唯一」已经是**最好**的结论了：想要「每一点都唯一」是不可能的。当我们写「$\frac{\mathrm d\Q}{\mathrm d\P}=2x$」时，意思是「$2x$ 是一个密度，任何其他密度都和它几乎必然相等」。教材里把这样一个具体的函数叫作 Radon–Nikodym 导数的一个**版本**（version）。

::: more 另一种证明：不做减法（选读）
对正整数 $k$，令 $A_k=\{L\ge L'+\frac1k\}$。在 $A_k$ 上 $L\ge L'+\frac1k$，积分得
$$
\Q(A_k)=\int_{A_k}L\dd\P\ \ge\ \int_{A_k}L'\dd\P+\frac1k\P(A_k)=\Q(A_k)+\frac1k\P(A_k).
$$
因为 $\Q(A_k)\le1$ 是有限数，两边减去它得 $0\ge\frac1k\P(A_k)$，所以 $\P(A_k)=0$。又因为 $L(\omega)>L'(\omega)$ 时总有某个 $k$ 使 $L(\omega)\ge L'(\omega)+\frac1k$，所以 $\{L>L'\}=\bigcup_k A_k$，由从下连续性 $\P(L>L')=0$。这个证明同样在「两边减去 $\Q(A_k)$」处用到了 $\Q(A_k)<\infty$。
:::

::: more 总量无穷时唯一性可以失败（选读）
取只有一个点的空间 $\Omega=\{0\}$，$\mu(\{0\})=\infty$，$\nu(\{0\})=\infty$（它们是测度，但不是概率）。常数函数 $L\equiv1$ 和 $L'\equiv2$ 都满足 $\nu(A)=\int_A L\dd\mu$：对 $A=\{0\}$ 两边都是 $\infty$（$1\cdot\infty=2\cdot\infty=\infty$），对 $A=\varnothing$ 两边都是 0。可是 $L\ne L'$ 在整个 $\Omega$ 上成立，而 $\mu(\Omega)=\infty\ne0$。上面证明的第 3 步在这里变成 $\infty-\infty$，没有意义。所以**第 2 步的有限性不是装饰，是证明的关键**。
:::

## 例子

::: ex 例 1：在有理数上乱改，密度仍然是同一个
$\Omega=[0,1]$，$\P=\lambda$，$\Q$ 的密度 $L(x)=2x$。令
$$
L'(x)=\begin{cases}2x, & x\ \text{是无理数},\\ 5, & x\ \text{是有理数}.\end{cases}
$$
- $L'$ 也是 $\Q$ 的密度：$\{L\ne L'\}$ 包含在 $[0,1]$ 的有理数集里，长度为 0，所以对每个 $A$，$\int_A L'\dd\lambda=\int_A L\dd\lambda=\Q(A)$。
- 这和命题一致：命题说两者几乎必然相等，这里 $\P(L\ne L')=0$ 确实成立。
- 这个 $L'$ 处处不连续，看起来和 $2x$ 很不一样，但**作为密度它们没有区别**。
:::

::: ex 例 2：离散空间里，唯一性只在零概率点上失效
$\Omega=\{a,b,c\}$，$\P=(0.5,0.5,0)$，$\Q=(0.2,0.8,0)$。取两个候选密度 $L=(0.4,1.6,0)$，$L'=(0.4,1.6,7)$（按 $a,b,c$ 的顺序）。

- 两者都是密度：它们只在 $c$ 上不同，而 $\P(\{c\})=0$。
- 按证明走一遍：$A=\{L>L'\}=\varnothing$，$\P(A)=0$；$B=\{L'>L\}=\{c\}$，$\P(B)=0$。所以 $\P(L\ne L')=0$。
- 在 $a$、$b$ 这两个 $\P$-概率为正的点上，$L$ 的值被 $\Q(\{\omega\})/\P(\{\omega\})$ **唯一确定**，改不了。
:::

::: ex 例 3：两个不同的函数，事件 {L > L′} 上就露馅
$\Omega=[0,1]$，$\P=\lambda$。$L(x)=2x$ 和 $L'(x)=2(1-x)$ 都满足非负、积分为 1，它们各自定义一个概率 $\Q$、$\Q'$。它们是不是同一个概率？

- 看「一个密度更大」的事件 $A=\{L>L'\}=\{2x>2-2x\}=(\frac12,1]$。
- $\int_A L\dd\lambda=\int_{1/2}^1 2x\dd x=\frac34$，$\int_A L'\dd\lambda=\int_{1/2}^1 2(1-x)\dd x=\frac14$。
- 在同一个事件上给出不同的概率，所以 $\Q\ne\Q'$。这正是证明的逻辑：**只要两个函数在一个正概率事件上真的不同，在「谁更大」的那个事件上积分就会不同。**
:::

::: ex 例 4：密度几乎必然等于 1 ⟺ 两个概率相同
设 $\Q\ll\P$，$L=\frac{\mathrm d\Q}{\mathrm d\P}$。

- **若 $L=1$ $\P$-几乎必然**：对每个 $A$，$\Q(A)=\int_A L\dd\P=\int_A1\dd\P=\P(A)$（零概率事件上的差别不影响积分），所以 $\Q=\P$。
- **若 $\Q=\P$**：常数函数 $1$ 满足 $\int_A1\dd\P=\P(A)=\Q(A)$，所以 $1$ 是一个密度；由唯一性，**任何**密度 $L$ 都满足 $L=1$ $\P$-几乎必然。
- 用法：想判断两个概率是不是同一个，可以算它们的密度，看是否几乎必然等于 1。例如 [[p:31]] 的两点空间中，$L\equiv1$ 恰好发生在 $q=p$ 的时候。
:::

## 常见疑问与易错点

::: warn 问：为什么不直接看事件 {L ≠ L′}？
**答**：在 $\{L\ne L'\}$ 上，$L-L'$ 有时为正、有时为负，积分为 0 可能只是正负抵消，推不出任何东西。把它拆成 $\{L>L'\}$ 和 $\{L'>L\}$ 两块，每一块上符号固定，才能用零积分原理。这就是小标题 *the event where one density is larger* 的用意。
:::

::: warn 问：证明里哪一步用到了「ℚ 是概率」？
**答**：第 2、3 步。要把 $\int_A(L-L')\dd\P$ 拆成两个积分相减，两个积分都必须有限；这里它们都等于 $\Q(A)\le1$。上面的选读例子说明，总量无穷时这一步会变成 $\infty-\infty$，唯一性也真的会失败。
:::

::: warn 问：既然密度不唯一，那「dℚ/dℙ」到底指哪一个函数？
**答**：指这些几乎必然相等的函数中的任何一个。所有关于它的等式都理解成「$\P$-几乎必然成立」，例如链式法则 [[p:34]] 就明确写着 $\P$-a.s.。在只关心积分、概率、期望的问题里，选哪个版本结果都一样。
:::

::: warn 问：几乎必然相等的两个函数，在某一点的值可以差很多吗？
**答**：可以，例 1 里 $L(0.5)=1$ 而 $L'(0.5)=5$。「几乎必然相等」只保证**不相等的点合起来概率为 0**，不限制在这些点上差多少。
:::

## 小结与自测

::: sum 本页小结
- **唯一性**：两个密度 $L$、$L'$ 若对所有事件给出相同的 $\Q$，则 $\P(L\ne L')=0$。
- **关键一步**：在 $A=\{L>L'\}$ 上 $L-L'>0$，但积分 $=\Q(A)-\Q(A)=0$，由零积分原理 $\P(A)=0$；对称地 $\P(L'>L)=0$。
- 「几乎必然」唯一是最好的结论：在零概率事件上改动密度不影响任何积分。
- 有限性（$\Q(A)\le1$）保证了减法有意义；总量无穷时唯一性可以失败。
- 用途：找到**任何一个**合格的 $\widetilde L$，它就是 $\frac{\mathrm d\Q}{\mathrm d\P}$。
:::

::::quiz 自测
**1.** $\Omega=[0,1]$，$\P=\lambda$。$L(x)=2x$，$L'(x)=2x\cdot\ind_{\{x\ \text{是无理数}\}}$。它们给出同一个 $\Q$ 吗？

:::answer
给出同一个 $\Q$。两者只在有理数上可能不同（$L'$ 在有理数上是 0），而 $[0,1]$ 中有理数的全体长度为 0，所以 $\P(L\ne L')=0$，对每个 $A$ 积分都相同。
:::

**2.** 在证明中，为什么 $g=(L-L')\ind_A$ 处处非负？

:::answer
在 $A=\{L>L'\}$ 上，$L-L'>0$，乘以 $\ind_A=1$ 仍为正；在 $A$ 外，$\ind_A=0$，$g=0$。所以处处 $g\ge0$。这正是只看「$L$ 更大」的事件带来的好处。
:::

**3.** 设 $\Omega=\{1,2\}$，$\P=(\frac13,\frac23)$，$\Q=(\frac12,\frac12)$。$\frac{\mathrm d\Q}{\mathrm d\P}$ 是否在**每一点**都唯一？为什么？

:::answer
每一点都唯一。两点的 $\P$-概率都为正，只有空集是 $\P$-零概率事件，「几乎必然相等」在这里就等于「处处相等」。具体地 $L(1)=\frac{1/2}{1/3}=\frac32$，$L(2)=\frac{1/2}{2/3}=\frac34$，检查 $\frac13\cdot\frac32+\frac23\cdot\frac34=\frac12+\frac12=1$。
:::
