## 第 1 部分会讲什么

| 页 | 内容 | 要回答的问题 |
| --- | --- | --- |
| [[p:5]] | 样本点与样本空间 | 一个概率模型从哪里开始？ |
| [[p:6]] | 事件 | 「某件事发生」在数学上是什么？ |
| [[p:7]] | 手写续页：无穷次抛硬币 | 「无穷多次正面」怎么写成集合？ |
| [[p:8]] | 可数可加性 | 概率要满足什么加法规则？ |
| [[p:9]] | σ-代数 | 允许谈概率的事件清单要满足什么？ |
| [[p:10]] | 为什么不总是用全部子集 | 清单为什么不能随便取最大的？ |
| [[p:11]] | 生成的 σ-代数、博雷尔 σ-代数 | 怎样从几个「基本事件」造出整张清单？ |
| [[p:12]] | 测度空间与概率空间 | 把以上拼起来，正式定义是什么？ |
| [[p:13]]、[[p:14]] | 测度的连续性 | 集合一点点变大 / 变小，测度怎样变化？ |

::: note 读这一部分的建议
这一部分几乎全是**集合语言**：并 $\cup$、交 $\cap$、补 $A^c$、子集 $\subseteq$。如果这些符号还不熟，先读[基础补课](../basics.html)里的「集合」一节，再往下读，会轻松很多。
:::
