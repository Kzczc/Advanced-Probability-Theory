## 这一页在讲什么

::: idea 一句话版
一个集合 $E$ 是「好集合」（可测），当且仅当：拿**任何**集合 $A$ 来，用 $E$ 把它切成两块，两块的外测度加起来**恰好等于**原来的外测度——切一刀不会凭空多出成本。满足这个条件的集合组成一个 σ-代数，外测度在上面就是真正的测度。
:::

上一页（[[p:18]]）的外测度对所有集合都有定义，但只有「$\le$」。这一页给出挑选「好集合」的标准，正是 [[p:15]] 板书路线里的「extension（扩张）」那一步：把外测度**限制**在好集合上，得到勒贝格测度。

## 先补基础

::: basics 差集 A \ E
$A\setminus E=\{x\in A: x\notin E\}$：在 $A$ 里但不在 $E$ 里的点，等于 $A\cap E^c$。于是

$$
A=(A\cap E)\cup(A\setminus E),\qquad (A\cap E)\cap(A\setminus E)=\varnothing .
$$

$E$ 把 $A$ 切成了**不相交**的两块：属于 $E$ 的部分和不属于 $E$ 的部分。
:::

::: basics 完备测度
一个测度是**完备的**（complete），如果「测度为 0 的集合的任何子集」也都在 σ-代数里（因此测度也是 0）。直观意思：零测集的碎片不会「不可测」。
:::

## 课件原文逐句精读

::: original Definition 13 (Carathéodory measurable set)
For an outer measure $m^*$, a set $E\subseteq\R$ passes the Carathéodory test if, for every $A\subseteq\R$,

$$
m^*(A)=m^*(A\cap E)+m^*(A\setminus E).\qquad\text{(C)}
$$
:::

::: zh
**定义 13（卡拉泰奥多里可测集）** 对外测度 $m^*$，如果对**每一个** $A\subseteq\R$ 都有 $m^*(A)=m^*(A\cap E)+m^*(A\setminus E)$（条件 (C)），就说集合 $E\subseteq\R$ 通过了卡拉泰奥多里判别。
:::

- **$E$ 是被检验的集合**，$A$ 是「试验用的集合」（test set）。
- **for every $A$**（老师圈了出来）：必须对**所有**试验集合都成立，一个都不能例外。这是一个非常强的要求。
- **(C) 的含义**：用 $E$ 当刀，把 $A$ 切成 $A\cap E$ 和 $A\setminus E$ 两块，分别算外测度再相加，结果和整块的外测度一样。换句话说，**$E$ 的边界「干净」，切开它不产生额外的覆盖成本**。

::: original Theorem 14 (Carathéodory measurable set theorem)
The sets satisfying (C) form a sigma-algebra, and $m^*$ restricted to this sigma-algebra is a complete measure. For Lebesgue outer measure, (C) is equivalent to the open approximation criterion.
:::

::: zh
**定理 14（卡拉泰奥多里可测集定理）** 满足 (C) 的集合组成一个 σ-代数，并且 $m^*$ 限制在这个 σ-代数上是一个完备测度。对勒贝格外测度而言，(C) 等价于「开集逼近判别」。
:::

::: thm 定理 14（卡拉泰奥多里）
设 $\mathcal L$ 是所有满足 (C) 的集合。那么：

1. $\mathcal L$ 是 σ-代数（含 $\R$，对补集和可数并封闭）；
2. $m^*$ 限制在 $\mathcal L$ 上是可数可加的，因而是测度，记作 $m$；
3. 这个测度是完备的；
4. 对勒贝格外测度，$E\in\mathcal L$ 当且仅当：对任意 $\eps>0$，存在开集 $O\supseteq E$ 使 $m^*(O\setminus E)<\eps$（开集逼近判别）。
:::

逐句讲：

- **form a sigma-algebra**：好集合对补集、可数并封闭——这正是第 1 部分要求事件族满足的规则（[[p:9]]）。所以好集合可以直接当「事件清单」。
- **restricted … is a complete measure**：在好集合上，「$\le$」升级成「$=$」，外测度变成真正的测度。这就是**勒贝格测度**，好集合就是**勒贝格可测集**。
- **open approximation criterion**：另一种等价说法——$E$ 可以被一个开集从外面「贴身」包住，多出来的部分外测度任意小。它更直观，但本课主要用 (C)。

## 老师板书在说什么

::: board 板书转写
1. 定义里 **every $A$** 被圈出；(C) 中的「$=$」被圈出，下面写了「$\ge$」。
2. 图下等式中两个 $E$ 下各画了一道短线。
3. $A$ is cut by $E$ creates no extra cost（「cost」下画双线，下面写 covering）.
4. $(S,\mathcal M,\mu)$，$\mu$ 下面画箭头：Jordan $\to$ outer $\to$ Carathéodory.
:::

### 第 1 行：为什么老师在「=」下写「≥」

由外测度的次可加性（[[p:18]]），**「$\le$」方向永远成立**：

$$
m^*(A)=m^*\big((A\cap E)\cup(A\setminus E)\big)\le m^*(A\cap E)+m^*(A\setminus E).
$$

所以检验 (C) 时，**只需要验证另一个方向「$\ge$」**：

$$
m^*(A)\ge m^*(A\cap E)+m^*(A\setminus E)\quad\text{对所有 }A .
$$

这是做题时最实用的一句话：证明一个集合可测，只证「$\ge$」。

### 第 3 行：「切一刀不增加成本」

cost 指的是**覆盖成本**（covering）：外测度就是最省的覆盖成本。(C) 说：先整体盖住 $A$ 的最省成本，等于把 $A$ 切开后两块分别盖的最省成本之和。对好集合，切开不需要额外花钱。

### 第 4 行：测度空间里的 μ 从哪来

第 1 部分只规定了测度空间 $(S,\mathcal M,\mu)$ 要满足的规矩。现在老师标出：实数轴上最重要的那个 $\mu$，就是沿着 **乔丹容量 → 外测度 → 卡拉泰奥多里判别** 这条路造出来的（和 [[p:15]] 的路线一致）。

## 例子

::: ex 例 1：零测集一定可测
设 $m^*(E)=0$。对任意 $A$：

1. $A\cap E\subseteq E$，由单调性 $m^*(A\cap E)\le m^*(E)=0$，所以 $m^*(A\cap E)=0$。
2. $A\setminus E\subseteq A$，由单调性 $m^*(A\setminus E)\le m^*(A)$。
3. 于是 $m^*(A\cap E)+m^*(A\setminus E)\le0+m^*(A)=m^*(A)$，这就是「$\ge$」方向。

所以 $E$ 通过判别。特别地，有理数集 $\Q$、任何可数集都是勒贝格可测的，而且零测集的任何子集也可测——这就是「完备」。
:::

::: ex 例 2：半直线 (−∞, c] 可测（思路）
取 $E=(-\infty,c]$，要证对任意 $A$ 有「$\ge$」。

1. 任取盖住 $A$ 的区间 $\{I_n\}$。
2. 每个 $I_n$ 在点 $c$ 处切成两段：$I_n\cap(-\infty,c]$ 和 $I_n\cap(c,\infty)$，**两段仍是区间**，长度之和恰好等于 $|I_n|$。
3. 左边那些段盖住 $A\cap E$，右边那些段盖住 $A\setminus E$，所以

$$
m^*(A\cap E)+m^*(A\setminus E)\le\sum_n|I_n| .
$$

4. 对所有盖法取下确界，得到 $\le m^*(A)$，即「$\ge$」方向。

关键在第 2 步：区间在一个点处切开，不产生额外成本。再由 σ-代数的封闭性，所有区间、开集、闭集都可测。
:::

::: ex 例 3：不可测集的样子（预告）
[[p:21]] 的维塔利集 $V$ 是一个「和自己的平移极端交错」的集合。拿 $A=[0,1)$ 当试验集合，用 $V$ 去切，两块都「碎到」无法用区间高效覆盖，外测度之和会大于 $m^*(A)$。这就是它通不过判别的原因。
:::

## 常见疑问与易错点

::: warn 问：为什么要对「所有」A 检验？只检验 A = ℝ 不行吗？
**答**：不行。如果只要求 $m^*(\R)=m^*(E)+m^*(E^c)$，两边都是 $\infty$，什么都说明不了。要求对所有 $A$ 成立，才能保证 $E$ 和**任何**集合配合时都不产生额外成本，这是证明可数可加性所需要的。
:::

::: warn 问：卡拉泰奥多里可测和勒贝格可测是一回事吗？
**答**：对实数轴上的勒贝格外测度，是一回事：勒贝格可测集就定义为通过 (C) 的集合，记作 $\mathcal L(\R)$（[[p:23]]）。卡拉泰奥多里判别本身更一般，对任何外测度都适用。
:::

::: warn 问：证明可测时，两个方向都要证吗？
**答**：只证「$\ge$」。「$\le$」由次可加性自动成立，这就是老师在「$=$」下写「$\ge$」的原因。
:::

## 小结与自测

::: sum 本页小结
- 卡拉泰奥多里判别：对**所有** $A$，$m^*(A)=m^*(A\cap E)+m^*(A\setminus E)$。人话：用 $E$ 切开任何集合都不增加覆盖成本。
- 「$\le$」总成立（次可加性），只需验证「$\ge$」。
- 通过判别的集合组成 σ-代数，外测度在上面是完备测度——这就是勒贝格测度。
- 零测集、区间、开集、闭集都可测。
:::

::::quiz 自测
**1.** 为什么检验 (C) 时只需证明「$\ge$」？

:::answer
因为 $A=(A\cap E)\cup(A\setminus E)$，由外测度的次可加性，$m^*(A)\le m^*(A\cap E)+m^*(A\setminus E)$ 对任何 $E$ 都成立，只剩「$\ge$」需要检验。
:::

**2.** 判断：全体有理数 $\Q$ 是勒贝格可测集。

:::answer
正确。$\Q$ 可数，$m^*(\Q)=0$；由例 1，外测度为 0 的集合一定通过卡拉泰奥多里判别。
:::

**3.** 用自己的话说说「完备测度」是什么意思，并举一个例子。

:::answer
零测集的任何子集都可测，并且测度为 0。例：$\Q\cap[0,1]$ 的测度为 0，那么它的任何子集（例如 $\{\tfrac12,\tfrac13,\tfrac14,\dots\}$）也可测，测度为 0。
:::
