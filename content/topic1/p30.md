## 这一页在讲什么

::: idea 一句话版
先挑最简单的可测函数：**只取有限个值**的函数（简单函数）。它们都能用「开关函数」$\ind_A$ 搭出来。对它们，积分只需一个最朴素的公式：**每个取值 × 取这个值的集合有多大，再全部加起来**。
:::

- 上一页 [[p:29]] 说明了哪些函数有资格被积分（可测函数）。但一般的可测函数可能很复杂，没法直接算面积。
- 这一页的策略是「先从积木开始」：
  1. 定义 21：**示性函数** $\ind_A$，最小的积木；
  2. 定义 22：**非负简单函数**，用有限块积木搭成的「台阶」；
  3. 定义 23：**简单函数的积分**，台阶的面积；
  4. 推论 24：积木 $\ind_A$ 的积分恰好是 $\mu(A)$。
- 之后 [[p:31]]、[[p:32]] 检查这个积分定义是否合理，[[p:33]] 再用「从下方逼近」把积分推广到一般的非负可测函数。
- 在概率里，这一页的公式就是**离散随机变量的期望** $\E[X]=\sum_k x_k\P(X=x_k)$，推论 24 就是 $\E[\ind_A]=\P(A)$。

## 先补基础

::: basics 求和符号 Σ
- $\sum_{k=1}^{r}c_k$ 读作「$k$ 从 1 到 $r$，把 $c_k$ 加起来」，也就是 $c_1+c_2+\cdots+c_r$。
- 下标 $k$ 只是计数用的名字，换成 $i$、$j$ 意思不变。
- 例：$\sum_{k=1}^{3}k^2=1+4+9=14$。
:::

::: basics 函数的值域、「不同的值」
- 函数 $s$ 的**值域**（range）是它实际取到的所有值组成的集合 $\{s(x):x\in S\}$。
- **值域有限**：$s$ 总共只取有限多个不同的值。比如掷骰子时「点数是偶数记 1，奇数记 0」这个函数，值域是 $\{0,1\}$。
- *distinct values* 指「互不相同的值」：把重复的值只算一次。例如 $s$ 在 $1,2,3$ 三个点上分别取 $5,5,7$，那么它的不同的值只有 $5$ 和 $7$ 两个。
:::

::: basics 函数的加法与数乘（逐点运算）
- 两个函数相加、函数乘以常数，都是**逐点**进行的：$(a\ind_A+b\ind_B)(x)=a\,\ind_A(x)+b\,\ind_B(x)$。
- 所以 $\sum_{k=1}^r a_k\ind_{A_k}$ 是一个函数，它在点 $x$ 的值是 $\sum_k a_k\ind_{A_k}(x)$。
- 例：$A=[0,2]$，$B=[1,3]$，$g=\ind_A+\ind_B$。在 $x=0.5$ 处只有 $\ind_A$ 等于 1，$g(0.5)=1$；在 $x=1.5$ 处两个都等于 1，$g(1.5)=2$；在 $x=5$ 处都为 0，$g(5)=0$。
:::

::: basics 分割：两两不交、并起来是全体
- 一族集合 $A_1,\dots,A_r$ 叫作 $S$ 的一个**分割**（partition），如果它们**两两不交**（任意两个没有公共点）并且**并起来恰好是 $S$**。
- 通俗地说：把 $S$ 里的每个点**恰好分进一个格子**，不遗漏、不重复。
- 例：$\{1,2,3\}$、$\{4,5\}$、$\{6\}$ 是 $\{1,2,3,4,5,6\}$ 的一个分割。
:::

::: basics 带 ∞ 的算术
测度可以等于 $\infty$（例如整条实数轴的长度），所以要约定含 $\infty$ 的运算：

- 对 $a\ge0$：$a+\infty=\infty$；
- 对 $a>0$：$a\cdot\infty=\infty$；
- 特别约定：$0\cdot\infty=0$（为什么这样约定，下面精读定义 23 时细讲）。
- 注意：$\infty-\infty$ **没有定义**，所以我们暂时只处理非负函数，保证求和时只做加法、不做减法。
:::

## 课件原文逐句精读

::: original Definition 21 (Indicator)
$$
\ind_A(x):=\begin{cases}1, & x\in A,\\ 0, & x\notin A.\end{cases}\qquad(A\in\mathcal S).
$$
:::

::: zh
**定义 21（示性函数）** 对 $A\in\mathcal S$，定义 $\ind_A(x)=1$（当 $x\in A$），$\ind_A(x)=0$（当 $x\notin A$）。
:::

### Indicators are the atomic measurable functions｜示性函数是最基本的可测函数

- **示性函数**（indicator function）$\ind_A$ 像一个开关：点在 $A$ 里就亮（取 1），不在就灭（取 0）。读作「$A$ 的示性函数」。
- 它**把集合变成函数**：知道 $\ind_A$ 就知道 $A$（$A$ 就是 $\ind_A$ 取 1 的那些点），反之亦然。
- 定义后面括号里的 $(A\in\mathcal S)$ 要求 $A$ 可测。原因在 [[p:29]] 例 3：$\ind_A$ 是可测函数**当且仅当** $A\in\mathcal S$。所以只有可测集的示性函数才能进入积分。
- 蓝条标题说它们是 *atomic*（原子的）：下面会看到，所有简单函数都由示性函数乘上常数再相加得到，就像分子由原子组成。

::: original Definition 22 (Nonnegative simple function)
A measurable function $s:S\to[0,\infty)$ is a nonnegative simple function if its range is finite. If its distinct values are $a_1,\dots,a_r$, then its canonical representation is
$$
s=\sum_{k=1}^{r}a_k\ind_{A_k},\qquad A_k=\{s=a_k\},\qquad S=\bigcup_{k=1}^{r}A_k .
$$
:::

::: zh
**定义 22（非负简单函数）** 一个可测函数 $s:S\to[0,\infty)$，如果它的值域是有限集，就称为**非负简单函数**。若它互不相同的取值是 $a_1,\dots,a_r$，那么它的**标准表示**是
$$
s=\sum_{k=1}^{r}a_k\ind_{A_k},\qquad A_k=\{s=a_k\},\qquad S=\bigcup_{k=1}^{r}A_k .
$$
:::

逐个条件看：

- **measurable（可测）**：保证每个 $A_k$ 都是可测集，后面才能算 $\mu(A_k)$。
- **$s:S\to[0,\infty)$**：取值非负并且**有限**（注意右端是圆括号，不含 $\infty$）。非负是为了求和时只做加法；不取 $\infty$ 是为了让「台阶的高度」都是普通的数。
- **range is finite（值域有限）**：函数只取有限个不同的值，所以图像是有限级「台阶」。这就是 *simple*（简单）的含义。
- **$A_k=\{s=a_k\}$**：第 $k$ 个格子装的是「取值恰好为 $a_k$ 的所有点」。因为 $s$ 可测，由 [[p:29]] 推导第 5 步，$\{s=a_k\}$ 是可测集。
- **$S=\bigcup_{k=1}^r A_k$**：每个点都取某一个值，所以落在某一个格子里；不同的值对应不同的格子，所以格子两两不交。于是 $A_1,\dots,A_r$ 构成 $S$ 的一个**分割**。
- **为什么 $s=\sum a_k\ind_{A_k}$ 成立**：任取一点 $x$，它恰好落在一个格子 $A_j$ 里，于是右边只有 $\ind_{A_j}(x)=1$，其余都是 0，右边等于 $a_j$；而左边 $s(x)$ 按 $A_j$ 的定义也等于 $a_j$。两边在每个点都相等。
- **canonical（标准）** 的意思：这种写法由 $s$ **唯一确定**（除了各项的先后顺序）。因为「不同的值有哪些」和「每个值由哪些点取到」都是 $s$ 自己决定的，没有选择的余地。

::: def 定义 22（非负简单函数与标准表示）
可测函数 $s:S\to[0,\infty)$ 若只取有限个值，称为**非负简单函数**（simple function）。设它的全部不同取值为 $a_1,\dots,a_r$，令 $A_k=\{s=a_k\}$，则 $A_1,\dots,A_r$ 是 $S$ 的可测分割，并且
$$
s=\sum_{k=1}^{r}a_k\ind_{A_k}\qquad(\textbf{标准表示}).
$$
:::

::: original Definition 23 (Simple integral)
$$
\int_S s\dd\mu:=\sum_{k=1}^{r}a_k\,\mu(A_k),\qquad 0\cdot\infty:=0 .
$$
:::

::: zh
**定义 23（简单积分）** 对标准表示为 $s=\sum_{k=1}^r a_k\ind_{A_k}$ 的非负简单函数，定义它的积分为 $\int_S s\dd\mu=\sum_{k=1}^{r}a_k\mu(A_k)$，并约定 $0\cdot\infty=0$。
:::

- **读法**：$\int_S s\dd\mu$ 读作「$s$ 在 $S$ 上关于 $\mu$ 的积分」。$\int_S$ 表示在整个空间上积分，$s$ 是被积函数，$\dd\mu$ 说明**用哪把尺子（哪个测度）量**。老师在 $\dd\mu$ 和右边的 $\mu(A_k)$ 下面都画了双线，就是在对应这两处：左边写 $\dd\mu$，右边就用 $\mu$ 去量每个格子。
- **公式的意思**：第 $k$ 级台阶的高度是 $a_k$，底座是集合 $A_k$，底座的「宽度」是 $\mu(A_k)$；这一级的面积是「高 × 宽」$=a_k\mu(A_k)$；所有台阶面积加起来就是积分。
- **和黎曼积分的区别**（回忆 [[p:26]]）：黎曼的台阶底座只能是区间；这里的底座 $A_k$ 可以是任何可测集，比如有理数集。
- **可能等于 $\infty$**：若某个 $a_k>0$ 而 $\mu(A_k)=\infty$，这一项就是 $\infty$，积分等于 $\infty$。因为每一项都 $\ge0$，不会出现 $\infty-\infty$，所以积分总是有定义的，值在 $[0,\infty]$ 中。

### 0 · ∞ := 0｜为什么这样约定

- **会在哪里遇到**：函数在一个测度为无穷的集合上取值 0。例如在整条实数轴上（勒贝格测度）取 $s=\ind_{[0,1]}$，它的标准表示是 $1\cdot\ind_{[0,1]}+0\cdot\ind_{\R\setminus[0,1]}$，第二项是「高度 0 × 宽度 $\infty$」。
- **为什么取 0**：一个高度为 0 的矩形，不管底有多宽，面积都应该是 0。如果不这样约定，连「处处为 0 的函数」在实数轴上的积分都没法定义，那就太荒唐了。
- **一致性**：有了这个约定，$\int\ind_{[0,1]}\dd\Leb=1\cdot1+0\cdot\infty=1$，正好是区间长度，符合直觉。
- **提醒**：这只是**乘积数值**的约定，**不是求极限的规则**。例如 $n\cdot\frac1n=1$，当 $n\to\infty$ 时它的极限是 1，不是 $0\cdot\infty$ 的「0」。

::: original Corollary 24 (Indicator identity)
For $A\in\mathcal S$, $\displaystyle\int_S\ind_A\dd\mu=\mu(A)$.
:::

::: zh
**推论 24（示性函数恒等式）** 对 $A\in\mathcal S$，有 $\int_S\ind_A\dd\mu=\mu(A)$。
:::

- 意思：**积木 $\ind_A$ 的积分就是集合 $A$ 的测度**。积分是测度的推广：测度量「集合」，积分量「函数」，而示性函数把两者连起来。
- 概率版本：$\E[\ind_A]=\P(A)$，「事件 $A$ 发生的次数（0 或 1）的期望 = 事件的概率」。这是概率论里最常用的恒等式之一。
- 证明见下面板书第 5–7 条和「推导」一节。

::: cor 推论 24（示性函数恒等式）
对每个可测集 $A\in\mathcal S$，$\displaystyle\int_S\ind_A\dd\mu=\mu(A)$。
:::

## 老师板书在说什么

::: board 板书转写（按从上到下的顺序）
1. 在定义 22 中把 simple function 圈了出来。
2. 在标准表示上方写：classify of the range（意思是「按值域分类」，即 classify by the range）。
3. 把 $s=\sum_{k=1}^r a_k\ind_{A_k}$ 左边的 $s$ 圈出，又把右边的和式 $\sum_{k=1}^r a_k\ind_{A_k}$ 整体圈出；从这个圈画一条箭头，一直指到定义 23 中 $\int_S s\dd\mu$ 里的 $s$。
4. 把 $\int_S s\dd\mu$ 整体圈出；在 $\dd\mu$ 下面画双线，在右边的 $\mu(A_k)$ 下面也画双线。
5. 在推论 24 右上方写：$\ind_A=1\cdot\ind_A+0\cdot\ind_{A}$（最后一项的下标看起来是 $A$，没有写补集记号；按数学意思应为 $A^c$）。
6. 在推论 24 的 $\int_S\ind_A\dd\mu$ 中，$\ind_A$ 下面画了双线。
7. 在推论 24 下面写：$=\mu(A)+0=\mu(A)$. #
:::

**第 1–2 条「按值域分类」**：这是标准表示的核心思想。不要按「$x$ 在哪一段」来切 $S$（那是黎曼的切法），而是按「$s(x)$ 取哪个值」把点分组：取值 $a_1$ 的点放进 $A_1$，取值 $a_2$ 的点放进 $A_2$……**先看值，再找点**，这正是勒贝格积分的精神。

**第 3 条的箭头**：提醒你积分定义里的 $s$ 必须先写成标准表示 $\sum a_k\ind_{A_k}$，然后才能套用公式 $\sum a_k\mu(A_k)$——**公式里的 $a_k$ 和 $A_k$ 就是从标准表示里读出来的**。

**第 4 条的双线**：左边的 $\dd\mu$ 和右边的 $\mu(A_k)$ 是同一个 $\mu$。换一个测度（比如从长度换成某个概率），同一个函数的积分就会变。

**第 5–7 条：推论 24 的证明**。老师把 $\ind_A$ 看成取两个值 1 和 0 的简单函数：取 1 的点组成 $A$，取 0 的点组成 $A^c$。所以它的标准表示是 $\ind_A=1\cdot\ind_A+0\cdot\ind_{A^c}$。套用定义 23：
$$
\int_S\ind_A\dd\mu=1\cdot\mu(A)+0\cdot\mu(A^c)=\mu(A)+0=\mu(A).
$$
中间的「$+0$」正是用到了约定 $0\cdot\infty=0$：即使 $\mu(A^c)=\infty$，这一项也是 0。末尾的 # 是老师表示「证明完毕」的记号。

## 例子

::: ex 例 1：掷骰子的奖金——简单积分就是期望
$S=\{1,2,3,4,5,6\}$，$\mathcal S=2^S$，每个点的概率是 $\frac16$（即 $\mu=\P$）。游戏规则：掷出 1、2、3 不给钱，掷出 4、5 给 2 元，掷出 6 给 10 元。奖金函数 $s$ 的不同取值是 $0,2,10$，标准表示为
$$
s=0\cdot\ind_{\{1,2,3\}}+2\cdot\ind_{\{4,5\}}+10\cdot\ind_{\{6\}} .
$$
按定义 23：
$$
\int_S s\dd\P=0\cdot\tfrac36+2\cdot\tfrac26+10\cdot\tfrac16=0+\tfrac23+\tfrac53=\tfrac73\approx2.33 .
$$
这正是中学学过的「期望奖金」$\sum(\text{奖金})\times(\text{概率})$。**测度论的积分就是期望的推广。**
:::

::: ex 例 2：按值合并——两段不相连的台阶合进同一个格子
在 $([0,3],\mathcal B,\Leb)$ 上，令 $s(x)=1$（$0\le x<1$），$s(x)=3$（$1\le x<2$），$s(x)=1$（$2\le x\le3$）。

- 不同的值只有 $1$ 和 $3$ 两个（值 1 虽然出现在两段上，只算一个值）。
- $A_1=\{s=1\}=[0,1)\cup[2,3]$，长度 $1+1=2$；$A_2=\{s=3\}=[1,2)$，长度 $1$。
- 标准表示：$s=1\cdot\ind_{[0,1)\cup[2,3]}+3\cdot\ind_{[1,2)}$。
- 积分：$\int s\dd\Leb=1\cdot2+3\cdot1=5$。

用画图核对：三个矩形面积分别是 $1\times1$、$3\times1$、$1\times1$，和为 5，一致。注意标准表示的格子 $A_1$ **不是一个区间**，这正是「按值域分类」和黎曼切法的不同。
:::

::: ex 例 3：底座是有理数集的台阶
在 $([0,1],\mathcal B,\Leb)$ 上，令 $s(x)=2$（$x$ 是有理数），$s(x)=5$（$x$ 是无理数）。

- 标准表示：$s=2\cdot\ind_{\Q\cap[0,1]}+5\cdot\ind_{[0,1]\setminus\Q}$。
- $\Leb(\Q\cap[0,1])=0$（可数集是零测集，见 [[p:28]]），所以 $\Leb([0,1]\setminus\Q)=1-0=1$。
- 积分：$2\cdot0+5\cdot1=5$。

这个函数处处不连续，黎曼积分不存在（和 [[p:28]] 的狄利克雷函数同理），但简单积分毫不费力。
:::

::: ex 例 4：0 · ∞ 的约定在起作用
在 $(\R,\mathcal B,\Leb)$ 上，$s=4\cdot\ind_{[0,\frac12]}$。它的不同取值是 $4$ 和 $0$：
$$
\int_\R s\dd\Leb=4\cdot\Leb([0,\tfrac12])+0\cdot\Leb(\R\setminus[0,\tfrac12])=4\cdot\tfrac12+0\cdot\infty=2+0=2 .
$$
没有 $0\cdot\infty=0$ 这条约定，这个一眼就能看出等于 2 的积分都算不出来。
:::

::: ex 反例：这些都不是非负简单函数
- $f(x)=x$（$0\le x\le1$）：取了无穷多个不同的值，值域不是有限集。
- $\ind_V$，$V$ 是维塔利集（[[p:21]]）：只取 0 和 1，但**不可测**，不满足定义里的 measurable。
- $h=\ind_{[0,1]}-\ind_{[2,3]}$：取了负值 $-1$，不是「非负」简单函数。
- $g=\infty\cdot\ind_{\{0\}}$（在 0 处取 $\infty$，其余为 0）：取值 $\infty$ 不在 $[0,\infty)$ 里。
:::

## 推导：一步一步来

::: proof 证明思路
推论 24：把 $\ind_A$ 写成标准表示，直接套定义 23；要单独处理 $A=\varnothing$ 和 $A=S$ 这两种「只取一个值」的特殊情况。
:::

设 $A\in\mathcal S$。按 $\ind_A$ 的值域分三种情况：

1. **$A\ne\varnothing$ 且 $A\ne S$**：$\ind_A$ 恰好取两个值 1 和 0。$\{\ind_A=1\}=A$，$\{\ind_A=0\}=A^c$，两者都可测（$A^c$ 可测是因为 σ-代数对补集封闭）。标准表示为 $1\cdot\ind_A+0\cdot\ind_{A^c}$，由定义 23，
   $$
   \int_S\ind_A\dd\mu=1\cdot\mu(A)+0\cdot\mu(A^c)=\mu(A),
   $$
   其中 $0\cdot\mu(A^c)=0$ 对 $\mu(A^c)$ 有限或无穷都成立（后者用约定 $0\cdot\infty=0$）。
2. **$A=S$**：$\ind_S$ 只取一个值 1，标准表示是 $1\cdot\ind_S$，积分 $=1\cdot\mu(S)=\mu(S)=\mu(A)$。
3. **$A=\varnothing$**：$\ind_\varnothing$ 只取一个值 0，标准表示是 $0\cdot\ind_S$，积分 $=0\cdot\mu(S)=0$（又用到 $0\cdot\infty=0$，如果 $\mu(S)=\infty$）。而 $\mu(\varnothing)=0$（测度的定义，[[p:12]]），所以积分 $=\mu(A)$。

三种情况都得到 $\int_S\ind_A\dd\mu=\mu(A)$。

::: more 反过来：有限个可测格子上的台阶函数一定是简单函数
设 $A_1,\dots,A_r$ 是 $S$ 的可测分割，$a_1,\dots,a_r\ge0$ 互不相同，$s=\sum_k a_k\ind_{A_k}$。那么 $s$ 可测：对每个实数 $a$，
$$
\{s>a\}=\bigcup_{k:\ a_k>a}A_k ,
$$
即「取值大于 $a$ 的那几个格子」的并，这是有限个可测集的并，所以可测。它只取 $a_1,\dots,a_r$ 这有限个值，于是它是非负简单函数。所以，**「非负简单函数」和「可测格子上的有限台阶」是同一回事**。
:::

## 常见疑问与易错点

::: warn 问：标准表示里的 a₁, …, a_r 要从小到大排吗？A_k 可以是空集吗？
**答**：不用排序，求和与先后顺序无关。$A_k$ 不会是空集：$a_k$ 是 $s$ **实际取到**的值，所以至少有一个点取这个值。但如果你自己随手写 $s=\sum_i c_i\ind_{C_i}$（不是标准表示），里面的集合就可能为空、可能重叠、同一个值也可能重复出现——这种一般写法的积分是否还等于 $\sum c_i\mu(C_i)$，正是下一页 [[p:31]] 和再下一页 [[p:32]] 要回答的问题。
:::

::: warn 问：0 · ∞ = 0 是不是说明「无穷乘以零等于零」在所有地方都成立？
**答**：不是。它只是**积分定义里的数值约定**，理由是「高为 0 的矩形面积为 0」。它不能用来算极限：$n\cdot\frac1n$ 的极限是 1，$n^2\cdot\frac1n$ 的极限是 $\infty$，都不是 0。遇到「一个因子趋于 0、另一个趋于 $\infty$」的极限，必须具体分析。
:::

::: warn 问：为什么要求简单函数非负？负的台阶不行吗？
**答**：如果允许负值，某一项可能是 $+\infty$（正的高度 × 无穷宽），另一项是 $-\infty$，和就变成没有意义的 $\infty-\infty$。先只处理非负函数，积分永远是 $[0,\infty]$ 里一个确定的数；带符号的函数到 [[p:33]] 的板书再用「正部减负部」来处理。
:::

::: warn 问：简单积分和中学的「期望」有什么关系？
**答**：当 $\mu=\P$ 是概率测度、$s=X$ 是只取有限个值的随机变量时，$\int X\dd\P=\sum_k x_k\P(X=x_k)$，正是离散型期望的公式（例 1）。测度论的积分把这个公式推广到了取无穷多个值、甚至不可数多个值的随机变量上。
:::

## 小结与自测

::: sum 本页小结
- **示性函数** $\ind_A$：在 $A$ 上取 1，其余取 0；它可测当且仅当 $A$ 可测。
- **非负简单函数**：可测、非负、只取有限个值；**标准表示** $s=\sum_k a_k\ind_{A_k}$ 按「取哪个值」把 $S$ 分成可测格子 $A_k=\{s=a_k\}$，写法唯一。
- **简单积分** $\int s\dd\mu=\sum_k a_k\mu(A_k)$：每级台阶的「高 × 底座测度」之和，值在 $[0,\infty]$ 中。
- 约定 $0\cdot\infty=0$：高为 0 的部分不贡献面积；它只是数值约定，不是极限规则。
- $\int\ind_A\dd\mu=\mu(A)$；概率版本 $\E[\ind_A]=\P(A)$。
:::

::::quiz 自测
**1.** 在 $(\R,\mathcal B,\Leb)$ 上，写出 $s=\ind_{[0,2]}+\ind_{[1,3]}$ 的标准表示，并按定义 23 计算 $\int s\dd\Leb$。

:::answer
逐段看 $s$ 的值：在 $[0,1)$ 上只有第一个示性函数为 1，$s=1$；在 $[1,2]$ 上两个都为 1，$s=2$；在 $(2,3]$ 上只有第二个为 1，$s=1$；其余地方 $s=0$。不同的值是 $0,1,2$：
$A_0=\R\setminus[0,3]$，$A_1=[0,1)\cup(2,3]$，$A_2=[1,2]$。
标准表示 $s=0\cdot\ind_{A_0}+1\cdot\ind_{A_1}+2\cdot\ind_{A_2}$，积分 $=0\cdot\infty+1\cdot2+2\cdot1=4$。（它恰好等于 $\Leb([0,2])+\Leb([1,3])=2+2$，这是下一页要证明的「与写法无关」的一个实例。）
:::

**2.** 掷一颗均匀骰子，$A=\{2,4,6\}$。求 $\int\ind_A\dd\P$，并用一句话说明它的概率含义。

:::answer
由推论 24，$\int\ind_A\dd\P=\P(A)=\frac36=\frac12$。含义：「掷出偶数」这个事件的示性变量（掷出偶数记 1，否则记 0）的期望，等于掷出偶数的概率。
:::

**3.** 在 $([0,1],\mathcal B,\Leb)$ 上，$s(x)=\lfloor 3x\rfloor$（$\lfloor y\rfloor$ 表示不超过 $y$ 的最大整数）。它是非负简单函数吗？若是，求它的积分。

:::answer
是。$s$ 只取 $0,1,2,3$ 四个值：$\{s=0\}=[0,\frac13)$，$\{s=1\}=[\frac13,\frac23)$，$\{s=2\}=[\frac23,1)$，$\{s=3\}=\{1\}$，都是区间或单点，可测。积分 $=0\cdot\frac13+1\cdot\frac13+2\cdot\frac13+3\cdot0=1$。注意单点 $\{1\}$ 的长度为 0，所以取值 3 对积分没有贡献。
:::
