## 这一页在讲什么

::: idea 一句话版
第 2、3 部分的成果汇总：勒贝格可测集组成的 σ-代数 $\mathcal L(\R)$ 包含所有博雷尔集，但不是全部子集；勒贝格测度 $m$ 在上面可数可加，区间的测度就是长度，而且是完备的。把它限制在 $[0,1]$ 上，就得到**均匀分布的概率** $\P$。
:::

这一页收尾第 3 部分：从 [[p:15]] 的路线图出发，经过外测度（[[p:18]]）、卡拉泰奥多里判别（[[p:20]]）、维塔利定理（[[p:21]]、[[p:22]]），终于得到了一个可以用来谈概率的连续测度。

## 先补基础

::: basics ⊆ 与 ⊊
- $A\subseteq B$：$A$ 包含于 $B$（可能相等）。
- $A\subsetneq B$：$A$ 包含于 $B$ **而且不相等**，即 $B$ 里至少有一个元素不在 $A$ 里。
:::

::: basics 博雷尔 σ-代数 𝓑(ℝ)
**博雷尔 σ-代数** $\mathcal B(\R)$ 是由所有开区间生成的 σ-代数（[[p:11]]）：包含开区间、闭区间、半开区间、单点、开集、闭集，以及它们的可数并、可数交、补集……日常能写出来的集合几乎都在里面。
:::

## 课件原文逐句精读

::: original Theorem 16 (Structure of Lebesgue measure)
The Lebesgue measurable sets and Lebesgue measure satisfy

$$
\mathcal B(\R)\subseteq\mathcal L(\R)\subsetneq2^{\R},\qquad m([a,b])=b-a\quad(a\le b),
$$

and, for pairwise disjoint $E_n\in\mathcal L(\R)$,

$$
m\Big(\bigcup_{n\ge1}E_n\Big)=\sum_{n\ge1}m(E_n).
$$

A measurable set $Z$ with $m(Z)=0$ is called null. Lebesgue measure is complete: every subset $N\subseteq Z$ is measurable and null.
:::

::: zh
**定理 16（勒贝格测度的结构）** 勒贝格可测集与勒贝格测度满足：$\mathcal B(\R)\subseteq\mathcal L(\R)\subsetneq2^\R$，$m([a,b])=b-a$（$a\le b$）；并且对两两不交的 $E_n\in\mathcal L(\R)$，$m(\bigcup_{n\ge1}E_n)=\sum_{n\ge1}m(E_n)$。

测度为 0 的可测集 $Z$ 称为**零测集**。勒贝格测度是**完备的**：零测集 $Z$ 的每个子集 $N\subseteq Z$ 都可测，而且也是零测集。
:::

逐条解读：

1. **$\mathcal B(\R)\subseteq\mathcal L(\R)$**：所有博雷尔集都勒贝格可测。理由：区间都通过卡拉泰奥多里判别（[[p:20]] 例 2），$\mathcal L(\R)$ 是 σ-代数，而 $\mathcal B(\R)$ 是包含区间的**最小** σ-代数（[[p:11]] 的最小性），所以 $\mathcal B(\R)\subseteq\mathcal L(\R)$。
2. **$\mathcal L(\R)\subsetneq2^\R$**：不是所有子集都可测——维塔利集 $V$ 就是反例（[[p:22]]）。
3. **$m([a,b])=b-a$**：在区间上，勒贝格测度就是我们熟悉的长度。
4. **可数可加**：不交的可测集，测度可以相加。这正是 [[p:12]] 对测度的要求。
5. **零测集与完备性**：零测集的任何子集都可测且测度为 0（[[p:20]] 例 1 已经证明了这一点）。

::: original Corollary 17 (Uniform probability)
Let $\mathcal L([0,1]):=\{E\cap[0,1]: E\in\mathcal L(\R)\}$. Then

$$
\P(A):=m(A),\qquad A\in\mathcal L([0,1]),
$$

defines the uniform probability measure on $[0,1]$.
:::

::: zh
**推论 17（均匀概率）** 令 $\mathcal L([0,1]):=\{E\cap[0,1]: E\in\mathcal L(\R)\}$。那么 $\P(A):=m(A)$（$A\in\mathcal L([0,1])$）定义了 $[0,1]$ 上的**均匀概率测度**。
:::

- **$\mathcal L([0,1])$**：勒贝格可测集与 $[0,1]$ 的交，也就是「$[0,1]$ 里的可测子集」，它是 $[0,1]$ 上的 σ-代数。
- **$\P(A)=m(A)$**：事件的概率就是它的长度。因为 $m([0,1])=1$，这是一个概率测度。
- 于是得到概率空间 $\big([0,1],\ \mathcal L([0,1]),\ \P\big)$：**在 $[0,1]$ 上「均匀随机取一个点」终于有了严格的数学模型。**

::: thm 定理 16 + 推论 17（整理）
$$
\big(\R,\ \mathcal L(\R),\ m\big)\ \text{是完备的测度空间},\qquad
\big([0,1],\ \mathcal L([0,1]),\ \P=m\big)\ \text{是概率空间}.
$$
:::

## 例子

::: ex 例 1：用均匀概率计算
在 $[0,1]$ 上均匀取一个点 $X$：

- $\P(0.2\le X\le0.5)=m([0.2,0.5])=0.3$；
- $\P(X=0.5)=m(\{0.5\})=0$：取到任何一个具体的点，概率都是 0；
- $\P(X\text{ 是有理数})=m(\Q\cap[0,1])=0$（可数集是零测集，[[p:18]]）；
- $\P(X\text{ 是无理数})=1-0=1$；
- $\P\big(X\in[0,0.1]\cup[0.5,0.7]\big)=0.1+0.2=0.3$（两段不相交，可加）。
:::

::: ex 例 2：不可数但测度为 0 的集合
**康托尔集**：从 $[0,1]$ 开始，挖掉中间三分之一 $(\tfrac13,\tfrac23)$，再从剩下两段各挖掉中间三分之一，无限进行下去。每一步剩下的总长是上一步的 $\tfrac23$，第 $n$ 步剩 $(\tfrac23)^n\to0$，所以康托尔集的测度是 0；但它有不可数多个点。第 2 讲会用它构造「连续但没有密度」的分布（[[t2:p:19]]）。**零测集不一定可数。**
:::

::: ex 例 3：完备性的用处
设某事件 $Z$ 的概率为 0，而 $N\subseteq Z$ 是它的一部分。完备性保证 $N$ 也是事件，概率也为 0。例如「取到的点在康托尔集里」概率为 0，那么「取到的点在康托尔集的某个奇怪子集里」也是事件，概率为 0，不会出现「不可测」的尴尬。
:::

::: note 一个漂亮的联系：均匀取点 = 无穷次抛硬币
把 $[0,1)$ 里的数写成二进制小数 $\omega=0.b_1b_2b_3\ldots$（每个 $b_n$ 是 0 或 1）。在勒贝格测度下：

- 「第 1 位 $b_1=0$」就是 $\omega\in[0,\tfrac12)$，概率 $\tfrac12$；
- 「前两位是 01」就是 $\omega\in[\tfrac14,\tfrac12)$，概率 $\tfrac14$；
- 一般地，前 $n$ 位取定某个 0/1 串，对应一个长度 $2^{-n}$ 的区间，概率 $2^{-n}$。

这和「独立抛 $n$ 次公平硬币得到某个指定结果」的概率完全一样。所以**在 $[0,1)$ 上均匀取一个点，等价于无穷次独立抛公平硬币**（把 1 当正面）。[[p:7]] 里的无穷次抛硬币模型，因此也有了严格的测度论基础——它就是 $([0,1),\mathcal L,m)$ 换了一种读法。
:::

## 常见疑问与易错点

::: warn 问：𝓑(ℝ) 和 𝓛(ℝ) 有什么区别？用哪个？
**答**：$\mathcal L(\R)$ 比 $\mathcal B(\R)$ 大：它还包含零测博雷尔集的所有子集（完备化）。概率论里两者通常可以互换使用，因为它们只差「零测集的子集」，不影响任何概率计算。第 2 讲定义随机变量时常用 $\mathcal B(\R)$。
:::

::: warn 问：每个点的概率都是 0，为什么整个区间的概率是 1？
**答**：可数可加只允许**可数个**集合相加。$[0,1]$ 是**不可数**个单点的并，不能把单点的概率加起来。这正是 [[p:1]] 例 1 提出的问题的答案：概率是直接给区间定的，而不是从单点拼出来的。
:::

::: warn 问：为什么只在 [0,1] 上定义均匀概率？能不能在整条实数轴上「均匀地」取一个点？
**答**：不能。「均匀」意味着长度相同的区间概率相同。把 $\R$ 切成可数个不相交的单位区间 $[k,k+1)$（$k$ 取遍所有整数），每段的概率都应该是同一个数 $q$。由可数可加性，$\P(\R)=\sum_kq$：$q=0$ 时总和是 0，$q>0$ 时总和是 $\infty$，都不可能等于 1。所以整条实数轴上不存在均匀分布；勒贝格测度 $m(\R)=\infty$ 也不能通过乘一个常数变成概率。只有总长度有限的区间（例如 $[0,1]$）才能「均匀地」取点。
:::

::: warn 问：测度为 0 的事件「不可能发生」吗？
**答**：不是。$\P(X=0.5)=0$，但 $X$ 取到 $0.5$ 并非不可能——每个具体的点都是这样。概率为 0 意思是「可以忽略」，不是「绝不发生」。这就是后面「几乎处处」（[[p:43]]）的出发点。
:::

## 小结与自测

::: sum 本页小结
- $\mathcal B(\R)\subseteq\mathcal L(\R)\subsetneq2^\R$：博雷尔集都可测，但不是所有子集都可测。
- 勒贝格测度 $m$：区间的测度是长度，可数可加，完备（零测集的子集可测且测度为 0）。
- 限制在 $[0,1]$ 上：$\P(A)=m(A)$ 是均匀概率，概率 = 长度。
- 可数集是零测集；零测集不一定可数（康托尔集）；概率为 0 不等于不可能。
:::

::::quiz 自测
**1.** 在 $[0,1]$ 上均匀取点，求 $\P\big(X\in[0,\tfrac14)\cup(\tfrac34,1]\big)$ 和 $\P(X\ne\tfrac12)$。

:::answer
两段不相交，概率 $=\tfrac14+\tfrac14=\tfrac12$。$\P(X\ne\tfrac12)=1-\P(X=\tfrac12)=1-0=1$。
:::

**2.** 为什么 $\mathcal B(\R)\subseteq\mathcal L(\R)$？用「最小性」说明。

:::answer
所有区间都勒贝格可测，而 $\mathcal L(\R)$ 是 σ-代数，所以它是一个「包含所有区间的 σ-代数」。$\mathcal B(\R)$ 是包含所有区间的**最小** σ-代数，因此 $\mathcal B(\R)\subseteq\mathcal L(\R)$。
:::

**3.** 判断：零测集一定是可数集。

:::answer
错误。康托尔集测度为 0 但不可数。反过来是对的：可数集一定是零测集。
:::
