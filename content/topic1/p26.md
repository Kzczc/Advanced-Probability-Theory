## 这一页在讲什么

::: idea 一句话版
黎曼和勒贝格都用「台阶函数」（一块块平顶）去逼近曲线下的面积。区别只有一个：**黎曼的台阶底只能是区间**，勒贝格的台阶底可以是**任意可测集**。按函数值横着切，每一层的底是「函数值不低于这一层的所有点」，它可以是好几段，甚至很碎。
:::

上一页（[[p:25]]）的达布和把台阶建在区间小格上。这一页用两张图对比勒贝格的做法，为下面几页的「简单函数」（[[p:30]]）做准备。

## 先补基础

::: basics 水平集 {x : f(x) ≥ y}
给定一个高度 $y$，$\{x: f(x)\ge y\}$ 是「函数值至少为 $y$ 的所有点」。在图上：画一条水平线 $y$，曲线在这条线**上方**的那些 $x$ 就是这个集合。

例：$f(x)=\sin(\pi x)$ 在 $[0,1]$ 上，$\{x: f(x)\ge\tfrac12\}=[\tfrac16,\tfrac56]$（一个区间）；但若 $f$ 有两个峰，这个集合会是**两段**。
:::

::: basics 示性函数与简单函数（预告）
$\ind_A(x)$ 在 $x\in A$ 时取 1，否则取 0。**简单函数** $s=\sum_ka_k\ind_{A_k}$：在集合 $A_k$ 上取值 $a_k$，是若干块「平顶」拼起来的台阶。正式定义在 [[p:30]]。
:::

## 图解

::: fig 图解：左边竖切，右边横切 | crop=0.03,0.16,0.97,0.64
**左图：Darboux: interval cells only（达布：只有区间小格）**

- 横轴被虚线分成若干等宽小区间，每个区间上立一个矩形（浅蓝色），高度由函数在这一格里的值决定。
- 台阶的「底」一律是**区间**；要让面积逼近准确，只能把区间切得更细。

**右图：Lebesgue: measurable level sets（勒贝格：可测的水平集）**

- 纵轴上画了一条条水平虚线（等间隔的高度）。每条水平线和曲线交于两点（绿色圆点）。
- 每一层的颜色带（从下往上由绿变青）宽度不同：越往上，曲线在这一高度之上的 $x$ 越少，所以带越窄。
- 每一层的「底」就是 $\{x: f(x)\ge y_k\}$：图里这条抛物线恰好只有一个峰，所以每层的底都是一段区间；如果函数有好几个峰，底就会是好几段（可以在下方演示里换一个函数观察）。
- 把所有层叠起来，就得到一个逼近曲线的台阶函数；层切得越细，逼近越准。
:::

::: demo riemann-lebesgue 自己切一切：竖切与横切
选「勒贝格」时，下方的彩条画出每一层的底 $\{x: f(x)\ge y_k\}$。这个函数有两个峰，所以较高的几层的底是**两段分开的区间**——它不是一个区间，但仍然是可测集，勒贝格照样可以把它当台阶的底。
:::

## 课件原文逐句精读

::: original What changes
**Riemann–Darboux:** the lower and upper staircases are tied to finitely many interval cells. Refining $P$ must force $U(f,P)-L(f,P)$ to zero.

**Lebesgue:** a simple staircase $s=\sum_ka_k\ind_{A_k}$ may use arbitrary measurable sets $A_k$. Taking all measurable simple sets can isolate scattered or dense null behavior instead of charging the surrounding intervals.
:::

::: zh
**有什么改变**

**黎曼–达布**：上下台阶被绑定在有限个区间小格上。加细分割 $P$ 必须能把 $U(f,P)-L(f,P)$ 逼到 0。

**勒贝格**：一个简单台阶 $s=\sum_ka_k\ind_{A_k}$ 可以使用**任意**可测集 $A_k$。允许所有可测的简单函数，就能把分散的或稠密的「零测行为」**单独隔离出来**，而不必连累周围的区间。
:::

逐句讲：

- **tied to finitely many interval cells**：黎曼的台阶只能是「有限个区间 × 常数高度」。
- **Refining $P$ must force $U-L$ to zero**：黎曼可积的唯一办法是把区间切细，让上下台阶贴紧。
- **may use arbitrary measurable sets $A_k$**：勒贝格的台阶 $\sum_ka_k\ind_{A_k}$ 中，$A_k$ 可以是任何可测集——一个点、可数个点、康托尔集、有理数全体……
- **isolate scattered or dense null behavior**（老师画了下划线）：如果函数只在一个零测集上「捣乱」（比如只在有理点上等于 1），勒贝格可以用一块底为「有理数集」的台阶单独处理它，这块台阶的面积是 $1\times0=0$；而黎曼做不到，因为有理数在每个区间里都有，**每个区间小格都被连累**（charging the surrounding intervals）。

## 老师板书在说什么

::: board 板书转写
1. 两张图下方：$\ind_{[0,1]\cap\Q}$
2. 圈出：simple staircase $s=\sum_ka_k\ind_{A_k}$ 中的 $a_k$、$A_k$，以及 measurable sets $A_k$。
3. 在 isolate scattered or dense null behavior 下画线。
4. 页面底部：Lebesgue integral permits discontinuous function. $\iff$ discontinuity set is a null set.（右侧写 $\mu(N)=0$，并画箭头指回 surrounding intervals）
:::

- **第 1 行 $\ind_{[0,1]\cap\Q}$**：老师举的例子就是狄利克雷函数。它在每个区间里都在 0 和 1 之间跳，黎曼的台阶永远贴不紧；勒贝格却可以直接写成「底为 $\Q\cap[0,1]$、高为 1」的一块台阶，面积 $=1\times m(\Q\cap[0,1])=0$。完整计算在 [[p:28]]。
- **第 2 行**：圈出的三处都在强调勒贝格台阶的两个要素：**高度 $a_k$** 和 **底 $A_k$**，而且底只要求是**可测集**。
- **第 4 行**：老师总结「不连续」这件事的两种处理：
  - 勒贝格积分允许（permits）很不连续的函数，只要它可测；
  - 对黎曼积分，著名的**勒贝格判别**是：有界函数黎曼可积 $\iff$ 它的**不连续点集是零测集**（$\mu(N)=0$）。箭头指回「surrounding intervals」：不连续点只要占的「长度」为 0，就不会连累太多区间。下一页（[[p:27]]）的论证就用到这个思想。

## 例子

::: ex 例 1：同一个面积，两种切法
$f(x)=x$ 在 $[0,1]$ 上，面积 $\tfrac12$。

- **竖切（黎曼）**：分成 $n$ 格，下和 $=\sum_{j=1}^n\frac{j-1}n\cdot\frac1n=\frac{n-1}{2n}\to\frac12$。
- **横切（勒贝格）**：高度 $y_k=\tfrac kn$。第 $k$ 层的底是 $\{x: x\ge\tfrac kn\}=[\tfrac kn,1]$，长度 $1-\tfrac kn$；每层厚 $\tfrac1n$。台阶面积 $=\sum_{k=1}^{n}\frac1n\big(1-\frac kn\big)=\frac{n-1}{2n}\to\frac12$。

两种切法得到同样的极限。区别只在于：横切时每层的底由**函数值**决定，而不是由人为选定的区间决定。
:::

::: ex 例 2：水平集可以很碎
$f=\ind_{\Q\cap[0,1]}$。高度 $y=\tfrac12$ 的水平集是 $\{x: f(x)\ge\tfrac12\}=\Q\cap[0,1]$——稠密地散布在整个区间里，完全不是区间，但它可测、测度为 0。勒贝格的台阶可以直接以它为底。
:::

## 常见疑问与易错点

::: warn 问：勒贝格积分是不是就是「横着切的黎曼积分」？
**答**：思路上可以这样理解，但关键不在「横着切」本身，而在于**允许任意可测集做底**。横切只是让我们自然地遇到「底不是区间」的情况。
:::

::: warn 问：为什么说勒贝格更适合概率？
**答**：概率里的样本空间 $\Omega$ 往往根本没有「区间」这回事（比如无穷次抛硬币的所有序列）。勒贝格积分只需要「集合 + 测度」就能定义，对任何概率空间都适用；期望 $\E[X]=\int X\dd\P$ 就是这样定义的。
:::

## 小结与自测

::: sum 本页小结
- 黎曼（达布）：台阶底只能是区间小格，只能靠加细分割逼近。
- 勒贝格：台阶 $s=\sum a_k\ind_{A_k}$ 的底可以是任意可测集；按函数值横切时，每层的底是水平集 $\{f\ge y_k\}$。
- 好处：只在零测集上捣乱的函数（如狄利克雷函数）可以被单独隔离，不连累周围区间。
- 勒贝格判别：有界函数黎曼可积 ⟺ 不连续点集是零测集。
:::

::::quiz 自测
**1.** $f(x)=\sin(2\pi x)+1$ 在 $[0,1]$ 上，水平集 $\{x: f(x)\ge1.5\}$ 是一个区间还是两个区间？

:::answer
$f\ge1.5\iff\sin(2\pi x)\ge\tfrac12\iff2\pi x\in[\tfrac\pi6,\tfrac{5\pi}6]\iff x\in[\tfrac1{12},\tfrac5{12}]$，在 $[0,1]$ 上只有这一段。若问 $\{f\le0.5\}$，则是 $[\tfrac7{12},\tfrac{11}{12}]$，也是一段。（如果函数有两个峰，高处的水平集就会是两段。）
:::

**2.** 为什么黎曼方法处理 $\ind_{\Q\cap[0,1]}$ 会失败，而勒贝格可以？

:::answer
有理数在每个区间里都有，无理数也是，所以每个区间小格的上下确界都是 1 和 0，上下和永远差 1。勒贝格可以用一块以 $\Q\cap[0,1]$（零测集）为底、高为 1 的台阶精确表示这个函数，面积为 0。
:::
