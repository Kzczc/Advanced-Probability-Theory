## 这一页在讲什么

::: idea 一句话版
想知道一个集合 $E$ 有多「长」，就用**可数个区间**把它盖住，算这些区间的总长度（「覆盖成本」）；在所有盖法里取**最省**的那个值，就是 $E$ 的**外测度** $m^*(E)$。它对**每个**子集都有定义，但还不是真正的测度。
:::

上一页（[[p:17]]）看到：乔丹容量只允许**有限个**区间，结果连有理数这种「稀稀拉拉的点」都量不准（外容量是 1）。这一页把「有限个」放宽成「**可数个**」，得到勒贝格外测度。

它解决了有理数的问题（$m^*(\Q\cap[0,1])=0$），但付出了代价：外测度只满足「并集的长度 ≤ 各部分长度之和」，不保证「等于」。下一部分（[[p:20]]）要挑出那些能让「等于」成立的集合。

## 先补基础

::: basics 下确界 inf：「最省的盖法」
一组数的**下确界** $\inf$ 是「最大的下界」：不比其中任何一个数大，而且再大一点就不行。它不一定被某个数真正取到。

例：$\inf\{1,\tfrac12,\tfrac13,\dots\}=0$，但 0 不在这组数里。外测度正是这种情况：可能没有「最省的那一种盖法」，但盖法的成本可以无限逼近某个值，这个值就是 $m^*(E)$。
:::

::: basics 覆盖与区间长度
- **覆盖**：$E\subseteq\bigcup_{n=1}^\infty I_n$ 的意思是「$E$ 的每一点都至少落在某一个 $I_n$ 里」。区间之间可以重叠。
- **区间长度** $|I|$：$[a,b]$、$(a,b)$、$[a,b)$ 的长度都是 $b-a$。
- **覆盖成本**：$\sum_{n=1}^\infty|I_n|$。它是非负项级数，所以一定有值（可能是 $\infty$）。
:::

::: basics 可数个 vs 有限个
「可数个区间」指可以排成 $I_1,I_2,I_3,\dots$ 的一列（有限个也算）。关键区别：可数个区间可以**一个点一个点地跟住**可数个点，而且让它们的长度越来越小，总长仍然很小（[[p:17]] 的 $\eps/2^n$ 技巧）。
:::

## 课件原文逐句精读

::: original Definition 12 (Lebesgue outer measure)
For every $E\subseteq\R$, （公式在课堂上手写，见下方板书）
:::

::: zh
**定义 12（勒贝格外测度）** 对每个 $E\subseteq\R$，（定义式由老师在板书中写出）
:::

::: def 定义 12（勒贝格外测度）
对实数轴的**任意**子集 $E\subseteq\R$，定义

$$
m^*(E)=\inf\Big\{\sum_{n=1}^{\infty}|I_n|\ :\ E\subseteq\bigcup_{n=1}^{\infty}I_n,\ \ I_n\text{ 都是有界区间}\Big\}.
$$

也就是：在「用可数个有界区间盖住 $E$」的所有方案里，总长度的下确界。
:::

逐项解释：

- **For every $E\subseteq\R$**：对**每一个**子集都有定义，无论多奇怪。这是外测度最大的优点。
- **$\inf$**：取「所有盖法」的成本的下确界。花括号里是一大堆数，每种盖法贡献一个数。
- **$\sum_{n=1}^\infty|I_n|$**：一种盖法的总成本。区间可以重叠，重叠部分会被重复计算——所以任何盖法的成本都**不小于**「真实长度」，这就是「外」测度这个名字的由来：从外面包住，只会高估，不会低估。

::: original Outer measure is not yet a measure on 2^ℝ
The value $m^*(E)$ exists for every subset $E$, but only monotonicity and countable subadditivity are guaranteed on the full power set. Even for disjoint sets, equality need not hold. A later measurability criterion will select the domain on which $m^*$ becomes countably additive.
:::

::: zh
**外测度还不是 $2^\R$ 上的测度。** 对每个子集 $E$，$m^*(E)$ 都有定义；但在整个幂集上，只能保证**单调性**和**可数次可加性**。即使两个集合不相交，等号也不一定成立。后面的「可测性判别」会挑出一个范围，在那里 $m^*$ 才变成可数可加的。
:::

- **monotonicity（单调性）**：$A\subseteq B\Rightarrow m^*(A)\le m^*(B)$。
- **countable subadditivity（可数次可加性）**：$m^*\big(\bigcup_nA_n\big)\le\sum_nm^*(A_n)$，注意是「$\le$」。
- **Even for disjoint sets, equality need not hold**：测度要求不相交时「$=$」，外测度做不到。
- **A later measurability criterion**：就是下一部分的卡拉泰奥多里判别（[[p:20]]）。老师把这段的标题**圈了出来**，强调「外测度 ≠ 测度」。

## 老师板书在说什么

::: board 板书转写
1. 在 For 旁边：$\rightsquigarrow$ countable sets $I_n$
2. $\mu^*(E)=\inf\big\{\sum_{n=1}^\infty|I_n| : E\subseteq\bigcup_{n=1}^\infty I_n\big\}$，where $I_n$ range over bounded intervals.
3. 示意图：集合 $A$（几个点）上方盖着短线 $I_n$；集合 $B$ 下方盖着短线 $J_n$。箭头 pool（合并）$\to$ $A\cup B\subseteq(\bigcup I_n)\cup(\bigcup J_n)$（红色）
4. $\mu^*(A\cup B)\le\mu^*(A)+\mu^*(B)$（红色）
5. 下方：「$K$ cover $A\cup B$」（红线）。下面画了一串交错的点；split?（能不能拆开？）打了一个 ✗：$K\cap A$ - - -，$K\cap B$ - - -，fragmented pieces?（碎片？）
6. cannot infer $\to$ $\mu^*(A\cup B)\ge\mu^*(A)+\mu^*(B)$
:::

老师把外测度写成 $\mu^*$，印刷部分写作 $m^*$，两者是同一个东西。

### 第 1–2 行：定义

「countable sets $I_n$」提醒：这里的覆盖用的是**可数个**区间，和上一页乔丹容量的「有限个」形成对比。

### 第 3–4 行：为什么「$\le$」总成立（合并覆盖）

图的意思：$A$ 有一套盖法 $\{I_n\}$，$B$ 有一套盖法 $\{J_n\}$。把两套区间**合在一起**（pool），就盖住了 $A\cup B$：

$$
A\cup B\subseteq\Big(\bigcup_nI_n\Big)\cup\Big(\bigcup_nJ_n\Big).
$$

合并后仍是可数个区间，它的成本是 $\sum|I_n|+\sum|J_n|$。所以 $A\cup B$ 的最省成本不会超过「$A$ 的成本 + $B$ 的成本」。精确的推导见下方「推导」一节。

### 第 5–6 行：为什么「$\ge$」推不出来（拆不开覆盖）

反过来想：拿一套盖住 $A\cup B$ 的区间 $K$，能不能把它**拆成两套**，一套只盖 $A$、一套只盖 $B$，而且总长度不增加？

- 如果 $A$ 和 $B$ 离得很远（比如 $A\subseteq[0,1]$，$B\subseteq[5,6]$），可以：盖 $[0,1]$ 附近的区间归 $A$，盖 $[5,6]$ 附近的归 $B$。
- 但如果 $A$ 和 $B$ 的点**交错得很厉害**（老师画的那串交错的点），一个区间里同时有 $A$ 的点和 $B$ 的点。$K\cap A$、$K\cap B$ 都变成「碎片」（fragmented pieces），不再是区间，没法直接当作覆盖。
- 所以**推不出**（cannot infer）$\mu^*(A\cup B)\ge\mu^*(A)+\mu^*(B)$。事实上，对某些极端「交错」的集合（例如维塔利集的平移，[[p:21]]），这个不等式真的会失败。

## 例子

::: ex 例 1：单点和可数集的外测度是 0
- 单点 $\{x\}$：用区间 $[x-\eps,x+\eps]$ 盖住它，成本 $2\eps$。$\eps$ 可以任意小，所以 $m^*(\{x\})=0$。
- 有理数 $\Q\cap[0,1]=\{q_1,q_2,\dots\}$：用长度为 $\eps/2^n$ 的区间盖住 $q_n$，总成本

$$
\sum_{n=1}^{\infty}\frac{\eps}{2^n}=\eps .
$$

$\eps$ 任意小，所以 $m^*(\Q\cap[0,1])=0$。乔丹外容量却是 1（[[p:17]]）。**可数覆盖能「一个点一个点地跟住」，这就是改进所在。**
:::

::: ex 例 2：区间的外测度就是它的长度
$m^*([0,1])=1$。

- $\le 1$：它自己就是一个覆盖，成本 1。
- $\ge 1$：要证明**任何**可数覆盖的总长都 $\ge1$。直观上显然（盖住一段长度为 1 的线段，总长不可能小于 1），严格证明要用「有界闭区间的任意开覆盖都有有限子覆盖」（紧性），这里当作已知结论。

所以外测度在区间上和「长度」一致——它确实是长度的推广。
:::

::: ex 例 3：合并覆盖的具体计算
$A=[0,1]$，$B=[0.5,2]$。$A$ 用 $[0,1]$ 盖（成本 1），$B$ 用 $[0.5,2]$ 盖（成本 1.5）。合并后盖住 $A\cup B=[0,2]$，成本 $2.5$。而 $m^*(A\cup B)=2<2.5$——两套覆盖在 $[0.5,1]$ 重叠了，重叠部分被算了两次。所以一般只有「$\le$」。
:::

## 推导：一步一步来

::: proof 证明思路
单调性：「盖住大集合的方案一定盖住小集合」。次可加性：给每个 $A_k$ 选一套「几乎最省」的盖法，把它们全部合并，再用 $\eps/2^k$ 控制浪费。
:::

**性质 1（单调性）**：若 $A\subseteq B$，则 $m^*(A)\le m^*(B)$。

1. 任取一套盖住 $B$ 的区间 $\{I_n\}$。因为 $A\subseteq B\subseteq\bigcup I_n$，它也盖住 $A$。
2. 所以「盖住 $B$ 的方案」都是「盖住 $A$ 的方案」：$A$ 的候选成本集合**更大**。
3. 在更大的集合里取下确界，结果只会更小或相等（[基础补课 · 上确界与下确界](../basics.html)）。所以 $m^*(A)\le m^*(B)$。

**性质 2（可数次可加性）**：$m^*\big(\bigcup_{k=1}^\infty A_k\big)\le\sum_{k=1}^\infty m^*(A_k)$。

1. 如果右边是 $\infty$，不等式自动成立。下面设右边有限，任取 $\eps>0$。
2. 对每个 $k$，因为 $m^*(A_k)$ 是下确界，存在一套盖住 $A_k$ 的区间 $\{I_{k,n}\}_{n\ge1}$，成本比下确界多不超过 $\eps/2^k$：

$$
\sum_{n}|I_{k,n}|\le m^*(A_k)+\frac{\eps}{2^k}.
$$

3. 把所有 $I_{k,n}$（$k,n=1,2,\dots$）合并。「可数个可数集的并」仍然可数，所以这仍是一套可数覆盖，而且盖住了 $\bigcup_kA_k$。
4. 它的成本是

$$
\sum_{k}\sum_{n}|I_{k,n}|\le\sum_k\Big(m^*(A_k)+\frac{\eps}{2^k}\Big)=\sum_km^*(A_k)+\eps .
$$

5. $m^*(\bigcup A_k)$ 不超过任何一套盖法的成本，所以 $m^*(\bigcup A_k)\le\sum_km^*(A_k)+\eps$。
6. $\eps$ 任意小，令 $\eps\to0$ 即得结论。板书第 4 行是 $k=2$ 的特例。

## 常见疑问与易错点

::: warn 问：外测度对所有集合都有定义，为什么不直接拿它当「长度」？
**答**：因为它不满足可数可加性——即使 $A,B$ 不相交，也可能 $m^*(A\cup B)<m^*(A)+m^*(B)$。拿它当概率，就会出现「两个互斥事件的概率之和大于它们并的概率」这种荒谬结果。所以要先挑出「好集合」（[[p:20]]）。
:::

::: warn 问：inf 能不能换成 min？
**答**：一般不能。比如 $E=\Q\cap[0,1]$，任何具体的盖法成本都 $>0$，但下确界是 0，没有哪一种盖法恰好成本为 0。
:::

::: warn 问：区间用开的还是闭的，有影响吗？
**答**：没有。把闭区间 $[a,b]$ 换成稍大一点的开区间 $(a-\delta,b+\delta)$，成本只多 $2\delta$，再用 $\eps/2^n$ 技巧让总浪费任意小，下确界不变。
:::

## 小结与自测

::: sum 本页小结
- 外测度 $m^*(E)=\inf\{\sum_n|I_n|: E\subseteq\bigcup_nI_n\}$：用可数个区间覆盖，取最省的成本。
- 对**每个**子集都有定义；区间的外测度就是长度；可数集的外测度是 0。
- 只保证单调性和可数次可加性（「$\le$」）；合并覆盖给出「$\le$」，但覆盖可能拆不开，所以「$\ge$」推不出来。
- 外测度还不是测度，下一部分用卡拉泰奥多里判别挑出让它可加的集合。
:::

::::quiz 自测
**1.** 求 $m^*(\{1,2,3\})$ 和 $m^*(\N)$（全体自然数）。

:::answer
都是 0。有限集和可数集都可以用 $\eps/2^n$ 长度的区间逐点盖住，总成本不超过 $\eps$，$\eps$ 任意小。
:::

**2.** 判断：若 $A\cap B=\varnothing$，则 $m^*(A\cup B)=m^*(A)+m^*(B)$。

:::answer
错误。外测度只保证 $\le$。当 $A,B$ 是「好集合」（例如区间、下一部分的可测集）时等号成立，但对任意子集不保证。
:::

**3.** 为什么证明次可加性时要用 $\eps/2^k$，而不是每个都多 $\eps$？

:::answer
因为有可数无穷多个 $A_k$。如果每个都多浪费 $\eps$，总浪费是 $\eps+\eps+\cdots=\infty$；用 $\eps/2^k$，总浪费是 $\sum_k\eps/2^k=\eps$，仍然可以任意小。
:::
