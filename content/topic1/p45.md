## 这一页在讲什么

::: idea 一句话版
上一页（[[p:44]]）推到了 $2\int g\le2\int g-\limsup\int|f_n-f|$。这一页用四个「⇒」把它推到底：$\int|f_n-f|\to0$，从而 $\int f_n\to\int f$。老师写完打了「#」，DCT 证毕。
:::

这是一页没有页码的手写续页，只有四行。下面先逐行讲清每个「⇒」的理由，再把 DCT 的完整证明串成一条链，最后给出「拿到题目时怎么用 DCT」的步骤和例题。

## 先补基础

::: basics 非负数列：limsup ≤ 0 就意味着趋于 0
设 $a_n\ge0$。因为每一项都 $\ge0$，所以 $0\le\liminf a_n\le\limsup a_n$。若又有 $\limsup a_n\le0$，就被夹成
$$
0\le\liminf a_n\le\limsup a_n\le0,
$$
上下极限都等于 0，所以 $a_n\to0$。这是第 1–2 行用到的全部道理。
:::

::: basics 三角不等式（积分版，[[p:43]]）
$\left|\int h\dd\mu\right|\le\int|h|\dd\mu$。取 $h=f_n-f$，就能用 $\int|f_n-f|$ 控制 $\left|\int f_n-\int f\right|$。
:::

## 老师板书在说什么

::: board 板书转写
1. $\displaystyle\Rightarrow\ 0\le\limsup_n\int|f_n-f|\dd\mu\le0$
2. $\displaystyle\Rightarrow\ \int|f_n-f|\dd\mu\to0$
3. $\displaystyle\Rightarrow\ \Big|\int f_n-f\dd\mu\Big|\to0$
4. $\displaystyle\Rightarrow\ \int f_n\to\int f$.　　#
:::

### 第 1 行：夹出 0

- 右边的「$\le0$」来自上一页最后的不等式：$2\int g\le2\int g-\limsup_n\int|f_n-f|$，两边减去**有限数** $2\int g$ 得 $\limsup_n\int|f_n-f|\le0$。
- 左边的「$0\le$」：$\int|f_n-f|$ 是非负函数的积分，每一项都 $\ge0$，所以上极限也 $\ge0$。

### 第 2 行：上极限为 0 ⇒ 收敛到 0

数列 $a_n=\int|f_n-f|\dd\mu$ 非负、上极限为 0，由「先补基础」，$a_n\to0$。这就是 **$L^1$ 收敛**：$f_n$ 在「平均绝对误差」的意义下趋于 $f$。

### 第 3 行：积分之差的绝对值也趋于 0

板书里的 $\int f_n-f\dd\mu$ 指 $\int(f_n-f)\dd\mu$。由三角不等式，
$$
0\le\Big|\int(f_n-f)\dd\mu\Big|\le\int|f_n-f|\dd\mu\to0 ,
$$
夹逼得 $\left|\int(f_n-f)\right|\to0$。

### 第 4 行：结论

$f_n$ 和 $f$ 都可积，积分可以拆开（线性，[[p:43]]）：$\int(f_n-f)=\int f_n-\int f$。差的绝对值趋于 0，就是 $\int f_n\to\int f$。老师写「#」表示证明结束。

## 推导：一步一步来

::: proof DCT 的完整证明（[[p:44]] + 本页）
**条件**：$f_n\to f$ a.e.，$|f_n|\le g$，$\int g<\infty$。

1. $|f|\le g$ a.e. ⇒ $f\in L^1$。
2. $|f_n-f|\le|f_n|+|f|\le2g$ ⇒ $h_n:=2g-|f_n-f|\ge0$。
3. Fatou：$\int\liminf h_n\le\liminf\int h_n$。
4. 左边：$|f_n-f|\to0$ a.e. ⇒ $\liminf h_n=2g$ ⇒ 左边 $=2\int g$。
5. 右边：$\liminf\big(2\int g-\int|f_n-f|\big)=2\int g-\limsup\int|f_n-f|$。
6. 消去有限的 $2\int g$：$\limsup\int|f_n-f|\le0$。
7. 非负数列 ⇒ $\int|f_n-f|\to0$（本页第 1–2 行）。
8. $\left|\int f_n-\int f\right|\le\int|f_n-f|\to0$ ⇒ $\int f_n\to\int f$（本页第 3–4 行）。$\blacksquare$
:::

整条链的结构是「**MCT ⇒ Fatou ⇒ DCT**」：Fatou 用 MCT 证明（[[p:41]]），DCT 用 Fatou 证明（这里）。下一页的 BCT 则是 DCT 的特例（[[p:46]]）。

## 例子：拿到题目时怎么用 DCT

::: idea 三步检查清单
1. **逐点极限**：对每个（或几乎每个）$x$，算出 $f(x)=\lim_nf_n(x)$。
2. **找屋顶**：找一个**不依赖 $n$** 的 $g$，使所有 $|f_n|\le g$；常用办法是对 $n$ 取上确界 $\sup_n|f_n(x)|$，或用初等不等式放大。
3. **验证屋顶可积**：$\int g<\infty$。区间无穷时，常数通常**不**可积，要找会衰减的 $g$。

三步都通过，就可以写 $\lim\int f_n=\int\lim f_n=\int f$。
:::

::: ex 例 1：$\displaystyle\lim_{n\to\infty}\int_0^1\sqrt{x+\tfrac1n}\,\dd x$
1. 逐点：$\sqrt{x+\tfrac1n}\to\sqrt x$。
2. 屋顶：$\sqrt{x+\tfrac1n}\le\sqrt{x+1}\le\sqrt2$。
3. 常数 $\sqrt2$ 在 $[0,1]$ 上可积。

DCT ⇒ 极限 $=\int_0^1\sqrt x\dd x=\tfrac23$。验证：$\int_0^1\sqrt{x+\tfrac1n}\dd x=\tfrac23\big[(1+\tfrac1n)^{3/2}-(\tfrac1n)^{3/2}\big]\to\tfrac23$。✓
:::

::: ex 例 2：$\displaystyle\lim_{n\to\infty}\int_0^\infty\frac{\sin(x/n)}{x(1+x^2)}\cdot n\,\dd x$
1. 逐点：$n\sin(x/n)\to x$（因为 $\sin t\approx t$），所以被积函数 $\to\frac{x}{x(1+x^2)}=\frac1{1+x^2}$。
2. 屋顶：$|\sin t|\le|t|$，所以 $\left|\frac{n\sin(x/n)}{x(1+x^2)}\right|\le\frac{n\cdot x/n}{x(1+x^2)}=\frac1{1+x^2}$。
3. $\int_0^\infty\frac{\dd x}{1+x^2}=\frac\pi2<\infty$。

DCT ⇒ 极限 $=\int_0^\infty\frac{\dd x}{1+x^2}=\frac\pi2$。这类题直接算原积分很难，用 DCT 一步就出来了。
:::

::: ex 例 3（失败的检查）：$f_n=\ind_{[n,n+1]}$ 在 $\R$ 上
1. 逐点极限：每个 $x$ 最终都在 $[n,n+1]$ 左边，$f_n(x)\to0$。
2. 屋顶：要压住所有 $f_n$，至少要 $g\ge\ind_{[1,\infty)}$。
3. $\int_\R\ind_{[1,\infty)}=\infty$：**屋顶不可积**，检查不通过。

结论确实不成立：$\int f_n=1\not\to0$。方块一直「滑」向无穷远，质量没有消失，只是跑到了无穷远处。
:::

::: ex 例 4：在概率里用 DCT——期望的极限
设 $X$ 在 $(0,1)$ 上均匀分布，$X_n=X^{1/n}$。求 $\lim_n\E[X_n]$。

1. 逐点：对每个 $x\in(0,1)$，$x^{1/n}=e^{(\ln x)/n}\to e^0=1$，所以 $X_n\to1$ 几乎必然。
2. 屋顶：$0<X^{1/n}<1$，取 $g\equiv1$。
3. 概率测度总质量为 1，所以 $\E[g]=1<\infty$。

DCT ⇒ $\E[X_n]\to\E[1]=1$。验证：$\E[X^{1/n}]=\int_0^1x^{1/n}\dd x=\dfrac{1}{1+1/n}=\dfrac{n}{n+1}\to1$。✓

在概率空间上，**有界**的随机变量总能用常数当屋顶（总质量有限），这就是下一页有界收敛定理（[[p:46]]）的内容。
:::

## 拓展延伸：和作业、小测的联系

::: more DCT 的几种变形
- **另一种证法**：对 $g+f_n\ge0$ 和 $g-f_n\ge0$ 各用一次 Fatou，分别得到 $\int f\le\liminf\int f_n$ 和 $\limsup\int f_n\le\int f$，夹出 $\int f_n\to\int f$。这是[[quiz1:p:2]] 要求的写法。它少一步，但只得到积分收敛，得不到本页更强的 $\int|f_n-f|\to0$。
- **屋顶可以随 $n$ 变**：若 $|f_n|\le g_n$，$g_n\to g$ a.e.，并且 $\int g_n\to\int g<\infty$，结论照样成立。证明和本页一样，只是把 $h_n=2g-|f_n-f|$ 换成 $h_n=g_n+|f|-|f_n-f|\ge0$，消去的有限数变成 $\int g+\int|f|$。这就是[[hw1:p:10]] 的「推广的控制收敛定理」；条件 $\int g_n\to\int g$ 不能少，否则尖峰 $g_n=f_n=n\ind_{(0,1/n)}$ 就是反例。
- **屋顶本身不可积也可能成立**：若 $0\le f_n\le f$、$f_n\to f$，即使 $\int f=\infty$，也有 $\int f_n\to\int f$。这时用的是 Fatou（下界）加单调性（上界），而不是 DCT，见[[hw1:p:11]]。
- **依概率收敛的版本**：把「a.e. 收敛」换成「依概率收敛」，DCT 仍然成立（第 3 讲 [[t3:p:20]]）。
- **最弱的够用条件**：在概率空间上，比「有共同的可积屋顶」更弱、又恰好够用的条件叫**一致可积**：依概率收敛再加一致可积，等价于 $\E|X_n-X|\to0$（[[quiz2:p:2]]）。
:::

## 常见疑问与易错点

::: warn 问：DCT 的结论里，f 的可积性是假设还是结论？
**答**：是结论。我们没有事先假设 $f$ 可积，而是由 $|f|\le g$ 推出来的（[[p:44]] 第 1 步）。这一点在应用中很方便：只要验证 $f_n$ 有共同的可积屋顶，极限函数的可积性就自动成立。
:::

::: warn 问：第 1 行左边的「0 ≤」是怎么来的？好像证明里没写。
**答**：是因为 $\int|f_n-f|$ 是**非负**函数的积分，每一项都 $\ge0$，所以它的上极限也 $\ge0$。老师把它直接写进第 1 行，和右边的 $\le0$ 一起「夹出」0。
:::

::: warn 问：为什么结论里 ∫|fₙ − f| → 0 比 ∫fₙ → ∫f 更重要？
**答**：它更强（第 3 行由它推出积分收敛），而且不允许「正负抵消」（[[p:43]] 例 5 那种正负尖峰在 DCT 条件下不会出现）。概率里它意味着 $\E|X_n-X|\to0$，即平均误差趋于 0。
:::

::: warn 问：条件只要求「几乎处处」收敛、「几乎处处」有屋顶，证明里却好像当成处处成立来用了，可以吗？
**答**：可以。每个 $n$ 都有一个零测集 $N_n$，在它外面 $|f_n|\le g$；还有一个零测集 $N_0$，在它外面 $f_n\to f$。可数个零测集的并 $N=N_0\cup N_1\cup N_2\cup\cdots$ 仍是零测集（可数次可加性）。在 $N$ 外，所有条件**同时**处处成立。把所有函数在 $N$ 上改成 0，积分一个也不变（[[p:43]]），于是就回到了「处处成立」的情形。注意这里用到「可数」：如果有不可数个零测集，它们的并可能不是零测集。
:::

::: warn 问：屋顶怎么找？有没有通用办法？
**答**：最自然的候选是 $G(x)=\sup_n|f_n(x)|$——它是**最小**的屋顶。如果 $G$ 可积，DCT 就能用；如果 $G$ 不可积，任何屋顶都不可积，DCT 一定用不了（例 3、[[p:44]] 例 3），只能另想办法（例如用 Fatou 得到一个方向的不等式）。
:::

## 小结与自测

::: sum 本页小结
- 板书四步：$0\le\limsup\int|f_n-f|\le0$ ⇒ $\int|f_n-f|\to0$ ⇒ $\left|\int(f_n-f)\right|\to0$ ⇒ $\int f_n\to\int f$。
- 理由：非负数列的上极限 $\le0$ 就收敛到 0；三角不等式 $\left|\int h\right|\le\int|h|$；积分的线性。
- 用 DCT 的三步：求逐点极限 → 找不依赖 $n$ 的屋顶 → 验证屋顶可积。
- 证明链：MCT ⇒ Fatou ⇒ DCT ⇒ BCT。
:::

::::quiz 自测
**1.** 若已知 $\int|f_n-f|\to0$，能否推出 $\int|f_n|\to\int|f|$？

:::answer
能。逐点有 $\big||f_n|-|f|\big|\le|f_n-f|$（三角不等式），所以 $\left|\int|f_n|-\int|f|\right|\le\int\big||f_n|-|f|\big|\le\int|f_n-f|\to0$。
:::

**2.** 用 DCT 求 $\displaystyle\lim_{n\to\infty}\int_0^1\frac{1}{1+x^n}\dd x$。

:::answer
逐点：$0\le x<1$ 时 $x^n\to0$，被积函数 $\to1$；只有 $x=1$ 时等于 $\tfrac12$（零测集）。屋顶：$\frac1{1+x^n}\le1$，在 $[0,1]$ 上可积。DCT ⇒ 极限 $=\int_0^11\dd x=1$。
:::

**3.** 第 2 行能不能改成「$\liminf\int|f_n-f|\le0$ ⇒ $\int|f_n-f|\to0$」？

:::answer
不能。下极限为 0 只说明有一个子列趋于 0，整列可能不收敛（例如 $0,1,0,1,\dots$）。必须是**上极限** $\le0$，才能把整列夹到 0。这也是为什么证明里要把 $\liminf$ 换成 $\limsup$（[[p:44]] 第 5 步）。
:::
