## 这一页在讲什么

::: idea 一句话版
我们希望「长度」满足三条很自然的规矩：**可数可加**、**平移不变**（挪动位置长度不变）、**区间的长度是右端点减左端点**。维塔利定理说：在选择公理下，**不可能**让实数轴的**每一个**子集都有满足这三条的长度。这一页先把用来制造矛盾的「坏集合」$V$ 造出来，下一页（[[p:22]]）推出矛盾。
:::

这是整讲最关键的「为什么」：它解释了第 1 部分为什么要引入 σ-代数（[[p:9]]、[[p:10]]），为什么不能把 $2^\R$ 当事件族。也解释了上一页为什么要费力挑出「可测集」（[[p:20]]）。

## 先补基础

::: basics 平移 E + t
$E+t=\{x+t: x\in E\}$：把集合 $E$ 整体往右挪 $t$（$t<0$ 就是往左）。例：$[0,1)+0.5=[0.5,1.5)$。长度应该不随位置改变，这就是**平移不变性**。
:::

::: basics 等价关系与等价类
一种「相似」关系 $\sim$ 叫**等价关系**，如果它满足：

1. 自反：$x\sim x$；
2. 对称：$x\sim y\Rightarrow y\sim x$；
3. 传递：$x\sim y$ 且 $y\sim z\Rightarrow x\sim z$。

等价关系把集合切成互不重叠的**等价类**：每一类里的元素彼此相似，不同类之间不相似。

生活中的例子：「同一天生日」是一个等价关系，它把所有人分成 366 类。
:::

::: basics 选择公理
**选择公理**（axiom of choice）：给定一族非空集合（可以是无穷多个、甚至不可数多个），可以从**每个**集合里各挑出**一个**元素。有限个集合时这是常识；无穷多个时它是一条公理，数学界普遍接受。维塔利集就是靠它才能「造出来」——我们无法写出具体的挑选规则，只知道这样的挑法存在。
:::

## 课件原文逐句精读

::: original Theorem 15 (Vitali impossibility theorem)
Assuming the axiom of choice, there is no countably additive measure

$$
\mu:2^{\R}\longrightarrow[0,\infty]
$$

such that, for every $E\subseteq\R$, $t\in\R$, and $a<b$,

$$
\mu(E+t)=\mu(E),\qquad \mu([a,b))=b-a .
$$
:::

::: zh
**定理 15（维塔利不可能定理）** 在选择公理下，不存在定义在 $\R$ 的全部子集上、可数可加的测度 $\mu:2^\R\to[0,\infty]$，使得对每个 $E\subseteq\R$、$t\in\R$、$a<b$，都有 $\mu(E+t)=\mu(E)$ 和 $\mu([a,b))=b-a$。
:::

定理要求的三条性质，每一条都是「长度」应当有的：

| 性质 | 写法 | 人话 |
| --- | --- | --- |
| 可数可加 | 不相交时 $\mu(\bigcup E_n)=\sum\mu(E_n)$ | 拆成可数块，长度相加 |
| 平移不变 | $\mu(E+t)=\mu(E)$ | 挪位置，长度不变 |
| 区间正确 | $\mu([a,b))=b-a$ | 区间的长度就是右减左 |

再加一条「定义在**所有**子集上」（$\mu:2^\R\to\cdots$），四条放在一起就矛盾。四条里必须放弃一条，数学家选择放弃「所有子集」——只在可测集上定义长度。

### Construct a Vitali selector｜构造维塔利选择集

::: original Construct a Vitali selector
On $[0,1)$, declare

$$
x\sim y\iff x-y\in\Q .
$$

Using choice, select exactly one representative from each equivalence class and call the resulting set $V$. Put

$$
Q_0:=\Q\cap(-1,1),\qquad U:=\bigcup_{q\in Q_0}(V+q).
$$
:::

::: zh
在 $[0,1)$ 上规定：$x\sim y$ 当且仅当 $x-y$ 是有理数。用选择公理，从每个等价类里**恰好**挑出一个代表元，组成的集合叫 $V$。再令 $Q_0:=\Q\cap(-1,1)$（$-1$ 到 $1$ 之间的有理数），$U:=\bigcup_{q\in Q_0}(V+q)$（$V$ 的所有这些平移的并）。
:::

分四步看：

1. **$x\sim y\iff x-y\in\Q$ 是等价关系**：$x-x=0\in\Q$（自反）；$x-y\in\Q\Rightarrow y-x=-(x-y)\in\Q$（对称）；$x-y,\ y-z\in\Q\Rightarrow x-z=(x-y)+(y-z)\in\Q$（传递，两个有理数之和还是有理数）。
2. **等价类长什么样**：$x$ 所在的类是「和 $x$ 相差一个有理数的所有点」，即 $(x+\Q)\cap[0,1)$。例如 $0$ 的类就是 $[0,1)$ 里的全体有理数；$\tfrac{\sqrt2}{2}$ 的类是 $\{\tfrac{\sqrt2}{2}+q\}\cap[0,1)$。每一类都是**可数**的，但类的个数**不可数**。
3. **$V$：每类挑一个**：$V$ 里任何两个不同的点都不相似（差不是有理数），而 $[0,1)$ 的每个点都和 $V$ 里恰好一个点相似。挑法没有具体公式，只能靠选择公理保证存在。
4. **$Q_0$ 与 $U$**：$Q_0$ 是 $(-1,1)$ 里的有理数，**可数无穷**多个。$U$ 是把 $V$ 按每个 $q\in Q_0$ 平移后的副本全部并起来。

### Why the translates work｜为什么这些平移副本恰好有用

::: original Why the translates work
- If $v_1+q_1=v_2+q_2$, then $v_1-v_2=q_2-q_1\in\Q$. Hence $v_1\sim v_2$, so uniqueness of representatives gives $v_1=v_2$ and $q_1=q_2$. Thus the translates are pairwise disjoint.
- For $x\in[0,1)$, its representative $v\in V$ gives $q=x-v\in Q_0$, so $x\in V+q$. Since $V\subseteq[0,1)$ and $q\in(-1,1)$,

$$
[0,1)\subseteq U\subseteq[-1,2).
$$
:::

::: zh
- 若 $v_1+q_1=v_2+q_2$，则 $v_1-v_2=q_2-q_1\in\Q$，所以 $v_1\sim v_2$；代表元唯一，于是 $v_1=v_2$，进而 $q_1=q_2$。因此这些平移副本**两两不相交**。
- 对 $x\in[0,1)$，取它的代表元 $v\in V$，令 $q=x-v\in Q_0$，则 $x\in V+q$。又因为 $V\subseteq[0,1)$、$q\in(-1,1)$，所以 $[0,1)\subseteq U\subseteq[-1,2)$。
:::

**第一条（两两不交）的逐步理由**：

1. 假设两个副本 $V+q_1$ 和 $V+q_2$ 有公共点，即存在 $v_1,v_2\in V$ 使 $v_1+q_1=v_2+q_2$。
2. 移项：$v_1-v_2=q_2-q_1$，右边是两个有理数之差，是有理数。
3. 所以 $v_1\sim v_2$，它们在同一个等价类里。
4. 但 $V$ 从每类**只挑了一个**，所以 $v_1=v_2$，代回得 $q_1=q_2$——两个副本其实是同一个。
5. 结论：$q_1\ne q_2$ 时两个副本没有公共点。

**第二条（夹在两个区间之间）的逐步理由**：

- **$[0,1)\subseteq U$**：任取 $x\in[0,1)$，它的代表元 $v$ 也在 $[0,1)$ 里，差 $q=x-v$ 是有理数，而且因为两个数都在 $[0,1)$ 里，$-1<q<1$，所以 $q\in Q_0$，于是 $x=v+q\in V+q\subseteq U$。
- **$U\subseteq[-1,2)$**：$U$ 里的点形如 $v+q$，$v\in[0,1)$，$q\in(-1,1)$，所以 $-1<v+q<2$。

## 例子

::: ex 例 1：一个等价类里有哪些点
取 $x=0.3$。它的类是 $\{0.3+q: q\in\Q\}\cap[0,1)$，包括 $0.3$、$0.8$（$q=0.5$）、$0.05$（$q=-0.25$）、$0.3+\tfrac1{7}$……全都和 $0.3$ 差一个有理数。$0.3$ 和 $\tfrac{\sqrt2}{2}\approx0.707$ 不在同一类，因为 $\tfrac{\sqrt2}{2}-0.3$ 是无理数。
:::

::: ex 例 2：为什么等价类有不可数多个
每一类都可数（和可数个有理数一一对应）。如果只有可数多个类，$[0,1)$ 就是「可数个可数集的并」，从而可数——但 $[0,1)$ 不可数（[基础补课 · 可数与不可数](../basics.html)）。所以类有不可数多个，$V$ 也有不可数多个点。
:::

## 常见疑问与易错点

::: warn 问：能不能具体写出 V 里有哪些点？
**答**：不能。维塔利集的存在依赖选择公理，没有任何具体的挑选规则。这也说明：不可测集非常「病态」，日常遇到的集合（区间、开集、闭集、它们的可数并交……）都是可测的。
:::

::: warn 问：为什么用 [0,1) 而不是 [0,1]？
**答**：半开区间让长度计算最干净：$\mu([a,b))=b-a$，而且平移、拼接时端点不会重复。用闭区间也能做，只是要多处理端点。
:::

::: warn 问：定理说「没有这样的测度」，那勒贝格测度怎么办？
**答**：勒贝格测度只定义在勒贝格可测集 $\mathcal L(\R)$ 上，不是定义在全部 $2^\R$ 上，所以不和定理冲突。定理的推论是：$V$ **不是**勒贝格可测集（[[p:22]]）。
:::

## 小结与自测

::: sum 本页小结
- 维塔利定理：可数可加 + 平移不变 + 区间长度正确 + 定义在所有子集上，四者不能同时成立。
- 构造：$x\sim y\iff x-y\in\Q$；每个等价类挑一个代表元组成 $V$（需要选择公理）。
- $V$ 的可数个有理平移 $V+q$（$q\in Q_0$）两两不交，并起来夹在 $[0,1)$ 和 $[-1,2)$ 之间。
- 下一页用可数可加性推出矛盾。
:::

::::quiz 自测
**1.** 验证 $x\sim y\iff x-y\in\Q$ 满足传递性。

:::answer
若 $x-y\in\Q$ 且 $y-z\in\Q$，则 $x-z=(x-y)+(y-z)$ 是两个有理数之和，仍是有理数，所以 $x\sim z$。
:::

**2.** $0.2$ 和 $0.45$ 在同一个等价类里吗？$0.2$ 和 $\pi-3$ 呢？

:::answer
$0.45-0.2=0.25\in\Q$，在同一类。$\pi-3-0.2=\pi-3.2$ 是无理数，不在同一类。
:::

**3.** 为什么 $V+q_1$ 和 $V+q_2$（$q_1\ne q_2$）不可能有公共点？用一句话说。

:::answer
有公共点就意味着 $V$ 里有两个点相差一个有理数，即它们在同一等价类里；但 $V$ 每类只挑了一个，所以只能是同一个点，从而 $q_1=q_2$，矛盾。
:::
