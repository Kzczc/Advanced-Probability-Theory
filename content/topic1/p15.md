## 老师板书在说什么

::: board 板书转写
- 第 1 部分旁边：$(\Omega,\F,\P)$，$(S,\mathcal M,\mu)$
- 页面下方两行：
  1. Algebra $\to$ pre-measure $\to$ outer-measure $\to$ extension Thm $\to$ Lebesgue measure.
  2. Jordan measure $\to$ outer-measure $\to$ extension $\to$ Lebesgue measure,
:::

### 第 1 部分的成果：两个三元组

- $(\Omega,\F,\P)$：**概率空间**（样本空间、σ-代数、概率测度），见 [[p:12]]。
- $(S,\mathcal M,\mu)$：一般的**测度空间**（空间、σ-代数、测度），总质量可以不是 1，甚至可以是 $\infty$。
- 老师把两者并列，意思是：**概率空间只是测度空间的特例**（总质量为 1 的那种）。接下来造「长度」，造的是一般测度空间 $(\R,\mathcal L(\R),m)$。

### 两条路线：它们在说什么

两行板书讲的是同一件事的两种走法——**怎样从「区间的长度」出发，最后得到定义在很多集合上的勒贝格测度**。

| 步骤 | 第 1 行（教科书标准路线） | 第 2 行（本课走的路线） |
| --- | --- | --- |
| 起点 | **代数（algebra）**：对有限次并、补封闭的集合族，例如「有限个区间的并」 | **乔丹测度 / 容量（Jordan content）**：用有限个区间从里、从外逼近（[[p:16]]） |
| 中间 | **预测度（pre-measure）**：在代数上定义的「长度」，已满足可数可加 | —— |
| 推广到所有子集 | **外测度（outer measure）** $m^*$：用可数个区间去覆盖（[[p:18]]） | 同左 |
| 收缩到好集合 | **扩张定理（extension theorem）**：只保留满足卡拉泰奥多里条件的集合（[[p:20]]） | 同左 |
| 终点 | **勒贝格测度** | **勒贝格测度** |

::: idea 用「称重」来理解这条路
1. 先会称最简单的东西：区间 $[a,b]$ 的长度是 $b-a$。
2. 再称有限个区间拼成的形状（乔丹容量）。
3. 形状太碎（比如全体有理数）时，有限个区间不够用 → 允许**可数**个区间去覆盖，取最省的总长度（外测度）。
4. 外测度对**所有**集合都有定义，但并不总是「可加」的 → 只保留那些切开之后重量不会凭空多出来的集合（卡拉泰奥多里可测集）。
5. 在这些集合上，外测度就是一个真正的测度：勒贝格测度。
:::

## 小结与自测

::: sum 本页小结
- 第 1 部分给出了规矩：概率空间 $(\Omega,\F,\P)$ 是测度空间 $(S,\mathcal M,\mu)$ 的特例。
- 第 2、3 部分要**造出**勒贝格测度：区间长度 → 乔丹容量 → 外测度 → 限制到可测集 → 勒贝格测度。
- 老师写的两条路线终点相同，本课走的是「乔丹容量 → 外测度 → 扩张」这一条。
:::
